# 공개 저장소 경계 — `omf-mes-client`

`omf-mes` 는 비공개지만 **`omf-mes-client` 는 공개(public)다.** 이슈의 **제목 · 본문 · 첨부 · 라벨 · 수정 이력**이 전부 함께 공개된다.

**되돌릴 수 없다** — 지워도 인덱싱된 사본과 포크는 회수되지 않는다.

---

## 표

| ✅ 적어도 되는 것 | ⛔ 적으면 안 되는 것 |
| --- | --- |
| 화면 ID(`W-06-03`) · 화면 이름 · 라우트 · 컴포넌트명 | 설계·기획 문서의 **본문 복사 · 발췌 · 요약** |
| 설계 저장소 이슈 번호(`omf-mes#42`) | **이미지** — 와이어프레임 · 화면 캡처 · 워크플로우 도식 |
| 문서의 **경로와 개정일** 같은 포인터 | 고객사명 · 공장/사업장 위치 · 담당자 실명 · 조직도 |
| MES 일반 업무 용어(자재LOT · 작업지시 · 특채 승인) | 실 사번 · 품목코드 · LOT 번호 · 거래처 코드 → **합성값을 쓴다** |
| 직접 지어낸 합성 예시값 | 금액 · 수량 · 단가 · 납기 등 계약·견적 정보 |
| 계약 정본의 **오퍼레이션 존재 여부**(있다/없다) | 인프라 정보 — IP · 호스트명 · 포트 · 계정 · 접속 문자열 |

**허용되는 것은 「어디에 있는지」까지이고 「거기에 뭐라고 쓰여 있는지」는 아니다.**

```
✅ 근거: omf-mes#42
✅ 근거: 공유계약.md v0.9
⛔ 근거: 공유계약 A-4(version_no 는 화면에 노출하지 않는다)     ← 괄호가 요약이다
⛔ 근거: "○○공장 3라인의 특채 승인은 …"                        ← 본문 복사
```

## 경계선에 있는 것 — 판단이 필요한 넷

검사기가 ⚠ 로 띄우는 것들이다. **자동으로 막지 않으니 사람이 정한다.**

### 1. 요구사항 번호 (`REQ-PR-0027`)

**번호만이면 포인터다** — 허용으로 본다. 다만 「REQ-PR-0027 의심 자재 등록 관리」처럼 **제목을 붙이면 내용**이 된다. 번호만 쓰거나, 설명이 필요하면 **일반 업무 용어로 바꿔 쓴다.**

### 2. 확정 기록 마커 (`✓확정 QA #4` · `✓설계확정 결정 10`)

**우리 내부 문서 체계의 이름**이다. 프론트가 그 문서에 접근할 수 없으므로 **적어도 도움이 안 된다.**

- 필요하면 **일반 표현으로** — 「PQC 생략은 품목·공정 단위 설정이다」
- 추적이 필요하면 **이슈 번호로** — `omf-mes#64`

### 3. 공유계약 조항 번호 (`A-4` · `B-1` · `§I-11`)

**번호는 허용, 괄호 안 요약은 금지.** OpenAPI 정본에서 같은 규칙을 이미 적용했다(이슈 #92 — 조항 요약 133곳을 `x-internal-note` 로 옮겼다).

```
✅ 공유계약 B-1 을 따른다
⛔ 공유계약 B-1(낙관적 잠금 — 409 시 재로드 후 재시도)
```

### 4. 물리 모델 컬럼명 (`inventory_balance.blocked_qty`)

**계약 정본에 이미 나와 있는 필드명은 허용**한다 — 공개된 `api.d.ts` 에 들어 있다. 다만 **계약에 없는 내부 컬럼**(예: 화면에 안 나가는 감사 컬럼, 미착지라 계약에도 없는 컬럼)은 적지 않는다.

⚠ **판별이 어려우면 필드명 대신 화면 용어로 쓴다** — 「보류 수량」.

## 실수했을 때

**조용히 지우거나 수정해 덮지 않는다.**

1. **즉시 알린다** — 무엇을 언제 올렸는지
2. 공개 저장소에서는 **올린 순간 노출된 것으로 보고** 대응한다
3. 조용한 삭제는 **대응 시점만 늦춘다**

이 순서는 `uiux/CLAUDE.md` §공개 저장소 반출 경계에 이미 규정돼 있다.

## 검사 순서 — 바꾸지 않는다

```
본문 작성  →  금지어 검사  →  발행
```

**발행 후 검사가 아니다.** 2026-08-04 에 DS 저장소(`design-system-v2-webui`)에서 발행 후 검사하다 제품 용어 2건을 흘렸고(#43·#45), 즉시 수정했으나 **수정 이력에는 원문이 남았다.**

```bash
python3 .claude/skills/uiux-client-handoff/scripts/check-issue.py <초안.md>
```

## 저장소마다 기준이 다르다

우리 산출물이 흘러가는 공개 저장소가 둘이고 **기준이 한 단계 다르다.**

| 저장소 | 제품 용어·화면명·화면 ID | 나머지 금지 항목 |
| --- | :-: | :-: |
| `omf-mes-client` | ✅ **허용** — 제품 자신이라 있는 게 정상 | ⛔ 금지 |
| `design-system-v2-webui` | ⛔ **금지** — **컴포넌트의 언어로만** | ⛔ 금지 |

**이 스킬은 `omf-mes-client` 전용이다.** DS 이슈를 낼 때 이 기준을 쓰면 화면 ID 가 새어 나간다.
