### 3. 확정된 것 — 이 화면에서 더 바뀌지 않는 것

- [ ] **필드 목록** — 화면에 놓일 항목과 표시 순서
- [ ] **검증 규칙** — 필수 · 형식 · 길이 · 조건부 필수 · 짝 제약
- [ ] **예외 표시** — 오류 · 경고 · 빈 상태 · 권한 없음의 문구와 위치
- [ ] **화면 전이** — 어디서 들어오고 어디로 나가는가
- [ ] **엔드포인트 존재** — 계약 정본에 필요한 오퍼레이션이 모두 있다

```
<메서드> <경로>        <이 화면에서 무슨 일을 하나>   (<어느 계약인가>)
```

⛔ **체크했으면 위 칸을 채운다.** 프론트는 계약 정본(비공개)을 볼 수 없고, 생성 타입에는
전 경로가 들어 있어 **「이 화면 몫이 어느 것인가」는 이 통지 말고 알 길이 없다.**
⚠ 요구서 표의 **「근거」 열은 옮기지 않는다** — 조항 번호와 설계 판단이 들어 있다.
