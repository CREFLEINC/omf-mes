## 읽을 때 주의 2가지

1. **예외 E-n ≠ 회신 E-n** — 원본에는 WF 예외 카탈로그 번호와 고객 회신 대기 코드가 같은 «E+숫자» 표기로 병존한다. 편람 전체에서 「예외 E-n」/「회신 E-n」으로 구분해 표기했다.
2. **«(정합주: …)»** — 원본 내부·간 모순(갱신 누락·스테일 서술)이 있는 지점에서 최신 확정을 채택했음을 밝히는 각주다. 전건 목록은 90 정리보고 부록 참조.

## 갱신 규칙 (제안)

- 원본에 새 확정기록·버전 갱신이 생기면: 02 §7 대장에 행 추가 → 영향 절(01/04/05) 갱신 → 해당 문서 변경 이력에 기록.
- `docs/.claude/skills/doc-consistency-checklist`의 파급 지도에 본 편람을 하류로 등재하는 것을 권고한다 (90 정리보고 §5).
- **HTML 판은 생성물이다** — `04-통합-IA.md`를 고친 뒤 `python3 build-04-ia-html.py`로 재생성한다(`04-통합-IA.html`을 직접 편집하지 않는다). crefle-doc 번들(CSS·폰트 9종 base64) 임베드 단일 파일이라 별도 자산 없이 열린다. 번들 원천 = `design-system-v2-doc` `dist/crefle-doc`(lock 0.1.0), 기본 입력 = 저장소 내 동일 lock 사본 `uiux/2026-07-25-화면목록-IA/crefle-doc/`.
- **01·02·03·05의 HTML 판도 생성물이다** — 공용 스크립트 `python3 build-doc-html.py [01|02|03|05|all]`(기본 all)로 재생성한다. `build-04-ia-html.py`를 계승하되 펜스 코드블록(```→`<pre><code>`, 렌더러 미내장 고지)·수평선(`---`→`<hr>`)을 추가 지원한다. 문서별 표지 문구·KPI 수치는 스크립트 상단 `CONFIG` 딕셔너리에서 관리 — md 집계가 바뀌면 여기도 맞춰 고친다(자동 파싱 아님).
- **도식본도 생성물이다** — `python3 build-04-ia-도식본.py`. 화면·유형·행위자·신뢰도는 `04-통합-IA.md`에서 직접 파싱하므로 md 갱신만으로 자동 반영되지만, 업무 흐름 배치·IA 트리·미결/이월 상수(§7·§8 스냅샷)는 md에 없는 편집 판단이라 생성기 상단에서 별도로 고쳐야 한다. 빌드 assert(108건·프로그램·도메인·신뢰도·유형 교차·결번 12건·차집합 0)가 어긋나면 생성이 중단된다 — 통과 시에만 파일이 갱신된다. 화면 108건 커버는 두 도식(③확정도×도메인, ④IA 3모델)에 이중화돼 있다.
  - **v2.0(현재) = crefle-doc 기반** — 표지·KPI·카드·콜아웃·강조·코드는 진짜 crefle-doc 컴포넌트를 그대로 쓴다. 정체성(프로그램) 색은 새 hex 없이 crefle-doc의 categorical 토큰 `--chart-2`(웹)·`--chart-8`(POP)·`--chart-5`(모바일)를 재사용했다. crefle-doc에 없는 컴포넌트 3종(칩·프로세스 흐름 다이어그램·인라인 미터/세그먼트 바)은 토큰만으로 문서 로컬 구현하고, `CREFLEINC/design-system-v2-doc`에 정식 컴포넌트화 이슈 [#7](https://github.com/CREFLEINC/design-system-v2-doc/issues/7)·[#8](https://github.com/CREFLEINC/design-system-v2-doc/issues/8)·[#9](https://github.com/CREFLEINC/design-system-v2-doc/issues/9)를 올려 두었다.
