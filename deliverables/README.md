## 읽을 때 주의 2가지

1. **예외 E-n ≠ 회신 E-n** — 원본에는 WF 예외 카탈로그 번호와 고객 회신 대기 코드가 같은 «E+숫자» 표기로 병존한다. 편람 전체에서 「예외 E-n」/「회신 E-n」으로 구분해 표기했다.
2. **«(정합주: …)»** — 원본 내부·간 모순(갱신 누락·스테일 서술)이 있는 지점에서 최신 확정을 채택했음을 밝히는 각주다. 전건 목록은 90 정리보고 부록 참조.
