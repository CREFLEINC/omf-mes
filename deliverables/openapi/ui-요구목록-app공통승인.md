## W-06-15

| 액션 | 활성 조건 |
| --- | --- |
| 결재선 추가 | 항상 — 저장 시 유형×사업부 중복 검사(§5-3) |
| 결재선 수정 | 선택 시 |
| 사용 / 사용 안 함 | 선택 시 — ⚠ 경고 필요(§5-6) |
| 단계 추가 | 결재선 선택 시. 승인자 구분은 사용자 고정(§5-2) |
| 단계 삭제 | 단계 행 선택 시 — ⚠ 마지막 한 단계는 삭제 불가(§6) |
| 단계 순서 재배치 | 단계 ≥ 2 — G-7(Table.reorderable) |
| 승인자 선택 | 단계 행에서 — app_user 검색·선택 |
| 저장 | 변경이 있을 때만. 결재선 단위 한 트랜잭션(§5-5) |
| 결재선 삭제 | ⛔ 두지 않는다 — B-4(마스터 물리 삭제 금지). 「사용 안 함」으로 물러난다 |
| 변경 이력 | ⛔ 없다 — §I-5(audit_event 키 규약 부재) · #68 |
