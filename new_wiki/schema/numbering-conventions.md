# 번호 체계 (승계 정본)

이 저장소 전체가 참조하는 번호 체계다. 처음 쓰는 자리에서 반드시 뜻을 함께 적는다
(규칙 4, `00-authoring-rules.md`).

| 번호 | 형식 | 뜻 | 예 |
| --- | --- | --- | --- |
| **화면 번호** | `W-<도메인2자리>-<일련2자리>` | 관리웹 화면. 공통 화면은 `W-CO-NN` | `W-06-01` 공정 등록 |
| | `P-<도메인2자리>-<일련2자리>` | POP(키오스크) 화면 | `P-02-04` 작업 실적 등록 |
| | `M-<도메인2자리>-<일련2자리>` | 모바일 화면 | `M-01-02` |
| **도메인 번호** | `01`~`06` | 01 자재창고관리 · 02 생산실행 · 03 품질관리 · 04 제품출하 · 05 설비툴관리 · 06 기준정보연계 | |
| **요구사항 번호** | `REQ-<PR\|OA>-nnnn` | 고객 요구사항 원문 항목 | `REQ-PR-0021` |
| **공유계약 조항** | `<절 A~L>-<일련>[-세부]` | `new_wiki/wiki/decisions-policy/공유계약.md`(155조항·12절) | `A-10` 다형 참조 대응표, `L-3-1` 기간 경계 |
| **설계 결정** | `결정 nn` / `✓설계확정 결정 nn` | 날짜별 설계결정서·확정기록의 결정 항목 | `결정 07` |
| **확정 QA** | `✓확정 YYYY-MM-DD QA #n` | 현장검증 확정기록 문답 | `QA #25` |
| **의사결정요청서** | `DR-0nn` | 설계가 물어 사용자가 답한 것(DR-001~013) | `DR-006` |
| **예외 번호(워크플로우)** | `예외 E-n` | 업무 흐름 예외 | — |
| **회신 대기 코드** | `회신 E-n` | 고객 회신 대기 코드 | — |

⚠ **예외 `E-n` ≠ 회신 `E-n`** — 같은 표기가 두 갈래로 병존한다. 반드시 "예외 E-n" · "회신
E-n"으로 갈라 적는다(`deliverables/README.md` 원문 경고).

| 신뢰도·마커 | 뜻 |
| --- | --- |
| `[가설]` | 근거 없는 판단 |
| `(확인 필요)` | 검증 필요 |
| `«(정합주: …)»` | 원본끼리 어긋난 지점에서 최신 확정을 채택했음을 밝히는 각주 |
| `[미착지]` | 모델에 담을 컬럼이 아직 없어 별도 처리 중인 필드 |
