## §1. 확정 사항 (#1~#8)

### #1 발행 권한·승인 — U8 긴급 축 종결

긴급 W/O 발행은 **허가된 권한 보유자만** 할 수 있고, **별도의 추가 승인 없이 즉시 실행 가능**하다(승인 워크플로우 없음 — 권한으로 통제하고 절차는 두지 않는다).

- 파생: 권한 유형·범위 정의 목록(REQ-PR-0015 · D1 고객 액션)에 **'긴급 W/O 발행 권한'** 항목 등재 필요.
- 범위 주의: 이번 확정은 **긴급 W/O에 한정** — 개발품 W/O 승인 주체(U8의 나머지 축)는 잔여(§3).

### #2 전개 절차 — 발행자 직접 수행, 무배정 유지

긴급 W/O의 전개는 발행자가 직접 수행한다: **제품 선택 → 생산량 선택 → 공정&BOM 확인(시스템 자동 전개) → W/O 확정·배포**.

- 공정&BOM은 제품·생산량 선택 시 자동 전개(Routing 존재 시). **Routing 미등록 품목은 일반 경로와 동일하게 BOM 기반 fallback(REQ-PR-0026) 적용**.
- **4M 배정 단계 없음** — 무배정 투입 유지(✓설계확정 2026-07-06 결정 04 재확인: 투입→배정 참조 null). 배정이 없으므로 **배정 Validation도 없음**.
- 해석 확정: "어떤 4M을 사용하는지 계획은 있다"의 의미 = 배정이 아니라 **공정&BOM·기준정보(설비-금형-품목 적합성) 기반으로 정합 확인이 가능하다**는 뜻.

### #3 점검 통제 우회 — 유지

작업 전 점검 통제의 긴급 W/O 우회 허용(✓확정 2026-07-04 QA #9)은 **그대로 유지**한다. 우회 발생 이력의 기록 여부(U2)는 미정 잔여(§3).

### #4 자재 조달 — U9 종결: 출고요청 과정 없음·기출고 재고 사용

긴급 W/O는 **출고요청 과정이 없다** — 출고요청 자동 발행(REQ-PR-0022) 대상에서 **W/O 유형=긴급 제외**.

- 생산에 필요한 자재는 **생산 현장 기출고 재고**(생산창고·라인사이드 — 다른 생산계획 목적으로 가져왔거나 여분으로 출고받은 분 포함)를 사용한다.
- 추가 자재가 필요하면 **신규 기능 「추가 자재 출고 요청」(#7)** 으로 자재창고 **정식 출고 절차를 경유**한다.
- **긴급 W/O라 해도 정식 출고 요청·절차 없이 창고에서 자재를 반출할 수 없다.**
- 차감 지점 신설 불요 — 창고 재고 차감=출고 시점(기존 01 S7/01-S-E 그대로), 라인 재고 차감=투입 스캔(기존 — 실적 3원·genealogy 정상 동일, QA #26 연계). 모든 수불이 기존 기록 지점 안에 남는다.

### #5 교차 투입 (신규 개념)

**타 W/O 목적으로 출고된(귀속) 자재라도 BOM 품목 정합이 맞으면 긴급 W/O에 투입해 사용할 수 있다.**

- 파생 규칙: 긴급 W/O가 소비해 원 W/O에 결품이 생기면 동일한 「추가 자재 출고 요청」으로 보충한다 — 출고요청 사유 기록('긴급 W/O 대응')으로 소비 원인 추적 가능.

### #6 오투입 검증 판정 기준 — 명문화

오투입 Validation의 판정 기준은 **BOM 품목 정합(정상·긴급 공통)** 이다. 출고 귀속(어느 W/O 앞으로 출고된 자재인지)은 판정 기준이 **아니다** — #5 교차 투입의 시스템적 근거.

- U1(검증 NG 시 차단 vs 강행)은 별개 잔여(§3).

### #7 신규 기능 요구 2건

1. **「추가 자재 출고 요청」** — W/O 생성 시 자동 발행(REQ-PR-0022)과 별개인 **수동 출고요청** 기능. 출고 이후 절차는 01 도메인 정식 출고 경로(01-S-E) 공용.
2. **출고요청 사유 필드** — 코드형, **'긴급 W/O 대응'** 항목 포함. 긴급 W/O와의 참조(FK) 연결은 두지 않는다 — 실투입 추적은 genealogy가 커버.

### #8 출고요청 자동 발행 예외 조건

REQ-PR-0022 자동 발행 트리거(W/O 생성 완료 → 출고요청서 자동 발행)에 **W/O 유형=긴급 제외** 조건을 병기한다.
