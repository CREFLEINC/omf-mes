# 02 생산실행 — 5단계 검증

> 작성일: 2026-08-11 · 선행: `04-OpenAPI작성.md`
> **산출물**: `deliverables/06-API-요구서-02생산실행.md` (**화면 소절 20** + 집계 1 · 액션 **103**)

## 1. 두 축으로 본다

| 축 | 무엇 | 누가 |
| --- | --- | :-: |
| **커버리지** | 화면의 액션이 요구서에 다 있는가 | **검사기** |
| ⭐ **적합성** | **이 API 로 이 화면을 그릴 수 있는가** | **사람** |

⚠ **커버리지 ✅ 가 적합성 ✅ 가 아니다** — 검사기는 **구조**를 보고, 「그릴 수 있나」는 **사람이 본다**.

## 2. 커버리지 — 통과

```
verify-ui-coverage.py    --domain 02   화면 14 · 액션 83
verify-mapping-coverage.py --domain 02   ✅ 전건 다뤘습니다
check-structure.py · check-public-safe.py · 단위 테스트 23   ✅
```

### 2-1. ⛔ **계수를 고쳤다 — 99가 아니라 103이다**

**2단계가 「본문 도출 16」이라 적었는데 추정이었다.** 5단계에서 소절을 만들며 **열거하니 20**이었다.

| 화면 | 본문 도출 |
| --- | :-: |
| `P-02-03` 자재 투입 | 5 |
| `P-02-06` 생산LOT 완료 | 3 |
| `P-02-08` 포장 | 3 |
| `P-02-10` 작업 중단 | 4 |
| `P-02-11` 러닝체인지 | 2 |
| `P-02-12` 긴급 W/O | 3 |
| **계** | **20** |

**액션 103 = 표 83 + 본문 20.** ⛔ **세어 보기 전에 수를 적지 않는다.**

⚠ **이 트랙에서 계수를 세 번 고쳤다** — 테이블 23→22 · 분류표 겹침 2 · **이번**. **추정을 수처럼 적은 것이 원인**이다.

## 3. ⭐ 적합성 — **「그릴 수 있나」를 화면별로 물었다**

### 3-1. ✅ 그릴 수 있다 — **17장**

**아래 §3-2·§3-4 의 셋**(`W-02-07`·`P-02-12`·`P-02-02`)**을 뺀 전부.** 목록·상세·저장·상태 전이가 다 있다.

⚠ **「그릴 수 있다 17」과 「통지 가능 15」는 다른 것을 센다** — `W-02-04`·`W-02-06` 은 **그려지지만 통지는 못 낸다**(누르면 무엇이 일어나는지 못 적는다 · §3-3).

### 3-2. ⛔ **그릴 수 없다 — `W-02-07` 긴급 W/O 발행**

```
POST /production/work-orders   →  501
```

**P/O `NOT NULL` 체인**(#76)에 막혀 **P/O 없는 W/O 를 만들 수 없다.** ⛔ **계약이 우회하지 않았다** — 501 을 그대로 뒀다.

⚠ **`P-02-12`(긴급 W/O 현장 투입)도 함께 막힌다** — 발행이 안 되면 **목록이 빈다.**

→ **착수 통지 불가 2장**

### 3-3. ⚠ **그릴 수 있으나 반쪽 — `W-02-06` P/O 변경 확인**

「반영 / 강행」은 `:acknowledge` 로 선다. ⛔ **「중단·취소」 판정이 `:cancel` 로 이어지는데 그 부수 효과를 계약이 못 적는다**(**DR-007** 대기).

⭐ **화면은 그려진다** — 버튼은 있고 누르면 상태가 바뀐다. **다만 「누르면 선발행 LOT 이 어떻게 되는지」를 말할 수 없다.**

→ **착수 통지 불가 2장** — `W-02-06` 과 **`W-02-04`**(선발행을 만드는 쪽이라 같은 미결에 걸린다)

### 3-4. ⚠ **남의 계약에 기대는 화면 5장**

| 화면 | 무엇을 남에게 | 상태 |
| --- | --- | :-: |
| `W-02-10` 추가 자재 출고 요청 | **01 계약이 전부** 받는다 | ✅ 있다 |
| `P-02-06` 생산LOT 완료 | **01** `POST /trace/lots/{id}:complete` | ✅ |
| `P-02-08` 포장 | **01** `handling-units` | ✅ |
| `P-02-02` 작업 전 점검 | ⛔ **05 계약** — 점검 이력 조회 | ⛔ **없다**(#67 대기) |
| `M-02-01`·`M-02-02` LOT 스캔 | **01** `GET /trace/lots` | ✅ |

⛔ **`P-02-02` 는 「다시 확인」 버튼이 부를 곳이 없다** — 05 계약이 아직 없다.

→ **착수 통지 불가 1장**

### 3-5. ⭐ 적합성이 **계약을 한 번 고치게 했다**

`W-02-03` 의 「**경고 확인 체크**」를 그리려니 **무엇이 경고이고 무엇이 차단인지 API 가 말해 주지 않았다.** `ErrorItem` 에는 등급 축이 없었다.

→ **`ValidationFinding.severity`(`BLOCK`/`WARN`) 신설.** ⭐ **「그릴 수 있나」를 물었기 때문에 나왔다.**

## 3-6. ⭐⭐ 역방향도 봤다 — **계약이 화면보다 넓었다**

**§3 은 「화면 → API」 한 방향이다.** 반대로 보니 **12경로가 아무 화면에도 안 걸렸다.**

| 갈래 | 수 | 판단 |
| --- | :-: | --- |
| 상세 GET | 5 | ✅ **둔다** — 목록에서 행을 누르면 필요하다 |
| 세션 부속(`workers`·`:leave`·`events`) | 4 | ⚠ **`events` 는 둔다** · **`workers` 2 는 부르는 화면을 못 짚었다** |
| `:cancel` · `:correct` | 2 | ⏳ **미결 대기**(DR-007 · #61) |
| ⛔ **`material-losses`** | **2** | ⛔⛔ **뺐다** |

### ⛔⛔ `material-losses` 를 계약에서 뺐다

`production.material_loss` 는 **실재하지만 부르는 화면이 0건**이다. ⭐ **`P-02-04` 의 「손실」은 `production_result.scrap_qty` 로 들어간다**(**R48** 3원 ↔ 5컬럼 · **#60**).

⛔ **「테이블이 있으니 경로를 만든다」는 01 정정 #2(테이블이 아니라 버튼을 센다)를 되돌리는 것**이다. **1단계가 「라. 업무 문서 8」에 넣을 때 화면 근거를 안 봤다.**

**계약이 경로 32 → 30 · 스키마 44 → 42 로 줄었다.** ⭐ **계약이 줄어든 첫 사례다.**

### ⚠ 남은 하나 — **교대 중 작업자 변경 화면이 없다**

`work-sessions/{id}/workers` 를 부를 화면이 없다. `P-02-01` 은 **시작 시점만** 다룬다. **계약은 둔다**(3단계가 「작업 중 사람이 바뀐다」로 근거를 댔다) — **화면 인벤토리 건으로 넘긴다.**

## 4. 화면이 요구했는데 **계약이 안 준 것 — 0건**

전수로 봤다. **액션 103건 중 「API 없음」으로 적은 것은 셋뿐이고 셋 다 이유가 있다.**

| 액션 | 왜 없나 |
| --- | --- |
| `W-02-01` 편집 | ⛔ **수신본은 고치지 않는다** — 연계 수신 잠금(#65) |
| `W-02-04`·`P-02-04` 취소 | **입력 화면을 닫는 것**이지 상태 전이가 아니다 |
| 키패드·＋10·자동 갱신·탭 전환 | **화면 안에서 끝난다** |

## 5. ⛔ 착수 통지 — **낼 수 있는 화면 15 / 못 내는 화면 5**

| 못 내는 화면 | 왜 |
| --- | --- |
| `W-02-07` 긴급 W/O 발행 | **#76** — 501 |
| `P-02-12` 긴급 W/O 현장 투입 | 동상 — 목록이 빈다 |
| `W-02-04` W/O 확정·배포·선발행 · `W-02-06` P/O 변경 확인 | **DR-007** — 취소 시 선발행 LOT 회수 규칙 미정 |
| `P-02-02` 작업 전 점검 이력 확인 | **05 계약 없음**(#67 대기) |

⛔⛔ **초안이 「못 내는 화면 4」라 적었다 — 화면은 5장이다.**

`W-02-04`·`W-02-06` 이 **같은 미결(DR-007) 하나**에 걸리는 것은 맞지만, **막히는 것은 미결이 아니라 화면**이다.

| 세는 것 | 값 |
| --- | :-: |
| **막히는 화면** | **5** |
| 막는 미결 | 4가지(#76 · DR-007 · 05 계약 부재 … #76 이 2장을 막는다) |
| **통지 가능 화면** | **20 − 5 = 15** |

⚠ **「미결 수」와 「화면 수」를 섞었다** — 이 트랙에서 **계수를 네 번째 고친다.**

⛔ **15장도 지금 내지 않는다** — 6단계에서 하네스로 발행한다.
