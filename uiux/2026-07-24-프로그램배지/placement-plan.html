목적

고객 협의용 v2 도식(페이지 219:4509)에 각 작업 지점에서 사용자가 어떤 프로그램을 쓰는지 배지로 표시한다. 프로그램 3종(결정 16 — React 코드 1벌·셸 3종): 관리웹(브라우저·사무 PC) / POP(Electron·산업용 패널 PC) / 모바일(Capacitor Android+무선 스캐너).

사용자 확정 표기 정책 (2026-07-24)

  1. 미정 지점 = 회색 점선 ? 배지로 표시 (생략하지 않음 — 고객 협의 유도).
  2. IQC·OQC 검사 결과 입력 = 관리웹 (결정 16 '오프라인 금지 작업(판정)=관리웹 온라인 전제' 해석 우선). PQC만 결정 12로 POP 확정.
  3. ERP 화면 소관 지점(06 품목·BOM 등록 등) = 배지 없음 (MES 3종 배지만 운용).
  4. 03 상태 전이도 = 판정 지점 4곳에 배지 부착 (의심자재등록·검사 판정·보류·Release — 전부 관리웹).

배지 표기 스펙 (범례 등재 필요)

  • 형태: 라운드 사각 칩(모서리 반경 8), 높이 40px, 폭 40~88px(라벨 맞춤). 대상 노드(작업자 User 또는 행위 노드)의 우상단 모서리에 8~12px 오버랩 부착. 한 노드에 2개 이상이면 가로 스택(간격 4px).
  • 색+라벨 이중 부호화: 관리웹=파랑(#2F6FED)·흰 글자 「웹」 / POP=주황(#F2994A)·흰 글자 「POP」 / 모바일=초록(#27AE60)·흰 글자 「모바일」 / 미정=회색(#9AA0A6)·점선 테두리·「?」.
  • 범례 추가: 00.범례(v2 219:4610)에 칩 4종 1줄 + 주석 스티키 1장: 「배지 = 사용 프로그램(폼팩터 3종, 결정 16). 기존 Mobile/Desktop 아이콘은 행위 유형(스캔·입력/화면 조작) 표기로 폼팩터가 아님 — 예: 사번입력은 Mobile 아이콘이지만 프로그램은 POP」.
  • FigJam 구현: SHAPE_WITH_TEXT(ROUNDED_RECTANGLE) 신규 생성 허용(클론 킷에 동형 소스 없음 — 배지는 기존 문법과 구분되는 신규 표기 계층이므로 clone-not-draw 원칙의 예외, 범례에 등재해 정당화).
