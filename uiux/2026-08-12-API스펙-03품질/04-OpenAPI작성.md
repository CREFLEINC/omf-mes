## 1. 규모

```
경로 17 · 오퍼레이션 20 · 스키마 27 · :동사 경로 2 · 83KB
검사기 2종 전건 통과 — check-structure · check-public-safe(description 194개)
```

| | 06 기준정보 | 01 자재창고 | 공통 | 02 생산실행 | **03 품질** |
| --- | :-: | :-: | :-: | :-: | :-: |
| 경로 | 78 | 63 | 15 | 30 | **17** |
| 오퍼레이션 | 116 | 85 | 19 | 42 | **20** |
| 스키마 | 107 | 105 | 27 | 42 | **27** |
| `:동사` | — | — | — | 11 | **2** |

⭐ **가장 작다.** 화면 7장인데 경로 17 — **남의 계약을 많이 쓴다**(06 마스터 · 01 LOT · 공통 승인 · 04 부적합).

### 1-1. ⭐ 2단계가 센 것과 **정확히 같다**

```
2단계 예측   경로 17 · 오퍼레이션 20 · :동사 2
파일 실측    경로 17 · 오퍼레이션 20 · :동사 2
```

⚠ **02 는 여기서 어긋났다** — 「2단계 목록 10 → 파일 11」이었고, 그 차이가 `:validate` 삭제와 `:leave`·`:correct` 신설이었다. **03 은 2단계에서 「만들지 않을 것 셋」을 먼저 정해 두어 어긋나지 않았다.**

### 1-2. ⭐ 검사기가 센 수와 내가 센 수를 **대조했다**

```
생성기 출력   경로 17 · 오퍼레이션 20
검사기 출력   경로 17 · 오퍼레이션 20      ✅ 같다
```

⚠ **02 는 여기서 검사기 구멍을 찾았다**(내 45 ↔ 검사기 43 = PATCH 2건). **이번엔 맞는다** — `WRITE_METHODS` 에 `patch` 가 들어간 뒤라 구멍이 없고, **03 은 PATCH 를 0건 쓴다**(규약).

## 2. 자체 감사 — **쓰기 5건 전수**

| 오퍼레이션 | 멱등키 | If-Match | 응답 |
| --- | :-: | --- | --- |
| `POST /quality/inspection-results` | ✅ | ⭐ **Optional**(C-9) | 201 · **202** · 400 · 403 · 409 |
| `PUT …/{id}` | ✅ | required | 200 · 400 · 403 · 404 · 409 |
| `POST …/{id}:confirm` | ✅ | required | 200 · 400 · 403 · 404 · 409 |

```
PATCH            0건   ✅ 규약

202 를 가진 것    1건   — 오프라인 대상이 하나뿐이라 맞다(3단계 §1)
```

## 3. ⭐⭐ 재현을 **지우고 다시 만들어** 확인했다

⛔ **02 가 한 번 속았다** — 조립부가 빠진 생성기인데 앞서 만든 JSON 이 남아 있어 검사기가 통과했다.

```
rm quality-03품질.json && python3 build-03-openapi.py
  → 1차 sha256  4e047f96…
  → 2차 sha256  4e047f96…     ✅ 같다
```

⭐ **처음부터 `rm` 후 생성으로 만들었고, 두 번 더 지워 재생성해 해시가 같음을 확인했다.**

## 4. ⭐ 헤더 잠금이 **성립하지 않는 오퍼레이션**이 처음 나왔다

`POST /quality/lot-holds` 는 **여러 LOT 을 한 트랜잭션으로 건다**(`W-03-03` §5-3). **토큰이 여럿이라 `If-Match` 헤더 한 칸에 담을 수 없다.**

```json
"LotVersionRef": { "lotId": 1001, "versionNo": 3 }
"LotHoldCreate": { "lots": [ LotVersionRef … ], … }
```

⚠ **하나라도 어긋나면 전체를 거부하고 어느 LOT 인지 문구에 담는다** — `ConflictResponse.conflictingLotId`.

⭐ **이것이 B-1 의 첫 예외 형태다** — 계약이 「헤더로 못 한다」를 스키마로 말한다. `x-internal-note` 에 사유를 적었다.

## 5. `ConflictResponse` 를 **도메인에 맞게 바꿨다**

02 를 그대로 베끼지 않았다.

| 02 | **03** |
| --- | --- |
| `OPEN_SESSION_EXISTS` | ⛔ 뺐다 — 열린 세션 개념이 없다 |
| `BATCH_DEPENDENCY_FAILED` | ⛔ 뺐다 — 큐 묶음이 없다(오프라인 1건 · 단발) |
| — | ⭐ **`DUPLICATE_HOLD`** — 해제되지 않은 전량 보류가 이미 있다 |
| — | ⭐ **`HOLD_QTY_EXCEEDED`** — 부분 보류 합계가 보유를 넘는다 |

⭐ **`W-03-03` §5-5 가 「⛔ 중복 보류 제약이 없다 — 화면이 진다」로 물러났던 것을 계약이 되찾았다.** 서버가 판정하고 화면은 문구만 보인다(**A-9 ⓑ**).

## 6. 계약이 **드러낸** 미해소 다섯 — 우회하지 않았다

⛔ **02 가 `#76` 을 501 로 남긴 것과 같게 간다.**

| 무엇 | 계약에 |
| --- | --- |
| ⛔ **Lot Status 변경이력 테이블 0건** | `GET /quality/lot-holds` 의 `x-internal-note` 에 **「전이 9건 중 5건 소실 · 2건 반쪽」**과 #64·#68 선후를 적었다. **없는 이력을 있는 척 내리지 않는다** |
| ⛔ **`lot_hold` 해제 사유 코드 부재** | `LotHoldRelease.remarks` 의 description 에 **「자유 텍스트로 물러난다 · 재판정으로 풀린 건을 셀 수 없다」**(#87 7번째) |
| ⛔ **`defect_record.work_order_id` NOT NULL** | 프로퍼티 description 에 **「W/O 없는 클레임 불량이 들어오지 못한다」** · `sourceAxisCode` 가 **5축 중 3축만** 낸다 |
| ⛔ **수리 실행 기록 테이블 부재(#83)** | `sourceAxisCode` 설명에 명시 |
| ⚠ **결정 12 N:M 미착지** | ⭐ **`DefectDistributionNode.duplicateRisk`** — 중복 계상 위험을 **응답이 실어 나른다** |

⭐ **마지막 것이 새롭다** — 앞 트랙들은 미해소를 `x-internal-note`(내부)에만 적었는데, **여기서는 응답 필드로 올렸다.** 화면이 경고를 **상시** 보여야 하기 때문이다(`W-03-05` §5-5 — 「분포를 보고 개선 대상을 정하는 화면이라 왜곡이 곧 잘못된 판단이 된다」).

## 7. ⭐ 05 계약 없이 **교정 만료를 낸다**

```
InspectionMeasurement.calibrationExpiredAtMeasurement : boolean   ← 서버가 판정
InspectionSummary.calibrationExpiredCount             : integer
?calibrationExpired = only | exclude                              ← 분리 조회
```

⛔ **기본은 섞어서 낸다** — 자동 제외하지 않는다(정책 미정 · 예외 E-9 ①). **L-8**(판정 불가 ≠ 정상)의 계약 판이다.

⭐ **화면이 두 계약을 조인하지 않는다** — 03 이 05 의 테이블을 읽어 **판정만** 하고 경로는 05 가 나중에 낸다(**L-2**).

## 8. 「만들지 않은 것」을 계약이 **말한다**

⛔ **조용히 빼지 않았다** — 안 적으면 04·05 트랙이 **같은 경로를 또 만든다**.

| 안 만든 것 | `x-internal-note` 가 적은 것 |
| --- | --- |
| `POST /quality/inspection-requests` | 「버튼 0건 · 서버가 입고·생산 실적에서 만든다 · 기준 NOT NULL 이라 기준 없으면 의뢰가 없다」 |
| `POST /quality/defect-records` | ⭐ 「**04 트랙이 POST 를 더할 때 새 경로를 만들지 말고 이 경로에 얹는다**」 |
| `POST /quality/concessions` | 「요청을 만드는 화면 미정 · 부적합(04)이 선행」 |
| 조건 수정 | 「결재는 예/아니오다(**J-10**) · 반려 사유로 돌려보낸다」 |

⭐ **역방향 ② 검사기가 이 약속을 지키게 한다**(`부록-역방향2-발견.md`).
