## 2. ⛔⛔ 진도를 두 판 동안 하나 많게 셌다 — **결번을 안 걸렀다**

| | 셌던 값 | 실제 |
| --- | :-: | :-: |
| 14차 | 106 | **105** |
| 15차 | 108 | **107** |

**파일 이름이 `[WPM]-NN-NN` 으로 시작하는 `.md` 를 셌는데, 그중 `W-06-13`(검사정책 설정)은 결번**이다 — v1.5 에서 `W-06-02` 로 **통합·폐지**됐고 1차에 쓴 스펙 파일만 남아 있다.

⭐ **세는 방법을 바꿨다** — 파일 목록이 아니라 **도식본 생성기의 `BY`(현행 115)·`VACATED`(결번 12)** 를 기준으로 센다. **그 둘은 검사기가 매번 검증**한다(`결번 12건 아님` 이면 die).

```python
spec = importlib.util.spec_from_file_location("gen", "build-04-ia-도식본.py")
...  set(m.BY) - 작성분        # 결번이 섞이지 않는다
```

⚠ **「실물을 센다」로 바꾼 것만으로는 부족했다**(11차 대책) — 실물을 셌지만 **폐지된 것을 걸러야 한다는 것**을 몰랐다. **세 번째 계수 오류**다.

| 화면 | 결정이 뺀 것 | 남은 것 |
| --- | --- | --- |

⭐ **화면이 작은 것이 설계 부실이 아니다** → **G-24 신설**(만들지 않기로 한 것을 목록으로 적는다 — **빠뜨린 것과 뺀 것을 구분**한다).

⚠ **의사결정 요청서 양식이 먼저 한 것**이다(DR-002 「확정하지 않은 것 — 두지 않기로 한 셋」) — **스펙이 이어받았다.**

### 3-1. ⭐ 「같은 이름의 규칙」이 실제로 같은지 봤다

DR-002 가 「**직전 비밀번호 재사용 금지**」를 뺐다. 「**현재와 같은 값 막기**」는 이름이 비슷하나 다르다.

| | 뺀 것 | 남긴 것 |
| --- | --- | --- |
| 무엇 | 직전 N개와 비교 | **지금 값**과 비교 |
| 필요한 것 | ⛔ **비밀번호 이력 테이블** | ✅ **없다** |

⭐ **뺀 이유가 「이력 저장이 필요해진다」였으므로** 이력이 필요 없는 쪽은 **뺀 범위에 들지 않는다.** ⚠ **확정을 좁게도 넓게도 읽지 않는다 — 뺀 이유를 보면 경계가 나온다.**

## 7. DS — 신규 갭 0건 (16차 연속)

- ⚠ **`AppShell` 을 쓰지 않는 유일한 관리웹 화면**(`W-CO-01` — 로그인 전에는 탐색이 없다)
- ⚠ **`Badge` 가 DS 에 없다** → 🔔 배지는 `Chip`(`c`). **한 곳이라 `d` 로 안 올린다**
- ⛔ **비밀번호 강도 표시기를 만들지 않는다** — 조합 규칙이 없어 **평가 기준이 없다**
- ⭐ **`MatrixGrid` 안 쓴다**(수신자 축이 3종이라 한 축으로 못 편다) — ⚠ **다섯 차수 연속** 「겉모습이 같다고 같은 갭이 아니다」
- **G-10 22곳**

⭐ **조항 인용 검사기가 16차 스펙에서 전건 성립** — 실재하지 않는 조항 0 · 글로스 불일치 0 · 표기 충돌 0.
