## 0. 도메인 적용 노트 (03에만 적용한 판단 규약)

1. **03은 상태 기계다.** 39행 중 상태 7·전이 16 = 23행이 상태·커넥터다. §2대로 상태 = `화면없음:상태값`, 전이 = `화면없음:전이`가 기본이다.
2. **판정 지점 4곳은 행위로 취급했다** — 배지 정본 정책 4가 「03 전이도 = 판정 지점 4곳에 배지 부착(의심자재등록·검사 판정·보류·Release — 전부 관리웹)」으로 못박았기 때문이다. 이 4곳에만 그룹을 만들었다(G-03-01~04).
3. **03에서는 S1·S2가 아무 경계도 가르지 못한다.** 배지 4개가 **전부 「웹」**이고(S2 무력), 대장에 **User 노드가 0개**다(S1 무력, 총괄 §2 집계 「03 사람 0」). 따라서 4개 판정 지점 사이의 경계는 **전적으로 S4(관리웹 메뉴 독립 항목 여부)·묶기 ③④**에 의존하며, 규칙 §3-4 판정 원칙(「S3·S4나 묶기 ③④가 개입한 경계 → 무조건 보류」)에 따라 **네 그룹 모두 보류**다. 그룹의 *존재*(관리웹 판정 화면이 있다)는 정본 정책 4로 확정이고, **분해 단위가 보류**다.
4. **미확정 3상태**(한도승인·특채·폐기)는 승인 주체·매체가 관리웹으로 확정(#11 #9)됐으나 캔버스에서 별표·무배선이라 배지 앵커가 없다 → 처분은 상태 기본값으로 두고 **보류**로 표시했다.
5. **행위 3행은 전부 경계 참조 카드다.** 03의 행위 분류는 File 유형에서 기계 파생된 것이고 실체는 타 도메인(01·02) 경계 DOC다. 처분은 `화면없음:섹션인계`로 두되 **계상 주체가 갈리므로 보류**로 표시했다.
