# 05 설비·툴 — 5단계 검증

## 1. 커버리지 — **액션 86 전건**

```
python3 deliverables/verify-ui-coverage.py --domain 05      화면 17 · 액션 86
python3 deliverables/verify-mapping-coverage.py --domain 05  ✅ 전건 다뤘습니다
```

⭐ **본문 도출이 0건이다.** 03 은 8건, 02 는 7장이 액션 표 없이 본문에서 읽혔는데 05 는 **착수 전에 세 장의 액션 표를 새로 써서** 전부 기계 검산 대상이 됐다.

⭐ **막힌 액션이 0건이다.** 「없음」 다섯은 전부 「없는 것이 정상」이고 **선행 미결도 미착지도 없다** — 물리 모델을 기다리지 않고 계약을 먼저 세웠기 때문이다.

## 2. ⛔ 게이트를 먼저 정직하게 만들었다

`--domain 05` 가 검사기에 없었다. **등록만 하고 요구서를 나중에 쓰면 게이트가 추적 역추적을 뱉는다** — 「아직 안 썼다」와 「깨졌다」는 다르다. 검사기가 그것을 가르게 고쳤다.

```
05 — ⛔ 요구서 가 아직 없다: deliverables/06-API-요구서-05설비툴.md
   → 요구서를 먼저 쓴다. 게이트는 그때까지 빨간 채로 둔다.
```

⭐ **요구서를 쓰기 전 하루 동안 이 상태로 두었다.** 초록을 먼저 만들고 문서를 나중에 쓰면 그 사이 아무도 결손을 못 본다.

## 3. ⭐⭐ 적합성이 계약을 **여섯 자리 키웠다**

「이 계약으로 이 화면을 그릴 수 있는가」를 17화면에 대해 되짚었다. **여섯에서 「못 그린다」가 나왔다.**

| # | 무엇이 없었나 | 막힌 화면 |
| :-: | --- | --- |
| ① | ⛔ **`gaugeId` 가 가리킬 자원이 사라졌다** | `W-05-10` |
| ② | 폐기된 설비를 목록에서 뺄 거르개 | `M-05-02` |
| ③ | 집계 탭이 셋인데 담을 배열이 하나 | `W-05-08` |
| ④ | 「설비 미지정 세션」을 셀 곳 | `W-05-08` |
| ⑤ | ⛔ **툴의 날짜 주기 축이 통째로** | `W-05-02` |
| ⑥ | 보전 지시의 기준일 | `W-05-02` |

### 3-1. ⭐ ①이 가장 위험했다 — **판정을 바꾸면 인용처를 센다**

4단계에서 「계측기 전용 경로를 두지 않는다」로 판정을 바꿨다. **그때 그 이름을 인용한 자리를 세지 않았다.**

```
계약:  Calibration.gaugeId · CalibrationCreate.gaugeId · 조회 파라미터 gaugeId
현실:  /mdm/gauges 는 «없다»
```

⛔ **저장 충돌 토큰을 「응답 헤더에서 받는다」고 적고 헤더를 선언하지 않아 19곳이 막힌 것과 같은 형태다** — 둘 다 **가리키는 곳이 없는 이름**이다.

⭐ **05 는 아직 착수 통지 전이라 지금 고치는 것이 공짜였다.** 통지 뒤였으면 ⛔ 변경 통지 대상이다.

### 3-2. ⭐ ⑤는 화면 하나가 통째로 성립하지 않던 자리다

확정이 「예방보전 트리거 = 타발수 + 날짜 주기 **겸용 설정형**」인데 계약에는 **타발수 축만** 있었다.

⚠ **화면 스펙에도 없었다.** 툴 마스터 스펙(11차)의 필드표에 주기 세 칸이 없다 — **13차가 「툴 마스터에 주기 축 셋을 더한다」로 정한 뒤 11차 필드표로 되돌아오지 않았다.** 이번에 함께 적었다.

> ⭐ **「뒤 차수가 앞 차수의 필드표를 고쳐야 하는데 안 고친 자리」를 잡는 검사기가 없다.** 같은 형태가 더 있는지는 세어 보지 않았다 — 남긴 것 §2.

### 3-3. 파생은 저장하지 않는다

⑤에서 더한 것 중 넷은 **컬럼이 아니다** — 다음 예정일 · 도래 여부 · 먼저 도달한 축 · 초과율.

> **판별 질문 하나 — 「아무도 아무것도 하지 않아도 이 값이 바뀌는가.」** 넷 다 「예」다.

## 4. 역방향 — **「계약은 있는데 화면이 없다」 둘**

| 경로 | 판정 |
| --- | :-: |
| 보전 실적 수정 | ⚠ 화면이 없다 |
| 비가동 한 건 수정 | ⚠ 화면이 없다 |

⛔ **경로를 지우지 않았다.** 현장이 잘못 적은 것을 사무가 고치는 길이 필요하고, **그 화면이 인벤토리에 없는 것이 결손일 수 있다** — 화면 인벤토리 쪽 판단으로 넘겼다.
