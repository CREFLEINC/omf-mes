# 기준정보 도메인 API 스펙 — 실행 계획

> **작업자에게:** 이 계획은 `superpowers:subagent-driven-development`(권장) 또는 `superpowers:executing-plans`로 태스크 단위 실행한다. 단계는 체크박스(`- [ ]`)로 추적한다.
> **설계 정본**: `uiux/2026-08-03-API스펙/00-설계.md` — 이 계획은 그것을 실행 단위로 쪼갠 것이다.
> **⚠ 계획 문서 위치**: 스킬 기본은 `docs/superpowers/plans/`이나 이 저장소는 **`docs/` 불가침**(`uiux/CLAUDE.md` §절대 규칙)이라 `uiux/` 작업 폴더에 둔다.

**목표:** 확대 1차 화면 스펙에서 도출한 기준정보 도메인 API를 **요구서 + OpenAPI + 자동 검산** 세 벌로 만들어 `deliverables/06`에 싣는다.

**구조:** OpenAPI는 물리 모델을 옮긴 것이고(정본=물리 모델), 요구서는 화면→API 매핑과 근거만 담으며(필드표 없음), 검산 스크립트가 둘의 어긋남을 기계로 잡는다. 리소스는 **테이블 경계 = 리소스 경계**로 자른다.

**기술:** Python 3.9 **표준 라이브러리만**(기존 스크립트 관행) · OpenAPI 3.1 **JSON**

## 전역 제약

이 절은 **모든 태스크의 요구사항에 암묵적으로 포함**된다.

- **표준 라이브러리만 사용** — `pip install` 금지. 기존 스크립트 관행(`base64, html, io, os, re, sys`)을 따른다
- **물리 모델이 정본** — `docs/research/2026-07-23-데이터모델링/mes_postgresql_physical_model.sql`. 타입·필수·유일·CHECK를 자의로 바꾸지 않는다. **다르면 결함이고 이슈로 낸다**
- **`docs/` 불가침** — 읽기만 한다. 수정이 필요하면 `[uiux→docs]` 이슈
- **없는 필드를 지어내지 않는다** — 물리 모델에 없으면 스키마에 넣지 않고 `description`에 「미착지 — #이슈번호」로 남긴다
- **감사 컬럼 제외** — `created_at`·`created_by`·`updated_at`·`updated_by`·`version_no`는 스키마에 넣지 않는다(공유계약 A-4). 단 `version_no`는 **낙관적 잠금 헤더**로 별도 전달
- **매핑 선언 필수** — 모든 스키마에 `x-source-table`, 모든 프로퍼티에 `x-source-column`. 검산이 이걸 읽는다
- **근거 한 줄** — 모든 경로의 `description` 끝에 `근거: <화면ID> §<절> · 공유계약 <항목>`
- **커밋 메시지** — `docs:` 접두. 본문은 한국어. 저장소 관례를 따른다

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""물리 모델 ↔ OpenAPI 검산.

SQL 을 파싱해 테이블·컬럼·제약을 뽑고 OpenAPI JSON 의 components.schemas 와
대조한다. 어긋나면 종료 코드 1.

매핑 선언 — 스키마에 x-source-table, 프로퍼티에 x-source-column.
표준 라이브러리만 쓴다(저장소 관행).
"""
import io, json, os, re, sys

AUDIT_COLS = {"created_at", "created_by", "updated_at", "updated_by", "version_no"}

_CREATE = re.compile(r"^CREATE TABLE ([a-z_]+\.[a-z_]+) \($", re.M)
_COL = re.compile(r"^\s{4}([a-z_]+)\s+(.+?)\s*,?\s*(?:--.*)?$")
_UQ = re.compile(r"CONSTRAINT (\w+)\s+UNIQUE\s*\(([^)]*)\)", re.S)
_CK = re.compile(r"CONSTRAINT (\w+)\s+CHECK", re.S)


def _split_blocks(text):
    """CREATE TABLE 한 개씩 (이름, 본문) 으로 자른다."""
    out = []
    for m in _CREATE.finditer(text):
        name = m.group(1)
        start = m.end()
        end = text.find("\n);", start)
        if end == -1:
            continue
        out.append((name, text[start:end]))
    return out


def parse_sql(path):
    """{테이블명: {"columns": {...}, "constraints": [...]}}"""
    text = io.open(path, encoding="utf-8").read()
    tables = {}
    for name, body in _split_blocks(text):
        columns, constraints = {}, []
        for line in body.split("\n"):
            stripped = line.strip()
            if stripped.startswith("CONSTRAINT"):
                continue
            if stripped.startswith("--") or not stripped:
                continue
            m = _COL.match(line)
            if not m:
                continue
            col, rest = m.group(1), m.group(2)
            if col in AUDIT_COLS or col.upper() in ("CONSTRAINT",):
                continue
            rest_nc = rest.split("--")[0].strip()
            typ = rest_nc.split()[0] if rest_nc else ""
            columns[col] = {
                "type": typ,
                "not_null": "NOT NULL" in rest_nc,
                "default": _default_of(rest_nc),
            }
        for m in _UQ.finditer(body):
            cols = [c.strip() for c in m.group(2).split(",") if c.strip()]
            constraints.append({"kind": "UNIQUE", "name": m.group(1), "columns": cols})
        for m in _CK.finditer(body):
            constraints.append({"kind": "CHECK", "name": m.group(1), "columns": []})
        tables[name] = {"columns": columns, "constraints": constraints}
    return tables


def _default_of(rest):
    m = re.search(r"DEFAULT\s+(\S+)", rest)
    return m.group(1) if m else None


if __name__ == "__main__":
    here = os.path.dirname(os.path.abspath(__file__))
    sql = os.path.join(here, "..", "docs", "research",
                       "2026-07-23-데이터모델링", "mes_postgresql_physical_model.sql")
    t = parse_sql(sql)
    print("테이블 %d개 파싱" % len(t))
```

⚠ **컬럼 정규식이 여러 줄 정의를 놓친다.** `plant_id bigint NOT NULL\n    REFERENCES ...` 형태는 첫 줄만 잡히는데, 우리에게 필요한 것(이름·타입·NOT NULL)이 첫 줄에 다 있으므로 문제없다. `REFERENCES` 줄은 `_COL` 이 매치하지 않아 자연히 버려진다.

```python
# 매핑 선언이 면제되는 스키마 — SQL 대응물이 없는 공통 응답 구조
EXEMPT = {
    "ErrorResponse", "ErrorItem", "ConflictResponse", "BatchResult",
    "BatchFailure", "Editability", "PageMeta",
}


def verify(tables, spec):
    """위반 메시지 목록을 돌려준다. 빈 목록이면 통과."""
    errs = []
    schemas = spec.get("components", {}).get("schemas", {})
    for sname, schema in sorted(schemas.items()):
        if sname in EXEMPT:
            continue
        table = schema.get("x-source-table")
        if not table:
            errs.append("%s: x-source-table 선언이 없다" % sname)
            continue
        if table not in tables:
            errs.append("%s: 물리 모델에 %s 가 없다" % (sname, table))
            continue
        cols = tables[table]["columns"]
        required = set(schema.get("required", []))
        for pname, prop in sorted(schema.get("properties", {}).items()):
            col = prop.get("x-source-column")
            if not col:
                errs.append("%s.%s: x-source-column 선언이 없다" % (sname, pname))
                continue
            if col in AUDIT_COLS:
                errs.append("%s.%s: 감사 컬럼 %s 을 노출한다(A-4 위반)" % (sname, pname, col))
                continue
            if col not in cols:
                errs.append("%s.%s: %s 에 %s 컬럼이 없다" % (sname, pname, table, col))
                continue
            if cols[col]["not_null"] and pname not in required:
                errs.append("%s.%s: %s 는 NOT NULL 인데 필수(required)가 아니다"
                            % (sname, pname, col))
            if not cols[col]["not_null"] and pname in required:
                errs.append("%s.%s: %s 는 NULL 허용인데 필수로 선언됐다"
                            % (sname, pname, col))
    return errs


def main():
    here = os.path.dirname(os.path.abspath(__file__))
    sql = os.path.join(here, "..", "docs", "research",
                       "2026-07-23-데이터모델링", "mes_postgresql_physical_model.sql")
    api = os.path.join(here, "openapi", "mdm-기준정보.json")
    tables = parse_sql(sql)
    spec = json.load(io.open(api, encoding="utf-8"))
    errs = verify(tables, spec)
    if errs:
        print("검산 실패 — %d건" % len(errs))
        for e in errs:
            print("  ✗", e)
        return 1
    n = len(spec.get("components", {}).get("schemas", {}))
    p = len(spec.get("paths", {}))
    print("검산 통과 — 스키마 %d · 경로 %d (물리 모델 테이블 %d)" % (n, p, len(tables)))
    return 0


if __name__ == "__main__":
    sys.exit(main())
```
