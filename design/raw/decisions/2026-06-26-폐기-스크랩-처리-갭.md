## 1. 결론
✅ **제품·자재 폐기(scrap/disposal)는 현재 설계에 사실상 없다.** 문서에서 "폐기"라는 단어는 **설비 master·툴/금형 master의 `신규입고/폐기 상태(Legacy 연계)`** 에만 나오며, 이는 **고정자산(설비·금형) 처분 플래그**일 뿐 제품·자재 폐기와 무관하다.

## 2. 인접 기능은 있으나 폐기가 아니다 (✅)
| 있는 것 | 무엇 | 폐기와의 차이 |
| --- | --- | --- |
| 불량/불량코드 (C4·C1) | 불량 수량·사유 *수집* | "불량이다"를 기록만 — 그 물건을 *처분*하는 단계 없음 |
| 반품(Return, C6) | 공급사 반품·고객 반품입고 | **외부 방향**(되돌림/들어옴), 내부 폐기 아님 |
| 수입검사 불합격→반품 | IQC 불합격 자재 | 공급사 반품 — 반품 불가분의 *폐기* 처리 없음 |
| Lot Status Hold (C4) | 격리 상태 | 묶어둘 뿐, Hold LOT을 *폐기로 종결*하는 트랜잭션 없음 |
| 재고실사 조정 (C6) | 실사 차이 조정 | 우발적 *차이* 보정 — 의도적 *폐기*(사유 코드)와 다름 |

✅ C6 트랜잭션 10종(입하·입고·출고·재고·출하·반품·재고실사·재고이동·P&P·포장합병분할)에 **폐기 없음.**

## 3. 빠진 폐기 시나리오 (🔶)
1. **공정 내 불량품 폐기** — 재작업 불가 불량 WIP/생산품 처분. (불량 *수량*은 작업실적에 잡히나, 재고화된 물건의 폐기 처리·재고 차감 트랜잭션은 없음)
2. **자재 폐기** — 유효기간 경과·손상·반품 불가 자재, 잔재 처분 → 자재 재고 차감.
3. **제품 폐기** — OQC 불합격·재작업 불가, 장기재고/진부화(obsolete), 클레임 반품 후 폐기.
4. **불량 LOT 전체 폐기** — Hold LOT이 특채·재작업도 안 되면 → 폐기 종결.

> 참고: *공정 중* 불량은 양품만 LOT/재고가 되는 식으로 **수율에 암묵 반영**될 수 있다. 그러나 **이미 재고에 잡힌 자재·제품의 폐기**와 **폐기 사유·수량·재고손익·genealogy 종결**은 별도 트랜잭션이 필요한데 부재.

## 4. 왜 중요한가 (🔶)
- **재고 정합** — 폐기는 *재고를 줄이는* 트랜잭션. 없으면 불량품이 재고에 남거나 임의로 사라져 재고 불일치.
- **회계** — 폐기 = 재고자산 손실 → **재고손익 전표(ERP)**. (B8 패턴: 폐기 *작업·사유*=MES, 손익 *전표*=ERP)
- **수율·원가** — scrap rate는 핵심 KPI. 폐기 수량/사유가 있어야 수율·로스 원가 산출.
- **추적성** — 폐기 LOT의 사유·시점, genealogy *종결점*.
- **재활용·잔재** — 금속·플라스틱 등은 scrap이 재투입(recycle)·부산물 판매 → 별도 처리 가능.

## 5. 폐기가 들어갈 자리 (🔶 설계 방향, 요구 확인 시)
- **C6에 신규 트랜잭션 '폐기(Scrap/Disposal)'** — 출고·반품의 형제. 속성: 대상 LOT/품목, 폐기수량, **폐기사유(불량/유효기간/손상/진부화)**, 처리일, 재고 차감.
- **연계**: 불량(C4) 사유 · Lot Status(C4) '폐기' 종결상태 · 재고(C6) 차감 · **ERP 재고손익 전표**(회계, 지시–작업지시–전표 패턴).
- **구분(헷갈림 방지)**: 폐기 ≠ 반품(외부 방향) · 폐기 ≠ 재고조정(우발적 차이) · 폐기 ≠ 불량기록(수집).

## 6. 현장 확인 사항 (⚠ 고객 요구 유무 — 사용자 확인 예정)
1. 불량품·만료·손상 자재/제품을 **실제로 어떻게 처분**하는가(재고 차감·사유·기록)?
2. 폐기를 **시스템에서 관리할 요구**가 있는가, 아니면 수기/ERP에서 처리하는가?
3. **재고손익 전표(ERP)** 와 연계되는가?
4. **잔재·재활용**(재투입/부산물 판매)이 있는가?
5. (있다면) 폐기 **사유 코드 체계**는?

→ 요구 확인 결과에 따라 §5 설계를 반영하거나, 범위 밖(ERP/수기)으로 명시한다.
