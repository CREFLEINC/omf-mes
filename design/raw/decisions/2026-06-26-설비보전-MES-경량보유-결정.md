## 1. 배경
🔶 ISA-95는 **보전 운영을 생산과 별도 영역**으로 두고, 보전 계획·오더·자산 수명·보전 비용·예비품 재고는 전형적 **EAM/CMMS** 도메인이다.
✅ 그러나 본 고객(삼진 비나)의 UNIMES 제안·C5 모델엔 별도 EAM 언급이 없고, 설비보전계획/지시·설비보전이력·설비점검이력·툴보전오더·툴PM실적이 **모두 C5(MES)** 에 들어 있다.
✔ **고객은 EAM/CMMS를 보유하지 않는다.** → 보전 계획·지시를 둘 곳이 MES뿐이다.

## 2. 결정 (✔ CREFLE)
- **점검(Daily/Monthly)** = **MES 유지**. 작업 전 점검 결과로 생산 통제(D3 작업 차단)와 직결, 생산 실행과 한 몸.
- **보전 계획·지시** = **MES 경량 보유**. EAM 미보유에 따른 현실적 선택.
- **MES 역할** = 설비 상태·비가동·점검·고장 *수집* + 보전 *트리거* + 생산 *통제* + 경량 보전 *계획/지시/실적*. (수동 뷰어 아님)
- **점검 ≠ 보전**: 점검 = "괜찮은지 본다(진단)", 보전 = "고치거나 미리 정비한다(조치)". 점검 NG·카운터가 보전을 *트리거*한다.

## 3. 경량 범위 (포함 / 제외)

| 구분 | **MES 경량 보유 (포함)** | 범위 밖 (추후 EAM/ERP) |
| --- | --- | --- |
| 계획 | 설비/툴 master의 보전항목·주기 기반 **예방보전 예정일** | 보전 비용·원가 회계 |
| 지시·실적 | 보전 지시·수행 실적(수행자·일시·결과) | 자산 감가상각·수명·자본 관리 |
| 사후보전 | **고장 기록 + 비가동(C4) 연계** | 예비품 재고·발주·구매 (사용 *기록*만 MES) |
| 트리거 | 점검 NG·누계타발수 초과 → 보전 발생 | 고급 신뢰성 분석(MTBF/MTTR 전용; 파생 집계는 가능) |
| 예비품 | 보전 시 예비품 *사용 내역* | 외주 보전 계약·발주 |

**원칙: "언제·무엇을·누가 정비했나"까지 MES, "얼마(비용)·자산·재고 발주"는 범위 밖.**

## 4. 미래 EAM 도입 시 — 지시·작업지시 패턴으로 이관
🔶 추후 EAM을 도입하면, 출하·물류에 쓴 **상위지시–작업지시 분리** 패턴을 그대로 적용한다:
```
(현재)        MES 경량 보전계획/지시/실적 — 한 몸
(EAM 도입 후) EAM 보전오더(상위 지시) ──> MES 보전작업/실적(실행) ──> EAM 비용·자산 정산
```
→ 이관을 대비해 **보전 계획/지시를 실행(실적)과 느슨 결합(nullable 참조)** 으로 두면 전환이 쉽다. (트랜잭션 발번 2계층 설계와 동형 — `research/2026-06-26-트랜잭션-발번-2계층설계-및-B섹션재정리.md`)

## 5. OMF/AX 정합
🔶 AX MES가 설비에서 내는 가치는 *보전 행정*이 아니라 **상태·이상 감시(condition/predictive)**. OMF-AI '이상감시 Agent'(1단계 제외)가 설비 상태기반이다. → 보전 *행정*은 경량으로만, MES+AI는 **상태 수집·예지보전(CBM)** 에 집중.

## 6. D4·C5 영향
- **D4 소유경계 = 결정됨**(MES 경량 보유). **잔여 미결** = ① 경량 *범위*(본 §3 표로 확정) ② 계획→지시→이력 분리/통합·보전지시:보전이력 1:1 vs 1:N.
- **C5 미결** '계획-지시-이력 3단계' 항목에 본 결정 반영.
