MES 관리 정보

MES에서 소모품·예비품 데이터를 다루는 방법

이 대장을 MES의 자재/재고(MRO) 관리 모듈로 옮길 때, 핵심은 수기 스냅샷 → 트랜잭션 기반 재고원장으로 바꾸고 소모품과 예비품을 다르게 관리하는 것입니다.

1. 소모품 vs 예비품 — 관리 방식이 다릅니다

현재 126개가 한 대장에 섞여 있지만 성격이 둘로 나뉩니다. 마스터에 품목유형 필드를 두고 재고정책을 다르게 태우는 것이 출발점입니다.

구분소모품 (Consumable)예비품 (Spare Part)
예시 (이 대장)PP원료·중성 이형제·열매체유·테프론테이프·가스각종 피팅·노즐/석션·에어호스·아이볼트
소비 특성생산량에 비례해 지속 소모고장·마모 시 교체 (드문드문)
발주 로직소요량(원단위)·소비추이 기반 예측 발주Min-Max + 중요도 기반
MES 연계공정 BOM(원단위) · 생산실적설비 마스터(호기) · 보전 작업지시
안전재고 관점월 소비량 기준 재산정설비 가동중단 리스크(critical) 기준

2. 데이터 3계층 구조

현재 "현재고·부족수량"은 수기로 갱신하는 스냅샷이라 이력이 없습니다. MES에서는 아래 3계층으로 분리해 재고를 계산값으로 만듭니다.

① 품목 마스터 Item Master · 잘 안 변하는 속성
  • 품목코드(유일키) · 다국어 품명(한/중/VN) · 규격 · 기본단위(UOM)
  • 품목유형(소모품/예비품) · 분류(피팅·원료·이형제·호스…)
  • 공급업체 · 리드타임 · 표준단가 · 통화(VND) · 대체품
② 재고 Inventory · 계산값(직접 입력 X)
  • 로케이션(창고/라인/호기)별 현재고
  • 현재고 = Σ 입출고 트랜잭션 으로 자동 산출
  • 재고 자산가치(현재고 × 단가)
③ 입출고 트랜잭션 Transaction · 모든 변동의 원천
  • 입고(GR) · 출고(사용) · 재고조정 · 반품
  • 출고를 작업지시·설비 호기·보전 WO에 연결 → 소비처 추적
  • 이 이력이 있어야 소비추이·자동발주·설비별 소모 분석 가능

3. 재고 통제(발주) 로직

현재 필요수량 = 안전재고 − 현재고 는 리드타임을 무시한 단순식입니다. MES에서는:
  • 발주점(ROP) = 리드타임 동안의 예상 소비 + 안전재고
  • 재고 ≤ ROP → 구매요청 자동 생성, 발주수량은 Max(정량)/EOQ까지 채움
  • 소모품: 생산계획·원단위로 소요 예측(MRP-lite)  /  예비품: Min-Max + 설비 중요도

4. 트랜잭션 흐름

입고(GR)→ 보관(로케이션)→ 출고 (작업지시 / 설비 / 보전 WO)→ 재고 차감→ ROP 도달 감지→ 구매요청(PR)→ 발주(PO)→ 입고
핵심은 "출고를 어디에 썼는지" 연결하는 것입니다 — 작업지시(공정)·설비 호기·보전 작업지시. 이 연결이 있어야 소비추이·설비별 소모가 보입니다.

5. 다른 마스터와의 연계

  • 설비 마스터(호기) ↔ 예비품 — "이 노즐·피팅은 어느 사출기용" → 고장 시 즉시 가용재고 확인
  • 점검·보전 체크리스트 ↔ 소모품 — 점검 시 교체하는 이형제·필터·에어호스를 보전 작업지시에서 자동 출고
  • 공정 마스터(BOM/원단위) ↔ 소모품 — 제품·공정별 소요량 → 생산량 기반 소비 예측
  • 구매 — ROP 미달 → 구매요청(PR) → 발주(PO) → 입고(GR)

공급업체 + 리드타임자동 발주(ROP)의 전제 조건
