01

ERD — 관계도

FK 제약은 없음 · 코드값 기준 논리 관계 (100% 참조 정합 확인)

인터페이스 테이블이라 물리적 FK 제약은 걸려 있지 않지만, ITEM_CD·BP_CD·PLANT_CD 코드값 기준으로 논리 관계가 성립합니다. 실측 결과 작업지시/구매/BOM의 품목·거래처 참조가 모두 마스터에 존재(참조 무결 100%)했습니다.

논리적 1:N 관계 (조인키) 공통코드 / 감사 참조 마스터 (참조 대상) 파란 박스 = 마스터 · 회색 박스 = 트랜잭션/코드

04

개발 시 유의사항

패턴인터페이스 공통 컬럼

거의 모든 테이블이 CREATE_TYPE(생성구분), IF_SEQ(인터페이스 순번), MES_APPLY_FLAG(MES 반영여부·현재 전부 N), MES_APPLY_DT/ERROR, 감사 INSRT_DT · UPDT_DT · MES_INF_ID를 가집니다. 신규 수신 로직은 이 컬럼들을 기준으로 미반영건을 처리하세요.

키복합 PK + PLANT_CD

대부분 PLANT_CD가 PK 선두에 포함된 복합키입니다. 조인·유니크 판정 시 반드시 사업장(PL11/PL13)을 함께 사용하세요. 같은 ITEM_CD가 사업장별로 존재할 수 있습니다.

주의날짜 타입 혼재

PO_DT · SO_DT · PLAN_START_DT · ENTER_DATE는 문자열(varchar)로 'YYYY-MM-DD' 저장, 반면 DLVY_DT · INSRT_DT · UPDT_DT는 datetime입니다. 파싱·비교 시 타입을 구분하세요.

주의char 고정폭 공백 패딩

ITEM_ACCT_NM(char 200), BASE_UNIT(예: "KG ") 등 char 컬럼은 뒤에 공백이 채워집니다. 비교·표시 전 LTRIM/RTRIM 필수.

주의물리 FK 없음

모든 관계는 코드값 기준 논리적 관계입니다(제약 없음). 무결성은 앱/ETL이 보장해야 하며, 유효하지 않은 코드가 유입될 수 있음을 전제로 방어적으로 조인하세요.

인코딩다국어 데이터

사원·거래처·부서명에 한국어·영어·베트남어가 혼재하며 nvarchar(유니코드)입니다. 추출/연동 시 UTF-8/UTF-16을 유지하고, SPEC 등 일부 텍스트에는 줄바꿈이 포함될 수 있습니다.

명명테이블 접두어

T_IF_SND_*_KO324 = ERP→MES 송신 인터페이스(KO324는 연동 코드), T_ERP_*_TIG_DOWN = ERP 다운로드 마스터. 신규 테이블도 이 규칙을 따르면 일관성이 유지됩니다.

보안개인정보

사원 성명·이메일·휴대폰(T_ERP_EMP), 거래처 담당자 연락처·사업자번호(BIZ_PARTNER)가 포함됩니다. 샘플·개발 환경 공유 시 마스킹을 권장합니다.

복원 & 조회 방법

macOS(Apple Silicon)에서 Docker로 SQL Server 2022를 띄워 .bak을 복원했습니다. 동일 절차:

# 1) SQL Server 2022 컨테이너 (arm64는 --platform 필요)
docker run --platform linux/amd64 -e ACCEPT_EULA=Y \
  -e MSSQL_SA_PASSWORD=Str0ng!Passw0rd -p 14330:1433 \
  --name mssql_restore -d mcr.microsoft.com/mssql/server:2022-latest

# 2) .bak 복사 후 논리파일명 확인
docker cp sample_mes_0708.bak mssql_restore:/var/opt/mssql/backup/sample.bak
sqlcmd ... -Q "RESTORE FILELISTONLY FROM DISK='/var/opt/mssql/backup/sample.bak'"

# 3) 복원 (논리명: sample_mes / sample_mes_log)
RESTORE DATABASE sample_mes FROM DISK='/var/opt/mssql/backup/sample.bak'
  WITH MOVE 'sample_mes' TO '/var/opt/mssql/data/sample_mes.mdf',
       MOVE 'sample_mes_log' TO '/var/opt/mssql/data/sample_mes_log.ldf', REPLACE;

접속: localhost:14330 · 사용자 sa · DB sample_mes. GUI는 DBeaver/Azure Data Studio 사용 가능.
