## 2. ⭐⭐ 이 트랙이 처음 한 것 — **물리 모델을 기다리지 않았다**

앞 여섯 트랙은 전부 **표가 있는 자리**에 계약을 얹었다. 05 는 다르다.

```
설비·툴 관련 물리 표     3개뿐  (설비 · 금형 · 검교정 이력)
점검 · 고장 · 보전지시 · 보전실적 · 예비품 · 캘린더     0건
```

2026-08-18 사용자 확정이 순서를 뒤집었다.

> **데이터 모델링은 설계 결정을 앞설 수 없다.** 무엇을 받나 · 필수인가 선택인가 · 어떤 값이 오나는 **설계가 정한다.**

⭐ **그 결과 05 는 「막힌 액션 0건」으로 끝났다.** 앞 도메인들은 「미착지」·「선행 미결」로 막힌 액션이 늘 있었는데 05 는 없다.

### 2-1. ⛔ 그렇다고 아무거나 적은 것은 아니다

**적지 않은 것을 함께 센다.**

| 무엇 | 왜 안 적었나 |
| --- | --- |
| 예비품의 규격·재고 기준·교체 주기 | **현행 대장 실물**을 봐야 안다 — 모델 문제가 아니다 |
| 중계 테이블의 변환 규칙 | 근거가 없다 |
| 송신의 「부속 항목」 | 인벤토리 근거란에만 있고 원문에서 확인되지 않았다 |
| 「개발품 제외」의 판정 축 | **두 문서가 다르게 읽힌다** — 계약이 임의로 고를 수 없다 |

⭐ **가르는 기준** — 「모델이 없어서 못 적나」와 「근거가 없어서 못 적나」는 다르다. **앞은 통지하고 나아가고, 뒤는 실물을 봐야 안다.**

## 3. ⭐⭐ 곁가지가 본가지보다 컸다 — 06 §6 이 사라졌다

같은 확정이 **05 밖의 세 화면도 풀었다.** 06 요구서 §6 「API 를 정의할 수 없는 화면 3건」은 이렇게 시작했다.

> 엔드포인트를 지어내지 않았다. 테이블이 없으면 스키마를 만드는 순간 전부 창작이 된다.

**그 문장은 물리 모델을 근거의 바닥으로 놓은 것이다.** 셋 다 확정이 넷 안팎씩 걸려 근거가 오히려 촘촘했다.

| 화면 | 지금 |
| --- | --- |
| 예비품 마스터 | ✅ 05 의 마스터 보완에 함께 섰다 |
| 연계 정의 관리 | ✅ `/integration/interface-definitions` 다섯 |
| 송신 항목 설정 | ✅ `/integration/outbound-item-settings` |

⭐ **06 요구서의 대상 화면이 11 → 14 가 됐다.**

## 4. ⛔ 계수를 **세 번 고쳤다** — 이 트랙이 가장 많이 틀렸다

| 언제 | 무엇 | 왜 |
| --- | --- | --- |
| 2단계 초안 | 「34경로 · `:동사` 4」 | **손으로 어림했다.** 세니 40 · 9 |
| 3·4단계 | 40 → 42 | 사진 첨부 · 최근 수신 신호가 드러났다 |
| **4단계** | **42 → 52** | ⛔ **세 갈래가 통째로 빠져 있었다** |

⭐ **셋째가 뜻이 있다.** 2단계는 `/mdm/equipments` 를 「기존 자원 — 신설 0」으로 셌는데 **있던 것은 조회 하나뿐**이었다.

> **「있다」와 「내가 쓸 수 있는 형태로 있다」는 다르다.**

⚠ **1단계가 0단계에 대해 정확히 같은 것을 잡았고**(「0단계가 기존 자원이라 한 넷이 계약에 없었다」) **그 교훈을 적어 뒀는데 2단계가 다시 밟았다.** 원인은 「기존 자원」이라 적을 때 **메서드까지 보지 않은 것**이다.

## 5. ⭐⭐ 적합성이 계약을 **여섯 자리 키웠다** — 트랙 최다

「이 계약으로 이 화면을 그릴 수 있는가」를 17화면에 되짚어 여섯을 고쳤다(5단계 §3). **가장 위험했던 것은 첫째다.**

```
4단계에서 「계측기 전용 경로를 두지 않는다」로 판정을 바꿨다
      ↓
그 이름을 인용한 자리(gaugeId 다섯 곳)를 «세지 않았다»
      ↓
구현팀은 /mdm/gauges 를 찾다 막힌다
```

⛔ **저장 충돌 토큰 19곳과 같은 형태다** — 둘 다 **가리키는 곳이 없는 이름**이다.

> ⭐ **규칙 하나를 얻었다 — 판정을 바꾸면 그 판정을 인용한 자리를 «센다».**
> 이슈를 닫기 전 인용처를 세는 규칙은 이미 있었는데, **판정 변경에는 없었다.**

## 6. ⭐ 검사기 셋을 고쳤다 — **셋 다 거짓 경보**

| 검사기 | 무엇이 잘못이었나 |
| --- | --- |
| 값 목록 협착 | **새로 만든 스키마·필드까지 ⛔ 로 울었다.** 없던 필드로는 깨질 코드가 없다 |
| 다형(한 칸이 상황에 따라 여러 표를 가리킨다) 참조 대응표 | **표가 아직 없는 도메인이 통째로 오탐**이 됐다 — 점검 「유형」 같은 분류 코드까지 잡혔다 |
| 매핑 커버리지 | 요구서가 없으면 **추적 역추적**을 뱉었다 — 「아직 안 썼다」와 「깨졌다」는 다르다 |

⚠ **거짓 경보가 쌓이면 검사기를 무시하게 되고, 그러면 진짜 결손이 지나간다.** 다형 검사기의 회귀 시험은 **직전 커밋부터 빨간 채**였다.
