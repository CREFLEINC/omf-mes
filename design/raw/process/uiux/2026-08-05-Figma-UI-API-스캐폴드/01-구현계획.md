**Goal:** Figma Design 파일 `S1PN6EX4xeU21yIqyZL2pZ`에 기준정보 변경 흐름 3화면과 사용자 액션별 API Rail을 구현한다.

**Tech Stack:** Figma Design Plugin API via `use_figma`, `@crefle/web-ui` v0.1 계열 CSS/React 소스, OpenAPI 3.1 `deliverables/openapi/mdm-기준정보.json`, Spoqa Han Sans Neo

## Global Constraints

- 대상은 Figma Design 파일 `S1PN6EX4xeU21yIqyZL2pZ`이며 기존 FigJam은 수정하지 않는다.
- 파일럿 화면은 `W-06-01`, `W-06-02`, `W-06-11` 세 개뿐이다.
- `docs/`와 기존 `uiux/` 정본은 읽기 전용이며 API·필드·업무 규칙을 지어내지 않는다.
- 화면 프레임은 관리웹 1440px 데스크톱, Table은 compact density를 사용한다.
- CREFLE Figma 라이브러리가 없으므로 Material 3·Simple Design System을 사용하지 않는다.
- 시각 값은 `/Users/rangkim/projects/crefle/designsystem/repos/design-system-v2-web-ui/styles/`를 기준으로 한다.
- 기본 글꼴은 Spoqa Han Sans Neo다. Figma 환경에 없으면 작화를 중단하고 폰트 설치 필요를 보고하며 임의 폰트로 확정하지 않는다.
- 사용자 예시는 합성 코드(`ITEM-1001`, `RT-INJ-001`, `WO-TEST-001`)만 사용한다.
- `use_figma` 한 호출은 논리 작업 10개 이하로 유지하고 모든 생성·수정 node ID를 반환한다.
- 각 페이지 완성 직후 구조 반환값과 스크린샷을 검증하고 오류를 다음 페이지로 넘기지 않는다.
- 모든 텍스트 변경은 폰트 로드 완료 뒤 수행한다.
- 상태는 색뿐 아니라 아이콘 또는 명시적 문구로 함께 표현한다.
