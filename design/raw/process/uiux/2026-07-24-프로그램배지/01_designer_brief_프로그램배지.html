배지 마스터·클론 전략 (Wave A 최우선)

placement-plan §2: 칩은 기존 클론 킷에 동형 소스가 없는 신규 표기 계층이므로 clone-not-draw 원칙의 예외로 SHAPE_WITH_TEXT(ROUNDED_RECTANGLE) 신규 생성을 허용한다. 단, 범례에 마스터 4종을 먼저 만들고, 63개 배치는 전부 그 마스터를 clone() 하여 스타일 100% 통일을 보증한다(칩을 배치마다 새로 그리는 것 금지).

마스터 칩 4종 스펙 (00.범례 219:4610 안에 신규 생성)

공통: SHAPE_WITH_TEXT, shapeType='ROUNDED_RECTANGLE', 높이 40, 모서리 반경 8(설정 가능하면 cornerRadius=8, ROUNDED_RECTANGLE 기본 라운딩으로 대체 가능). 텍스트는 색+라벨 이중 부호화. 폰트는 하드코딩 금지 — 생성 직후 getStyledTextSegments(['fontName'])로 현재 폰트 로드 후 characters·크기·색 설정(폰트 미로드 오류 방지). 텍스트 크기 14, 굵게(Semi Bold 있으면 Semi Bold, 없으면 Medium). 한국어 글자는 FigJam 자동 폴백 사용.

주석 스티키 문구 전문(placement-plan §2 그대로, 글자 단위 준수):

배지 = 사용 프로그램(폼팩터 3종, 결정 16). 기존 Mobile/Desktop 아이콘은 행위 유형(스캔·입력/화면 조작) 표기로 폼팩터가 아님 — 예: 사번입력은 Mobile 아이콘이지만 프로그램은 POP.

  • 스티키 auto-height 주의: 460폭에 위 문구 주입 후 실측 .height 재확인. 범례 하단(로컬 y 1760)까지 여유 있으나, 실측 bottom이 1760을 넘으면 y를 위로 조정(1300→최소치)하거나 폭을 넓혀 줄 수 감소.

좌표 규칙 (전 배치 공통 — 반드시 준수)

  1. 좌표계: 배지 칩을 대상 섹션에 appendChild 한 뒤 chip.x/chip.y를 설정한다. 섹션 자식의 x/y는 섹션 로컬 좌표이므로, 본 지시서의 모든 배지 좌표는 이미 (섹션 ID + 로컬)로 산정돼 있다. 클론 소스(범례 칩)를 대상 섹션으로 옮긴 다음 좌표를 찍을 것.
  2. 기본 위치(단일 칩): 앵커 노드 우상단 모서리에 칩의 좌하단이 8~12px 걸치도록.
    • chip.x = 앵커.x + 앵커.w − 10
    • chip.y = 앵커.y − 30 (칩 높이 40 → 칩 하단 = 앵커.y+10, 상단 스트립 10px 오버랩)
    • 아이콘 인스턴스는 전부 120×120이므로 대개 chip.x = 앵커.x + 110, chip.y = 앵커.y − 30. 본 지시서 「배치 목록」 표에 배치별 최종 (x,y)를 이미 계산해 명시했으니 표 값을 그대로 사용하고, 공식은 검산용으로만.
  3. 다중 칩(가로 스택): 간격 4px, 오른쪽→왼쪽 순(첫 칩이 최우측, 다음 칩이 그 왼쪽). 해당 케이스는 04-S-D 1건뿐이며 배치 목록에 두 칩의 개별 좌표를 명시.
  4. 겹침 금지: 이웃 노드·라벨과 도형↔라벨 ≥16px 유지. 우상단이 막힌 앵커는 배치 목록에 대안 위치를 개별 지정(검사 판정 / 관리자 확인 / 04-S-D 스택 3건). 드로어는 표 좌표를 임의 변경하지 말 것 — 조정이 필요하면 designer에 질의.
