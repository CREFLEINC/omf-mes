## ⑤ 지시서와 달라진 점 · 질의 (전부 API 제약 또는 지시서 명시 허용 범위 내)

1. **cornerRadius=8 미설정 → ROUNDED_RECTANGLE 기본 라운딩 사용.** §1-1이 "ROUNDED_RECTANGLE 기본 라운딩으로 대체 가능"으로 명시 허용한 범위. 마스터 4종·34클론 전부 기본 라운딩. (SHAPE_WITH_TEXT의 cornerRadius 강제 지정은 원자적 실패 리스크가 있어 지정하지 않음.)
2. **주석 스티키 폭 460 → 416으로 조정(API 제약).** FigJam STICKY는 width가 읽기 전용이며 240(square)/416(wide) 2택만 지원, resize 불가. 460 요청 불가 → 최대폭 416(isWideWidth=true) 사용. 실측 높이 240, bottom 로컬 y=1540으로 범례 하단 1760 이내 — §1-2가 우려한 오버플로 없음. **배치·문구 무변경, 폭만 -44px.**
3. **범례 제목/캡션 TEXT·스티키 색상은 지시서 미명시 → 표준값 선택.** 제목 Inter Semi Bold 16, 캡션 Inter Medium 14, 텍스트색 #1E1E1E(dark); 주석 스티키 fill #E6E6E6(gray, 중립 주석). 지시서는 이들의 문구·좌표만 지정했고 서체·색은 신규 등재 요소의 표준 스타일링으로 판단(내용 창작 아님). 검토자 확인 요망 시 조정 가능.

**질의(진행 차단 아님)**: 위 1~3은 모두 API 한계·명시 허용·표준 스타일링이라 진행을 막지 않았음. 지시서 §0의 정합 경고(웹 총계 29 vs 계획 30 · 02메인 「6.생산관리자」 라벨)는 Wave A 배치에 영향 없음(배지는 앵커에 그대로 부착, 캔버스 라벨 무수정). **미배치·미해결 앵커 0건.**
