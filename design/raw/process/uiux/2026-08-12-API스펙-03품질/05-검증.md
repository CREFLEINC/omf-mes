# 03 품질 — 5단계 검증

> 작성일: 2026-08-12 · 선행: `04-OpenAPI작성.md`
> **산출물**: `deliverables/06-API-요구서-03품질.md` (화면 소절 **7** + 집계 1 · 액션 **53**)

## 1. 세 축으로 본다 — **02 에서 하나 늘었다**

| 축 | 무엇 | 누가 |
| --- | --- | :-: |
| **커버리지** | 화면의 액션이 요구서에 다 있는가 | 검사기 |
| ⭐ **적합성** | **이 API 로 이 화면을 그릴 수 있는가** | **사람** |
| ⭐⭐ **역방향 ②** | **요구서가 인용한 경로가 계약에 있는가** | **검사기(신설)** |

⚠ **커버리지 ✅ 가 적합성 ✅ 가 아니고, 적합성 ✅ 도 인용이 맞다는 뜻이 아니다.**

## 2. 커버리지 — 통과

```
verify-ui-coverage.py    --domain 03    화면 6 · 액션 45   ⚠ 표 없는 화면 1: W-01-01
verify-mapping-coverage.py --domain 03  ✅ 전건 다뤘습니다  (소절 7)
check-structure.py · check-public-safe.py                  ✅
verify-doc-citations.py  --doc 03       ✅ 인용 42 전건 계약에 있다
단위 테스트 27 (03 4건 신설)                                ✅
```

### 2-1. ⭐ 계수를 **고치지 않았다** — 이 트랙 처음

| 트랙 | 계수 정정 |
| :-: | :-: |
| 01 | 2회 |
| 02 | **4회** |
| **03** | ⭐ **0회** |

**왜인가** — 세 가지를 앞당겼다.

1. **0단계에서 화면을 셌다** — 「도메인 배지 5」가 아니라 **계약 대상 7**임을 착수 전에 잡았다
2. **1단계에서 `grep -c` 로 세고 원소 유일로 검산**했다(quality 15 = 06 5 + 03 5 + 04 3 + 05 1 + 범위 밖 1)
3. **2단계에서 본문 도출을 추정하지 않고 열거**했다(`W-01-01` 8건)

⚠ **02 의 네 정정은 전부 「추정을 수처럼 적었다」가 원인이었다.**

## 3. 검사기를 **두 개 손댔다**

| 무엇 | 결과 |
| --- | --- |
| `verify-ui-coverage.py` **03 도메인 등록** | ⭐ **단위 테스트가 변경을 잡았다** — `sorted(cov.DOMAINS)` 단언. 02 때와 같다 |
| ⭐⭐ **`verify-doc-citations.py` 신설** | **02 가 후속으로 남긴 「요구서↔계약 역방향 검사기」** — §5 |

### 3-1. ⛔ 단위 테스트를 붙였는데 **돌지 않았다**

새 테스트 클래스를 파일 끝에 붙였더니 **`unittest.main()` 뒤라 정의만 되고 실행되지 않았다.**

```
Ran 23 tests    ← 4건을 붙였는데 수가 그대로였다
```

⭐ **「OK」가 아니라 「몇 개 돌았나」를 봤기 때문에 잡았다.** 클래스를 `__main__` 블록 앞으로 옮기니 **27** 이 됐다.

⚠ **02 의 「검사기가 센 수와 내가 센 수를 대조한다」와 같은 형태**다 — **통과 여부가 아니라 계수를 본다.**

## 4. ⭐ 적합성 — 화면별로 물었다

| 판정 | 화면 |
| --- | --- |
| ✅ **그릴 수 있다 — 5** | `W-01-01` · `W-03-02` · `W-03-03` · `P-02-13` · *(+`W-03-01` 부분)* |
| ⚠ **반쪽 — 2** | `W-03-05`(불량코드 분포 **데이터 0건**) · `W-03-01`(이력 **절반**) |
| ⏳ **판단 대기 — 1** | `W-03-09`(「부적합 열기」가 **04 계약**) |

### 4-1. ⭐⭐ 적합성이 계약을 **키웠다** — 경로를 하나 더했다

**요구서 §3 을 쓰다가 세 화면이 안 그려지는 것을 발견했다.**

`W-03-01`·`W-03-02`·`W-03-03` 의 대상 목록은 **LOT + 품질 상태 + 보류 요약 + 창고**를 한 행에 요구한다. **01 계약의 `GET /trace/lots` 로는 못 준다** — 실측:

| 화면이 요구하는 것 | 01 `/trace/lots` |
| --- | :-: |
| 창고 필터 | ⛔ 파라미터 없음 |
| 보류 수량 합계 · 가용 | ⛔ `held` boolean 뿐 |
| 「최근 전이」·사유 | ⛔ 없음 |
| **전량 보류 여부**(선택 불가 표시 · `W-03-03` §5-8) | ⛔ 없음 |

→ ⭐ **`GET /quality/lot-statuses` 신설** — 경로 **17 → 18** · 스키마 27 → 28.

⛔ **01 경로에 파라미터를 더하지 않았다.** 축이 다르고(물류 ↔ 품질), **남의 계약을 이 트랙이 고치지 않는다.**

⚠ **02 는 적합성이 계약을 「고치게」 했고**(`ValidationFinding.severity`) **03 은 「키웠다」.** ⭐ **둘 다 커버리지 검사기가 못 잡는다** — 「그릴 수 있나」를 물어야 나온다.

### 4-2. ⚠ 반쪽 둘은 **화면 설계가 이미 물러나 있다**

| 화면 | 무엇이 안 되나 | 화면이 이미 한 것 |
| --- | --- | --- |
| `W-03-01` | 이력 검색 3축 중 **판정유형**이 안 선다 | **A-11** — 「보류 이력만 보입니다」를 결과 표 머리에 |
| `W-03-05` | **불량코드 분포 데이터가 0건** | ⚠ **이건 새로 나온 것** — §4-3 |

### 4-3. ⛔ 경로는 있는데 **데이터가 없다**

`GET /quality/defect-records` 를 만드는 화면이 **셋인데 전부 03 밖이고 둘이 막혀 있다** — `M-02-02`(#83) · `P-04-03`(04 미착수) · `M-01-10`(대상 여부 불명).

⭐ **화면 골격은 선다** — `EmptyState` 로 「아직 불량 실적이 등록되는 화면이 없습니다」. **착수 가능이다.**

⚠ **「경로가 없다」와 「데이터가 없다」는 다르다.** 앞의 것은 못 그리고, 뒤의 것은 **빈 채로 그린다.**

## 5. ⭐⭐ 역방향 — **두 방향이었다**

### 5-1. 역방향 ① — 계약 → 화면

**18경로 전수.** ⭐ **부르는 화면이 0건인 경로가 없다.**

⚠ **02 는 여기서 `material-losses` 2경로를 뺐다.** 03 이 안 뺀 이유는 **2단계에서 「만들지 않을 경로 셋」을 먼저 정했기** 때문이다 — 의뢰 등록·불량 등록·특채 생성.

### 5-2. ⭐⭐ 역방향 ② — 요구서 → 계약 (**신설**)

**02 가 후속으로 남긴 검사기를 만들었다.** 그리고 **02 자신의 요구서에서 결손을 찾았다.**

```
전 요구서 인용 213 중 허공 10
   ✅ 표기 오류 6 — 고쳤다
   ⛔ 계약 결손 4 — 화면 3장 (W-02-10 · P-02-06 · P-02-08)
```

⛔ **세 화면 다 02 트랙에서 착수 통지가 나가 있다.**

⚠ **①은 자기 계약만 보면 되지만 ②는 「남의 계약을 인용한 것」이 대상이라 트랙 하나로는 절대 안 잡힌다.**

→ **상세와 권고는 `부록-역방향2-발견.md`.** ⛔ **01 계약 수정과 클라이언트 통지는 03 트랙이 임의로 하지 않는다.**

## 6. 화면이 요구했는데 계약이 안 준 것 — **1건**

전수로 봤다. 액션 53 중 「API 없음」으로 적은 것은 **9건**이고 **8건은 이유가 있다.**

| 액션 | 왜 없나 | 정상인가 |
| --- | --- | :-: |
| 모드 전환 · 보기 전환 · 정렬·페이지 | **화면 안에서 끝난다** | ✅ |
| 판정·전이 처리 → · 변경 이력 보기 · 의심자재 등록 | **화면 이동**이다 | ✅ |
| 검사 결과 수정 | **조회 화면**이다 | ✅ |
| 조건 수정 · 요청 취소 | **J-10 · B-3** — 두지 않기로 했다 | ✅ |
| 처분 선택(`P-02-13`) | **잠정**이고 확정은 04 다 | ✅ |
| 내보내기(`W-03-05`) | ⚠ **미정** — 대외비 반출 경계와 함께 판단 | ⚠ |
| ⛔ **부적합 열기**(`W-03-09`) | **04 계약이 없다** | ⛔ **아니다** |

⛔ **마지막 하나가 진짜 결손이다** — 6단계 통지 판단 대상.
