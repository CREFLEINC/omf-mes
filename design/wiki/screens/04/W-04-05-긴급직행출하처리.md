# W-04-05 · 긴급 직행 출하 처리

## §0. 요약

- **개요**: 관리웹에서 물류담당이 생산 완료품을 완제품 창고에 물리적으로 입고시키지 않고 곧바로 출하 처리하는 화면(04-S-A 직행). 확정 버튼 하나가 제품 입고 전표와 출하 전표를 같은 트랜잭션에서 함께 만드는, 04 도메인에서 유일한 자리다.
- **주요 데이터**: `goods_receipt`+`_line`(제품 입고 — `source_document_type_code`+`source_document_id` 다형) · `shipment`+`_line`+`_lot_allocation`(출하) · `trace.lot`(생산 완료 LOT) · `inventory.inventory_transaction`(입고·출고 전기 각 1건, `uq_inventory_idempotency UNIQUE(idempotency_key, business_date)`로 중복을 막는다).
- **핵심 액션**: 생산 완료분 LOT과 출하작업지시를 선택하고 상차 정보·긴급 사유(필수)를 입력한 뒤 **직행 출하 확정**을 누르면 ① 제품 입고 전표 생성 ② 출하 전표 생성(재고 차감) ③ ERP 송신 대기열 적재가 한 트랜잭션으로 일어나며, 하나라도 실패하면 전부 되돌아간다. Lot Status가 Release가 아니면 진행할 수 없다 — 건너뛰는 것은 창고 경유·피킹·포장이지 품질 게이트가 아니다.

> 작성일: 2026-08-07 · 서식: `00-화면스펙서식.md` v1.0 · 작성 주체: CREFLE OMF 팀 (UI/UX)
> ⭐ **한 버튼이 전표 두 건을 만든다.** 제품 입고와 출하가 **같은 트랜잭션**에서 일어나는 04의 유일한 자리다.
> **04-S-A 직행** — 생산 완료품이 완제품 창고를 **물리적으로 거치지 않고** 바로 나간다.

## §5. 액션·상태

### §5-1. ⭐ 원자성이 이 화면의 전부다 — **B-8**

```
① 제품 입고 전표 + 입고 전기
② 출하 전표 + 출고 전기
③ ERP 송신 outbox 적재
─────────────────────────────  ← 여기까지 한 트랜잭션
④ 실제 ERP 호출                 ← 밖
```

**셋 중 하나라도 실패하면 전부 되돌아간다.** 부분 성공이 있으면 **재고가 들어왔는데 안 나간 상태**가 남는다 — 그것이 바로 이 화면이 피하려는 것이다.

⚠ **C-2(부분 실패)를 쓰지 않는다.** 01 트랙이 「화면이 한 트랜잭션이라 C-2 를 쓰지 않았다」고 규약 편차로 기록했는데, **이 화면은 그 판단이 가장 강한 자리**다. 「①은 됐고 ②는 실패했습니다」를 보이면 **사용자가 무엇을 해야 하는지 알 수 없다.**

### §5-2. ⭐ 결과 구획이 **버튼 위에 있어야 한다** — J-7

원클릭이라 **누르기 전에 무엇이 일어나는지**를 알 수 없다. J-5·J-7이 요구하는 결과 구획을 **버튼 바로 위**에 둔다.

```
① 제품 입고 전표 생성 — 완제품 창고 입고 (장부상)
② 출하 전표 생성 — 재고 500 EA 차감
③ ERP 전표 송신 대기열 적재
⛔ 셋 중 하나라도 실패하면 전부 되돌아갑니다
⛔ OQC 검사를 건너뜁니다 — 검사 대상이면 진행할 수 없습니다
```

⚠ **「일어나지 않는 것」이 마지막 줄이다** — 정상 흐름의 검사·피킹·포장이 **전부 빠진다.** 그것을 모르고 누르면 **검사 안 한 물건이 고객에게 간다.**

### §5-3. ⛔ Release 가 아니면 **진행할 수 없다** — 결정 10은 예외를 두지 않는다

직행이라도 **Lot Status 차단은 우회하지 않는다.**

| 상태 | 동작 |
| --- | --- |
| Release | ✅ 진행 |
| **검사 대기** | ⛔ **차단** — 「OQC 판정이 나면 진행할 수 있습니다」 |
| Hold | ⛔ 차단 |

⚠ **그러면 「긴급」의 의미가 무엇인가** — 건너뛰는 것은 **물리적 창고 경유와 피킹·포장**이지 **품질 게이트가 아니다.** 화면이 그 경계를 분명히 한다.

⛔ **검사 대상이 아닌 라인**(`shipping_inspection_required = false`)이면 검사 없이 Release 일 수 있다. **그 경우가 이 화면의 정상 사용처**다.

### §5-4. 「O3 실물 합류」 — **장부와 실물이 갈리는 지점**

프로세스가 「**O3 실물 합류**」라 적었다. 물리적으로는 **생산 현장에서 트럭으로 바로** 가는데 **장부는 창고를 거친다.**

| | 물리 | 장부 |
| --- | --- | --- |
| 경로 | 생산 → 트럭 | 생산 → **완제품 창고** → 트럭 |
| 위치 기록 | 없다 | 입고 전표에 창고·위치가 남는다 |

**화면이 그 사실을 적는다** — 「완제품 창고 입고 (**장부상**)」. 안 적으면 **창고 담당이 물건을 찾으러 간다.**

⚠ **적치 위치를 무엇으로 넣는가** — `putaway_task` 를 만들면 **하지 않을 적치 지시**가 남는다. **만들지 않는다** — 입고 전표의 창고만 채우고 위치는 대표 Location 으로 둔다 → §8-2.

### §5-5. ⛔ 긴급 사유를 담을 자리가 **없다**

「긴급」이라는 예외 경로인데 **왜 긴급인지 남길 컬럼이 없다.**

| 후보 | 실측 |
| --- | :-: |
| `goods_receipt.reason_code` | ⚠ 있으나 **반품입고 등 사유**로 쓰인다(주석) |
| `goods_receipt.remarks` | ✅ text |
| `shipment.remarks` | ✅ text |
| 전용 컬럼 | ⛔ **없다** |

**A-11로 물러난다** — **`shipment.remarks` 에 적고 화면이 필수로 만든다**(A-12). 코드가 아니라 자유 텍스트라 **집계는 안 된다.**

⚠ **`W-01-13` 이 「취소 흔적 컬럼 0건」에서 승인 기록으로 물러난 것과 같은 형태**인데, **이 화면은 승인을 타지 않는다**(원클릭이 취지다). 그래서 자유 텍스트가 유일한 자리다 → §8-1.

### §5-6. 멱등 — **한 번 더 누르면 전표가 두 벌 생긴다**

```
uq_inventory_idempotency   UNIQUE (idempotency_key, business_date)
```

**C-1·C-8이 원장에서 중복을 막는다.** 그러나 **화면이 같은 키를 보내야** 막힌다.

**규칙** — 확정 버튼을 누르는 순간 **키를 고정**하고, 실패 후 재시도에도 **같은 키**를 쓴다. **새로고침하면 새 키**가 되므로 화면이 그것을 막는다(버튼 비활성 + 진행 표시).

⚠ **`business_date` 가 키의 일부다**(C-8) — 자정을 넘겨 재시도하면 **같은 키로도 두 벌이 생긴다.** 클라이언트가 영업일까지 정해 보낸다.

### §5-7. 액션

| 액션 | 활성 조건 |
| --- | --- |
| 생산 완료분 선택 | 항상 — 입고되지 않은 제품 LOT |
| 출하작업지시 선택 | LOT 선택됨 — **품목이 맞는 것만** |
| 수량 입력 | **≤ LOT 수량 AND ≤ 배정 잔여** |
| 상차 정보 입력 | 항상 — 선택 입력 |
| **긴급 사유 입력** | ✅ **필수**(§5-5 · A-12) |
| **직행 출하 확정** | **Release AND 수량 유효 AND 사유 입력** — ⚠ **확인 필요** |
| 취소 | 항상 — 화면 이탈 |
| 되돌리기 | ⛔ **두지 않는다** — 확정 전이면 `W-04-12` 에서 취소한다(`W-04-04` §5-2와 같은 건) |

## §9. 이 장에서 나온 공유 계약 후보

1. ⭐ **원클릭 화면일수록 「일어나지 않는 것」이 결정적이다** — 정상 흐름 넷을 하나로 접었으므로 **검사·피킹·포장이 전부 빠진다.** 그것을 버튼 위에 적지 않으면 **검사 안 한 물건이 고객에게 간다.** J-5가 「승인하면 무엇이 일어나는가」였다면, 이것은 **「건너뛰면 무엇이 안 일어나는가」**다 (§5-2)
2. **예외 경로라도 품질 게이트는 우회하지 않는다 — 무엇을 건너뛰는지 화면이 경계를 긋는다** — 「긴급」이 건너뛰는 것은 **물리적 창고 경유와 피킹·포장**이지 Lot Status 차단이 아니다. 결정 10에 예외를 만들면 **차단의 단일 지점이라는 전제가 무너진다** (§5-3)
3. **장부와 실물이 갈리는 화면은 「장부상」을 문구에 넣는다** — 물리적으로는 창고를 안 거치는데 전표는 거친다. 「완제품 창고 입고」라고만 쓰면 **창고 담당이 물건을 찾으러 간다.** A-11(구판 물러남 — 반영·통지 재검토 대상)의 **경로 판** (§5-4)
