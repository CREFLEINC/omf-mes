## 1. 기준정보(Master)

> 정본 = UNIMES(MES). ERP는 ~~코드·~~조직·작업자·품목·BOM·작업지시의 송신 원천이다 «(정합주: 2026-08-31 — 공통코드는 빠졌다. **MES 정본**(✓확정 2026-08-22 · B-4-3 · omf-mes#197). 거래처도 넣지 않는다(✓확정 2026-08-31))» — 단, **공정(Routing)·툴/금형/지그는 ERP 연계 대상에서 제외**한다('ERP에서 공정 정보가 없을 경우'가 실재 전제(충돌①) ✅ REQ-PR-0026 — 공정은 ERP에 존재 시 수신하는 선택 경로로 격하(As-Is 실제 운용 확인 잔여), 툴은 ERP 미사용·엑셀 관리 (REQ-PR-0003 현행)). 연계분(Legacy 출처) 기준정보의 MES 수정/삭제 불가 원칙(근거p53·54)은 **ERP 연계가 실재하는 마스터(품목·BOM·공통코드·조직·작업자·P/O)로 한정**하고, MES 정본 마스터는 수정 가능하되 **변경 이력을 필수**로 남긴다("$모든 정보는 수정 가능" ✅ REQ-PR-0021 — **적용 범위=MES 정본 마스터 전체 확정, 연계 수신본(품목·BOM·P/O)은 읽기 전용** ✓확정 2026-07-04 QA #34). **일관 원칙: 연계 원본 필드는 읽기 전용 + MES 확장 속성(개발품 플래그·하위 코드 등)은 편집 가능** (QA #34·#35 2026-07-04). 본 클러스터는 마스터 성격 엔티티만 소유한다 — 실적/이력/LOT/검사실적은 타 클러스터 소유로 참조만 한다.

### 미결 (현장 검증)
- ✓[확정 2026-06-24] **작업실적 키·분할 단위** — 작업실적 = 생산LOT 단위(1:1), W/O당 N건. 분할 기준 = **양품 목표 수량(정량 LOT)** — 회차/교대/자재배치 무관.
- ✓[확정 2026-06-24] **작업실적→생산LOT 카디널리티** — **1:1**(실적 1건=LOT 1건). 이동단위별 LOT 발행 없음(분해도 2.2.2.1 불채택). 생산LOT = 양품 목표 수량 단위.
- **LOT 발행주체 ERP 경계 충돌** — **부분 해소(2026-07-01)**: 자재LOT=경로 이원화 발번(사전부착=공급사 수용·직접부착=MES)·등록(입하 Hold)→Release(IQC 합격) ✓(✅ REQ-PR-0007 — ✓확정 2026-07-20 §재정의 #4·#5, 기존 서술 폐기: MES 발번·IQC 합격 생성). ~~잔여: 제품LOT 발번 주체~~ → **종결(2026-07-04)**: 제품LOT=**MES 발번** (✓확정 2026-07-04 QA #1 — §8.A.1 완전 종결). 역추적=포장구성 경유 확정(QA #2 — C3 참조).
- **W/O 자원배정 vs 4M투입 분리 [확인필요]** — '배정(계획)'과 '투입(실적)'을 2엔티티로 분리했으나, 원본은 양쪽 모두 설비·작업자·자재·툴 4M으로 동일 어휘 사용. 단일 엔티티 상태전이(배정→투입)로 통합할지 분리 유지할지 — **현장 검증 대상에서 제외, CREFLE 내부 설계 결정으로 전환** (QA §1 전환 D11, 2026-07-04) → **종결(2026-07-06)**: **분리 유지 확정** + 4M투입에 배정 참조(nullable FK) 추가, 키=surrogate+논리 유니크(W/O·자원유형·자원ID) — [확인필요] 해소 (✓설계확정 2026-07-06 결정 04).
- **P/O 소유 경계** — ERP 발행·MES 수신(수정 없음) 구조가 현장 검증됨(✅ REQ-PR-0024 — D.10 확정). 연계 수신 테이블 vs 소유 엔티티 표기 조율은 유지. ~~P/O 변경 무시·강행 옵션 필요 여부~~ → **종결(2026-07-04)**: 강행 옵션 필요 — 관리자 확인 화면에서 '변경 반영 vs 기존 유지(강행)' 선택+강행 시 P/O-W/O 불일치 플래그 (✓확정 2026-07-04 QA #23 — E11·D10 완전 종결).
- **전달사항 vs 현장 Popup 전달(클러스터 4) 중복** — 본 클러스터 전달사항(근거p30)과 현장관리 '관리자→작업자 정보 전달'(근거p32·61, 클러스터 4)이 동일 데이터일 가능성. 소유 클러스터 단일화 — **현장 검증 대상에서 제외, CREFLE 내부 설계 결정으로 전환**(QA §1 전환 C1, 2026-07-04) → **종결(2026-07-06)**: 전달사항+공지사항+현장 Popup='공지/전달(Notice)' 단일 엔티티(scope: 전사/사업부/설비그룹/작업조/W-O + 표시방식: Popup 강제·확인 요구 + 수신자별 확인이력 1:N). 알림(§6.5)과의 경계=자동(시스템 이벤트 발송)/수동(사람 작성 게시) 확정(✅ REQ-PR-0016) (✓설계확정 2026-07-06 결정 02).

## 3. LOT/추적 (코어)

> 생산 추적성의 중심. **자재→생산→제품 LOT 승계**가 핵심. 발행 주체: **자재LOT=경로 이원화(사전부착=공급사 번호 MES 수용·등록/직접부착=MES 발번) ✓확정(2026-07-20 §재정의 #4)** — 라이프사이클: **입하 시 등록(Lot Status=Hold) → IQC 합격 시 Release → 분할·부분출고·잔량 관리**(✅ REQ-PR-0001·0007 · ✓확정 2026-07-20 §재정의 #5, 기존 서술 폐기: 사전발행(선택)→입하→IQC→합격 시 생성/활성의 2단계 라이프사이클. 원본 p.57 'ERP부문' 도식 폐기 이력 유지). 생산LOT=MES 선발행(**선발행=번호 슬롯 예약, 실물은 양품만 귀속** ✓확정 2026-07-15). **제품LOT=MES 발번 ✓확정 — LOT 3종 전부 MES 발번** (✓확정 2026-07-04 QA #1 — §8.A.1 종결, 기존 서술 폐기: 원본 p.57 'ERP부문' 도식 기반 잔여 미결). **생산불량LOT(신규, 2026-07-15)=MES 파생 발행** — PQC 판정·현장 발견·의심자재로 생산LOT에서 제외된 물량을 W/O 직접 귀속으로 별도 추적(design/raw/decisions/2026-07-15-생산불량LOT-정책-확정기록.md).

LOT 코어(자재LOT·생산LOT·제품LOT·인식표·포장단위)는 **클러스터 3 소유** — 재정의하지 않고 정본 명칭으로 참조만 한다. 창고/Location·품목(Item)은 **클러스터 1 소유**, 검사(수입검사/출하검사 실적)·Lot Status는 **클러스터 4 소유**, W/O·작업실적은 **클러스터 2 소유**로 참조. `[창고제안]`(ERP+바코드, raw/02)과의 차이는 비고에 §8.1 기준으로 명시(충돌 시 MES 우선). **출하 상위지시의 원천은 ERP가 아니라 고객사 출하지시서(엑셀) import**(충돌② ✅ REQ-PR-0029 — 기존 가설 폐기: ERP 출하지시 발행·수신 전제). 3계층 골격(상위지시(nullable) → MES 출하작업지시 → ERP 전표)은 유지하되 상위지시=고객사 지시서.
