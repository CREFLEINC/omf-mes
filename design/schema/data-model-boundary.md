# 데이터 모델 경계 — 「타입·길이」만 준다

> ⛔⛔ 사용자 확정 2026-08-18: **데이터 모델링은 설계 결정을 앞설 수 없다.**
> 이 원칙은 `docs/research/2026-07-23-데이터모델링/` 폴더가 삭제된 뒤에도 존속하는 지식이다
> — 폴더가 없어졌다고 이 규칙이 없어지는 것이 아니다.

## 누가 무엇을 정하나

| 무엇 | 누가 정하나 |
| --- | :-: |
| **무엇을 받나**(어떤 필드를 두나) | ⭐ 설계 |
| **필수인가 선택인가** | ⭐ 설계 |
| **어떤 값이 오나**(값 목록) | ⭐ 설계 또는 고객 설정 마스터 |
| **타입·길이** | 물리 모델 도메인을 그대로 쓴다 |

⛔ 모델의 `NOT NULL`·`CHECK`·`UNIQUE`를 근거로 화면의 필수·구성을 정하지 않는다. 확정과
모델이 어긋나면 **확정이 이긴다**.

## 왜 못박나 — 실측 사례 (uiux/CLAUDE.md 원문 보존)

| 어디 | 무슨 일이 있었나 |
| --- | --- |
| 폐기 출고 계약 | 도착지가 없는 경우가 성립하는데 모델이 「비울 수 없음」이니 모델이 바뀐 뒤에 고치자고 적었다 |
| 작업 실적 등록 | 정본이 「회차·교대 무관」인데 `NOT NULL`을 보고 교대를 필수로 받아 적어 계약까지 내려갔다 |
| 공정 등록 | 「유효 시작일(선택)」을 필수로 뒤집고 「제약은 하류가 정본」을 원칙으로 적었다 |

## 모델이 화면 요구를 못 담을 때

1. 계약은 화면대로 쓴다
2. **업무 「사실」을 계약·스펙에 적는다** — 「도착지가 없는 폐기 출고가 성립한다」처럼.
   내부 주석에 모델 결손과 근거(확정·요청 번호)를 남긴다
3. **거기서 끝이다 — 기다리지 않는다.** 그다음에 우리가 할 일은 없다

### ⭐ 「담당에게 통지한다」는 절차가 아니다 (2026-09-03 V3)

옛 ③ 은 「데이터 모델 담당(백엔드팀)에게 통지한다」였다 «(구표기 보존)». `multi-agent-team-workflow-v3.md`
규칙 2 아래 **설계팀 → 개발팀 직접 소통은 「설계 변동 공지」 이슈 하나뿐**이고, 그 공지는 배포를
선언할 때 **바뀐 파일 목록만** 싣는다(규칙 5). ⇒ **결손 하나를 알리는 별도의 「통지」 행위는
어디에도 없다.**

| 단계 | V3 에서 실제로 일어나는 일 |
| --- | --- |
| 우리가 하는 것 | 계약·스펙에 **업무 사실을 적고 커밋한다.** 여기까지다 |
| 전해지는 방법 | 다음 **설계 변동 공지**에 그 «파일»이 한 줄로 실린다(`.claude/skills/design-change-notice/`) |
| 개발팀이 하는 것 | 저장소를 **직접 열람해** 내용을 확인하고, 처리 방식도 스스로 정한다 |

⭐ **그래서 「기다리지 않는다」가 전보다 더 강하다** — 답을 받을 채널 자체가 없다. 설계팀은
개발팀의 업무 진행 정보를 **보유하지 않는다**(2026-09-03 사용자 확정).

⚠ 「⏳ 회신 대기」(고객·팀 리더 확정처럼 **답이 와야 다음이 되는 것**)와 헷갈리지 않는다.
판별은 하나다 — **「그 답이 없으면 내가 지금 못 하는 일이 있나」.** 없으면 적고 끝낸다.

### ⛔ 적는 것과 적지 않는 것

| | 무엇 | 예 |
| :-: | --- | --- |
| ✅ | **업무 사실** | 「도착지가 없는 경우가 성립한다」 · 「이 칸은 비는 경우가 있다」 · 「교대는 작업 실적과 무관하다」 |
| ⛔ | **모델·구현 지시** | 「널 가드를 넣어 달라」 · 「`NOT NULL` 을 풀어 달라」 · 「이 컬럼을 만들어 달라」 |

모델링 «방식»은 백엔드팀이 정한다. 우리가 그것을 지시하면 규칙 2 가 닫은 문을 우회하는 것이고,
설계 소관 밖의 결정을 우리가 하는 것이다.

### 표기 — 스펙·계약 본문에 쓰는 것

| 표기 | 언제 | 뜻 |
| --- | --- | --- |
| ⏳ **회신 대기** | 고객·팀 리더 확정 | **답이 와야 다음이 된다** — 우리가 막힌다 |
| 📄 **기록만** | 모델 결손·구현 소관 | 적고 끝낸다 · **우리 차단 없음** |

⚠ V3 이전 문서에 남은 **「📨 작업 통지」는 📄 기록만과 같은 뜻이다** «(정합주: 2026-09-03 V3 로
「통지」 행위가 없어졌다 — 표기만 남았다)». 소급해 고치지 않는다. **새로 쓸 때는 📄 기록만**으로 적는다.
