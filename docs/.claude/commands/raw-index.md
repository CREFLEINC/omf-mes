description: raw/ 자료 목록(research/raw-자료-목록.md) 갱신
---

raw/ 의 자료 목록을 갱신한다. raw/는 읽기 전용이므로 절대 수정하지 않고 읽기만 한다.

1. raw/ 를 재귀적으로 훑어 전체 파일 목록을 만든다.
2. `research/raw-자료-목록.md` 를 갱신한다. 표 형식: `| 경로 | 형식 | 확인일 | 내용 요약 |`
3. 목록에 없는 새 파일은 내용을 열어 2~3문장으로 요약해 추가한다 (PDF도 Read 도구로 읽는다). 기존 항목의 요약은 유지한다.
4. 목록에 있지만 raw/에서 사라진 파일은 행을 지우지 말고 요약 끝에 `(삭제됨, YYYY-MM-DD)` 를 덧붙인다.
5. 문서 머리의 갱신일을 오늘로 바꾼다.
