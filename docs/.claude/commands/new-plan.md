새 기획안을 시작한다: $ARGUMENTS

1. planning/ 의 기존 기획안을 확인해 주제가 겹치지 않는지 본다. 겹치면 사용자에게 확인한다.
2. `planning/YYYY-MM-DD-<제목>.md` 작업본을 만든다 (날짜는 오늘). 문서 머리는 CLAUDE.md의 blockquote 형식을 따르고, 버전은 `v0.1 — 작성 중`. 문서 끝에 빈 '변경 이력' 표를 둔다.
3. research/ 와 raw/ 를 훑어 이 주제와 관련된 자료를 찾아 '근거 자료'에 경로를 채운다 (raw/는 읽기만 한다).
4. 기획안에 들어갈 목차(섹션 골격)를 제안하고 사용자 의견을 확인한 뒤 본문 작성을 시작한다.
