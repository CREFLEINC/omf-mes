01
Overview

6개 도메인 · 도식 구성 원칙

각 도메인 = 메인 구조도(정상 주 흐름) + 사이드 구조도(복잡 예외 분리). 확정 근거가 있는 요소만 그리고, 미확정 지점은 빨간 미정의 마커로 노출해 협의 대상을 명시한다.

01자재창고관리자재 입하부터 검사·적치·출고·실사·반품/폐기까지 자재창고 전 흐름
02생산실행생산계획 수신부터 작업 실행·실적 수집·W/O 마감·ERP 회신까지
03품질관리공정검사(PQC) 수행부터 합부 판정·불량 처리·처분까지
04제품출하출하지시 접수부터 Picking·OQC·Packing·출하 확정까지
05설비툴관리설비 점검 루프·작업 전 통제·툴 PM·보전·비가동 관리
06기준정보연계신규 품목 기준정보 온보딩과 ERP↔MES 마스터 연계 체계
02
How to read

도식 읽는 법 공통 범례 — 전 도메인 동일 문법

핵심 규칙
  • 상태 박스 색 — 빨강=흐름 시작 · 검정=진행 중 · 파랑=완료
  • 작업자 아래로 행위 체인 전개 — 모바일(스캔) · 화면 · 문서 · 목록 선택
  • MES 기록 = 서버 아이콘 + 초록 노트(KEY·기록 항목·상태)
  • ERP 연계 = 원통 아이콘 + 조건 헥사곤(예: 합격품 한정 G/R 송신)
  • 검정 헥사곤 = 조건·분기 / 회색 화살표 = 대안·생략·타 도식 위임
  • 빨간 봉투 = 미정의 — 협의·후속 결정 대기 지점
39전 도메인의 미정의 마커 총계 — 각 도식에 위치와 사유가 표기되어 있으며, 협의에서 하나씩 확정한다

Domain 01 · 자재창고관리

메인 — 입하 · 검사 · 적치 자재 도착부터 적치 완료까지

자재 도착 → 수입 검사(IQC) → 입하 완료 → 위치 적치 → 적치 완료 (불합격 → 반품)
핵심 확정 규칙
  • 자재LOT은 IQC 합격 시점에 MES가 발행 — 1입하 다LOT 지원
  • 수량 초과분은 별도 입하로 분리 생성 후 P/O 등록 처리
  • 거래명세서 스캔으로 입하 목록 자동 생성(수기 등록은 대안)
  • 위치 확인·코드 검증은 생략/강제 변경 가능한 설정형
  • 검사기준은 MES 정본 — 검사 결과는 ERP로 보내지 않음

Domain 01 · 자재창고관리

사이드 — 출고 · 생산창고 · 이동 · 실사 · 반품

A. 자재 출고FEFO/FIFO 피킹 · 출고 QR 항상 발행
B. 생산창고·호퍼출고 QR 입고 스캔 · 호퍼 잔량 실측 · 재생재 등록
C. 이동·불량 반출출/입 양방향 스캔 기록 · 불량은 불량창고 반출
D. 실사·조정장부-실물 대조 · 조정은 수불 트랜잭션으로 기록
E. 반품·폐기불합격·초과분 반품 · 품의 기반 폐기(기타출고)
타 도식 경계
출고요청 ← 024M 투입·라인 검증 → 02재작업/폐기 판정 → 03G/R 송신 = 이 도식
7미정의 — 수량 부족 입하 처리 · 부분 불량 판정 · 실사 동결/승인 권한 · 폐기 계정 항목 등

Domain 02 · 생산실행

메인 — P/O 수신부터 W/O 마감까지

P/O 수신 → W/O 배포 → 생산 진행 → 생산LOT 완료 → 전 공정 완료 → W/O 마감
핵심 확정 규칙
  • W/O 전개 기준: 공정(Routing)=MES 정본 · BOM=ERP 수신본
  • W/O 배포 시 생산LOT 선발행 · Routing Rev 스냅샷 고정
  • 작업 전 점검 = 진행 선행조건 — 통제는 차단/경고/미적용 설정형
  • 실적 = 생산LOT 1:1 · 양품/불량/손실 3원 집계(수율 분리)
  • 인식표 = 양품 개체별 1:1 발행 · 불량품은 수량만 집계

Domain 02 · 생산실행

사이드 — 홀드 · 러닝체인지 · P/O 변경 · 긴급 직행

A. 작업 홀드사유 선택 · 홀드품 라인사이드 적치 · N회 재개 가능
B. 러닝체인지설비 무중단 부품 교체 — W/O 유지 · 생산LOT만 분할
C. P/O 변경관리자 확인 후 반영 또는 강행(불일치 플래그)
D. 긴급 W/O 직행P/O 비귀속 · 점검 우회 — 실적 기록은 정상과 동일
타 도식 경계
긴급 직행 출하 → 04PQC → 03불량 반출 → 01마감 실적 송신 = 이 도식
8미정의 — 오투입 NG 시 차단/강행 · WIP 이동 단위 · 초과 생산 LOT 추가 발행 · 긴급 자재 조달 경로 등

Domain 03 · 품질관리

메인 — 공정검사(PQC)와 판정 · 불량 처리

검사 대상 → 측정 완료 → 판정(Release / Hold) → 불량창고 입고 → 재작업 양품화 / 폐기
핵심 확정 규칙
  • PQC는 Routing에 검사 공정 명시 시만 수행(opt-in 설정형)
  • IQC·PQC·OQC 3종 = 단일 검사실적 구조 · 기록은 3계층
  • 출고·출하 차단은 Lot Status 단일 지점만 참조 · 전이 전수 이력화
  • 불량은 불량창고 우선 입고 후 재작업/폐기 2분류
  • 판정 불량은 검사실적에만 기록 — 작업실적과 중복 집계 방지

Domain 03 · 품질관리

사이드 — 수리 왕복 · 상태 전이 · 측정 I/F · 계측기 · 불량코드

A. 수리 왕복수리 투입·반출 추적 · I/O 검사부터 계보 재개
B. Lot Status 전이수명주기·품질판정·작업홀드 3축 분리 정의
C. 설비 데이터 I/F캠데코 측정치 표준 I/F 수집 · 1차는 상하한 판정
D. 계측기 검교정검교정 유효한 계측기만 검사에 사용
E. 불량코드 2계층대분류+상세 · 현장엔 공정 매핑 코드만 노출
타 도식 경계
IQC 상세 = 01OQC 상세 = 04판정 의뢰 ← 01·04ERP 화살표 0 (비연계)
6미정의 — 판정 유형 목록·통제 수준 · 특채/한도승인 절차 · 폐기 계정 · 알람 유형 등

Domain 04 · 제품출하

메인 — 지시 접수부터 출하 확정까지

지시서 수신 → 출하지시 등록 → Picking → OQC 합격 → Packing → 출하 완료(PGI)
핵심 확정 규칙
  • 출하지시 = 고객사 문서 import(D+1 분량) · 일부 시간대별 슬롯
  • 선출 정책 품목별 — 유효기한 품목 FEFO · 그 외 FIFO
  • Hold LOT은 피킹 차단 — Lot Status 단일 지점 참조
  • 납품라벨 = OQC 합격 시 출력 · 매칭 불일치 시 부착 차단
  • 포장라벨 사전발행 → Packing 확정 시 활성 · 미사용분 폐번

Domain 04 · 제품출하

사이드 — 긴급 직행 · 재작업 · 반품 · 포장 재구성

A. 긴급 직행 출하창고 적치 생략 직행 · 입고+출하 기록 원클릭 자동 생성
B. OQC 불합격재작업 적치 후 양품화 · 출하 흐름 재진입
C. 반품·클레임불량창고 반품입고 통일 · 원천 구분 기록
D. 포장 재구성합병/분할 단일 이벤트 기록 · 신규분 새 라벨 발번
타 도식 경계
긴급 직행 ← 02반품 판정 → 03공급사 반품 = 01PGI 송신 = 이 도식
4미정의 — 출하지시서 샘플 양식 · 납품라벨 형식 · 판정 유형 목록 · 반품 ERP 연계 방식

Domain 05 · 설비툴관리

메인 — 설비 점검 루프와 작업 전 통제

점검주기 도래 → 점검 수행 → 이력 등록 → 작업전 통제 → 생산 진행 → (다음 주기 루프)
핵심 확정 규칙
  • 작업 전 통제 = 차단/경고/미적용 3단계 설정형
  • 긴급 W/O는 통제 우회 허용 — 우회·경고 진행도 기록
  • 점검 NG·가동 중 고장 → 보전 트리거(점검=진단 · 보전=조치)
  • 점검자·작업자 = 로그인 없이 사번 입력 식별
  • PM 트리거 = 타발수+날짜 주기 겸용 설정형

Domain 05 · 설비툴관리

사이드 — 툴 PM · 경량 보전 · 데이터 수집 · 비가동

A. 툴/금형 PMQR 식별 · 타발수 수동 기입(환산 옵션) · 도달 시 PM
B. 경량 보전점검 NG·고장·PM 예정 합류 → 지시·실적·예비품 기록
C. 표준 I/F 수집캠데코 1차 적용 · 두절 시 POP 버퍼링 후 자동 동기화
D. 비가동 기록계획=캘린더 계층형 · 실적=현장 수집 2원 관리
타 도식 경계
W/O 중단 = 02 소유측정값 → 03ERP 아이콘 0 — MES 단독 정본
7미정의 — 점검 매체(POP) 확정 · 설비 대장 매체 · 알람 유형 포함 여부 · 공장 배치도 회수 등
13
Domain 06 · 기준정보연계

메인 — 신규 품목 온보딩 축

신규품목 발생 → ERP 마스터 등록 → MES 수신반영 → Routing 등록 → 검사기준 등록 → 기준정보 완성
핵심 확정 규칙
  • ERP 수신 마스터 = 품목·BOM·공통코드·조직·작업자 5종 한정
  • Routing·검사기준·툴·창고·예비품 = MES가 정본
  • 수신본 원본은 읽기 전용 — MES 확장 속성만 편집
  • Routing 수정 = 신규 Rev 발행만 · W/O 전개 시 스냅샷 고정
  • PQC = Routing 명시 공정만(opt-in) + 품목·공정 생략 설정
