OMF는 어떻게 구성되는가

OMF는 2가지 핵심 서브 유닛에서 출발한다 — 갇힌 제조 데이터를 여는 OMF-DX, 생산 워크플로우를 운영하는 OMF-MES. 두 유닛이 만든 데이터 위에 3가지 AI 역할을 별도 솔루션으로 얹어, OMF 환경 안에서 모든 서브 유닛과 유기적으로 연결한다. 일반적인 스마트 팩토리가 아니라 AX(AI 전환) 스마트 팩토리가 목표인 만큼, AI의 도입과 역할이 구성의 중심에 놓인다.

2

AI 3대 역할 각 역할의 핵심 기술과 1단계 목표

LLM의 등장으로 과거 로직·이미지 처리에 치중했던 제조 현장 AI의 역할이 다시 가시화됐다. OMF가 계획 중인 AI 역할은 크게 3가지다.

AI-1 1단계 포함

RAG 기반 정보 조회

제조 환경의 데이터를 모두 Vector화해, 필요한 정보를 빠르고 정확하게 조회한다.

핵심 기술
제조 환경의 데이터를 모두 Vector화하는 기술. 딥러닝 기반 Vector 모델과 다양한 기술을 접목해 빠르고 정확한 Vector 모델·데이터 파이프라인을 구축한다.
flag1단계 목표 — 제조 데이터에 최적화된 Vector 모델 확보
AI-2 1단계 포함

AI Agent 기반 생산계획 자동화 (APS)

MES의 생산 실적 평가를 기반으로 점진적 학습을 거쳐, 고객에게 최적화되는 성장형 Agent가 된다.

핵심 기술
상황 판단을 위한 Long Context 관리와, 지속적 성장(학습)이 가능한 sLM 모델 구축이 핵심으로 판단된다.
flag1단계 목표 — 점진적 성장이 가능한 sLM 구축과 성장 파이프라인 구축
AI-3 1단계 제외

포괄적 이상 감시 AI Agent

LLM은 사용자와의 소통 도구가 되고, 이상 탐지는 Transformer 기반 이상 탐지 딥러닝 모델을 사용하는 방향으로 본다.

난이도
이상 탐지 영역은 난이도가 매우 높아 기술 연구 기간이 필요하다는 판단이다.
schedule1단계 제외 — 본 단계에서는 이상 감시 Agent 유닛을 개발 범위에서 제외
insights

AI의 정의 — 넓게, 그러나 LLM이 다시 연 가능성

어떤 방식·형태든 컴퓨터가 의사 결정을 할 수 있으면, 로직이든 통계든 AI가 될 수 있다. 다만 과거 딥러닝·이미지 처리에 치중해 한계를 보였던 제조 현장 AI 도입은 LLM(대형 언어 모델)의 등장으로 다시금 가능성과 역할이 가시화되고 있다.
