아래 요구사항은 앞서 정의한 작업지시·자재투입·생산실적·품질관리 구조를 전제로 합니다.

* MES 관리 대상 공정별 작업지시를 생성한다.
* MES 미관리 공정도 전체 라우팅에는 유지한다.
* 자재 LOT는 작업지시의 자재투입과 연결한다.
* 생산실적은 반제품·완제품 생산 LOT와 연결한다.
* 품질판정에 따라 LOT의 사용 가능 여부를 통제한다.
* 부분 생산, 복수 자재 LOT 투입, LOT 분할·병합을 지원한다.
* 공급사 LOT부터 출하 LOT까지 정방향·역방향 추적이 가능해야 한다.

# MES 핵심 기능 요구사항 ⑤ LOT 추적성

## 1. 기능 목적

LOT 추적성 기능은 자재의 입고부터 생산, 품질검사, 재고이동, 출하까지 발생하는 모든 LOT의 생성·변경·사용·이동 관계를 기록하고 조회하는 기능이다.

LOT 추적성은 다음 질문에 답할 수 있어야 한다.

* 이 완제품을 생산할 때 어떤 자재 LOT를 사용했는가?
* 특정 자재 LOT가 어떤 반제품·완제품에 사용되었는가?
* 해당 제품은 어느 작업지시, 공정, 설비, 금형, 작업자가 생산했는가?
* 품질문제가 발생한 LOT의 영향범위는 어디까지인가?
* 해당 LOT가 어느 창고에 있으며 어느 고객에게 출하되었는가?
* LOT가 분할·병합·재작업된 이후 현재 어떤 LOT로 존재하는가?

기본 추적 구조는 다음과 같다.

```text
공급사 LOT
→ 내부 자재 LOT
→ 자재재고
→ 자재투입
→ 공정별 작업지시
→ 생산실적
→ 반제품·완제품 생산 LOT
→ 품질판정
→ 재고이동
→ 포장·출하 LOT
→ 고객 출하
```

---

# 2. 용어 정의

## 2.1 LOT

동일한 생산·입고·품질·추적 조건으로 관리되는 자재 또는 제품의 추적 단위이다.

LOT는 단순히 번호만 의미하지 않으며 다음 정보를 포함하는 관리단위이다.

* 대상 품목
* 수량
* LOT 유형
* 생성 근거
* 생성일시
* 품질상태
* 재고상태
* 보관위치
* 상위·하위 LOT 관계
* 작업지시 및 생산실적 관계

## 2.2 공급사 LOT

공급사가 부여한 자재의 원래 LOT 번호이다.

## 2.3 내부 자재 LOT

자재 입하·검사·입고 과정에서 MES가 생성하거나 관리하는 자재 LOT이다.

공급사 LOT가 없는 경우 내부 기준에 따라 대체 LOT를 생성할 수 있다.

## 2.4 생산 LOT

작업지시와 생산실적을 통해 생성된 반제품 또는 완제품의 LOT이다.

## 2.5 포장 LOT

박스, 팔레트, 컨테이너 등 포장단위로 묶인 추적단위이다.

## 2.6 출하 LOT

고객에게 출하하는 품목과 수량을 추적하기 위해 구성된 출하단위이다.

하나의 출하 LOT에 여러 생산 LOT가 포함될 수 있다.

## 2.7 LOT 계보

원자재 LOT가 생산과정을 거쳐 반제품·완제품·출하 LOT로 변환되는 부모·자식 관계이다.

## 2.8 정방향 추적

특정 자재 LOT가 어떤 생산품과 출하에 사용되었는지를 조회하는 것이다.

```text
자재 LOT
→ 작업지시
→ 생산 LOT
→ 출하 LOT
→ 고객
```

## 2.9 역방향 추적

특정 완제품·출하 LOT를 생산할 때 어떤 자재 LOT와 생산조건을 사용했는지 조회하는 것이다.

```text
출하 LOT
→ 생산 LOT
→ 생산실적
→ 작업지시
→ 자재 LOT
→ 공급사 LOT
```

## 2.10 LOT 분할

하나의 LOT 수량을 둘 이상의 독립적인 LOT 또는 재고단위로 나누는 것이다.

## 2.11 LOT 병합

둘 이상의 LOT 또는 재고단위를 하나의 관리단위로 합치는 것이다.

원본 LOT 식별정보는 병합 이후에도 유지해야 한다.

# 3. LOT 유형

시스템은 최소한 다음 LOT 유형을 지원해야 한다.

| LOT 유형    | 주요 발생 시점        |
| --------- | --------------- |
| 공급사 LOT   | 공급사 납품          |
| 내부 자재 LOT | 자재 입고           |
| 반제품 LOT   | 중간 생산공정 완료      |
| 완제품 LOT   | 최종 생산 완료        |
| 재작업 LOT   | 불량품 재작업         |
| 잔량 LOT    | 자재 또는 생산품 잔량 분리 |
| 포장 LOT    | 박스·팔레트 포장       |
| 출하 LOT    | 고객 출하           |
| 대체 LOT    | 공급사 LOT가 없는 경우  |
| 격리 LOT    | 품질 보류·불합격 분리    |

품목과 공정에 따라 사용하지 않는 LOT 유형은 비활성화할 수 있어야 한다.

---

# 4. 기본 데이터 관계

```text
품목
 └─ LOT
     ├─ LOT 재고
     ├─ LOT 품질이력
     ├─ LOT 이동이력
     ├─ LOT 분할·병합이력
     ├─ 자재투입이력
     ├─ 생산실적
     ├─ 상위 LOT
     └─ 하위 LOT
```

LOT의 계보 관계는 다대다 구조를 지원해야 한다.

```text
여러 자재 LOT
→ 하나의 생산 LOT
```

```text
하나의 자재 LOT
→ 여러 생산 LOT
```

# 5. 기능적 요구사항

## FR-LT-001 LOT 관리대상 설정

시스템은 품목별로 LOT 관리 여부와 관리방식을 설정할 수 있어야 한다.

설정항목은 다음을 포함한다.

* LOT 관리 여부
* 공급사 LOT 필수 여부
* 내부 LOT 생성 여부
* 생산 LOT 생성 여부
* 개별 일련번호 관리 여부
* LOT 분할 허용 여부
* LOT 병합 허용 여부
* 유효기간 관리 여부
* 품질판정 필수 여부
* 출하 LOT 관리 여부

---

## FR-LT-002 내부 자재 LOT 생성

자재 입고 시 내부 자재 LOT를 생성할 수 있어야 한다.

내부 자재 LOT에는 최소한 다음 정보가 포함되어야 한다.

* 내부 LOT 번호
* 자재 품목
* 공급사
* 공급사 LOT
* 입하번호
* 입고번호
* 입고일자
* 제조일자
* 유효기간
* 입고수량
* 단위
* 품질상태
* 재고상태
* 최초 보관위치

---

## FR-LT-003 공급사 LOT 연결

내부 자재 LOT는 공급사 LOT와 연결할 수 있어야 한다.

하나의 공급사 LOT를 여러 차례 나누어 입고한 경우 여러 내부 LOT와 연결할 수 있어야 한다.

```text
공급사 LOT S001
├─ 내부 LOT M001: 100kg
├─ 내부 LOT M002: 150kg
└─ 내부 LOT M003: 50kg
```

---

## FR-LT-004 공급사 LOT 미존재 처리

공급사가 LOT 정보를 제공하지 않는 경우 내부 대체 LOT를 생성할 수 있어야 한다.

대체 LOT 생성기준은 다음 정보를 조합하여 설정할 수 있어야 한다.

* 공급사
* 품목
* 입고일자
* 입하번호
* 순번

대체 LOT에는 공급사 LOT 미제공 여부와 생성사유를 기록해야 한다.

---

## FR-LT-005 LOT 번호 자동 생성

LOT 번호는 설정된 규칙에 따라 자동 생성할 수 있어야 한다.

예시:

```text
품목코드-생산일자-순번
MAT001-20260715-001
```

또는:

```text
공장-공정-생산일자-근무조-순번
VN-INJ-20260715-D-001
```

LOT 번호 생성규칙은 품목군, 공장, LOT 유형별로 설정할 수 있어야 한다.

---

## FR-LT-006 LOT 번호 중복 방지

동일한 LOT 관리범위에서 LOT 번호가 중복 생성되지 않아야 한다.

바코드 재스캔, 네트워크 재전송 또는 버튼 중복 클릭이 발생해도 동일 LOT가 중복 생성되지 않아야 한다.

---

## FR-LT-007 생산 LOT 생성

생산실적을 기준으로 반제품 또는 완제품 생산 LOT를 생성할 수 있어야 한다.

생산 LOT에는 다음 정보가 포함되어야 한다.

* 생산 LOT 번호
* 품목
* 작업지시
* 생산실적
* 생산공정
* 생산일자
* 실제 근무조
* 설비
* 금형
* 작업자
* 생산수량
* 양품수량
* 품질상태
* 재고상태
* 적용 라우팅 및 버전

---

## FR-LT-008 생산 LOT 생성시점 설정

생산 LOT 생성시점은 품목·공정별로 다음 중 하나를 설정할 수 있어야 한다.

* 작업 시작 시
* 최초 생산실적 등록 시
* 일정 수량 완료 시
* 박스 완료 시
* 팔레트 완료 시
* 근무조 종료 시
* 자재 LOT 변경 시
* 작업지시 완료 시
* 사용자 수동 생성 시

---

## FR-LT-009 하나의 작업지시에서 복수 생산 LOT 생성

하나의 작업지시에서 여러 생산 LOT를 생성할 수 있어야 한다.

예시:

```text
작업지시 WO-001: 10,000개

생산 LOT P001: 3,000개
생산 LOT P002: 3,000개
생산 LOT P003: 4,000개
```

LOT 분리기준은 다음과 같이 설정할 수 있어야 한다.

* 생산일자
* 근무조
* 설비
* 금형
* 자재 LOT 변경
* 공정조건 변경
* 품질판정
* 포장단위
* 고객 요구사항

---

## FR-LT-010 여러 생산실적의 동일 LOT 연결

같은 조건에서 연속 생산된 여러 부분 생산실적을 하나의 생산 LOT에 연결할 수 있어야 한다.

생산 LOT의 수량은 연결된 유효 생산실적의 합계와 일치해야 한다.

---

## FR-LT-011 자재 LOT와 생산 LOT 연결

LOT 추적 대상 자재는 자재투입·생산실적을 통해 생산 LOT와 연결되어야 한다.

기본 관계는 다음과 같다.

```text
자재 LOT
→ 자재투입
→ 공정 작업지시
→ 생산실적
→ 생산 LOT
```

---

## FR-LT-012 복수 자재 LOT 사용관계 관리

하나의 생산 LOT에 동일 품목 또는 서로 다른 품목의 여러 자재 LOT가 사용될 수 있어야 한다.

```text
생산 LOT P001
├─ Resin LOT R001
├─ Insert LOT I005
├─ Gasket LOT G003
└─ Harness LOT H008
```

각 자재 LOT별 사용수량을 저장해야 한다.

---

## FR-LT-013 하나의 자재 LOT의 복수 생산 LOT 사용

하나의 자재 LOT가 여러 생산 LOT에 나누어 사용될 수 있어야 한다.

```text
Resin LOT R001
├─ 생산 LOT P001: 50kg
├─ 생산 LOT P002: 30kg
└─ 생산 LOT P003: 20kg
```

사용수량 합계는 해당 자재 LOT의 가용수량을 초과할 수 없어야 한다.

---

## FR-LT-014 자재 LOT 전환구간 관리

작업지시 수행 중 자재 LOT가 변경되면 변경 전후 생산 LOT 또는 생산구간을 구분할 수 있어야 한다.

구분방법은 다음 중 하나 이상을 지원해야 한다.

* 생산실적 순번
* 전환시각
* 생산수량 범위
* 생산 LOT 분리
* 작업자 지정 전환점

---

## FR-LT-015 MES 미관리 공정의 LOT 관계 유지

MES 미관리 공정에 별도 작업지시와 생산실적이 없더라도 전체 라우팅 관계가 끊어지지 않아야 한다.

예시:

```text
사출 생산 LOT
→ 사상 공정(MES 미관리)
→ 조립 작업지시
```

조립 공정 투입 시 사출 생산 LOT를 스캔하거나 선택하여 앞뒤 관리 공정 간 LOT 관계를 연결할 수 있어야 한다.

---

## FR-LT-016 공정 간 LOT 인계

선행 MES 관리 대상 공정에서 생성된 생산 LOT를 후속 공정에 투입할 수 있어야 한다.

후속 공정 투입 시 다음을 검증해야 한다.

* 품목 적합성
* 라우팅 순서
* 선행 공정 완료 여부
* 품질상태
* 가용수량
* 보류·격리 여부
* 동일 LOT 중복 투입 여부

---

## FR-LT-017 부분수량 공정 인계

하나의 생산 LOT 전체가 아니라 일부 수량만 후속 공정에 인계할 수 있어야 한다.

```text
사출 LOT P001: 5,000개

조립 공정 투입
- 1차: 2,000개
- 2차: 1,500개
- 잔여: 1,500개
```

LOT별 가용수량과 공정 투입수량을 관리해야 한다.

---

## FR-LT-018 LOT 분할

하나의 LOT를 여러 LOT 또는 재고단위로 분할할 수 있어야 한다.

분할 시 다음 정보를 기록해야 한다.

* 원본 LOT
* 신규 LOT
* 분할 전 수량
* 분할수량
* 분할 후 잔량
* 분할사유
* 분할일시
* 처리자
* 보관위치
* 품질상태

분할된 LOT는 원본 LOT의 자재·생산·품질 이력을 상속해야 한다.

---

## FR-LT-019 동일 LOT 번호 유지 분할

LOT 번호는 유지하면서 재고단위나 포장단위만 분리할 수 있어야 한다.

예:

```text
생산 LOT P001: 총 1,000개

박스 1: 300개
박스 2: 300개
박스 3: 400개
```

이 경우 동일 LOT 내의 포장단위 식별자를 별도로 관리해야 한다.

---

## FR-LT-020 신규 LOT 번호를 이용한 분할

품질상태, 고객요구 또는 재작업 등의 사유로 원본 LOT에서 별도 신규 LOT를 생성할 수 있어야 한다.

```text
원본 LOT P001: 1,000개

분할
- P001-A: 합격 800개
- P001-B: 보류 150개
- P001-C: 불합격 50개
```

각 신규 LOT는 원본 LOT와의 계보관계를 유지해야 한다.

---

## FR-LT-021 LOT 병합

둘 이상의 LOT 또는 포장단위를 하나의 출하·포장단위로 병합할 수 있어야 한다.

병합 시 원본 LOT 번호를 제거하거나 대체해서는 안 되며 병합 구성정보를 보존해야 한다.

```text
포장 LOT PK001
├─ 생산 LOT P001: 300개
├─ 생산 LOT P002: 400개
└─ 생산 LOT P003: 300개
```

## FR-LT-022 품질상태가 다른 LOT 병합 통제

다음 상태의 LOT를 병합하려는 경우 차단해야 한다.

* 합격과 보류
* 합격과 불합격
* 일반품과 특채품
* 재검사대기와 합격품

관리자 승인으로 예외 병합하는 경우 사유와 승인정보를 기록해야 한다.

## FR-LT-053 LOT 관계유형 관리

시스템은 LOT 간 연결관계의 의미를 구분하여 저장해야 한다.

LOT 관계유형은 최소한 다음을 지원해야 한다.

* 투입됨 `CONSUMED_INTO`
* 생산됨 `PRODUCED_FROM`
* 공정 인계됨 `TRANSFERRED_TO`
* 분할됨 `SPLIT_FROM`
* 병합됨 `MERGED_INTO`
* 재작업됨 `REWORKED_FROM`
* 포장됨 `PACKED_INTO`
* 출하구성됨 `SHIPPED_AS`
* 라벨 재부여됨 `RELABELED_AS`
* 잔량 분리됨 `REMAINDER_FROM`
* 외주 출고됨 `SENT_TO_SUBCONTRACTOR`
* 외주 입고됨 `RETURNED_FROM_SUBCONTRACTOR`

관계유형별로 원본 LOT, 대상 LOT, 처리수량, 처리단위, 발생일시 및 근거 이벤트를 저장해야 한다.

LOT 간 연결을 단순한 부모·자식 관계만으로 관리해서는 안 된다.

---

## FR-LT-054 LOT 사용수량 배분방식 관리

자재 LOT와 생산 LOT를 연결할 때 사용수량을 어떤 방식으로 배분했는지 기록해야 한다.

배분방식은 최소한 다음을 지원해야 한다.

* 직접 지정
* 생산실적별 지정
* 생산수량 비례배분
* 투입시간 기준
* LOT 전환시각 기준
* FIFO 기준
* BOM 표준소요량 기준
* 관리자 사후 조정

각 연결관계에는 다음 정보를 저장해야 한다.

* 배분수량
* 배분단위
* 배분방식
* 배분 근거
* 정확 추적 여부
* 추정 추적 여부
* 조정자 및 조정사유

실제 사용구간을 정확히 알 수 없는 경우에도 임의로 정확한 관계인 것처럼 저장해서는 안 된다.

---

## FR-LT-055 추적 정확도 수준 표시

시스템은 LOT 연결의 추적 정확도를 구분할 수 있어야 한다.

추적 정확도는 다음과 같이 관리할 수 있어야 한다.

* 정확: 실제 스캔 또는 명확한 수량구간으로 연결
* 추정: 시간, FIFO 또는 비례배분으로 연결
* 미확정: 연결 대상은 알지만 수량배분이 확정되지 않음
* 누락: 필수 연결정보가 존재하지 않음

정방향·역방향 추적 결과에서 추적 정확도를 사용자에게 표시해야 한다.

---

## FR-LT-056 추적정보 완전성 검증

시스템은 LOT 추적관계의 누락과 단절을 자동으로 검증할 수 있어야 한다.

검증항목은 최소한 다음을 포함해야 한다.

* 공급사 LOT가 필요한데 등록되지 않은 경우
* LOT 추적 대상 자재가 작업지시에 투입되지 않은 경우
* 생산실적은 있으나 생산 LOT가 없는 경우
* 생산 LOT는 있으나 생산실적이 없는 경우
* 생산 LOT에 필수 자재 LOT가 연결되지 않은 경우
* 후속 공정 투입 LOT의 선행 생산이력이 없는 경우
* 출하 LOT에 생산 LOT가 연결되지 않은 경우
* LOT 분할 전후 수량이 일치하지 않는 경우
* LOT 관계가 순환구조를 형성하는 경우
* 현재수량과 이벤트 누적수량이 일치하지 않는 경우

필수 추적정보가 누락된 경우 작업지시 마감, 완제품 가용 전환 또는 출하를 제한할 수 있어야 한다.

---

## FR-LT-057 추적성 예외목록 관리

시스템은 추적성 검증에서 발견된 오류와 미완료 항목을 예외목록으로 관리해야 한다.

예외정보에는 다음 내용이 포함되어야 한다.

* 예외유형
* 대상 LOT
* 작업지시
* 품목
* 발생공정
* 발생일시
* 중요도
* 담당부서
* 처리상태
* 처리기한
* 처리결과

예외가 해결되기 전까지 자동으로 사라지거나 삭제되어서는 안 된다.

---

## FR-LT-058 LOT 관계 정정 및 역처리

잘못된 LOT 투입·분할·병합·이동·포장·출하 연결을 승인된 절차에 따라 역처리할 수 있어야 한다.

역처리 시 다음 항목을 검증해야 한다.

* 후속 공정 사용 여부
* 생산실적 연결 여부
* 품질검사 여부
* 재고이동 여부
* 포장 여부
* 출하 여부
* ERP 반영 여부

후속처리가 없는 경우 원 이벤트를 취소할 수 있어야 한다.

후속처리가 존재하는 경우에는 원 이벤트를 삭제하지 않고 반대 수량의 보정 이벤트 또는 관련 업무의 역처리를 생성해야 한다.

---

## FR-LT-059 시점 기준 LOT 상태조회

사용자는 특정 시점 당시의 LOT 상태를 조회할 수 있어야 한다.

조회 대상은 다음을 포함한다.

* 당시 수량
* 당시 품질상태
* 당시 재고상태
* 당시 보관위치
* 당시 상위·하위 LOT 관계
* 당시 작업지시 및 생산실적
* 당시 출하 여부

현재 상태만 저장하여 과거 시점의 상태를 복원할 수 없는 구조로 구현해서는 안 된다.

---

## FR-LT-060 용기 및 취급단위 관리

LOT와 별도로 박스, 대차, 트레이, 통, 파렛트 등의 물리적 취급단위를 관리할 수 있어야 한다.

취급단위에는 다음 정보가 포함되어야 한다.

* 취급단위 식별번호
* 취급단위 유형
* 포함 LOT
* LOT별 포함수량
* 현재 위치
* 사용상태
* 상위 취급단위
* 바코드 또는 QR 코드

하나의 LOT를 여러 취급단위에 나눌 수 있고, 하나의 취급단위에 여러 LOT를 담을 수 있도록 정책적으로 허용할 수 있어야 한다.

LOT와 물리적 용기를 동일한 개념으로 관리해서는 안 된다.

---

## FR-LT-061 취급단위 일괄 처리

박스·대차·팔레트 등의 취급단위 바코드를 스캔하여 포함된 LOT를 일괄 이동, 공정 인계, 검사 또는 출하 처리할 수 있어야 한다.

처리 전 다음 항목을 검증해야 한다.

* 포함 LOT 목록
* LOT별 수량
* 품질상태
* 재고상태
* 이동 또는 출하 가능 여부
* 혼합 적재 허용 여부

---

## FR-LT-062 외주공정 LOT 추적

외주공정이 존재하는 경우 외주 출고부터 외주 입고까지 LOT 관계를 추적할 수 있어야 한다.

외주공정 추적에는 다음 정보가 포함되어야 한다.

* 외주 작업지시
* 외주처
* 출고 LOT
* 출고수량
* 출고일시
* 외주처 LOT
* 외주 처리수량
* 입고 LOT
* 합격·불량·분실수량
* 외주 입고일시
* 외주 검사결과

외주처가 MES를 사용하지 않아도 출고·입고 시점에서 관계를 등록할 수 있어야 한다.

---

## FR-LT-063 외부창고 및 위탁창고 LOT 추적

사내 MES 단말기가 설치되지 않은 외부창고 또는 위탁창고의 LOT 이동을 관리할 수 있어야 한다.

다음 방식을 지원할 수 있어야 한다.

* 출고 시 외부창고 이동처리
* 외부창고 재고파일 일괄 수신
* API 또는 ERP 연계
* 담당자 수동 입출고 등록
* 출고·회수 문서 기준 사후등록

외부창고에 있는 LOT도 현재 위치, 수량, 품질상태 및 소유구분을 조회할 수 있어야 한다.

---

LOT 조회 시 내부 LOT 번호 또는 외부 식별번호 중 어느 값으로도 검색할 수 있어야 한다.

## FR-LT-067 개별 부품과 완제품 일련번호 매칭

중복 부품 사용, 이미 사용된 일련번호 재사용 및 잘못된 품목 일련번호 투입을 차단해야 한다.

일괄 보류 전 대상 LOT와 수량을 사용자에게 제시해야 한다.

## FR-LT-073 기존 LOT 데이터 이관

MES 도입 이전 또는 타 시스템에서 관리하던 LOT를 이관할 수 있어야 한다.

이관 LOT에는 다음을 구분하여 표시해야 한다.

* 원본 시스템
* 원본 식별번호
* 이관일시
* 이관자
* 추적 가능한 범위
* 누락된 과거정보
* 이관 검증결과

불완전한 이관 데이터를 정상 MES 생성 LOT와 동일한 완전성을 가진 것으로 표시해서는 안 된다.

## FR-LT-074 추적성 데이터 정합성 재구축

LOT 현재수량, 상태 및 계보관계가 원본 이벤트와 불일치하는 경우 권한 있는 사용자가 정합성을 재계산할 수 있어야 한다.

재구축 전후 결과와 변경내역을 기록해야 하며, 원본 이벤트를 임의 수정해서는 안 된다.

# 6. 비기능 요구사항

## NFR-LT-001 추적조회 응답성

일반적인 LOT 조회는 정상적인 사내 네트워크 환경에서 다음 응답시간을 목표로 해야 한다.

* LOT 바코드 조회: 2초 이내
* LOT 상세조회: 3초 이내
* 일반 정방향·역방향 추적: 5초 이내
* 대규모 영향범위 분석: 10초 이내

대규모 추적조회는 진행상태를 사용자에게 표시해야 한다.

---

## NFR-LT-002 추적관계 완전성

LOT 추적 대상 자재는 다음 관계가 누락되지 않아야 한다.

```text
공급사 LOT
→ 내부 LOT
→ 자재투입
→ 작업지시
→ 생산실적
→ 생산 LOT
→ 출하
```

필수 추적관계가 누락된 경우 작업완료·마감·출하를 제한할 수 있어야 한다.

## NFR-LT-003 수량 정합성

LOT 생성, 분할, 병합, 투입, 이동, 출하 및 폐기 과정에서 수량 정합성이 유지되어야 한다.

동시 처리로 인해 다음 상황이 발생해서는 안 된다.

* 가용수량 초과 사용
* 동일 LOT 중복 출하
* 동일 잔량 중복 투입
* 분할 후 수량 증가
* 병합 시 원본 LOT 누락
* 음수재고 발생

## NFR-LT-004 트랜잭션 정합성

예:

* LOT 생성과 생산실적 연결
* LOT 투입과 수량 차감
* LOT 이동과 로케이션 변경
* 품질판정과 LOT 상태 변경
* 출하와 재고 차감
* 분할과 신규 LOT 생성

일부 처리만 성공하는 상태가 발생해서는 안 된다.

## NFR-LT-005 동시성 통제

시스템은 다음 중 하나 이상의 방식을 적용해야 한다.

## NFR-LT-006 중복처리 방지

LOT 생성·분할·이동·출하 요청은 멱등성을 보장해야 한다.

LOT 현재수량과 계보는 원본 이벤트를 기준으로 재계산하거나 정합성 검증할 수 있어야 한다.

## NFR-LT-021 오프라인 처리 및 재동기화

현장 네트워크가 일시적으로 중단되는 경우 단말기는 허용된 범위의 LOT 스캔 이벤트를 로컬에 임시 저장할 수 있어야 한다.

오프라인 이벤트에는 다음 정보가 포함되어야 한다.

* 단말기
* 작업자
* 작업지시
* LOT
* 처리유형
* 처리수량
* 실제 발생일시
* 저장일시

네트워크 복구 후 저장된 이벤트를 서버로 재전송할 수 있어야 한다.

재동기화 시 다음을 검증해야 한다.

* 중복 이벤트

* 시간순서 충돌

충돌한 이벤트는 임의 자동반영하지 않고 예외처리 대상으로 분리해야 한다.

## NFR-LT-022 이벤트 순서 보장

LOT 이벤트는 실제 발생순서와 MES 수신순서를 구분하여 관리해야 한다.

지연입력 또는 오프라인 입력으로 이벤트가 순서와 다르게 수신되더라도 LOT 계보와 수량을 올바르게 계산할 수 있어야 한다.

불가능한 이벤트 순서는 차단하거나 승인대상으로 처리해야 한다.

예:

```text id="972bek"
출하 이후 생산실적 등록
소진 이후 추가 투입
후속 공정 투입 이후 선행 LOT 생성 취소
```

## NFR-LT-023 계보 순환 방지


서버에는 표준화된 시각으로 저장하고 화면에는 공장 현지시간을 명확하게 표시해야 한다.

일광절약시간 또는 시간대 변경으로 이벤트 순서가 왜곡되어서는 안 된다.

대량조회는 일반 생산 트랜잭션과 자원을 분리하거나 제한하여 생산실적·자재투입 업무의 성능에 영향을 최소화해야 한다.

정정 또는 추가입력으로 결과가 달라진 경우 변경원인을 확인할 수 있어야 한다.

## NFR-LT-032 변경관리 및 테스트 가능성

LOT 생성·분할·병합·역처리·추적 알고리즘이 변경되는 경우 기존 주요 시나리오에 대한 회귀시험을 수행할 수 있어야 한다.

최소한 다음 시나리오를 자동 또는 반복 검증할 수 있어야 한다.

* 한 자재 LOT가 여러 생산 LOT에 사용됨
* 여러 자재 LOT가 하나의 생산 LOT에 사용됨
* LOT 분할 후 공정 인계
* LOT 병합 후 출하
* 재작업 LOT 생성
* 품질 보류와 부분 해제
* 출하 후 리콜 영향범위 조회
* 오프라인 이벤트 재동기화

---

## NFR-LT-033 데이터 위변조 방지

LOT 생성, 품질판정, 출하 및 정정과 같은 중요 이벤트는 무단 변경을 방지해야 한다.

중요 이벤트의 변경은 승인권한과 감사이력을 요구해야 하며, 데이터베이스 직접 변경도 운영절차상 탐지할 수 있어야 한다.

필요한 경우 이벤트 순서번호, 해시 또는 변경감사 로그를 적용할 수 있어야 한다.

---

## NFR-LT-034 장기보관 데이터 조회

운영 데이터가 장기보관 또는 아카이브 영역으로 이동된 이후에도 품질사고와 고객문의 발생 시 LOT 추적조회가 가능해야 한다.

아카이브 데이터의 조회방법과 최대 복원시간을 정의해야 한다.


# 7. 핵심 업무 규칙

## BR-LT-001

LOT 추적 대상 품목은 LOT 없이 입고·투입·생산·출하할 수 없다.

## BR-LT-002

모든 LOT는 반드시 하나의 품목과 LOT 유형을 가져야 한다.

## BR-LT-003

생산 LOT는 작업지시 또는 승인된 수동 생성 근거와 연결되어야 한다.

## BR-LT-004

자재 LOT와 생산 LOT의 연결은 자재투입과 생산실적을 근거로 생성해야 한다.

## BR-LT-005

하나의 생산 LOT에 여러 자재 LOT를 연결할 수 있다.

## BR-LT-006

하나의 자재 LOT를 여러 생산 LOT에 사용할 수 있다.

## BR-LT-007

LOT 분할·병합 이후에도 원본 LOT 계보를 보존해야 한다.

## BR-LT-008

분할된 LOT 수량의 합계는 원본 분할수량과 일치해야 한다.

## BR-LT-009

품질상태가 서로 다른 LOT는 원칙적으로 병합할 수 없다.

## BR-LT-010

보류·격리·불합격 LOT는 일반 생산투입이나 출하에 사용할 수 없다.

## BR-LT-011

후속 공정에 투입된 LOT 수량은 선행 LOT 가용수량을 초과할 수 없다.

## BR-LT-012

출하완료 또는 소진된 LOT는 다시 가용수량으로 사용할 수 없다.

## BR-LT-013

재작업·재검사·특채 이후에도 원래 불량 및 품질이력을 보존해야 한다.

## BR-LT-014

LOT 번호를 변경하더라도 기존 번호와 변경이력을 보존해야 한다.

## BR-LT-015

생산·품질·출하이력이 존재하는 LOT는 물리적으로 삭제할 수 없다.

## BR-LT-016

LOT 수량 변경은 반드시 입고·투입·생산·이동·출하·폐기·조정 등의 근거 이벤트를 가져야 한다.

## BR-LT-017

LOT 생성과 생산실적 연결은 동일한 트랜잭션으로 처리해야 한다.

## BR-LT-018

LOT 품질상태 변경과 사용 가능 여부 반영은 동일한 트랜잭션으로 처리해야 한다.

## BR-LT-019

실제 LOT 발생일시와 MES 입력일시는 구분하여 보존해야 한다.

## BR-LT-020

MES 미관리 공정이 존재하더라도 앞뒤 MES 관리 대상 공정 사이의 LOT 연결관계는 유지해야 한다.

# 8. 기본 정방향 추적 흐름

```text
공급사 LOT 조회
   ↓
내부 자재 LOT 확인
   ↓
자재투입 작업지시 조회
   ↓
공정별 생산실적 조회
   ↓
생성된 반제품·완제품 LOT 조회
   ↓
포장 LOT 조회
   ↓
출하 LOT 조회
   ↓
고객 및 출하정보 조회
```


# 10. 품질문제 영향범위 분석 흐름

```text
문제 LOT 또는 자재 LOT 선택
   ↓
정방향 LOT 계보 조회
   ↓
관련 생산 LOT 식별
   ↓
현재 재고·공정재·포장재고 확인
   ↓
출하 LOT 및 고객 확인
   ↓
관련 LOT 일괄 보류
   ↓
재검사·선별·회수 대상 관리
```

LOT 추적성에서 가장 중요한 의사결정은 **생산 LOT를 어느 시점과 어떤 수량단위로 생성할 것인지**입니다. 품목별로 `작업지시 1개당 1 LOT`, `근무조별`, `박스별`, `자재 LOT 변경 시` 등의 정책을 설정할 수 있게 하는 것이 적절합니다.
