## 1. 메인 구조도 — Lot Status 상태 전이도

### 1.0 도식 성격 (문서 근거)

**메인 = Lot Status 상태 전이도.** 3종 검사(IQC/PQC/OQC)의 합부 판정이 **공통으로 수렴하는 상태기계** — 판정 허브(⊕)에서 합격→Release / 보류→보류 / 불합격→Hold로 분기하고, 의심자재등록이 보류를 트리거하며, 재판정·재Hold 전이와 변경이력 기록(N6·N7)으로 구성된다. `(기존 서술 폐기: 구 §1.0 "메인 축 = PQC 트리거→수행→판정→Lot Status→불량 처리" — 03 재정의 결정 2로 PQC 공정검사 축 폐기)`

- **검사 수행 3종은 각 도메인으로 co-locate**(03재정의 결정 1) — 03은 검사 흐름을 그리지 않고 **판정이 흘러드는 진입점(유입)만** 표기: IQC=01(사이드 C·WF01 S3) · PQC=02(02-S-E 사이드·WF02) · OQC=04(도식 M6/M7·WF04 S5). 불량 처리 흐름도 각 검사 도메인 co-locate.
- **03 = 품질 공통 거버넌스**(03재정의 §3) — Lot Status는 자재/생산/제품 3 LOT 공통·특정 도메인 집이 없는 크로스 도메인 품질 상태의 정본(결정 10 C4 단일 정본)이라 03에 둔다. 정적 마스터(판정유형 코드 목록)는 06/도메인, **동적 상태 전이 로직은 03**.
