## 4. [확인] co-locate grep 매치 위치 편차 (편집 오류 아님 — 투명성 보고)

지시서 "완료 후 자가 검증" 절은 `도식 co-locate\|co-location` 매치 위치를 "주석 4곳(범위IN·S2·S8·S9) + 헤더"로 서술했으나, 실측 매치는 **S2·S8·S9·변경이력(v1.5행)** 4곳이었다. 원인을 대조한 결과 **내 편집이 지시서 §E 원문과 글자 단위로 정확히 일치**함을 확인했다 — 편차는 지시서의 자가검증 grep 패턴 서술과 §E 편집문 실제 표현 간의 사소한 불일치이지, 앵커 오매칭이나 재해석이 아니다:

- **E-1(헤더)**: 지시서 원문이 "검사 수행 도식 **도메인** co-locate"로 되어 있어(`도식 co-locate` 연속 문자열이 아님) 패턴 미매치. 그대로 옮김.
- **E-2(범위IN)**: 지시서 원문이 "FigJam 도식 표현은 **도메인** co-locate된다"로 되어 있어 동일하게 미매치. 그대로 옮김.
- **E-3·E-4·E-5(S2·S8·S9)**: 지시서 원문에 정확한 마커 `**[도식 co-locate]**`가 있어 매치. 그대로 옮김.
- **E-6(변경이력)**: 지시서 원문에 "범위(IN) **co-location** 문단"이라는 표현이 있어(location 어미) 두 번째 OR 조건에 매치. 그대로 옮김.

즉 실제 삽입 문구는 지시서 §E-1~E-6과 100% 일치하며, grep 결과 편차는 검증 담당자가 자가검증 섹션을 작성할 때의 패턴-대상 서술 차이일 뿐이다. 별도 수정 없이 사실만 보고한다.
