## 리더 판단 개입 요약 (재검토 요청 — 3건)

지시서 리터럴 텍스트의 `[유형↝캔버스]`/`[커넥터ID↝캔버스]` 마킹이 누락되었거나 캔버스 맵과 상충한 지점에서, "동일 노드 ID는 캔버스 맵의 단일 사실을 따른다" 원칙으로 마킹 여부와 무관하게 캔버스 맵을 우선 적용했다. 창작이 아니라 리더가 이미 제공한 동일 ID의 실측값을 재적용한 것이나, 지시서 원문과 자구가 다른 지점이므로 전부 표면화한다:

1. **G-A.6**: 실적 등록(486:7413) 두 번째 언급 — 지시서 "Desktop"(마킹 없음) → **Mobile**로 통일(첫 언급의 `[유형↝캔버스]`=Mobile과 동일 ID).
2. **G-A.7**: 제품 포장(497:4582) — 지시서 "Mobile"(마킹 없음) → **Service**(리더 노드맵 명시값).
3. **G-B.4**: 제품 검사(497:5460) — 지시서 "Mobile"(마킹 있음, `[유형↝캔버스]`) → **Service**(리더 노드맵 명시값. 마킹은 있었으나 지시서가 적어둔 유추값 자체가 리더 맵과 불일치).

추가로 **G-A.9에서 작성 중 자체 오류를 발견해 즉시 정정**했다(497:5326→497:5340, 리더 커넥터 맵 재대조로 확인 — 최종 결과물에는 정정된 값만 존재).
