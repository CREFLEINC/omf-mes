## 0. 작업자·검토자 필독 (계약·특칙)

### 0.1 좌표계 계약 (B2 함정 재발 방지 — 절대 준수)
- 본 지시서의 **모든 노드 좌표는 절대 캔버스 좌표(abs x/y, top-left)**다.
- 작업자는 `clone()` → `section.appendChild(clone)` **후**, `clone.x = abs_x − 섹션originX`, `clone.y = abs_y − 섹션originY`로 **로컬 변환**해 배치한다(섹션 자식은 로컬 좌표계).
  - **메인 섹션 origin = (−1730, 8900)** → `localX = absX + 1730`, `localY = absY − 8900`.
  - **사이드 섹션 origin = (−1730, 10950)** → `localX = absX + 1730`, `localY = absY − 10950`.
- **커넥터는 `figma.createConnector()` + `connectorStart/End = {endpointNodeId:id, magnet:'AUTO'}`** — 좌표를 주지 않는다(노드 ID만). 절대/로컬 변환과 무관. 이중 오프셋 함정 주의.

## 4. 분기·조건·경계 표기 (v2 인라인 라벨 + OR⊕ — 검정 헥사곤 폐기)

문법 정본: `research/2026-07-13-도식-조건라벨-표기체계-v2.md`. **검정 조건 헥사곤 미사용**(01/02 v2 = 검정 hex 0 실측). 실분기=OR(⊕)+OR-발 초록 라벨 · 단일경로 조건=인라인 라벨(미색) · 확정규칙 조건=강조(노랑 Bold) · 경계=회색 텍스트/hex.
