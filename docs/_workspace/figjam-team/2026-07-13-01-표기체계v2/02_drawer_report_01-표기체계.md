## 6. 실행 중 기술 노트 (검토자·후속 참조)

1. **커넥터 인라인 recipe(빈 커넥터)**: 빈 커넥터는 문자 런이 없어 `fontName` 선설정이 무효 → **characters 먼저 → fontName 후설정** 순서라야 Bold 등이 적용됨. (강조 3건에 적용.)
2. **`textBackground` API**: 지시서 표기 `connector.textBackground = [...]`는 실제로 `connector.textBackground.fills = [...]` (LabelSublayerNode). `.fills`로 설정함.
3. **범례 텍스트 clone**: FigJam `clone()`은 섹션 자식이라도 **페이지에 배치**됨 → 섹션 `appendChild` 후 섹션 상대좌표로 재설정 필요(초기 좌상단 이탈 → 교정 완료).
4. **범례 커넥터 샘플**: 페이지 레벨 플로팅 커넥터는 섹션 스크린샷에 미포착 → **섹션 자식 + 절대 플로팅 좌표**로 설정해 렌더 보장(섹션 자식은 endpointNodeId 없는 순수 플로팅이면 좌표를 절대값으로 줘야 원위치).
5. 매 use_figma 콜 서두 `setCurrentPageAsync('219:4509')` 준수 — v1 무오염.
