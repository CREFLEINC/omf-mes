## 0. 작업자·검토자 필독 (계약·특칙)

### 0.1 좌표계 계약 (B2 함정 재발 방지 — 절대 준수)
- 본 지시서의 **모든 노드 좌표는 절대 캔버스 좌표(abs x/y, top-left)**다.
- 작업자는 `clone()` → `section.appendChild(clone)` **후**, `clone.x = abs_x − 섹션originX`, `clone.y = abs_y − 섹션originY`로 **로컬 변환**해 배치한다(섹션 자식은 로컬 좌표계).
  - **메인 섹션 origin = (−1730, 14700)** → `localX = absX + 1730`, `localY = absY − 14700`.
  - **사이드 섹션 origin = (−1730, 16700)** → `localX = absX + 1730`, `localY = absY − 16700`.
- **커넥터는 `figma.createConnector()` + `connectorStart/End = {endpointNodeId:id, magnet:'AUTO'}`** — 좌표를 주지 않는다(노드 ID만). 절대/로컬 변환과 무관. 이중 오프셋 함정 주의.

### 0.3 본 도메인 특칙 (스펙 §0 — 위반 시 검토 FAIL)
1. **ERP(Database) 아이콘은 정확히 0개.** 설비·툴 도메인은 ERP 연계 접점이 **전무**하다(툴·금형·지그=MES 정본, 보전=MES 경량 단독, 예비품=별도 MES 마스터). 메인·사이드 통틀어 Database 아이콘이 **하나라도 있으면 오류.** **클론 소스 219:4633(Database)은 절대 쓰지 마라 — 클론 소스표에서 제외.** 마스터/정본은 전부 Server(MES)+스티키로만 표기.
2. **캠데코설비 = 중립 사각형**(일반 SHAPE_WITH_TEXT SQUARE·회색 테두리·흰 채움, 06 추적관리시스템과 동형). 클론 소스 **174:4531**(교차페이지 clone→appendChild). 실패 시 `createShapeWithText('SQUARE')` 190×96·stroke 회색 `{r:.702,g:.702,b:.702}` w2·fill 흰색 폴백. **ERP 아이콘 아님.**
3. **주기 루프 = 회색 점선(`dashPattern=[16,10]`).** ① 메인 **A5→A1** "다음 주기"(전 폭 상단 아치) ② 사이드 A **H5→SA1** "미도달·누계"(회귀) ③ 사이드 A **SA2→H5** "차기 PM 기준 갱신". 이 3본만 점선. 나머지 회귀/경계는 실선 회색.

5. **판정 소관**: 본 도메인은 반품·폐기 '판정'을 그리지 않는다(05 범위 아님). 사이드 E 계측기 게이트는 '판정'이 아니라 검사 도메인(01/02/04)으로의 **선행조건 경계**(회색 hex)다.
