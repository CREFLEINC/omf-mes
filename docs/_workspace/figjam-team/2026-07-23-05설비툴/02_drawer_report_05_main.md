### ⚠ 3-A. A5→A1 아치 분리 — FigJam 구조 한계 대응 (검토자·설계자 확인 요청)
- **문제**: FigJam ELBOWED 커넥터는 웨이포인트 API가 없고, 두 엔드포인트 위로 **고정 오프셋(~52px)만** 아치한다(중간 장애물 무회피 검증·헬퍼 무효·자동 회피 20px는 비결정적 재현 불가·CURVED는 14040으로 섹션 이탈). 따라서 A5→A1·H3→A2 두 TOP 아치는 기본적으로 **동일 높이(14868)에 겹침**.
- **해결**: A5 직상에 투명 앵커(766:7740)를 두고 A5→A1 시작을 그 위로 부착 → 아치를 **14800으로 결정적 상승**(H3→A2 14868과 68px 분리). 도착부(A1) 화살표는 A1.TOP에 정상 접합.
- **트레이드오프**: A5→A1 **시작부가 A5 상단에서 ~68px 부양**(점선 루프의 리프트오프로 읽힘·화살표는 A1 정상 도착). "겹침 0·≥40 분리"는 충족하나, "A5 노드에 시작 접합"은 앵커 경유. **대안**: 양끝 접합을 우선하면 자동 회피 20px(비결정적)뿐 — ≥40 미달. 설계자 이견 시 조정 가능.
