## 0. 이 지시서의 범위·핵심 전환 (먼저 읽어라)

**무엇을 바꾸나:** 02 메인의 [3.작업자](작업자3, 297:5377)·[4.현장반장](작업자4, 297:5379) 두 구간을 사용자 확정(2차 게이트 Q1~Q5)대로 재배선하고, 신규 사이드 02-S-E(불량)·02-S-H(비가동 미정)를 신설한다.

**5대 전환(설계안 r1 대비 개정점 = ★):**
1. ★ **PQC 선행**: 작업자3 → **OR 분기(PQC 명시 여부)** → [명시] **파란 DOC 「03.품질 검사」 경유 → 실적 입력** / [생략] 실적 즉시 입력. (r1의 "실적→PQC 순서 유지"는 폐기. PQC가 실적보다 **앞**.) 작업실적 3원(양품/불량/손실)은 유지.
2. ★ **불량 = 신규 사이드 02-S-E 위임**. 메인 「불량코드 선택」·01-S-G·태그 2종·N8은 사이드 E로 **이관**. 메인은 **빨간 DOC 「02-S-E」 2개**로 위임 — 발신 2지점: (a) PQC 경로 「불량 발생 시」 (b) 실적 입력 「현장 불량 발견 시」.
3. ★ **비가동 = 메인 완전 삭제**(비가동 입력 5425·인라인 5434) + 신규 사이드 **02-S-H 「비가동 처리」 미정 골격**(제목+리셉션+미정의 마커, 02-S-F/G 패턴). **메인 발신 참조 없음**(02-S-C 선례의 비대칭 허용 — 리셉션 문구로 의미 보존).
4. **인식표·LOT 완료 → 작업자3 이관**: LOT 완료 처리·인식표 발행·인식표 부착이 작업자3 체인으로. 인식표 = 선택적 발행 분기(인라인 「인식표 발행 대상」 / 「비대상」). 양품만 부착.
5. **현장반장 축소 = 다음 공정 이동·WIP 전담**. U4·U5 Email 마커 삭제 → 속성 태그 확정 전환.

**설계자 결정 사항(확정 지시에 명시 안 됨 — 검토·필요 시 사용자 확인 대상, §D-3에 근거):**
- **D1. N9(생산LOT완료·인식표) → 작업자3 MES 5471로 이관**(인식표 액션이 작업자3). **N10(포장단위) → 현장반장 MES 5477 유지**(제품입고=포장단위=완료·인계 성격, 현장반장 MES 비지 않게).
