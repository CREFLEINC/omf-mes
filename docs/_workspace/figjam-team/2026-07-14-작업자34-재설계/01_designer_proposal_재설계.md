## ① 승인 요청 요약 (핵심 결정 5건 — 3분 검토용)

**결정 1 — PQC 시점 가설 검증 결과: 리터럴 순서는 상충, 의도는 재해석으로 충족 (권장 = 재해석안).**
사용자 가설 「PQC를 실적 입력 **앞**에 두고 **양품만 실적 등록**」은 확정 모델과 **상충**합니다. 근거: ① WF02 S8은 PQC를 "작업실적 수집 **중/후**" 트리거로 정의(실적이 먼저) ② 03 스펙 입력 경계가 "작업실적 불량수 = **현장 발견분만** / 검사 판정 불량 = **검사실적에만**"으로 두 기록을 **별개 병렬**로 못박음(작업실적=양품/불량/손실 3원 — QA #13·결정 09). "양품만 작업실적"은 이 분리를 깨뜨립니다.
반면 사용자의 **의도**(PQC 게이트·양품만)는 **인식표 발행**에 정확히 매핑됩니다: 인식표 = 양품 개체별 1:1·불량품 미부착(N9·확정), PQC는 LOT를 Hold 가능(S8 Result). → **권장안: 실적 입력(3원 유지) → PQC 검사(명시 시, Hold 게이트) → 양품 확정 → 인식표 발행·부착.** PQC를 **인식표 앞** 게이트로 배치해 "양품만 인식표"를 보장하되, 작업실적 3원은 스펙대로 유지.

**결정 2 — 인식표·LOT 완료를 [4.현장반장] → [3.작업자] 구간으로 이관 (역할 재배분 확정).**
확정: 인식표 발행·부착 주체 = 작업자, 실적 입력 시(§2.4). 현 캔버스는 현장반장(작업자4)이 「LOT 완료 처리→인식표 발행→인식표 부착」 수행. 작업실적=생산LOT 1:1이므로 실적을 넣는 작업자가 같은 LOT을 완료·인식표까지 처리하는 것이 정합. **작업자4(현장반장)는 「다음 공정 이동·WIP」만 담당**하도록 축소. (부수 효과: 「LOT 완료 처리」가 축 상태 「생산LOT 완료」를 *생성*하는 위치로 이동 — 현재의 상태-후행 배치 오류도 교정.)

**결정 3 — 인식표 발행 = 선택적 작업, 분기 신설.** 확정: 발행 대상/비대상 품목 구분(§2.4). LOT 완료 처리 → [인라인 「인식표 발행 대상 품목」] → 인식표 발행·부착 / 비대상 → 인식표 생략, 「생산LOT 완료」 직행. U5 확정(초과 생산분 = 추가 생산 LOT 발행·기본 수량+수정) 인라인 반영.

**결정 4 — 불량 코드 선택·비가동 입력을 신규 사이드 `02-S-E`(결번 활용)로 통합 이관.**
확정: 불량 코드 선택·비가동 입력 = 사이드 이관(§2.4). 02 사이드 섹션의 **E는 이미 "불량/비가동 후보"로 결번 예약**(스펙 §2). 권장: **02-S-E 「불량·비가동 수집」 단일 사이드**(리셉션 2 — 불량 진입·비가동 진입). **비가동 분기 = 실적 입력 전**으로 이동, **불량 코드 선택 = PQC 진행 여부 종속**(실적 후·검사 경로와 통합). 01-S-G DOC(371:7957)·태그 2종(6672·6676)·노트 N8(5473) 동반 이관.

**결정 5 — 미정의 마커 2건(U4·U5) 종결.** U4(WIP 이동=생산LOT 단위·이동 스캔 LOT 단위)·U5(초과분=추가 생산 LOT) 확정(§3) → 빨간 Email 마커 삭제·인라인 전환.

> **승인 판단이 필요한 지점**: 결정 1의 **권장안(재해석)** 채택 여부. 사용자 리터럴 가설(PQC를 작업실적 앞 하드 게이트·양품만 작업실적)을 고수하려면 03 입력 경계(결정 09·QA #13)의 **변경**이 선행되어야 하며, 검사 판정 불량과 현장 불량의 **이중 집계 리스크**가 발생합니다(§2 Option B). 나머지 결정 2~5는 모두 확정기록 근거가 명확해 승인만 필요.

## ② PQC 시점 조사 결과 (가설 검증 — 부합/상충 근거)

### 2.1 사용자 가설 (검증 대상)
> 「PQC 명시 시 실적 입력 **전**(=LOT 라벨 부착 전) 03.품질관리 경유, 결과 **양품만 실적 등록**」
> 예시 흐름: 제품 생산 → PQC → (양품) → 작업자 실적 등록 → 인식표 발행&부착. (§2.4 `[가설 — 사용자 제시, 설계 검증 대상]`)

### 2.4 검증 결론 및 권장 배선

- **권장안 (Option A — 재해석, 스펙 정합)**: `실적 입력(양품/불량/손실 3원, 현장 기록)` → `[PQC 명시 시] 03.품질 검사(파란 DOC, Hold 게이트)` → `양품 확정` → `LOT 완료 처리` → `[발행 대상 품목] 인식표 발행·부착`.
  - PQC를 **인식표 앞**에 배치 → 사용자 의도("양품만 인식표") 충족.
  - 작업실적 3원·검사실적 분리 **유지** → 03 입력 경계·QA #13 위반 없음.
  - PQC 미명시 경로 = DOC 우회(태그 「PQC 미명시 시 생략」 유지). `[가설]` 불요(전부 스펙 근거).
  - 현 캔버스의 "실적 입력 → PQC" 순서는 **유지**(가설의 역전이 아님) — 사용자께 이 점을 명확히 보고. 다만 인식표를 PQC **뒤·양품 확정 후**로 재배치해 "양품만 인식표"를 시각적으로 보장.

- **대안 (Option B — 리터럴 가설, 스펙 변경 필요)**: PQC를 실적 입력 **앞** 하드 게이트로 두고 양품만 작업실적. 채택 시 필수 선행:
  1. 03 입력 경계 규칙(결정 09) 개정 — 검사 판정 불량과 작업실적 불량수 통합 정책 재정의.
  2. 이중 집계 방지 재설계 + QA #13(3원·수율 분리) 정합 재검토.
  3. 해당 경로 전체 `[가설]` 표기 + 고객 재확인.
  → **비권장**(확정 모델 다수 충돌·리스크 큼). 사용자 명시 선택 시에만 진행.

## ④ 신규 사이드 구성안 — 02-S-E 「불량·비가동 수집」

- **코드**: `02-S-E` — 캔버스 현황상 02 사이드 사용분 A·B·C·D·F·G, **E는 결번(불량/비가동 예약, 스펙 §2)**. 충돌 없음. 예약 슬롯 정본 활용.
- **분리 사유**: 저중요·부수 입력(실적의 곁가지) + 두 분기가 메인 회랑을 가중 → 메인 가독성 확보(사이드 기준 ②). S9(불량·비가동 수집) 단일 스텝을 한 사이드로 응집.
- **권장: 단일 사이드(리셉션 2)** — 근거: E는 단일 결번 예약, S9는 한 스텝. 두 진입점(불량·비가동)만 분기.

**구성(이관 + 신규):**
```
[02-S-E 「불량·비가동 수집」] (제목 신규)
 ├ 리셉션① 회색 헥사곤 「← 02 메인 (불량 발생)」   ← 메인 실적입력发 빨간 DOC 「02-S-E」
 │    → Wallet 「불량코드 선택」(이관 297:5424) [태그 「재작업/폐기 2분류」6672·「불량창고 우선 입고」6676 이관]
 │        → 빨간 DOC 「01-S-G」(이관 371:7957 — 불량 반출→01, 타 도메인 사이드 직접 참조)
 └ 리셉션② 회색 헥사곤 「← 02 메인 (비가동 발생)」  ← 메인 작업자3 진입发(실적 전) 빨간 DOC 「02-S-E」
      → Mobile 「비가동 입력」(이관 297:5425) (사유·시간)
 Server 「MES」 + 스티키 N8 「불량·비가동 기록」(이관 297:5473)
```

- **메인 발신 참조**: 표기체계 §1.6 표준(빨간 DOC 「02-S-E」 + 수신 커넥터 인라인). 진입 2개 → 메인에 발신 DOC 2개(불량용·비가동용), 각 인라인 「불량 발생 시」·「비가동 발생 시」.
- **대안(비권장)**: E(불량)+H(비가동) 2분할. 진입점이 서로 달라 분할도 가능하나, 결번 예약이 E 단일이고 S9가 한 스텝이라 **통합이 정합**. 사이드 섹션 폭 추가 확장 부담도 통합이 유리.
