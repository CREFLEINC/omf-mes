# omf-mes 기획 문서

omf-mes(OhMyFactory MES — AI Agent 네이티브 MES) 프로젝트의 기획안을 작성·관리하는 저장소다.
코드 없이 한국어 Markdown 문서만 다룬다. 작성 주체는 CREFLE OMF 팀.

**모든 문서는 내부 대외비다.** 문서 내용을 외부 서비스에 업로드·공유·게시하지 않는다.

## 폴더 구조

| 폴더 | 용도 | 핵심 규칙 |
| --- | --- | --- |
| `planning/` | 작성한 기획안 정리 (버전 관리) | 아래 버전 관리 규칙을 따른다 |
| `research/` | 기획 과정에서 직접 만든 조사·정리 자료 | 출처를 반드시 남긴다 |
| `raw/` | 외부에서 가져온 참조용 원본 자료 | **읽기 전용 — 생성·수정·삭제 금지** |

공통 파일명 규칙: `YYYY-MM-DD-<제목>.md` (날짜 = 최초 작성일).

## raw/ — 읽기 전용 (절대 규칙)

- raw/ 안의 파일은 **읽기만 한다.** 어떤 파일도 만들거나, 고치거나, 지우거나, 옮기지 않는다. 다운로드 저장도 금지. 자료 추가는 사용자가 직접 한다.
- 이 규칙은 `.claude/settings.json` 권한 규칙과 `.claude/hooks/protect_readonly.py` 훅이 강제한다. 작업이 차단되면 우회하지 말고, 산출물을 research/ 또는 planning/에 만든다.
- raw/ 자료를 요약·발췌·번역·정리한 결과물은 research/에 새 문서로 작성한다.
- raw/ 자료 현황은 `research/raw-자료-목록.md`에서 관리한다. 갱신은 `/raw-index`.

## research/ — 조사·정리 자료

- 문서 머리에 출처를 남긴다 — raw/ 파일이면 경로, 웹이면 URL과 접근일, 조사 방법.
- 검증된 사실과 해석·추정을 구분해 표기한다 (기존 문서의 적대적 검증 표기 방식 유지).

## planning/ — 기획안과 버전 관리

```
planning/
├── YYYY-MM-DD-<제목>.md   # 작업본 — 항상 최신 내용, 수정은 여기에만
└── versions/
    └── <제목>-v1.1.md     # 확정 스냅샷 — 수정·삭제 금지(훅이 차단)
```

- 작업본을 수정해 가다가, 매듭 시점에 `/snapshot`으로 버전을 확정한다(작업본을 versions/에 복사).
- 스냅샷 파일명: 작업본 파일명에서 날짜 prefix를 떼고 `-v<버전>`을 붙인다.
- 버전 의미: `v0.x` 초안 단계, `v1.0` 최초 확정, 이후 변경 폭에 따라 증가.
- 작업본을 수정하면 문서 머리의 버전·날짜 표기를 갱신한다.

문서 머리 형식 (기존 문서와 동일한 blockquote 스타일):

```markdown
# <제목>

> 작성일: YYYY-MM-DD (v0.1 — 작성 중) · 작성 주체: CREFLE OMF 팀
> 근거 자료: research/·raw/ 경로 나열
> 표기 원칙: 검증된 사실과 **내부 가설**을 구분 표기한다. 가설은 `[가설]`로 표시하고 검증 방법을 병기한다.
```

문서 끝에 변경 이력 표를 둔다:

```markdown
## 변경 이력

| 버전 | 날짜 | 변경 요지 |
| --- | --- | --- |
```

## 작성 지침

- 기획안의 사실·수치는 research/ 문서에 근거를 두고 해당 경로를 '근거 자료'에 남긴다. 근거가 없으면 `[가설]` 또는 `(확인 필요)`를 붙인다.
- 문서 간 링크는 저장소 루트 기준 상대 경로를 쓴다.
- 날짜는 항상 `YYYY-MM-DD` 형식.

## 하네스 구성 (.claude/)

- `settings.json` — raw/ 쓰기 거부 권한 규칙 + 보호 훅 등록.
- `hooks/protect_readonly.py` — raw/ 전체와 `planning/versions/` 기존 파일의 변경을 차단한다(파일 도구·Bash 모두). 훅이 작업을 막으면 의도된 동작이므로 우회하지 말고 사용자에게 알린다.
- 커맨드:
  - `/new-plan <주제>` — 새 기획안 작업본 스캐폴딩
  - `/snapshot [주제] [버전]` — 작업본을 버전 스냅샷으로 확정
  - `/raw-index` — raw/ 자료 목록 갱신
