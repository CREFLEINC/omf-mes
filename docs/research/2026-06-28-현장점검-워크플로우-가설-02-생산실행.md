## 0. 사용법 · 범위 · 발견 방법

**이 문서의 위상**: 사전 정의 = *커버리지 체크리스트 + 현행 가설*. 현장에서 채우는 틀이 아니라 **반증할 가설**이다. 각 단계의 Medium·Pain은 전형적 제조 SME(종이·엑셀·구두·반자동) 기준 추정이며, **UNIMES 제안서(벤더 To-Be)에 앵커링하지 않는다** — 단계 목록(분해도 §2·3·4)만 커버리지로 빌려오고, *현행이 실제 어떻게 도느냐*는 개방형으로 듣는다.

**범위(IN)**: P/O 수신 → W/O 전개·확정 → 자원배정(4M 계획) → 작업 시작(작업 전 점검 통제) → 작업실적 수집(생산수량·4M투입·불량·비가동·검사실적 트리거) → 생산LOT·인식표 발행 → 공정 이동(WIP) → W/O 완료·마감. 즉 **지시가 현장에 내려가 실물 생산·실적·LOT으로 완결되는 사이클**.
**범위(OUT, 별도 워크플로우)**: 자재 입출고·재고(자재창고 문서 ①)·품질 검사 *내부 절차*(검사항목 측정·판정·성적서 — 품질 문서)·제품 출하·Picking&Packing. (단 경계로 맞닿는 지점은 🔗로 표시 — 특히 자재 출고(투입), 검사 트리거)

**발견 방법(현장)**: ① 1건 추적(실제 W/O 1건을 편성→배포→작업시작→실적→생산LOT→완료까지 따라가기) ② 관찰(말이 아니라 실제 동작 — POP/단말에서 무엇이 *찍히는지*) ③ 실물·데이터 수집(작업지시서·실적 입력 화면·인식표 라벨 실물·비가동 코드표·DB 스키마+덤프). 각 단계 끝 **[Check(확인)]** 에 관찰·수집·질문 포인트.

**워크플로우 개요(가설)**
```
[ERP 발주/생산계획(P/O)] ─연계 수신→ S1
  S1 ─→ S2 W/O 전개·편성(세부공정) ─→ S3 자원배정(4M 계획)·유효성Validation ─→ S4 W/O 확정·현장 배포
                                                                                  (+생산LOT 선발행·전달사항 배포)
  현장 ─→ S5 작업 전 점검 ──미실시→ [작업 통제/차단] (D3)
            └합격→ S6 작업 시작·4M 투입(자재LOT·금형ID 스캔, 오투입 Validation)
                      └─→ S7 작업실적 수집(생산수량·양품/불량·작업조건)   ← 작업실적 = 생산LOT 1:1 ✅
                            ├─ S8 공정검사(PQC) 트리거 ──→ [품질 검사 절차(OUT)]
                            ├─ S9 불량·비가동 수집(불량코드·계획비가동/실적)
                            └─ S10 생산LOT 완료·인식표 발행(양품 개체별 1:1 ✅)
                                  └─→ S11 공정 이동/WIP ──(다음 공정 S5~)──→ S12 W/O 완료·마감 ─→ [ERP 회신]
```

## S1. P/O 수신 / 생산계획 인지

- **Trigger(촉발)**: ERP에서 P/O(생산계획·대표공정 단위) 발행 → MES 연계 송신 / 생산 착수 임박.
- **Actor(주체)**: 전산(ERP 연계)담당 · 생산관리자.
- **Action(행위)**: P/O(품목·수량·완료예정일·자재예약정보)를 MES가 연계 수신·인지, W/O 전개 대상 식별.
- **Input(입력)**: P/O(ERP 발행분), BOM·Routing(ERP→MES I/F 동기화 마스터).
- **Medium(매체)** 🟡: *가설* — ERP가 Time Schedule/Event로 송신 → MES Temp Table 적재(자동) **또는** 현행은 ERP 화면 조회 후 **엑셀/구두로 생산계획 공유**(연계 미구축 시). 어느 쪽인지가 핵심 분기.
- **Result(결과)**: P/O 연계 참조본 보유(MES). **상태변화 없음**(정보 수신). W/O 전개 대기.
- **Rule(선행조건·규칙)**: P/O 존재. **P/O는 ERP 발행·MES 수신본(수정 불가)** — ✅ 모델 정의(C2).
- **Exception(예외·선행조건 미충족)** 🟠: ① **P/O 없는 긴급·시제(試製) 생산** — 영업 구두·메모로 바로 현장 투입 → MES W/O를 P/O 없이 단독 생성하나(3계층 nullable 상위지시), ERP에 사후 등록하나? ② **P/O 수신 지연/누락**(연계 타이밍 갭) ③ P/O 수정(수량·납기 변경)이 MES 반영 안 됨. [확인] 무(無)P/O 생산 빈도·경로, P/O 변경 시 MES 동기화 방식.
- **Pain/Wish(문제·요구)** 🟡: *가설* — 생산계획이 시스템에 표시되지 않아 *건별로* 지시 / 자재예약(결품 시뮬레이션) 수기 / P/O-실생산 괴리.
- **Boundary(경계)** 🔗: **ERP → MES**. P/O는 ERP 정본(상위지시 계층). BOM·Routing도 ERP 정본(I/F 동기화).
- **Open-Issue(연계 미결)**: ⚠ D10(P/O 수정 가능성·소유) · D18(ERP 연계 통신방식) · B8(3계층 중 상위지시=ERP P/O).
- **[Check(확인)]**: MES가 P/O를 *어디서* 보나(연계 자동? ERP 화면? 엑셀?). P/O 화면에서 MES 수정 가능 여부(D10). 자재예약 정보가 P/O에 실려 오나.

## S2. W/O 전개 · 편성 (세부공정)

- **Trigger(촉발)**: P/O 수신·확인.
- **Actor(주체)**: 생산관리자 (+전산담당).
- **Action(행위)**: ERP P/O를 **Routing 기준으로 세부공정 W/O(작업지시)로 전개**(1 P/O → N W/O), 공정·수량·생산LOT 크기(양품 목표) 설정.
- **Input(입력)**: P/O, 공정/Routing(품목+공정Ver+Sequence), 품목 마스터(생산LOT 기본크기).
- **Medium(매체)** 🟡: *가설* — MES W/O 편성 화면 **또는** 현행은 **엑셀 작업지시서·종이 제조지시서**(레거시·수기 전개). 공정 분할이 담당자 경험에 의존할 가능성.
- **Result(결과)**: W/O 생성(키=W/O No=WorkOrderID), 상태='편성'. **상태변화**: P/O → 세부 W/O 다건.
- **Rule(선행조건·규칙)**: Routing 존재(공정 순서·외주공정 구분). W/O 크기=양품 목표 수량(품목 기본값 + W/O override) — ✅ 모델(C2·C3). 1 P/O→N W/O 전개(✅ C2 관계).
- **Exception(예외·선행조건 미충족)** 🟠: ① **Routing 미등록/구버전**(신규 품목·공정 변경) → 임시 공정·수기 전개? ② **외주공정 포함 W/O**(사내↔외주 분기) 처리 ③ **W/O 없는 긴급생산**(편성 건너뛰고 현장 직투입) → 사후 W/O 역생성? [확인] Routing 없을 때 전개 방법, 외주공정 W/O 분리 여부, 무W/O 생산 실태.
- **Pain/Wish(문제·요구)** 🟡: *가설* — Routing이 시스템에 없어 공정 전개가 수기·경험 의존, P/O↔W/O 수량 정합 수기 대조.
- **Boundary(경계)** 🔗: **ERP(P/O·Routing) → MES(W/O)**. W/O는 MES 작업지시 계층(항상 MES 소유, P/O를 nullable 참조).
- **Open-Issue(연계 미결)**: ⚠ B2(Routing 공정Ver·Sequence 키) · B8(W/O=MES 작업지시 채번) · D10(P/O→W/O 전개 권한).
- **[Check(확인)]**: **현행 P/O→작업 전개 *로직·규칙·입도*** — 1 P/O를 *누가·무슨 기준으로* 몇 개 작업단위로 쪼개나(공정 단위? 수량 단위?). 그 '작업지시' 개념이 우리 W/O 정의(Routing 기준 세부공정)와 일치하나. **P/O→W/O 경계**(ERP가 production order로 어디까지 전개? D10). W/O 채번 주체(B8). 외주공정 포함 여부. *(현행 매체 엑셀/종이/레거시는 마이그레이션·DX 범위 부가 — To-Be는 MES 생성 전제.)*

## S3. 자원배정 (4M 계획) · 유효성 Validation · 우선순위

- **Trigger(촉발)**: W/O 편성됨.
- **Actor(주체)**: 생산관리자 (+설비/현장담당).
- **Action(행위)**: W/O에 **4M 자원 배정**(설비·작업자·자재·툴/금형) → 배정 적합성 Validation(OK/NG·이상 알림) → W/O 우선순위 조정.
- **Input(입력)**: W/O, 설비·작업자·작업조·툴/금형 마스터, BOM 소요량(자재예약).
- **Medium(매체)** 🟡: *가설* — MES 자원배정 화면 **또는** 현행은 **반장 배정(구두/화이트보드)·엑셀 일정표**. Validation은 *사람 판단*일 가능성.
- **Result(결과)**: W/O 자원배정 라인(키=W/O No+자원유형+자원ID), Validation 결과(OK/NG). **상태변화**: W/O '편성'→'확정 대기'. ※ **이것은 계획(배정)이며 실적(4M투입, S6)과 분리** — ⚠ **D11**.
- **Rule(선행조건·규칙)**: 자원 가용(설비 비점유·작업조 편성·자재 가용재고·툴 사용가능)·유효성 OK라야 확정 진행.
- **Exception(예외·선행조건 미충족)** 🟠: ① **자원 충돌·중복 배정**(한 설비 다 W/O 동시) → 우선순위·강제 배정? ② **Validation NG 무시하고 확정**(이상 알림 묵살) → 권한·기록? ③ 배정 자재가 결품(가용재고<소요) → 배정 보류/부분 배정? ④ 배정 작업자 미출근·자격 미달. [확인] Validation NG 시 차단되나, 배정-투입이 화면상 분리되나(D11), 충돌 배정 조정 방법.
- **Pain/Wish(문제·요구)** 🟡: *가설* — 자원 배정이 시스템 밖(경험)이라 오배정·중복, 결품 사전 인지 못 해 착수 후 중단, 우선순위 수기 조정.
- **Boundary(경계)** 🔗: **MES 내부**(생산관리↔현장). 자재 자원은 **창고(C6) 재고**와 맞닿음(가용/Hold 판정). 설비·툴은 C5 상태(점검·보전) 의존.
- **Open-Issue(연계 미결)**: ⚠ **D11**(자원배정 계획 vs 4M투입 실적 분리) · D2(자재 Hold분 배정 차단) · D6(툴 배정·타발수 한도).
- **[Check(확인)]**: 자원배정 화면이 *실제로* 있나, 있으면 Validation이 *동작*하나. 배정한 자원이 그대로 투입으로 넘어가나(D11). 배정 단위(설비·작업자·자재·툴 4종 모두?).

## S4. W/O 확정 · 현장 배포 (+ 생산LOT 선발행 · 전달사항)

- **Trigger(촉발)**: 자원배정·Validation 완료(OK).
- **Actor(주체)**: 생산관리자 → (배포) 현장반장·작업자.
- **Action(행위)**: W/O 확정 → **자동 현장 배포**(POP/단말) → **생산LOT 선발행**(W/O 배포 시점, N=양품목표÷LOT크기) → **전달사항 등록·배포**(작업자 확인 점검).
- **Input(입력)**: 확정 W/O, 생산LOT 크기(양품 목표), 전달사항 메시지.
- **Medium(매체)** 🟡: *가설* — MES→POP 자동 배포 **또는** 현행은 **종이 작업지시서 출력·게시판 부착·구두 전달**. 생산LOT 선발행은 미실시(현장 실시간 발번)일 가능성 — 발행 방식 자체가 미정.
- **Result(결과)**: W/O 상태 '확정→배포', **생산LOT N건 선발행**(상태=대기, 키=생산LOT No), 전달사항 배포·확인 이력. **상태변화**: 지시가 현장 가시화 → 작업 착수 가능.
- **Rule(선행조건·규칙)**: 확정 W/O라야 배포. **생산LOT = MES 발행 정본**, W/O 배포 시 선발행 — ✅ 모델(C2·C3). 작업실적—생산LOT **1:1**(✅ A3·B3 확정). 전달사항은 W/O 기준 배포·확인.
- **Exception(예외·선행조건 미충족)** 🟠: ① **생산LOT 발번 실패/중복**(채번 충돌·연번 깨짐) → 수기 채번/재시도? ② **선발행 vs 현장 실시간 발행 불일치**(모델은 선발행, 현장은 작업 끝나고 발번) → 어느 쪽? ③ **전달사항 미확인 채 작업 시작**(확인 점검 무력) ④ 배포 후 W/O 수정·취소(LOT 회수?). [확인] 생산LOT을 *언제* 발번하나(배포 시? 완료 시?), 발번 실패 처리, 전달사항 확인이 작업 통제와 연동되나.
- **Pain/Wish(문제·요구)** 🟡: *가설* — 지시 전달이 종이·구두라 누락·버전 혼선, 생산LOT 채번 수기로 중복, 전달사항 확인 여부 추적 불가.
- **Boundary(경계)** 🔗: **생산관리 → 현장(POP)**. **전달사항 소유경계** = 생산실행(C2 전달사항) vs 현장 Popup 전달(C4) — ⚠ **C1**(질문지)·종합10. 생산LOT 발행=**MES 정본**.
- **Open-Issue(연계 미결)**: ⚠ **C1**(전달사항 C2↔C4 소유, 종합10) · A3·B3(작업실적=생산LOT 1:1, ✅확정 — 현장 실태만) · 생산LOT 선발행 vs 실시간(C3 발행방식, 분해도 2.2.2.3).
- **[Check(확인)]**: **현행 작업지시가 작업자에게 *어떻게 전달·확인*되나**(구두? 종이 출력·게시? 화이트보드?) 및 그 Pain. 생산LOT 발번 *시점·화면*(선발행 vs 완료 시). 전달사항과 현장 Popup이 *같은 메시지*인가(C1). 전달사항 확인 이력 남나. *(전달 방식은 현행 Pain·DX 범위 — To-Be는 POP 전제.)*

## S5. 작업 전 점검 / 작업 통제

- **Trigger(촉발)**: 작업자 POP 로그인 → 배포 W/O 선택 → 작업 착수 시도.
- **Actor(주체)**: 현장반장·작업자 (+설비담당).
- **Action(행위)**: 설비 작업 전 점검(Daily Check 등) 수행·기록 → **점검 이력 없으면 작업 통제(차단)**.
- **Input(입력)**: 설비 점검 항목·기준(설비 마스터), 점검 이력.
- **Medium(매체)** 🟡: *가설* — 종이 점검표·체크시트 **또는** POP 점검 입력. 통제(차단)가 *시스템 강제*인지 *반장 구두 확인*인지 불명.
- **Result(결과)**: 점검 이력 생성, 작업 진행 허용/차단. **상태변화**: W/O '배포'→'진행 가능' 또는 '진행불가'.
- **Rule(선행조건·규칙)**: **작업 전 점검 이력 존재 = 작업 진행 선행조건** — ✅ 분해도 3.1.1.
- **Exception(예외·선행조건 미충족)** 🟠: ① **점검 미실시인데 작업 강행**(긴급·통제 미작동) → 차단되나 우회되나, 누가 승인? ② **점검 NG(설비 이상)** → 작업 통제 + 보전(C5) 연계·비가동 처리? ③ 점검 항목 미등록(신규 설비). [확인] 점검 미실시 시 *실제로* 작업이 막히나(시스템 강제 vs 구두), NG 시 보전/비가동 전환 경로, 통제가 W/O 상태에 반영되나.
- **Pain/Wish(문제·요구)** 🟡: *가설* — 점검이 형식적(사후 일괄 체크), 통제 미작동으로 미점검 설비 가동, 점검-비가동-보전 연계 끊김.
- **Boundary(경계)** 🔗: **설비점검(C5 이력) ↔ 작업진행(C2/C3)**. 작업 통제 판정이 점검이력에 의존 — 경계 검증 지점.
- **Open-Issue(연계 미결)**: ⚠ **D3**(작업 통제↔설비점검 이력 연계) · D4(설비 보전 경량 보유 — 점검 MES 유지).
- **[Check(확인)]**: 점검 미실시 시 작업 통제가 *걸리는지* 시연 관찰. 점검 입력 매체(종이/POP). 점검 NG가 비가동·보전으로 *이어지는지*.

## S6. 작업 시작 · 4M 투입 (자재LOT·금형ID 스캔)

- **Trigger(촉발)**: 작업 전 점검 통과·작업 시작.
- **Actor(주체)**: 작업자·현장반장.
- **Action(행위)**: 설비 선택 → 작업 시작 → **4M 투입**(작업자·자재LOT·금형·작업조건) — **자재LOT·금형ID 스캔** → 오투입 Validation(작업지시 적합성).
- **Input(입력)**: 진행 W/O, 투입 자재LOT(창고 출고분), 설비·작업자·툴/금형, 작업조건 설정값.
- **Medium(매체)** 🟡: *가설* — POP 스캔(바코드/QR) **또는** 현행은 **종이 투입기록·구두**(LOT 미스캔). 스캔 인프라 유무가 genealogy의 분기점.
- **Result(결과)**: 4M투입 라인 생성(키=작업실적 No+투입유형+자원ID), **genealogy 시작**(자재LOT→생산LOT). Validation(적합/오투입). **상태변화**: 자재 → WIP 투입, 생산LOT '대기'→'진행'.
- **Rule(선행조건·규칙)**: 투입 자재LOT은 **가용(Release)분**이라야 투입. 투입유형별 자원ID 참조(자재LOT·설비·작업자·툴). 오투입 Validation(작업지시 BOM 적합).
- **Exception(예외·선행조건 미충족)** 🟠: ① **자재 결품·부족으로 작업 중단**(출고 자재 < 소요) → 부분 투입/대체자재/대기? ② **오투입(Validation NG)**(배정 외 자재·금형 스캔) → 차단되나 강행되나? ③ **LOT 미스캔 투입**(스캔 생략) → genealogy 끊김, 수기 보정? ④ Hold 자재 강제 투입 ⑤ 금형 사용한도(적정타수) 초과 투입. [확인] 결품 시 작업 중단/대체 처리, 오투입 차단 실효, LOT 미스캔 빈도, 타발수 한도 통제(D6).
- **Pain/Wish(문제·요구)** 🟡: *가설* — 투입 LOT을 안 적어/안 찍어 **역추적(genealogy) 끊김**, 오투입 사후 발견, 작업조건 수기 기록 누락.
- **Boundary(경계)** 🔗: **창고(C6 출고) → 생산(C2 4M투입)**. 자재LOT 발행주체(MES vs ERP)가 genealogy 시작점 — ⚠ **A1**. 금형 타발수는 툴사용실적(C5)으로 집계.
- **Open-Issue(연계 미결)**: ⚠ **A1**(자재LOT 발번·genealogy 시작) · A5(역추적 시작) · D11(배정 vs 투입 분리) · D2(Hold 자재 투입 차단) · D6(타발수 수집 단위·한도).
- **[Check(확인)]**: 투입 시 *어느 자재LOT을 넣었는지* 기록·스캔하나(genealogy 핵심). 오투입 Validation이 *실제로* 막나. 금형ID 스캔→타발수 수집되나. Hold 자재 투입 차단 걸리나.

## S7. 작업실적 수집 (생산수량 · 양품/불량 · 작업조건)

- **Trigger(촉발)**: 작업 진행·완료 시점(회차/교대 무관, 양품 목표 단위).
- **Actor(주체)**: 작업자·현장반장 (+향후 IoT 자동수집).
- **Action(행위)**: W/O 단위 생산실적 수집 — 생산수량·양품수·불량수·작업조건(설정값/실측값)·시작·종료시간. **작업실적 1건 = 생산LOT 1건**에 누적.
- **Input(입력)**: 진행 W/O·생산LOT(선발행분), 카운터/계측값, 작업조건.
- **Medium(매체)** 🟡: *가설* — POP 수작업 입력(바코드/스캐너) **또는** 현행은 **종이 생산일보→엑셀 이중입력**. 자동수집(DAS/SCADA)은 향후.
- **Result(결과)**: 작업실적 생성(키=작업실적 No, **생산LOT 단위 ✅**), 생산LOT에 생산·불량 누적. **상태변화**: 생산LOT 진행 누적(양품 목표 향해).
- **Rule(선행조건·규칙)**: **작업실적 키 = 생산LOT 단위, W/O당 N건**(정량 분할, 회차/교대/자재배치 무관) — ✅ **B3·A3 확정**. 작업실적→생산LOT **1:1** — ✅ A3.
- **Exception(예외·선행조건 미충족)** 🟠: ① **실적 사후 수기 보정**(실시간 미입력 → 교대 끝나고 몰아서/엑셀 역입력) → 시점·승인·정합? ② **회차/배치별로 실적이 쌓이는 운영**(모델은 정량 LOT 1:1 — 현장이 회차 누적이면 키 재검토) ③ 생산수량 > 양품 목표(초과 생산) → LOT 추가 발행? ④ 작업조건 미수집(설비 자동연계 없음). [확인] 실적을 *실시간* 입력하나 사후 몰아서 하나, 실적 화면이 회차별로 쌓이나 LOT 1건인가(B3), 초과 생산 처리.
- **Pain/Wish(문제·요구)** 🟡: *가설* — 실적 종이→엑셀 이중입력·지연, 작업조건 수기 누락, 실시간 현황 부재(P/O·W/O 대비 진척이 보이지 않음).
- **Boundary(경계)** 🔗: **현장(POP) ↔ 생산관리(C2)**. 작업조건 실측값은 **SPC측정값(C4)**·설비측정값과 동일 실체인지 경계 — ⚠ C5(질문지)·D9. 작업실적(현장 4.2.4) vs 작업실적(생산 2.2) 소유 단일화 검증.
- **Open-Issue(연계 미결)**: ⚠ **B3·A3**(작업실적=생산LOT 1:1, ✅확정 — 실태만) · C5(SPC 측정값=검사결과값 vs 설비 자동수집) · D9(설비측정값-SPC 매핑) · D6(타발수=작업실적 단위 여부).
- **[Check(확인)]**: 실적 입력이 *회당 1건(LOT)*인지 *회차별 List 누적*인지(B3). 실적 입력 매체·시점(실시간 vs 사후). 작업조건 실측값이 수집되나(SPC 연계).

## S8. 공정검사(PQC) 트리거 · 품질 연계

- **Trigger(촉발)**: 작업실적 수집 중/후 공정검사 발생(자주·초중종).
- **Actor(주체)**: 작업자(자주) · 품질담당(초중종) (+계측기).
- **Action(행위)**: 공정검사(PQC) **트리거·연계**(검사실적 호출) — *검사 내부 절차(항목 측정·판정·성적서)는 품질 문서 범위(OUT)*. 본 단계는 생산실행이 검사를 *부르고 결과를 받는* 경계만 다룬다.
- **Input(입력)**: 진행 생산LOT/W/O, 검사기준(검사항목·UCL/LCL/Target), 계측값.
- **Medium(매체)** 🟡: *가설* — POP 검사 화면(계측값 자동 연계) **또는** 현행은 **종이 검사일지·엑셀 자주검사표**. 검사기준 정본 위치 불명.
- **Result(결과)**: 검사실적 트리거(C4 소유), 합/불·불량 연계. **상태변화**: (검사 결과에 따라) 생산LOT 진행/Hold·불량 가산.
- **Rule(선행조건·규칙)**: 공정검사 시점 규칙(초·중·종/자주 주기) 존재. 검사기준 등록(검사항목).
- **Exception(예외·선행조건 미충족)** 🟠: ① **검사기준 미등록**(신규 품목/공정) → 무검사 진행/임시기준? ② **검사 NG(공정 불량 발생)** → 작업 중단·재작업·특채 분기? ③ 계측기 미검교정·자동연계 두절 → 수기 입력? ④ 자주검사 미실시(생략). [확인] 검사기준 없을 때 진행 방법, NG 시 생산 통제 경로, 계측값 자동/수기.
- **Pain/Wish(문제·요구)** 🟡: *가설* — 검사 결과 종이→엑셀 이중입력, 검사-생산 실적 연계 끊김, 검사기준 버전 혼선.
- **Boundary(경계)** 🔗: **생산(C2) ↔ 품질(C4)**. 검사 *기준* 정본(ERP QM/MES/별도 QMS 미정) — ⚠ **B5**. 검사 *결과* 헤더/라인 구조 — ⚠ B4. (검사 내부 절차·Lot Status는 품질 문서)
- **Open-Issue(연계 미결)**: ⚠ B5(검사기준 정본·결과 연계) · B4(검사결과 헤더/라인) · 검사실적—W/O 연결(C4 미결, PQC가 W/O vs 생산LOT 단위).
- **[Check(확인)]**: 공정검사를 *생산 POP에서* 하나 *품질 화면에서* 하나(소유). 검사 결과가 작업실적·생산LOT에 *연계*되나. 검사기준이 어디 저장되나(B5).

## S9. 불량 · 비가동 수집

- **Trigger(촉발)**: 작업 중 불량 발생 · 설비/공정 정지(고장·자재대기·Job Change 등).
- **Actor(주체)**: 작업자·현장반장 (+품질·설비담당).
- **Action(행위)**: **불량 수집**(불량코드 부여·불량수) + **비가동 수집**(사유 분류·시간). 계획 비가동(WorkCalendar)과 실적 비가동(현장) 구분.
- **Input(입력)**: 불량코드(공정별/공통), 비가동 사유코드, WorkCalendar(계획 비가동 기준), 작업실적.
- **Medium(매체)** 🟡: *가설* — POP 불량/비가동 입력 **또는** 현행은 **종이 일보 비고란·구두**. 사유코드 체계 유무·준수 불명.
- **Result(결과)**: 불량 실적(생산LOT 불량수 가산)·비가동 실적(시간·사유). **상태변화**: 양품수 확정에 반영(양품=생산-불량), 가동률 산출 기초.
- **Rule(선행조건·규칙)**: 불량코드 부여. **비가동: 계획=WorkCalendar(C1) / 실적=현장(C4)** — ✅ 용어사전 구분. 불량은 **양품 미부착**(인식표는 양품만).
- **Exception(예외·선행조건 미충족)** 🟠: ① **불량 과다·재작업**(불량률 급증) → 작업 중단/재작업 LOT 처리·수율 반영? ② **비가동 사유 미분류**('기타'로 뭉뚱그림·미입력) → 가동률 왜곡, 강제 분류? ③ 같은 불량이 **품질 검사·현장·생산에서 중복 집계** → 소유 단일화? ④ 계획 비가동을 실적으로 잘못 기록. [확인] 불량 입력 경로(품질/현장/생산)와 중복 여부(C2), 비가동 사유 미분류 처리, 재작업 흐름.
- **Pain/Wish(문제·요구)** 🟡: *가설* — 비가동 사유가 '기타' 일색이라 분석 불가, 불량 중복·누락 집계, 재작업 추적 부재, 수율 부정확.
- **Boundary(경계)** 🔗: **현장(C4 비가동·불량) ↔ 생산(C2 작업실적) ↔ 품질(C4 검사 불량)**. 불량 실적 소유경계 — ⚠ **C2**(질문지)·종합11. 비가동 계획/실적 — C1↔C4·C5.
- **Open-Issue(연계 미결)**: ⚠ **C2**(불량 실적 소유 품질 vs 현장 vs 생산, 종합11) · **D7**(공정별 vs 공통 불량코드) · **D8**(WorkCalendar 귀속 단위) · 비가동 계획/실적 연계(C4·C5).
- **[Check(확인)]**: 불량을 *어디서* 입력하나(중복 경로 추적, C2). 비가동 사유코드가 *실제로* 분류되나('기타' 비율). WorkCalendar가 어느 자원에 걸리나(D8). 재작업이 LOT·수율에 반영되나.

## S10. 생산LOT 완료 · 인식표 발행

- **Trigger(촉발)**: 생산LOT 양품 목표 수량 달성(또는 마감 결정).
- **Actor(주체)**: 작업자·현장반장 (+Label Printer).
- **Action(행위)**: 생산LOT 완료 처리 → **인식표(QR) 발행·부착**(양품 생산품 **개체별 1:1**, seq=개체 일련번호). 불량품 미부착(불량수만 집계).
- **Input(입력)**: 완료 생산LOT(양품수), 인식표 양식(생산LOT No+seq).
- **Medium(매체)** 🟡: *가설* — Label Printer 자동 발행 **또는** 현행은 **수기 라벨·미부착**(인식표 체계 없음 가능). 부착 단위(개체/이동/박스)가 핵심.
- **Result(결과)**: 생산LOT 완료(상태='완료'), **인식표 N장**(N=양품수, 개체별). **상태변화**: 생산LOT 양품 확정, WIP→이동/입고 대상.
- **Rule(선행조건·규칙)**: **인식표 = 생산품 개체별 1:1, seq=개체 일련번호** — ✅ **A4 확정**. 완료=양품 목표 달성(표준, **모델 비강제** — 미달 완료는 별도 명시 액션). 이동단위 인식표 없음(출하단위=제품LOT) — ✅ A4.
- **Exception(예외·선행조건 미충족)** 🟠: ① **계획 대비 실적 미달 완료**(양품 목표 못 채우고 마감) → 미달 사유·잔량 W/O 처리·LOT 부분완료? ② **인식표 발행 실패**(프린터 장애·seq 중복) → 수기 라벨/재발행? ③ **인식표 미부착 운영**(라벨 체계 부재) → 개체 추적 불가, 박스/이동 단위로만? ④ 초과 생산분 LOT(양품 > 목표). [확인] 미달 완료 시 처리·기록, 인식표 발행 단위·실물, 발번 실패 대응.
- **Pain/Wish(문제·요구)** 🟡: *가설* — 인식표 미부착으로 개체 추적 불가, seq 수기 채번 중복, 완료 판정이 사람 임의(목표 비강제).
- **Boundary(경계)** 🔗: **생산(C2) → LOT코어(C3)**. 생산LOT=MES 정본. 인식표 발행=MES(Label Printer). 다음 단계(공정이동·제품입고)는 C6 경계.
- **Open-Issue(연계 미결)**: ⚠ **A4**(인식표 개체별 1:1·seq, ✅확정 — 실태만) · A3(작업실적-생산LOT 1:1) · 생산LOT 완료 비강제(C3, 미달 완료 액션).
- **[Check(확인)]**: 인식표가 *실제 부착*되나, *한 LOT에 몇 장* 붙나(개체별 검증, A4). 목표 미달 시 *완료가 되나*(비강제 실태). seq 채번 주체.

## S11. 공정 이동 / WIP

- **Trigger(촉발)**: 공정 완료(생산LOT/인식표 단위) · 다음 공정 인계.
- **Actor(주체)**: 현장반장·작업자.
- **Action(행위)**: 적재 완료분을 다음 공정으로 이동(Push/Pull), WIP(재공) 위치·상태 관리. 인식표 기준 재공 추적.
- **Input(입력)**: 완료 생산LOT/인식표, 다음 공정 Routing, 이동/적치 위치.
- **Medium(매체)** 🟡: *가설* — POP 이동 스캔 **또는** 현행은 **구두·종이 공정이동표·반제품 대차 이동**(시스템 미반영). WIP 위치가 담당자 기억에 의존할 가능성.
- **Result(결과)**: WIP 위치·상태 갱신, 다음 공정 대기. **상태변화**: 생산LOT/재공 위치 이동(공정 진척).
- **Rule(선행조건·규칙)**: 이동 단위(인식표 개체/박스/대차) 정의. 다음 공정 Routing Sequence 존재. **이동단위 인식표는 없음**(개체별 인식표·출하 제품LOT만) — ✅ A4. 반제품도 다음 W/O 자재로 투입(genealogy 연속).
- **Exception(예외·선행조건 미충족)** 🟠: ① **공정 간 정체·WIP 누적**(다음 공정 미준비) → 임시 적치·우회? ② **이동 후 위치/실적 갱신 누락**(시스템 미반영) → WIP 부정확, 사후 보정? ③ 반제품 분할/합류(여러 LOT 혼입) → genealogy 추적? ④ 외주공정 이동(사외 반출). [확인] 공정 이동을 *기록*하나, WIP 위치가 시스템에 있나, 반제품 LOT 추적되나, 외주 반출입 처리.
- **Pain/Wish(문제·요구)** 🟡: *가설* — WIP가 시스템에 없어 재공 파악 불가, 공정 간 LOT 추적 끊김, 정체 병목이 보이지 않음.
- **Boundary(경계)** 🔗: **공정↔공정(C2/C3 내부)**, 반제품 입출고는 **창고(C6)** 와 맞닿음(반제품 창고). 외주공정은 외주 반출입 경계.
- **Open-Issue(연계 미결)**: ⚠ A5(역추적 — 공정 간 LOT 승계) · A4(이동단위 인식표 불요, ✅확정) · 반제품 genealogy 연속(C3).
- **[Check(확인)]**: 공정 이동 시 *무엇을* 스캔/기록하나. WIP 현황을 *어디서* 보나. 반제품이 다음 공정 자재로 *연결 추적*되나.

## S12. W/O 완료 · 마감

- **Trigger(촉발)**: W/O 내 모든 생산LOT 완료 · 생산 종료.
- **Actor(주체)**: 생산관리자·현장반장 (+전산담당).
- **Action(행위)**: W/O 완료·마감 처리 → 계획(P/O·W/O) 대비 실적 집계 → 제조이력(투입·실적·LOT) 확정 → ERP 회신(MES→ERP 제조이력 송신).
- **Input(입력)**: 완료 생산LOT·작업실적·4M투입·불량·비가동, P/O·W/O 목표.
- **Medium(매체)** 🟡: *가설* — MES 마감 화면 + 연계 송신 **또는** 현행은 **엑셀 실적 집계·수기 ERP 입력**(연계 미구축 시). 마감-회신 사이 수기 갭 가능.
- **Result(결과)**: W/O 상태 '완료/마감', 생산현황 확정, ERP 제조이력 회신. **상태변화**: 지시 사이클 종료(P/O 진척 갱신).
- **Rule(선행조건·규칙)**: W/O 내 생산LOT 완료(또는 미달 마감 명시). 마감 후 실적 수정 통제. **MES→ERP 송신**(투입자재·공수·설비시간·생산/불량/비가동/검사 실적) — 분해도 1.3.3.2.
- **Exception(예외·선행조건 미충족)** 🟠: ① **계획 대비 실적 미달 마감**(목표 미달성 종료) → 잔량 W/O 이월/재지시·미달 사유? ② **마감 후 실적 보정 필요**(오류 발견) → 마감 취소·역분개 권한? ③ ERP 회신 실패/지연(연계 두절) → 수기 입력·재전송? ④ 미완료 LOT 잔존 채 마감(강제 마감). [확인] 미달 마감 처리·잔량 이월, 마감 후 수정 권한·기록, ERP 회신 방식·실패 대응.
- **Pain/Wish(문제·요구)** 🟡: *가설* — 마감이 엑셀 집계라 지연·오류, 계획 대비 실적 분석 수기, ERP 회신 수기 이중입력, 마감 후 보정 추적 부실.
- **Boundary(경계)** 🔗: **MES → ERP**(제조이력 회신·생산 실적 확정). 회계전표 성격 약함(생산 실적은 주로 MES 정본, ERP는 원가·자재소비 반영). P/O 진척은 ERP.
- **Open-Issue(연계 미결)**: ⚠ B8(3계층 — 생산은 회계전표 약함, MES 주도) · D18(MES→ERP 송신 통신방식) · D10(P/O 진척 갱신 주체).
- **[Check(확인)]**: **현행 W/O 마감 *기준·절차*** — 무엇을 충족해야 마감하나(양품 목표 도달? 수기 판단?), 계획 대비 실적이 *집계·대조되나*. **ERP 회신이 자동인가 수기인가**(연계 방식). 마감 후 수정 통제되나. *(마감은 To-Be에선 MES 수행 — 매체보다 마감 *규칙*·ERP 회신 방식이 핵심.)*

## 현장 실행 체크리스트 (생산 실행)

- 종이/엑셀 양식: 작업지시서(제조지시서)·생산일보·자주검사표·비가동 일지·점검 체크시트·실적 집계표
- 라벨 실물: **인식표(QR) 라벨**(한 LOT당 장수 = 개체별 검증, A4) · 공정이동표
- 화면 캡처: W/O 편성·자원배정·POP 작업실적 입력·생산LOT 발번·생산현황 화면
- **DB 스키마 + 대표 덤프**: W/O·작업실적·4M투입·생산LOT·인식표·비가동 테이블 (B섹션 L3 결론)

**정량 데이터(APS·사이징용)**: 일/월 W/O 건수, P/O당 평균 W/O 수(공정 분할), 일 생산LOT 발생량, 작업실적 건수, 평균 양품 목표(LOT 크기), 불량률·비가동률, 공정 수·설비 수, 인식표 발행량.

**관찰 포인트(말 말고 동작)**: 생산LOT이 *언제* 발번되나(배포 시 선발행 vs 완료 시), 투입 자재LOT을 *실제로 스캔/기록*하나(genealogy), 인식표가 *개체별로* 붙나, 점검 미실시 시 작업이 *정말* 막히나(D3), 비가동 사유가 *분류되나*('기타' 비율), 실적을 *실시간* 입력하나 사후 몰아서 하나.
