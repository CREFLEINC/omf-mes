## 1. 메인 구조도 — 공정검사(PQC) 중심 축

### 1.0 축 설계 판단 (문서 근거)

**메인 축 = PQC(공정검사) 트리거 → 검사 수행 → 합부 판정 → Lot Status → 불량/부적합 처리.** IQC·OQC는 상세를 그리지 않고 경계 표시만 한다.

- **IQC 제외 근거**: WF03 v1.2 범위(OUT) — "수입검사(IQC)는 자재 창고 관리 문서 S3에 작성… 본 문서는 참조만 하고 중복 작성하지 않는다". 자재LOT은 IQC 합격 시점 생성이므로(REQ-PR-0007) IQC 검사 대상 식별도 01 도식 소관.
- **OQC 제외 근거**: WF04 v1.2 범위(IN)에 출하검사(OQC)가 포함된다(WF04 S5 — MES 출하작업지시의 Pick→OQC→Pack 실행 체인). 04 도식이 OQC·납품라벨 Matching 상세를 소관하므로 03 도식은 경계 표시만 하여 중복을 없앤다.
- **공통 구조 주석**: 검사 3종(IQC/PQC/OQC)은 **단일 검사실적 엔티티 + 검사유형 코드**(WF03 요약 '검사 3종 통합')이므로, 메인 축의 검사 기록(3계층)·Lot Status 단일 정본 구간은 3유형 공통 구조임을 경계 스티키에 명시한다 — IQC·OQC 도식도 같은 MES 노트 구조를 따른다.

### 1.4 ④ MES 데이터 노트 전문 (Server(MES) 아이콘 + 초록 스티키)

Server 아이콘 그룹 4개(기준정보 / 검사 3계층 / Lot Status / 불량) 아래 스티키 10장. 각 스티키 ≤12줄.

**N1 — 검사기준 (H0·U1 위쪽, U1 `검사실적 입력`으로 초록 화살표)**
```
검사기준 (품질기준값)
KEY - 검사유형+품목+검사항목
· 검사유형: IQC/PQC/OQC
· UCL · LCL · Target · 단위
· 정본 = MES (현행 엑셀 → 이관)
상태 : 검사 전 등록 필수
```

**N2 — 검사정책 (H0 옆)**
```
검사정책 (PQC 수행 여부·방식)
KEY - 품목+공정+검사유형
· Routing 검사 명시 = 수행 / 미명시 = 생략 (opt-in)
· 검사 방식 = 전수 / 샘플 (설정값)
· 샘플 = 제품 단위 / LOT 단위 + 비율(%)
· W/O 전개 시 % 무작위 배정
· 합격판정개수 (공정별) 초과 → W/O 전체 재검사
· 검사기준 미비 = 정상/불량 단순 선택 + 자유 입력
상태 : 기준정보 (건별 승인 아님)
```
※ 검사 방식(전수/샘플)·합격판정개수·재검사 흐름은 ✓확정 2026-07-15(research/2026-07-15-PQC-검사방식-확정기록.md). PQC 최소 단위=제품. **v2 이식 시 H0 분기에 「검사 방식」 표기·「PQC 검사 필요」(재검사 Hold) 흐름 추가 반영 대상.**

### 1.5 ⑤ ERP 연계 — 비연계 원칙의 명시 방법

**품질 도메인에서는 ERP 화살표를 단 하나도 그리지 않는다** — 검사 기준·검사 결과(합불 수량 포함) 모두 ERP 비연계 확정. 다만 고객이 '합불 수량 ERP 전달'을 관성적으로 기대할 수 있으므로, 오해 방지를 위해 **Database(ERP) 아이콘 1개를 우상단에 연결선 없이 배치**하고 옆에 회색 주석 스티키를 붙인다:

```
ERP 비연계 (품질 도메인)
· 검사 기준·검사 결과 모두
  ERP 전달 없음
· ERP 필수 송신 = 생산 실적뿐
  (개발품 제외 — 02 도식)
· G/R=01 · 출하 PGI=04 —
  여타 송신 = 해당 도식 참조
· 이 도식에 ERP 화살표 없음
```
