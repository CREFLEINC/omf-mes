## 0. 사용법 · 범위 · 발견 방법

**이 문서의 위상**: 사전 정의 = *커버리지 체크리스트 + 현행 가설*. 현장에서 채우는 틀이 아니라 **깨러 가는 가설**이다. 각 단계의 Medium·Pain은 전형적 제조 SME(종이·엑셀·레거시) 기준 추정이며, **UNIMES 제안서(벤더 To-Be)에 앵커링하지 않는다** — 단계 목록(커버리지)만 데이터모델에서 빌려오고, *현행이 실제 어떻게 도느냐*는 개방형으로 듣는다.

**범위(IN)**: 완제품(제품·외주 반제품) 창고의 입고~보관~출하 사이클 — 제품입고(생산완료/외주 → 완제품 창고, 제품LOT 형성) · 완제품 재고 보관(가용/Hold) · ERP 출하지시 수신 · Picking(제품LOT 선택) · 출하검사(OQC) · Packing(제품LOT·납품라벨·고객 바코드) · 고객 출하(PGI) · 포장 합병/분할 · 고객 반품·클레임입고 · 제품 폐기(⚠갭).
**범위(OUT, 별도 워크플로우)**: 자재 입출고(가설본 ①) · 생산 실적 *내부* 절차 · 생산 투입용 자재 출고(Issue). (경계로 맞닿는 지점은 🔗로 표시)

**핵심 결정 반영(확인 후 현장 검증 대상)**
- ✅ **A2 확정** — 생산LOT↔제품LOT = **N:M**, **제품LOT 크기 = 포장 수량**(생산LOT N개 묶음·개수 가변). 포장구성이 매개. (현장은 포장 단위 실태만 확인)
- ✅ **출하 3계층(우리 결정)** — **ERP 출하지시(상위) → MES 출하작업지시(실행: Pick·OQC·Pack·LOT확정) → ERP 출하(PGI) 전표(매출·COGS·세금)**. 회계전표 = ERP 소유, 실행 = MES 소유(상위지시 nullable 참조).
- 🟡 **제품LOT 선택 시점 = MES Picking**(FEFO/위치/가용재고). ERP 사전할당도 선택지이나 덜 일반적 — **우리 보정, [확인필요]**(A5 역추적 시작점과 직결).
- ⚠ **제품LOT 발행 주체** — 정본=MES이나 원본 p.57·아키텍처는 제품LOT을 ERP부문으로 도식(소유 경계 혼재, A1).

**발견 방법(현장)**: ① 1건 추적(실제 출하 1건을 제품입고→재고→출하지시→Picking→OQC→Packing→고객출하까지 따라가기) ② 역추적 1건(클레임/반품 1건을 제품LOT→생산LOT→자재LOT으로 거꾸로 시연받기 — A5) ③ 관찰(말이 아니라 실제 동작) ④ 실물·데이터 수집(납품서·출하대장 엑셀·납품라벨/고객 바코드 실물·포장 사진·DB 스키마+덤프). 각 단계 끝 **[확인]** 에 관찰·수집·질문 포인트.

**워크플로우 개요(가설)**
```
[생산완료(생산LOT)] / [외주 제품·반제품 도착] ─→ S1 제품입고(포장단위·제품LOT 형성) → S2 완제품 재고 보관(가용/Hold)
                                                          │
[ERP 출하지시] ─수신→ S3 출하작업지시 생성 ─→ S4 Picking(제품LOT 선택·FEFO) → S5 출하검사(OQC)
                                                          ├─합격→ S6 Packing(납품라벨·생산LOT Matching·고객 바코드) → S7 고객 출하 → [ERP 출하(PGI) 전표]
                                                          └─불합격→ 출하 보류 → 재검/특채/폐기
  S2 ──┬─ 재포장·출하단위 조정 → S8 포장 합병/분할(genealogy 승계) ⚠
       └─ 고객 부적합·클레임 → S9 반품·클레임입고(3유형 재고영향) → 재검(OQC/IQC)
  S1/S2/S9 ─ 불량·진부화·재작업불가 → S10 제품 폐기(Scrap) ⚠갭(D21)
```

## S1. 제품입고 (생산완료/외주 → 완제품 창고 · 제품LOT 형성)

- **Trigger**: 생산LOT 완료(양품 목표 달성) / 외주 제품·반제품 도착.
- **Actor**: 물류(완제품창고)담당 (+생산/현장담당, 외주분은 품질담당 동석).
- **Action**: 생산완료품(생산LOT)·외주품을 제품창고 입고·적치 → **포장단위(Pallet/박스) 형성** → **제품LOT 형성**(=포장 수량 묶음). 외주품은 *제품입고 시점* 수입검사로 분기.
- **Input**: 생산LOT(완료분)/외주 납품분, 인식표(생산품 개체 QR), 포장 기준(포장 수량), 창고/Location.
- **Medium** 🟡: *가설* — **레거시/구 ERP 제품입고 입력 또는 엑셀 제품재고대장 가산**. 인식표 스캔으로 묶는지, 수기 집계인지 불명. (생산↔물류 핸드오프가 *갇힘↔열림*의 분기)
- **Result**: **제품LOT 생성**(키=제품LOT No), 포장라벨, **제품 재고 증가**(품목+제품LOT+Location). **상태변화**: 생산LOT/외주분 → 완제품 가용 재고(또는 Hold).
- **Rule/선행조건**: ✅ **A2** — 제품LOT = 포장 수량(생산LOT N개 묶음·N:M). 생산LOT↔제품LOT은 **포장구성**이 매개. 제품입고—생산LOT 1:N, 제품입고—포장단위 1:N(⚠ 확인). 제품LOT 발번 주체 = **MES vs ERP**(⚠ **A1**, 원본 p.57=ERP부문 혼재).
- **예외(선행조건 미충족)** 🟠: ① **포장 미완·벌크 입고**(포장 전 제품을 우선 재고화) → 제품LOT을 언제 채우나(입고 시 vs 포장 시) ② **외주품 IQC 미완 입고**(긴급) → 검사 전 가입고? ③ 제품LOT 채번 실패/중복 ④ **부분 완료품 입고**(양품 목표 미달 LOT) ⑤ 적치 공간 부족. [확인] 포장 전 입고 허용·제품LOT 형성 시점, 외주 검사 전 입고와 사후 정합.
- **Pain/Wish** 🟡: *가설* — 생산LOT↔제품LOT 묶음이 수기라 **포장구성(genealogy) 끊김**, 제품LOT 채번 중복·누락, 제품재고대장 수기 가산 지연.
- **경계** 🔗: **생산(C2/C3) → 물류(C6)**. 제품LOT 발행=MES 정본(우리 모델) vs ERP 도식 → **A1** 걸림. 외주 제품입고 검사는 **품질(C4)** 과 맞닿음.
- **연계 미결**: ⚠ A1(제품LOT 발번) · A2(생산LOT↔제품LOT N:M·포장수량, ✅확정·실태확인) · D12(제품입고 LOT 묶음) · B8(제품입고 발번 3계층).
- **[확인]**: **제품LOT 라벨/포장라벨 실물**과 **발번 화면**(ERP/MES/레거시)을 *같이* 본다. 생산LOT 몇 개가 한 제품LOT(포장)으로 묶이나(N 관찰). 외주 제품입고 IQC가 *언제* 걸리나(입하 vs 제품입고).

## S2. 완제품 재고 보관 · 상태(가용/Hold) 관리

- **Trigger**: 제품입고 완료 / 상태 변경 사유 발생(검사·홀드·해제·유효기간).
- **Actor**: 물류(완제품창고)담당 (+품질담당: Hold/Release 판정).
- **Action**: 완제품 재고 현황 유지, 가용/Hold 상태 관리, 유효기간·선입선출(FEFO) 기준 관리.
- **Input**: 제품 재고 스냅샷, 검사결과/Lot Status, 유효기간.
- **Medium** 🟡: *가설* — **엑셀 제품재고대장**(일/주 갱신). 실시간성 없음. Hold는 비고란/색칠.
- **Result**: 완제품 재고 현황(수량·위치·상태). **상태변화**: 가용 ↔ Hold. 가용재고 = Release분.
- **Rule/선행조건**: **Hold/Release를 재고가 직접 보유 vs 품질 Lot Status 참조** — ⚠ **D2**. 재고 키 = 품목+제품LOT+Location 복합 여부·LOT:재고 카디널리티 — ⚠ **B7**. 출하 가용분 = Release·미할당.
- **예외(선행조건 미충족)** 🟠: ① **유효기간 경과/임박** → 자동 Hold·폐기 대상(S10)? ② **장기재고·진부화(obsolete)** 식별·처리 ③ **부분 Hold**(제품LOT 수량 일부) ④ 장부-실물 불일치(실사 외 시점) 발견. [확인] 유효기간 관리·자동 Hold 여부, 진부화 식별, 부분 Hold 사례.
- **Pain/Wish** 🟡: *가설* — 제품재고대장-실물 불일치, 가용/Hold 수기로 **오출고 위험**, 유효기간 임박품 추적 불가, FEFO 미준수.
- **경계** 🔗: **물류 ↔ 품질**(상태 소유). 제품 재고 정본(ERP vs MES) 정합 — B7의 L2 측면.
- **연계 미결**: ⚠ D2(Lot Status 위치·이력화) · B7(재고 키·상태컬럼) · 부분 Hold 여부.
- **[확인]**: 출하 차단을 *어디서* 판정하나(재고 상태컬럼? 품질 Lot Status 조회?). 유효기간·진부화 관리하나. 제품재고대장 갱신 주기·실물 대조 빈도.

## S3. ERP 출하지시 수신 / 출하작업지시 생성 (3계층 상위)

- **Trigger**: ERP에서 **출하지시(납품오더)** 발행 / 고객 납기 임박.
- **Actor**: 전산(ERP 연계)담당 · 물류(출하)담당.
- **Action**: ERP 출하지시(품목·수량·고객·납기) 수신 → **MES 출하작업지시 생성**(Pick·OQC·Pack 실행 단위). 출하지시는 ERP 정본·수신본.
- **Input**: ERP 출하지시, 가용 제품 재고.
- **Medium** 🟡: *가설* — ERP 화면 조회 후 **엑셀/종이로 출하예정표(피킹리스트) 수기 작성** 또는 구두 공유. (ERP는 시스템이나 창고로의 전달이 엑셀·구두면 끊김)
- **Result**: 출하작업지시 생성(상태: 수신/생성). **상태변화 없음**(실행 전, 정보 전달). **제품LOT 미확정**(S4 Picking에서 선택, 우리 보정).
- **Rule/선행조건**: ✅ **출하 3계층** — ERP 출하지시(상위, nullable) → **MES 출하작업지시(항상 MES 소유)** → 후속 PGI 전표(ERP). 1 출하지시 → N 작업지시(분할), N 지시 → 1 작업지시(혼적) 표현 가능. 출하지시 소유=ERP(P/O와 동형, ⚠ **D10** 계열).
- **예외(선행조건 미충족)** 🟠: ① **출하지시 없는 긴급출하/샘플/무상**(ERP 상위지시 부재) → MES 작업지시 **단독 생성(standalone)** 허용? 사후 ERP 매칭? ② 출하지시 수량 > 가용재고(결품 → S4 분기) ③ 출하지시 ERP 미연계/타이밍 갭. [확인] 긴급·샘플 출하 빈도·경로, 출하지시 없는 출하의 ERP 사후 정합. 🔗 무지시 출하 = **3계층 nullable 상위지시 검증**.
- **Pain/Wish** 🟡: *가설* — 출하지시가 시스템에 안 떠서 *그때그때* 인지, 가용재고와 출하지시 대조 수기, 분할/혼적 출하 계획 머릿속에.
- **경계** 🔗: **ERP → 창고**. 출하지시 = ERP 정본(지시 계층 = ERP).
- **연계 미결**: ⚠ B8(출하 발번 3계층: 지시=ERP / 작업지시=MES / 전표=ERP) · D10 계열(출하지시 소유 경계) · D18(ERP 연계 통신방식).
- **[확인]**: 출하지시를 창고가 *어디서* 보나(ERP 직접? 엑셀 사본?). **출하지시에 제품LOT이 찍혀 오나, Picking에서 MES가 고르나**(★ A5·제품LOT 선택 시점 직결). 출하예정표/피킹리스트 실물 수집.

## S4. Picking (제품LOT 선택 — FEFO/위치/가용재고)

- **Trigger**: 출하작업지시 생성.
- **Actor**: 물류(출하)담당.
- **Action**: 출하 대상 **제품LOT 선택**(FEFO/위치/가용재고) → 피킹 → 출하 단위 집결. **제품LOT 확정 지점**(우리 보정).
- **Input**: 출하작업지시, 가용 제품 재고(제품LOT·Location), FEFO·유효기간.
- **Medium** 🟡: *가설* — **종이 피킹리스트 또는 엑셀**. 제품LOT 선택은 *구두/경험*(FIFO). 바코드 스캔 피킹 여부 불명.
- **Result**: 피킹 완료(제품LOT·수량 확정), 출하 대상 집결. **상태변화**: 제품LOT → 출하 진행(할당). **역추적 시작점 확정**(제품LOT).
- **Rule/선행조건**: 🟡 **제품LOT 선택 시점 = MES Picking**(우리 결정, FEFO/위치/가용재고). **가용(Release)분만 피킹**(Hold 차단, **D2**). 1 출하 다 제품LOT / 1 제품LOT 다 출하(분할) — ⚠ **D12**(출하—제품LOT N:M).
- **예외(선행조건 미충족)** 🟠: ① **재고 부족(결품)** → **분할/지연 출하**·대체 제품LOT·백오더 ② **가용 없음(Hold분만)** → 강제 피킹/특채 출하 허용? ③ **ERP 사전할당 LOT과 실물 불일치**(우리 보정 vs ERP 할당 충돌) → 어느 쪽 우선? ④ FEFO 위반(유효기간 늦은 것 먼저) ⑤ 제품LOT 미지정 피킹. [확인] 결품 시 분할/지연 처리, Hold 강제출고 여부, **출하지시에 LOT 사전할당이 오는지**(A5).
- **Pain/Wish** 🟡: *가설* — 어느 제품LOT 나갔는지 기록 부실 → **역추적 끊김**, FEFO 미준수로 유효기간 역전, 가용/할당 수기 대조.
- **경계** 🔗: **창고(C6) 내부 → 출하**. 제품LOT 선택 = MES 실시간 재고 영역(우리 보정). 역추적 시작점 — **A5 직결**.
- **연계 미결**: ⚠ A5(역추적 시작·제품LOT 선택 시점) · D12(출하—제품LOT N:M·분할출하) · D2(Hold 출하 차단) · B7(가용재고 판정).
- **[확인]**: 피킹 시 *어느 제품LOT 꺼냈는지* 기록하나(역추적 핵심). 제품LOT 선택을 누가/무엇 기준으로(FEFO?). Hold 제품이 *정말* 막히나. 1 출하가 여러 제품LOT으로 갈리는/합쳐지는 실제 사례(D12).

## S5. 출하검사 (OQC) 의뢰 / 수행 / 판정

- **Trigger**: Picking 완료(출하 대상 집결).
- **Actor**: 품질담당 (+물류 출하담당 동석).
- **Action**: 출하 대상 샘플 채취 → 검사항목 측정 → 합/불 판정 → 성적서(Coa/Coc) 발행. **합격 시 납품라벨 출력 트리거**.
- **Input**: 피킹된 제품LOT, **검사기준(검사항목·UCL/LCL/Target)**, 고객 사양.
- **Medium** 🟡: *가설* — **종이 출하검사성적서 / 엑셀 검사대장**. 검사기준 정본 시스템 불명(품질 PC 엑셀? 별도 QMS?).
- **Result**: OQC 합/불 판정, 출하성적서. **상태변화**: 합격→Packing(S6) / 불합격→출하 보류.
- **Rule/선행조건**: OQC 합격해야 출하. 검사 *기준* 정본 = ERP QM/MES/별도 QMS 미정 — ⚠ **B5**. OQC 합격 시 납품라벨 출력→생산LOT Matching(S6, **A5**).
- **예외(선행조건 미충족)** 🟠: ① **OQC 불합격 → 출하 보류**: 재검·특채(조건부 출하)·반려(재포장/재작업)·폐기(S10) 중? 권한·기록? ② 검사기준 미등록(신규 제품) → 무검사 통과/임시기준? ③ 계측기 미검교정 ④ 고객 사양 미반영. [확인] OQC 불합격 시 실제 처리(보류·특채·반려·폐기) 흐름·권한·기록 매체.
- **Pain/Wish** 🟡: *가설* — 검사 결과 종이→엑셀 이중입력, 검사기준 버전관리 미흡, 출하성적서 수기 보관, 출하 직전 OQC로 납기 압박.
- **경계** 🔗: **품질(C4) ↔ 물류(C6)**. 검사 *기준*의 정본(ERP QM/MES/QMS)? — ⚠ B5. OQC 실적은 C4 소유, 물류는 출하 분기로 참조.
- **연계 미결**: ⚠ B5(검사기준 정본·결과 연계) · C4(OQC 소유·LOT 판정) · B4(검사결과 헤더/라인).
- **[확인]**: 출하검사를 *품질 화면*에서 하나 *물류 출하 화면*에서 분기하나. 검사기준이 어디 저장되나(실물). 불합격분이 *어디로* 가나(보류 격리·재검·폐기). 특채 출하 절차·권한·기록.

## S6. Packing (제품LOT·납품라벨·생산LOT Matching·고객 바코드)

- **Trigger**: OQC 합격.
- **Actor**: 물류(출하)담당 (+품질: Matching 검증).
- **Action**: **납품라벨 출력 → 생산LOT Matching → 일치 시 부착** → Packing(Pallet/박스 구성·사진) → **고객 바코드** 연계·발행.
- **Input**: 합격 제품LOT, 납품라벨, 생산LOT(Matching 대상), 고객 바코드 체계, Pallet.
- **Medium** 🟡: *가설* — **라벨 프린터 + 종이 패킹리스트/엑셀**. 고객 바코드는 고객사 포털/지정 양식. 포장 사진 수기 보관.
- **Result**: 포장단위 확정(Pallet/박스), 납품라벨·고객 바코드 부착, 패킹 완료. **상태변화**: 제품LOT → 출하 준비 완료.
- **Rule/선행조건**: ✅ OQC 합격 시 납품라벨 출력→**생산LOT Matching**→일치 시 부착. **Matching이 제품LOT 경유인지 직접인지** — ⚠ **A5**. P&P가 출하 종속(1:1)인지 독립(1:N)인지·**포장단위 생성 시점** — ⚠ **D13**.
- **예외(선행조건 미충족)** 🟠: ① **납품라벨–제품LOT(생산LOT) 불일치 → 부착 차단**: 누가 해제·재발행? ② 고객 바코드 체계 미등록/변경(신규 고객) ③ **혼적 포장**(다 제품LOT 1 Pallet)·**분할 포장**(1 제품LOT 다 박스) genealogy 처리 ④ 포장 사진 누락. [확인] 라벨 불일치 시 차단/우회·권한, 고객 바코드 신규 등록 경로, 혼적/분할 포장 시 제품LOT-포장단위 관계.
- **Pain/Wish** 🟡: *가설* — 납품라벨-생산LOT 수기 대조로 **오부착·오출하**, 고객별 바코드 양식 제각각 수작업, 포장 사진/패킹리스트 종이 보관.
- **경계** 🔗: **창고 → 고객**(고객 바코드 = 외부 식별체계). 납품라벨–생산LOT Matching = **품질(C4)↔LOT코어(C3)** 연계. 포장단위 생성 = C3 포장 구성.
- **연계 미결**: ⚠ A5(납품라벨–생산LOT Matching 경유 vs 직접) · D13(P&P 독립성·포장단위 생성 시점) · D12(혼적/분할 포장).
- **[확인]**: 납품라벨에 *제품LOT/생산LOT 중 무엇이* 찍히나(A5 핵심). 라벨-실물 불일치가 *실제로* 차단되나. Packing 결과 포장단위가 *언제* 생기나(피킹? 패킹?). 고객 바코드 실물·발행 화면 수집.

## S7. 고객 출하 (PGI 전표)

- **Trigger**: Packing 완료.
- **Actor**: 물류(출하)담당 (+전산: ERP 전표 연계).
- **Action**: 고객 인도(차량 상차·납품) → 출하 확정 → **ERP 출하(PGI) 전표 발행**(매출·COGS·세금계산서).
- **Input**: 패킹 완료분, 출하작업지시, 납품서/거래명세서, 고객사.
- **Medium** 🟡: *가설* — **종이 거래명세서/납품서 발행 + 엑셀 출하대장**. 실행 결과(실제 출하 제품LOT·수량·납품라벨)를 ERP에 *수기/연계* 송신.
- **Result**: **제품 재고 감소**(제품LOT·Location), 출하 기록, **genealogy 종결점**(제품LOT→고객). ERP 출하(PGI) 전표·매출 인식. **상태변화**: 제품 재고 → 출하 완료(고객 귀속).
- **Rule/선행조건**: ✅ **3계층 전표 = ERP** — MES 출하작업지시 완료를 트리거로 ERP가 PGI 전표 채번. 출하 No 발번 = 지시(ERP)/작업지시(MES)/전표(ERP) — ⚠ **B8**. 물류 모니터링(Delivery Order Monitoring) — ⚠ **D20**.
- **예외(선행조건 미충족)** 🟠: ① **혼적/분할 출하**(다 출하지시 1 차량 / 1 출하지시 다 차량) → 전표·납품서 정합 ② **출하 후 반품/회수**(오출하·고객 거부) → 즉시 입고 역흐름(S9) ③ ERP 전표 미발행/연계 실패(MES 출하했으나 ERP 미반영) → 재고 이중 차감/누락 ④ 부분 출하(잔량 백오더). [확인] 혼적/분할 출하 실제 처리, MES 출하-ERP 전표 *타이밍·정합*, 출하 직후 반품.
- **Pain/Wish** 🟡: *가설* — MES 출하와 ERP 전표 *따로 놀아* 재고/매출 불일치, 출하대장 수기, 납품서 종이 보관, 물류 진행 가시성 없음(어디까지 나갔는지).
- **경계** 🔗: **창고 → 고객** · **MES ↔ ERP**(PGI 전표=ERP 정본, 출하 실행=MES). 회계 마감·세금계산서 법정연번 = ERP.
- **연계 미결**: ⚠ B8(출하 발번 3계층·PGI 전표) · D20(물류 모니터링 컬럼·로직) · D12(혼적/분할 출하).
- **[확인]**: 출하 확정 시 *무엇이 ERP로 넘어가나*(전표 자동? 수기?). PGI 전표 채번 주체·타이밍. 거래명세서/납품서 실물. 물류 모니터링을 *원하는* 항목(D20 청취).

## S8. 포장 합병 / 분할 (genealogy 승계) ⚠

- **Trigger**: 출하 단위 조정·재포장·고객 요청(Pallet 통합/분할).
- **Actor**: 물류(완제품창고)담당.
- **Action**: 포장단위 LOT 바코드 스캔 → **합병/분할** → **신규 포장라벨 발번** → 구성 LOT 재구성.
- **Input**: 원 포장단위 LOT(들), 작업유형(합병/분할), Pallet.
- **Medium** 🟡: *가설* — **바코드 스캔 또는 종이/엑셀 수기**. 신규 포장라벨 프린터 유무 불명.
- **Result**: 신규 포장단위·포장라벨, 구성 변경(수량 불변). **상태변화**: 포장 구성 재편. **genealogy 승계 필요**(원 LOT 추적성).
- **Rule/선행조건**: 포장단위 = 생산LOT→제품LOT 승계 매개(C3). 합병/분할 시 **신규 포장단위 LOT 발번 + 원 LOT 추적성 승계**(C3 포장구성 N:M) — ⚠ **D16**. 파렛트가 포장단위 상위 묶음인지 — ⚠ **D15**.
- **예외(선행조건 미충족)** 🟠: ① **합병 후 genealogy 끊김**(신규 라벨이 원 LOT 미참조) → 역추적 단절 ② 분할 시 수량/구성 정합 오류 ③ 서로 다른 제품LOT/유효기간 혼합 합병(FEFO·추적 충돌) ④ 합병/분할 미기록(라벨만 교체). [확인] 합병/분할 시 신규 라벨이 *원 LOT을 잇는지*(D16), 이종 LOT 혼합 합병 허용 여부, 미기록 재포장 빈도.
- **Pain/Wish** 🟡: *가설* — 재포장 시 **원 LOT 추적 끊김**(역추적 핵심 단절점), 합병/분할 수기로 재고-실물 불일치, 라벨만 갈고 구성 미기록.
- **경계** 🔗: 창고 내부(시스템 경계 없음) · **C6 포장합병분할 ↔ C3 포장구성 genealogy**. 동일 평가영역이면 회계전표 없음.
- **연계 미결**: ⚠ D16(포장 합병/분할 genealogy 승계) · D15(파렛트-포장단위 관계) · A5(역추적이 포장단위 경유 시 승계 규칙).
- **[확인]**: 합병/분할 화면과 라벨 변화 관찰. 신규 포장라벨이 *원 LOT을 참조*하나(genealogy). 파렛트가 포장단위 상위인가(D15). 이종 제품LOT 혼합 합병 사례.

## S9. 고객 반품 · 클레임입고 (3유형 재고영향)

- **Trigger**: 고객 부적합 통보·반품 / 클레임 결과 입고 / 오출하 회수.
- **Actor**: 물류(완제품창고)담당 (+품질담당: 재검).
- **Action**: 반품 유형 구분(공급사반품/**고객반품입고**/**클레임입고**) → 실물 입고·재검(OQC/IQC) → 재고 반영. *이 도메인은 고객반품입고·클레임입고*(공급사반품은 자재창고 ①).
- **Input**: 반품 제품LOT/품목, 반품수량, 사유, 고객 클레임, ERP 반품지시(RMA).
- **Medium** 🟡: *가설* — **종이 반품전표/엑셀**. 재검 결과 종이→엑셀.
- **Result**: 반품 기록, **재고 증가**(반품입고) 또는 별도 처리. **상태변화**: 반품분 → Hold(재검 대기) → 재판정. 재검 후 재입고/폐기 분기.
- **Rule/선행조건**: ✅ 반품 3유형의 **재고 증감 방향 유형별 상이** — ⚠ **D14**. 클레임 결과 입고가 일반 입고와 동일 엔티티/화면인지(별도 입고 트랜잭션 생성 여부) — ⚠ D14. 반품=credit memo/매출반품 전표(ERP, **B8**). 재검 = 품질(C4), Hold 상태(D2).
- **예외(선행조건 미충족)** 🟠: ① **클레임 반품입고 → 재검 → 폐기**(재작업·재판매 불가) → S10 전환·재고손익 ② 반품 사유-실물 불일치 ③ **반품-원출하 연결 추적 실패**(어느 출하/제품LOT인지 모름) ④ 부분 반품 ⑤ ERP 반품지시 없는 반품(긴급). [확인] 반품 3유형별 재고 증감·화면, 재검 후 폐기 경로, 반품-원출하-제품LOT 연결(역추적), credit 연계.
- **Pain/Wish** 🟡: *가설* — 반품-원출하 연결 추적 부실(역추적 끊김), 재고 증감 방향 헷갈림, 반품전표 수기, 클레임 결과 입고가 재고에 안 잡힘.
- **경계** 🔗: **고객 → 창고**(역흐름) · 반품=credit memo(회계) → **ERP 전표**(B8) · 재검 = **품질(C4)**.
- **연계 미결**: ⚠ D14(반품 3유형 재고영향·별도 입고 트랜잭션) · B8(반품 발번·credit) · C4(재검 OQC/IQC) · D2(반품분 Hold) · D21(재검 불합격 → 폐기).
- **[확인]**: 고객반품입고·클레임입고가 *각각 재고를 늘리나/줄이나*(D14). 클레임 결과 입고가 *일반 입고와 같은 화면*인가. 반품을 *원출하/제품LOT에 거는지*(역추적). 반품전표 실물·ERP credit 연계.

## S10. 제품 폐기 (Scrap/Disposal)  ⚠ 설계 갭 (D21)

- **Trigger**: OQC 불합격·재작업 불가 / 진부화(obsolete)·장기재고 / 유효기간 경과 / 클레임 반품 후 재판매 불가.
- **Actor**: 물류담당 (+품질담당·전산담당).
- **Action**: 폐기 대상 선별 → 처분 → 제품 재고 차감 → (요구 시) ERP 재고손익 전표.
- **Input**: 폐기 대상 제품LOT/품목, 폐기수량, 폐기사유(불량/진부화/유효기간/손상), 처리일.
- **Medium** 🟡: *가설* — **불명**. 종이/엑셀 수기 or *아예 미관리*(재고에 남거나 임의 차감)일 가능성.
- **Result**: (요구 시) 제품 재고 감소, 폐기 기록, **genealogy 종결**. ERP 재고손익 전표·수율 반영.
- **Rule/선행조건**: **현 모델 미설계** — "폐기"는 설비·툴 자산 처분 플래그뿐. 반품(외부)·실사조정(차이)·불량(수집)과 별개. 요구 시 C6 신규 트랜잭션('폐기': 대상 LOT/품목·폐기수량·폐기사유·재고 차감) + ERP 재고손익 전표(지시–작업지시–전표 패턴).
- **예외(선행조건 미충족)** 🟠: 폐기 전반이 미설계 — ① **승인 권한**·폐기사유 코드 체계 ② **재고손익(전표)** 처리 ③ 재활용/잔재(재투입·부산물 판매) 분기 ④ Hold LOT 폐기 종결(특채·재작업도 안 될 때). (D21) [확인] 폐기 승인 흐름, 손익 반영, 재활용 경로, 사유 코드.
- **Pain/Wish** 🟡: *가설* — 폐기가 시스템에 없어 *제품 재고 부정합*, 폐기손익(재고손익) 누락, **scrap rate(수율) 산정 왜곡**, 진부화 재고 방치.
- **경계** 🔗: 폐기손익=ERP 전표. 폐기 작업·사유=MES. 재검 불합격(C4)·Lot Status(C4) '폐기' 종결상태 연계.
- **연계 미결**: ⚠ **D21(신규)** — 제품·자재 폐기 요구 유무·처분 방식·재고손익 연계·재활용/잔재. **(고객 확인 대기)** · C4(불량·Lot Status 연계) · B8(폐기 손익 전표).
- **[확인]**: 불합격·진부화·만료 제품을 *실제로 어떻게* 처분하나. 재고에서 빼나, 사유 남기나, ERP 손익 반영하나. 폐기를 *시스템에서 관리할 요구*가 있나(없으면 범위 밖=ERP/수기 명시). 재활용/부산물 있나.

| 단계 | 핵심 미결(질문지) | 경계(🔗) | 발번 3계층(지시/작업지시/전표) |

| S2 완제품 재고보관 | D2·B7 | 물류↔품질 | — |

| **S4 Picking** | **A5·D12·D2·B7** | 창고 내부 | 작업지시=MES 출하작업(LOT 확정 지점) |

## 현장 실행 체크리스트 (제품 출하·완제품 창고)

**1건 추적(필수)**: 실제 출하 1건을 골라 S1 제품입고→S2 재고→S3 출하지시→S4 Picking→S5 OQC→S6 Packing→S7 고객출하까지 *따라가며* 매체·핸드오프·제품LOT 흐름 관찰.
**역추적 1건(필수)**: 클레임/반품 1건을 골라 **제품LOT→생산LOT→자재LOT** 역추적을 *시연받는다*(A5 — Matching이 제품LOT 경유인지 직접인지, 포장 합병/분할 구간에서 끊기는지).

**수집물(실물·데이터)**:
- 종이 양식: 출하예정표/피킹리스트·출하검사성적서·패킹리스트·거래명세서/납품서·반품전표
- 엑셀: 제품재고대장·출하대장·반품 파일
- 라벨 실물: **제품LOT/포장라벨·납품라벨·고객 바코드**(고객별 양식)
- 사진: Packing 사진(Pallet/바코드)
- 화면 캡처: 발번 화면(ERP/MES/레거시)·출하지시·제품재고 조회·Matching 화면
- **DB 스키마 + 대표 덤프**: 출하·재고·제품LOT·포장단위·반품 테이블 (B섹션 L3 결론)

**정량 데이터(APS·사이징용)**: 일/월 출하 건수, 고객사 수, 제품(SKU) 수, 제품LOT 발생량, 분할/혼적 출하 빈도, 반품/클레임 빈도, 포장 합병/분할 빈도, 평균 완제품 재고 회전·유효기간 임박 비율.

**관찰 포인트(말 말고 동작)**: 피킹 시 *어느 제품LOT 꺼냈는지 적는지*, 납품라벨에 *제품LOT/생산LOT 무엇이 찍히는지*, 라벨 불일치가 *정말* 차단되는지, Hold 제품이 *정말* 막히는지, MES 출하와 ERP 전표가 *맞는지*, 재포장 후 *원 LOT이 이어지는지*.

## 예외 흐름 카탈로그 (선행조건 미충족)

각 예외는 **공통 4질문**으로 점검한다 — **(a) 차단하나 / 우회(가입고·특채·강제출고·standalone)하나 · (b) 누가 승인하나 · (c) 어디에 기록(매체)하나 · (d) 사후 정합(ERP·재고·genealogy) 방법.**

| # | 예외 유형 | 발생 단계 | 깨지는 선행조건 |
| --- | --- | --- | --- |
| E1 | 포장 전 벌크 입고·외주 검사 전 입고·제품LOT 형성 시점 | S1 | 제품LOT(=포장) 형성·검사 합격 |
| E2 | 유효기간 경과·진부화·부분 Hold | S2 | 가용 상태·정합 |
| E3 | 출하지시 없는 긴급출하/샘플(standalone) | S3 | ERP 출하지시 존재 |
| E4 | 결품·분할/지연 출하·Hold 강제출고·ERP 사전할당 충돌 | S4 | 가용재고 충분·LOT 선택 일관 |
| E5 | OQC 불합격→보류·특채·반려·폐기 | S5 | OQC 합격·검사기준 등록 |
| E6 | 납품라벨–제품LOT(생산LOT) 불일치 부착 차단·혼적/분할 포장 | S6 | 라벨-실물 일치 |
| E7 | 혼적/분할 출하·출하 후 반품·MES출하–ERP전표 불일치 | S7 | 1:1 출하·전표 정합 |
| E8 | 포장 합병 후 genealogy 끊김·이종 LOT 혼합·미기록 재포장 | S8 | 추적성 승계 |
| E9 | 클레임 반품입고→재검→폐기·반품-원출하 연결 실패·3유형 방향 | S9 | 원출하 연결·재고 방향 |
| E10 | 제품 폐기 승인·재고손익·재활용 | S10 | (전반 미설계) |

> **핵심 원리**: 예외는 *"선행조건 ↔ 그 조건이 깨질 때"* 의 쌍이다. 정상 흐름의 Rule 하나마다 대응 예외가 최소 1개 있다. 출하 도메인에서 *진짜 운영 차이*는 정상 흐름이 아니라 **이 예외 처리에서** 드러난다(긴급출하 standalone·결품 분할출하·OQC 특채·라벨 불일치 우회·재포장 추적 단절·폐기 미관리의 존재 여부).
