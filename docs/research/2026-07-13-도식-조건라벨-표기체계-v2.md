## 1. 배경 — 무엇이 문제였나

기존 문법은 조건/분기 라벨을 **검정 헥사곤**(SHAPE_WITH_TEXT, 검정 채움·흰 글자)으로 표기했다. 사용자 확인 결과 핵심 문제는 **귀속 추적성**: 라벨이 커넥터와 별개 도형이라 ① 선을 덮거나 선에서 떨어져 어느 선의 조건인지 추적이 어렵고 ② 선을 재라우팅해도 라벨이 따라오지 않아 이탈이 누적된다(01-S-I 재배선 사례). 부차적으로 검정 덩어리가 노드보다 무거워 시각 위계가 역전된다.

또한 검정 헥사곤이 실제로는 4가지 용도(분기 조건 · 성립 조건 · **속성 주석** · ERP 송신 조건)로 혼용되어, "조건"이 아닌 것까지 조건처럼 읽혔다.

## 2. 결정 — 새 문법 3요소

| 요소 | 형태 (FigJam 구현) | 용도 | 스타일 값 (검증됨) |
| --- | --- | --- | --- |
| **인라인 조건 라벨 (기본)** | 커넥터 내장 텍스트 (`connector.text`) + 배경(`textBackground`) | 분기 조건·플로우 진행 조건 (예: "양품", "불량", "수량 초과"). `[가설]`은 문구에 병기 | 배경 미색 `{r:.96, g:.96, b:.93}` · Inter Medium 16 · 글자 검정(기본) |
| **인라인 조건 라벨 (강조)** | 동일 + 배경색·굵기 차등 | **위반 금지 확정 규칙** 조건에 한정 (예: "합격품 한정, G/R 송신") — 남용 금지, 도메인당 소수 | 배경 노랑 `{r:1, g:.84, b:.35}` · Inter **Bold** 15 |
| **속성 태그** | ROUNDED_RECTANGLE SHAPE_WITH_TEXT, 노드 우측 인접 | 노드의 성질 표기 — 흐름·조건 아님 (예: "P/O 비귀속") | 140×44 기준 · 채움 `{.945,.945,.93}` · 테두리 `{.55,.55,.55}` w2 · 글자 `{.2,.2,.2}` Inter Medium 15 |

- **검정 조건 헥사곤은 소멸**한다(도메인별 마이그레이션 완료 시점부터).
- **회색 헥사곤(위임·진입·대안 경로)은 유지** — 역할이 다르다(경계 표기이지 조건이 아님).
- 분기 규약 유지: 조건 라벨 없는 선 = 조건 무관 공통 수행.

## 3. 채택 근거 (실물 실험 3회)

1. **귀속의 구조적 해결**: 인라인 라벨은 커넥터의 속성이라 선과 분리될 수 없고, 재라우팅 시 자동 추종한다. 검증: IQC 양품/불량 분기 실물 적용 — 라벨이 선 위 자동 정착.
2. **강조 대체 확인**: 테두리(strokes)는 `textBackground`가 **미지원**(fills만 노출 — API 프로브로 실증). 노랑 배경+Bold로 강조 실험 — G/R 송신 조건에서 충분한 강조력 확인.
3. **속성 분리 확인**: 라운드 사각 태그를 01-S-B "P/O 비귀속"에 실물 적용 — 헥사곤(조건)·스티키(데이터)와 형태로 구분되어 "노드 성질"로 읽힘.
4. 대안 비교: 아웃라인 칩(흰 바탕 헥사곤)은 저비용이나 별개 도형이라 귀속 문제를 절반만 해소 — 속성 태그 용도로만 채택.

## 4. 운영 규칙

- **문구 길이**: 인라인 기본 ≤12자 권장(선 중앙 자동 배치라 짧은 선에서 긴 문구는 선을 넘음). 강조 라벨은 예외 허용하되 검토자가 겹침 검증.
- **강조 남용 금지**: 강조 = "위반하면 확정 규칙(QA·설계결정서)과 어긋나는 조건"에 한정. 전부 강조하면 위계가 다시 무너진다.
- **속성 태그 위치**: 대상 노드 우측(공간 없으면 좌측) 인접, 커넥터·타 노드와 겹침 0.
- **API 주의**: 커넥터 텍스트는 폰트 로드 후 `fontName` 설정 → `characters` 순서(미설정 시 invalid font). 매 use_figma 콜 서두 `setCurrentPageAsync('219:4509')` — currentPage가 v1으로 리셋되기 때문.

## 5. 적용 계획

1. 범례 개정: "조건·분기" 검정 헥사곤 항목 → 인라인 라벨 2단 샘플로 교체 + 속성 태그 항목 신설 + 전환 각주("구 표기 = 검정 헥사곤, 도메인별 전환 중").
2. **01 자재창고관리(v2 페이지) 마이그레이션**: 검정 헥사곤 전수를 [인라인 기본 / 인라인 강조 / 속성 태그] 3분류로 이관. 팀 표준 경로(설계자 매핑·분류표 → 작업자 → 검토자). 이때 G/R 송신 조건(기지적 회귀)이 강조 라벨로 복원된다.
3. 02~06: v1→v2 이식 시 새 문법을 함께 적용(도메인 단위 순차).
4. 각 도메인 완료 시 해당 도식스펙 문서·QA 확정기록 동기 갱신.
