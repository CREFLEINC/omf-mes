## §1. 배경 — 무엇을 재정의하나

03 품질관리 도식의 원래 메인 축은 **PQC(공정검사) 그 자체**였다(도식스펙-03 v1.0 §1: "메인 축 = PQC 트리거→수행→판정→Lot Status→불량 처리", IQC·OQC는 경계만).

2026-07-16 02 캔버스 재동기화에서 **PQC 수행이 통째로 02-S-E 사이드로 이전**됨이 확정(실측·사용자 확정)됐다. 이로써 03 메인 축(=PQC)이 공허해졌고, "03을 어떻게 재편할지"가 열렸다. 옵션 3(하이브리드 — 검사 수행은 도메인 co-locate, 공통 거버넌스는 03 재정의)을 토대로 아래로 확정한다.

## §2. 확정 결정 (✓확정 2026-07-20)

### 결정 1 — 검사 수행 3종은 각 도메인 섹션으로 co-locate
IQC/PQC/OQC의 **검사 수행·실적 기록·불량 처리**는 각 검사가 종속된 도메인에 둔다. 03은 검사 흐름을 그리지 않는다(각 도메인 참조).

| 검사 | 도메인 | 상태 |
| --- | --- | --- |
| PQC(공정검사) | **02 생산실행**(02-S-E 사이드) | ✅ 완료(2026-07-16 재동기화) |
| IQC(수입검사) | **01 자재창고관리**(S3) | ✅ 기존 이미 01 S3 소재(03은 참조만) — 확인·정합 대상 |
| OQC(출하검사) | **04 제품출하** | ⬜ 이관 필요(03 가설 S8 → 04 실이관) |

불량 처리 흐름(불량코드 부여·불량 실적·불량창고 반출)도 각 검사 도메인으로 co-locate(PQC 불량은 이미 02-S-E).

### 결정 2 — 03 도식 = Lot Status 상태 전이도 (유일 잔존)
03에 남는 **워크플로우 도식 콘텐츠는 Lot Status 상태 전이도 하나**다 — 3종 검사(IQC/PQC/OQC) 판정이 **공통으로 흘러드는 상태기계**(Hold/Release/한도승인/특채/폐기/PQC 검사 필요).

- **근거**: Lot Status는 이미 **품질 판정 = C4 단일 정본**(✓설계확정 2026-07-06 결정 10)이고, 자재/생산/제품 3 LOT 공통이라 특정 도메인 집이 없다 → 크로스 도메인 공통 품질의 집 = 03.
- **정적/동적 분리 원칙**: 정적 마스터(코드 리스트)는 06/도메인, **동적 판정 로직·상태 전이는 03**. Lot Status 전이는 검사 판정 이벤트가 굴리는 동적 로직이라 03.

### 결정 3 — 검사실적·판정 유형·검사방식 정책은 "도식"이 아님 (03 도식 비대상)
품질 공통이되 **도식이 아닌** 것들은 03 도식에 넣지 않는다(이미 각 문서에 소재하므로 이관·중복도 아님):
- **검사실적 엔티티**(단일 엔티티 + 검사유형 코드) → 개념데이터모델(§4 품질)
- **판정 유형 코드 목록** → 06 기준정보(코드 마스터)
- **검사방식 정책**(전수/샘플·합격판정개수) → `research/2026-07-15-PQC-검사방식-확정기록.md`

## §3. 재정의 후 03의 모습
- **03 품질관리 = "품질 공통 거버넌스" 섹션**, 도식 본체는 **Lot Status 상태 전이도**.
- IQC/PQC/OQC 검사 흐름은 03에서 그리지 않고 각 도메인(01/02/04) 참조.
- 매우 얇은 03이지만, 3종 검사 판정이 수렴하는 **공통 상태 정본의 시각적 집**으로 존재 이유가 분명(사용자가 느낀 "PQC 종속인데 왜 독립 섹션?" 위화감 해소 — 03은 PQC의 집이 아니라 Lot Status 거버넌스의 집).

## §5. 정합 확인 (리더 점검 2026-07-20 — 하드 충돌 없음)
- **Lot Status = C4 단일 정본(결정 10)** — 03이 전이도를 보유, 01/04가 참조하는 건 기존 아키텍처 그대로(04 WF §Rule "출하 차단=Lot Status 단일 지점 참조"). **충돌 없음.**
- **검사실적 = 단일 엔티티 + 검사유형 코드**(용어사전·개념모델·03 가설 확정) — 03 도식이 아닌 엔티티라 이관 대상 자체가 아님. **정합.**
- **IQC 이미 01 S3 소재** — 03 가설(2026-06-28 §26)이 "IQC는 자재창고 S3 참조·중복 작성 안 함"으로 명시. "IQC→01"은 기존 상태의 확인. **무충돌.**
- 본 재정의는 기 합의 옵션 3(진행메모 §2)의 정밀화이며, 기존 확정을 뒤집지 않는다.
