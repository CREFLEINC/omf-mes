## §0. 도식 문법·제작 원칙 (01. 자재창고관리 도식과 동일)

| 요소 | FigJam 표현 | 규칙 |
| --- | --- | --- |
| 상태 박스 | Archive 아이콘 | 가로 메인 축. 시작=**빨강**, 진행=**검정**, 완료=**파랑** |
| 작업자 | User 아이콘 | 상태 박스와 교대로 메인 축 배치 |
| 행위 체인 | Mobile(스캔)·Desktop(화면)·File(기록)·Wallet(목록) | User에서 초록 화살표로 연결 |
| MES 노트 | Server 아이콘 + 초록 스티키 | 스티키 첫 줄 **"KEY - …" 필수**, ≤12줄 |
| ERP 연계 | Database 아이콘 + 조건 헥사곤 | 예: "출하 확정 시, PGI 송신" |
| 분기 | 검정 헥사곤 | 조건·반복 구간 라벨도 헥사곤 |
| 검증/합류 | OR(⊕) | 일치 검증·경로 합류 |
| 미정의 | 빨간 Email 아이콘 | 고객 회신 대기 항목만 (E번호) |
| 화살표 | 검정=주 흐름 · 회색=대안/생략 · 초록=행위 · 빨강=시작 | 사이드 구조의 진행·복귀는 회색 |

제약: 메인 축 ≤12개 · 행위 노드(Mobile/Desktop/File/Wallet) 총 ≤30개 · 아이콘 라벨 ≤10자 · 헥사곤 ≤16자 · 스티키 ≤12줄. 전부 한국어(고유 용어 Picking·Packing·OQC·PGI 등은 원어 유지).

도식의 기준 시점: **To-Be MES 워크플로우**(확정 요구·설계 결정 반영). As-Is 가설(🟡 Medium 등)은 도식에 올리지 않는다.

## §1. 메인 구조도

흐름 개요: **출하지시 import(고객사 엑셀, D+1·시간대별) → Picking(품목별 FEFO/FIFO·Lot Status 차단 판정) → OQC 출하검사(합격 시 납품라벨 출력) → Packing(P&P — 생산LOT Matching·포장라벨 사전발행→활성) → 출하 확정(ERP PGI 송신)**. 기포장품(생산 포장)은 Packing 스킵 회색 대안 경로.

| --- | --- | --- | --- | --- |

### ④ MES 노트 전문 (Server + 초록 스티키)

**N1 — M3(출하지시) 하단**
```
KEY - 출하지시 No (MES 발번)
- 원천: 고객사 지시서 엑셀 import (nullable)
- 등록 범위: D+1일치 분량만
- 일부 항목: 시간대별 슬롯 지시
- 3계층: 지시(고객사)→작업지시(MES)→전표(ERP)
- 출하작업지시=항상 MES 소유
```

**N2 — M5(Picking) 하단**
```
KEY - 제품LOT No (MES 발번)
- 선출 정책: 품목별 설정
  유효기한 관리 품목=FEFO / 나머지=FIFO
- 강제/선택 옵션(선택 시 타 LOT 허용)
- 출하 차단 판정=Lot Status 단일 지점
  (재고는 상태 비보유·참조 판정)
- 역추적 시작점=제품LOT
```

**N3 — M7(OQC) 하단**
```
KEY - Lot Status (품질 정본)
- OQC 합격 시 납품라벨 출력 트리거
- 판정 변경이력 1:N 보존
- 기포장품 OQC=개봉 샘플링·재봉함
- 파괴검사 수량 변동=재구성 이벤트로 기록
```

**N4 — M9(Packing) 하단**
```
KEY - 포장라벨 No (포장단위)
- 포장단위=포장 실적 시점 생성
- 라벨 사전발행(placeholder)→Packing 확정 시 활성
- 미사용·취소 라벨=폐번 기록(재사용 금지)
- 포장 원천 축: 생산 포장 / 출하 포장
- Matching=포장구성 경유(직접 FK 불요)
  납품라벨→제품LOT(포장)→생산LOT
- 출하 1:N P&P(시간대·파렛트 단위 분할)
```

**N5 — M11(출하 완료) 하단**
```
KEY - 출하 No (MES) · PGI 전표 (ERP)
- 출하—제품LOT N:M(출하 병합/분할 실재)
- 출하 후 ERP 반영(PGI 성격)
- MES→ERP 송신=항목별 선택형(on/off)
- 제품 재고 차감·genealogy 종결점
```

## §2. 사이드 구조도 (4개 — 취사선택 근거 병기)

사이드 구조는 메인 축 아래(또는 위)에 배치하고, 진입은 빨강(독립 시작) 또는 회색(메인 분기), 진행·복귀는 회색 화살표로 그린다.

### 사이드 A — 긴급 W/O 직행 (채택 근거: 확정 — REQ-PR-0014 요구 + QA #26 종결)

| 순서 | 요소 | 라벨 | 의미 |
| --- | --- | --- | --- |
| SA1 | 상태(빨강) | 긴급 생산완료 | 긴급 작업지시 생산분 — 창고 적치 생략(실물 직행) |
| SA2 | 작업자 | 물류담당 | '직행 처리' 수행 |
| B1 | Desktop | 직행 처리 | 원클릭 — 기록 2건 자동 생성 트리거 |
| B2 | File | 기록 2건 자동 | 기록상 제품입고+즉시 출하 모두 생성 |
| SA3 | 합류 | → O3 | 실물이 출하 확정 앞으로 직행 합류(회색) |

**N6 — 사이드 A 스티키**
```
KEY - 직행 처리 (원클릭)
```
