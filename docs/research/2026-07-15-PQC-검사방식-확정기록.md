## §1. 배경

03 품질관리 도식을 v2 페이지로 이식하기 전, PQC에 얽힌 미정 사항 6건(A-1~A-6)을 정리했다. 기존 문서에는 "PQC 생략 여부(opt-in)"만 확정돼 있었고 **검사 방식(전수/샘플링)은 미정의 마커(03 스펙 D5)**로 남아 있었다. 본 결정으로 검사 방식·불합격 판정·검사기준 미비 처리·검사 최소 단위가 전부 확정된다.

## §2. 확정 결정 사항 (A-1 ~ A-6)

### A-1. 검사 방식 = 전수/샘플 선택제 (사업부 고정 아님)
- **전 사업부가 전수 또는 샘플 검사를 품목·공정 단위로 설정**해 사용한다. OA사업부가 현재 전수지만 **추후 샘플로 바뀔 수 있으므로 사업부 고정값이 아니라 설정값**이다(기존 "OA=전수·부품사업부 미확인" 이분 폐기).
- **샘플 기준 2종 선택**: 제품 단위 샘플 / LOT 단위 샘플.
- **샘플 수 = % 설정.** W/O 전개 시 설정된 %에 맞게 **무작위로 PQC 필수 대상이 배정**된다.
  - **제품 단위 샘플링**: 샘플 %만큼의 제품이 전체 LOT에 **균등 배분**. 예) 1,000개·LOT당 100개(=10 LOT)·10% → 각 LOT에 10개씩 PQC 필수. 각 LOT은 지정된 10개 제품의 PQC 실적만 입력되면 완료 처리 가능.
  - **LOT 단위 샘플링**: 샘플 %만큼의 LOT이 무작위 선택되고, **선택된 LOT은 전수 검사**. 예) 10 LOT·10% → 무작위 1개 LOT 선택 → 그 LOT의 100개 전수 검사.
- **샘플 미대상 물량 = 양품 처리**: 샘플 수만큼 검사 실적이 기록되면 나머지는 양품 처리. **단, 인위적 양품 검사 실적을 생성하는 것이 아니라, 출하 포장 단계로 Hold 되지 않고 LOT이 정상 진행된다는 의미**(생산LOT에 담기는 양품 = 직접 검사된 양품 + 샘플이 대표해 통과시킨 미검사 양품). → 생산불량LOT 정책의 "생산LOT=양품만"과 정합(양품 정의가 'PQC 통과분'에서 'PQC 미탈락분'으로 확장).

### A-1(불합격). 합격판정개수 초과 시 처리
- **합격판정개수(Acceptance Number) 사용** — 샘플 N개 중 허용 불량 개수. **공정별 설정값**.
- **초과 시**: ① 초과 시점에 **관리자 알람 전달** ② **현재 W/O에서 이미 생산된 모든 제품(모든 생산LOT)을 불합격 처리** → 상태 = **"PQC 검사 필요"(불량 아님)** ③ **Hold 상태**가 되어 출하 포장 단계로 진행 불가 ④ **전수 검사 후 검수 결과 등록**해야 양품 처리.
- 재검사 결과 실제 불량으로 판정된 개체만 생산불량LOT(원천=PQC)으로 분리, 양품은 생산LOT Release. → 생산불량LOT 정책과 정합.

### A-2. 판정 유형 상세 — 고객 회신 대기 (유지)
- 보류·한도승인·특채·폐기 등 판정 유형 실재는 확정(REQ-PR-0027)이나, **전체 목록·특채 승인 권한·기록 매체는 여전히 고객 회신 대기.** 변경 없음.

### A-3. 검사기준 미비 시 처리
- 신규 품목·공정에 검사기준(품질기준값)이 아직 없을 경우, **항목 측정 없이 "정상/불량 단순 선택 + 자유 입력"으로 검사·기록**한다(무검사 진행도, 임시 정식 기준 등록도 아님 — 제3안 확정).

### A-4. PQC 최소 단위 = 제품
- PQC의 **최소 단위는 제품(개체)**. 오늘 확정된 PQC 개념(제품 단위 샘플/LOT 단위 샘플)과 정합. 개념데이터모델의 "PQC=W/O 단위 vs 생산LOT 단위" [확인필요]를 **제품(개체) 단위 + 샘플 % 기반**으로 종결.

### A-5. 계측값 자동 연계 현황
- **현행 = 모든 계측 수기 처리.** MES 도입 시점에 **캠데코(자사 개발·납품 설비)만 자동 연계**(설비 데이터 수집 표준 I/F·캠데코 1차 적용 — 기존 QA #8 확정과 일치). 그 외 일반 계측기는 수기 유지.

### A-6. 검사 매체 현황 — 종결
- **현행 = 종이 기록 후 엑셀 전사**(일부는 종이 상태로만 관리). 미확인 항목 해소 — DX 대체 대상(이중 입력) 확인 완료.

## §3. 엔티티 반영 — 검사정책·Lot Status

### 검사정책(InspectionPolicy) 속성 확장
기존(생략 opt-in 플래그)에 다음 추가:
- **검사 방식**(전수 / 샘플) — 품목·공정 단위 설정
- **샘플 기준**(제품 단위 / LOT 단위) — 샘플 방식일 때
- **샘플 비율(%)** — W/O 전개 시 무작위 배정 근거
- **합격판정개수** — 공정별 설정값
- **검사기준 미비 시 처리**(정상/불량 단순 선택 + 자유 입력) 허용

### Lot Status 판정유형 신규 값
- **"PQC 검사 필요"(재검사 대기)** 추가 — Hold의 일종(출하 포장 차단). 합격판정개수 초과로 W/O 전체 생산LOT이 재검사 대상이 될 때 부여. 전수 검사·결과 등록 후 Release(양품) 또는 생산불량LOT 분리(불량).
