## 5. 정리자 관찰 — 데이터 특이사항 (해석 포함, 원문과 구분)

1. **버전 표기 불일치**: 표지 '문서 버전' 필드는 v1.0이나 개정 이력에는 v1.1(2026-07-01 점검 미팅 결과 반영)이 있고 파일명은 `_v1`. 본문 내용은 미팅 결과가 반영된 상태(현행/개선요구 열에 미팅 결정 사항 기재)이므로 **실질 v1.1로 간주**한다.
2. **시트명-요약 불일치**: 요약 시트는 '제조팀 36건'으로 집계하나 해당 시트명은 '부품사업부'다. 동일 대상으로 판단(합계 47 = 36+11 일치).
3. **우선순위 분류 미완**: 우선순위 열은 REQ-PR-0018('중요') 1건만 기재. 요약 시트의 필수/중요/선택 집계도 0. **47건의 우선순위 확정은 후속 과제**다.
4. **행 데이터 결측**: REQ-PR-0009는 No. 열이 공란(순번 9 위치, ID로 식별 가능). 제안자·직책·요청일·검토결과 열은 전 시트 공란.
5. **오탈자 처리**: "부착하하여"(0003)·"(장에선"(0009)·"사용하는대"(0008)·"고객서"(0031) 등은 문맥상 교정하되 `[원문: …]`으로 원문을 병기했다. 의미가 바뀌는 교정은 하지 않았다.
6. **열 배치 특이**: REQ-PR-0035·0036의 "출하지시서 요청"·"납품 라벨 형식 요청"은 비고 열(N열)에 기재된 값으로, 해당 요구사항의 개선요구가 아니라 **고객 대상 자료 요청 메모**다.
7. **요구사항 성격 혼재**: '구분' 열의 기능/비기능 분류가 일부 관례와 다르다 — 예: 다국어(0012)는 통상 비기능이나 '기능'으로 기재. 원문 분류를 유지하고 재분류는 통합분석에서 다룬다.
8. **[2026-07-20 CREFLE 재정의 — REQ-PR-0007·0001]**: 내부 결정으로 자재 LOT 관리 모델을 재정의했다 — REQ-PR-0007 "IQC 합격 시점에 LOT 생성" → **"LOT 등록=입하(Hold)·Release=IQC 합격"**, REQ-PR-0001 "LOT 번호 사전 발행" → **"공급사 번호 수용·등록(사전부착 경로)"**. 고객 요구 원문(위 표 L43·L49 셀)은 전사 무결성상 보존하며, 재정의는 해석 계층에서만 표기한다. 근거: research/2026-07-20-자재LOT관리-재정의-확정기록.md.
