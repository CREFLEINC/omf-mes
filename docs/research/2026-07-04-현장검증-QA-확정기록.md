## 1. 설계 결정 전환 (질문 목록에서 제외 — CREFLE 내부 설계로 이관)

현장·고객 확인이 아니라 CREFLE 설계 재량으로 결정할 사안으로 합의(2026-07-04):

- **전체 전환 6건**: B4(검사결과 정규화 — 헤더/라인) · C1(전달사항 vs Popup 단일화) · D8(WorkCalendar 적용 단위) · D11(자원배정 vs 4M투입 분리) · D13(P&P 종속성·포장단위 생성 시점) · D17(계측기 이력 종류 세분)
- **부분 전환 8건**(설계 부분만 내부, 실태 질문은 문답으로 해소): B2잔(Routing 키) · B7잔(재고 키 스킴·카디널리티) · C2잔(불량 중복 집계 규칙) · D2잔(Lot Status 보유 위치·이력화) · D9잔(SPC 매핑 구조) · D7(불량코드 체계) · D16(합병/분할 계보 규칙) · E13(작업 홀드 상태 모델)

전환 근거: 고객에게 실사할 기존 MES가 없음이 확인되어(요구사항 명세서 v1.1), 참조모델 검증형 질문들이 신규 설계 결정으로 성격 전환됨.

## 3. 종합 — 확정된 설계 지도

### 3.1 정본(소유) 지도 최종

| 데이터 | 정본 | 비고 |
| --- | --- | --- |
| 자재LOT·생산LOT·제품LOT | **MES 발번** | 자재LOT: 사전발행+IQC 합격 생성 2단계 |
| Routing·툴/금형/지그·검사기준·Location·예비품(별도 마스터) | **MES** | As-Is 엑셀 → DX 마이그레이션 |
| 품목·BOM(Rev)·공통코드·조직·작업자·P/O | **ERP(UNIERP)** | 연계 원본 필드 읽기 전용 + **MES 확장 속성(개발품 플래그·하위 코드 등)은 편집 가능** |
| 출하지시 | **고객사 문서 import** | D+1·시간대별 |

### 3.2 ERP(UNIERP) 연계 스펙

- 방식: **DB 중계 테이블**. 수신: 품목·BOM·공통코드·조직·작업자·P/O. 송신: **생산 실적(필수, 개발품 제외)** · G/R(IQC 합격 직후 건별) · 출하(PGI) · 반품·실사조정 — **송신은 항목별 선택(on/off) 연계**. 검사 결과는 비연계.
- 추가 연계 시스템: **추적관리시스템**(자사 개발, OA 생산·포장·출하 바코드 이력) — **병행 운영+연계**, 역할·데이터 경계 정의는 설계 과제.
- 설비: **'설비 데이터 수집 표준 I/F'**(생산 실적+검사 결과·측정값) — 캠데코(자사 제작 자동 생산 설비)=1차 적용, 스펙=CREFLE 정의.

### 3.3 신규 구조 결정

**출고 QR**(보관/이동 단위 분리·항상 발행) · **손실 3원 집계**(양품/불량/손실 — 퍼징·시작불량, 수율 분리) · **재생재 코드 2단**(품목코드+하위 코드, 관리자만 조회, genealogy 완전 기록) · **자재LOT 보관단위 기본값+override** · **FEFO/FIFO 품목별** · **긴급 직행=기록 2건 자동 생성** · **러닝체인지=계획·LOT 동시 분할** · **문서 자동 등록 패턴 2종**(거래명세서 입하·출하지시서 import) · **P/O 변경 강행 옵션+불일치 플래그** · **미달 마감 이월/소멸 관리자 선택** · **클레임 입고 원천 구분** · **다국어 전범위(사용자별 언어)** · **POP 로컬 버퍼링 폴백** · **P/O 초과 입고=초과분 별도 입하 분리 생성(P/O 비귀속)**(#36, 2026-07-06)

### 3.4 일관 설계 원칙 (문답 전반에서 확립)

1. **설정형(configurable) 우선**: 점검 통제 3단계 · ERP 송신 on/off · 중단 사유 코드 관리자 관리 · FIFO 강제/선택 · 알람 채널 선택 · 타발수 환산 옵션 · 위치 관리 선택적.
2. **기록은 생략하지 않는다**: 긴급 직행도 기록상 입고+출하 생성 · 전량 출고에도 출고 QR · 재생재도 내부 genealogy 완전 기록.
3. **연계 원본 읽기 전용 + MES 확장 속성 편집**: 마스터 편집 정책의 통일 규칙.

### 3.5 해석 정정 2건 (기존 문서 정정 필요)

1. **거래명세서 기반 입고(REQ-PR-0006)** = 입하(도착) 등록의 문서 분석 자동화. '창고 입고 생략 간이 경로' 서술(WF01 S2·질문지 B8④·데이터모델 C6 입하) 전면 정정.
2. **캠데코** = 자사(CTO) 제작·납품 자동 생산 설비(비전 검사 포함). 외부 벤더 장비로 읽히는 서술 정정.
