**본 도메인 특칙**

1. **ERP(Database) 아이콘 등장 금지.** 툴·금형·지그 마스터=MES 직접 등록·정본(I/F 연계 대상에서 툴 제외), 보전=EAM/CMMS 미보유로 MES 경량 단독 채번, 예비품=별도 MES 마스터. 설비·툴 도메인에는 ERP 연계 접점이 없다 — 도식에 Database 아이콘이 하나라도 있으면 오류.
2. **직선 흐름이 아니라 주기 루프.** [구성 판단] 이 도메인은 점검(Daily/Monthly)·보전·PM이 주기적으로 반복되는 루프 성격이므로, 고객이 매일 접하는 대표 루프인 **설비 점검 루프를 메인 축**으로 잡고(수행 빈도 최고 + 생산 통제와 직결 — 작업 전 점검 통제가 생산(②) 도메인과 맞닿는 유일한 강결합 지점), 나머지는 사이드 구조 5종(툴 PM · 경량 보전 · 표준 I/F · 비가동 · 계측기 검교정)으로 분리한다. 루프 회귀는 회색 점선으로 표현한다. *(사이드 E 계측기 검교정 = 2026-07-20 03 재정의 이관 수령 — 캔버스 배치는 작화 시 확정)*
3. S1(자산 등록·기준정보)·S9(폐기)는 도식 범위 외 — 기준정보는 Wallet(목록) 참조로만 등장시키고, 자산 수명주기는 본 도식에서 다루지 않는다. [구성 판단: 고객 협의의 초점=운영 루프]

**수량 제약 준수 현황 (v2 캔버스 실측 2026-07-23 — 메인 746:7514 자식 60 · 사이드 780:7745 자식 114)**: 메인 축 7개(≤12) · 행위 노드 총 22개(≤30 — 사이드 E 계측기 +2) · MES 노트 12매(사이드 C 수집채널매핑 MES-10 + 사이드 E 계측기 MES-11·12 — **작화 완료**) · **분기·조건 표기(v2 표기체계 — 검정 조건 헥사곤 0)**: OR(⊕) 7(메인 H1~H4·⊕-1 + 사이드 H5·⊕-2, 외곽 초록) + 인라인 조건 라벨(OR-발 초록·진행/경계 미색·**강조 노랑 Bold 1건**=계측기 게이트) + 회색 리셉션/경계 hex 5(리셉션 3·바인딩경계·계측기 게이트) · 미정의 마커 8개(M1~M7 + 계측기확인 M8) · **ERP(Database) 아이콘 0**(특칙①·독립 sweep 검증) · **캠데코=중립 사각형 1**(174:4531) · 주기 루프 회색 점선 3본(A5→A1·H5→SA1·SA2→H5).

## 2. 사이드 구조도 (5종)

[구성 판단] 후보 전부를 채택한다 — A~D 4종은 확정 근거(QA #7~#12·#32, 결정 03)가 있고 메인 루프와 접점이 명확하다. **사이드 E(계측기 검교정)는 2026-07-20 03 품질섹션 재정의 이관 수령**(확정기록 결정 4 — 계측기=설비/자산). 배치: A~D=메인 축 하단 2×2(좌상=A 툴 PM, 우상=B 경량 보전, 좌하=C 표준 I/F, 우하=D 비가동), **E=하단 추가 배치(작화 시 확정 — 캔버스 이연)**.
