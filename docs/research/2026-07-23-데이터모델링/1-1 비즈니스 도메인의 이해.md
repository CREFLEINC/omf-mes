## 1. MES의 핵심 가치 (Core Value)

MES 데이터 모델이 궁극적으로 실현해야 하는 가치는 딱 세 가지입니다. 이 세 가지를 충족하지 못하는 모델은 현장에서 버려집니다.

- **실시간 시각화 (Real-time Visibility):** "지금 3번 라인의 2번 설비가 돌고 있는가, 멈췄는가? 멈췄다면 왜 멈췄는가?"를 즉시 보여줄 수 있어야 합니다.
    
- **완벽한 추적성 (Traceability):** "오늘 출하된 제품 A에 불량이 발견되었다. 이 제품에 들어간 원자재는 언제 들어온 누구 전표의 것이며, 어떤 설비에서 어느 작업자가 만들었는가?"를 단 1초 만에 추적할 수 있어야 합니다. (일명 **Lot Tracking**)
    
- **생산 효율 극대화 (KPI 제공):** 설비 가동률, 불량률, 작업자 생산성 등 공장의 상태를 숫자로 증명해 내는 데이터 구조여야 합니다.

## 2. 비즈니스의 시작과 끝 (End-to-End Flow)

공장이 돌아가기 시작해서 제품이 나가기까지의 데이터 흐름입니다. 데이터 모델 역시 이 흐름을 그대로 따라갑니다.

```
[시작] ERP 계획 수신 ➡️ 기준정보 확인 ➡️ 작업지시 발행 ➡️ 원자재 투입 ➡️ 공정 진행 (재공) ➡️ 품질 검사 ➡️ 포장 및 완제품 입고 [끝]
```

- **시작 (Trigger):** 상위 시스템(ERP)으로부터 **"이번 주에 A 제품 1,000개 만들어라"** 하는 생산 계획(Production Plan)이 들어오면서 시작됩니다.
    
- **진행 (Execution):**
    
    1. 시스템이 계획을 확인하고 현장에 구체적인 작업 지시(Work Order)를 내립니다.
        
    2. 창고에서 원재료가 출고되어 공정에 투입되며 **LOT 번호**가 부여됩니다.
        
    3. 각 공정(Routing)을 거치며 원재료가 가공되거나 조립됩니다. (이때의 상태를 **재공, WIP**이라고 합니다.)
        
    4. 설비 데이터와 작업자 실적이 실시간으로 테이블에 쌓입니다.
        
- **끝 (Terminal):** 제품이 최종 검사(QC)를 통과하여 완제품 창고에 입고(수불 처리)되고, 전체 생산 이력(Lot Lineage)이 완성되어 ERP로 실적 데이터가 전송되면서 하나의 사이클이 끝납니다.

## 3. 현업 도메인 용어 사전

현업(공장 관리자, 현장 작업자)과 소통할 때 이 용어를 모르면 대화가 되지 않습니다. 테이블 및 컬럼 설계 시 논리명/물리명으로 적극 활용해야 하는 핵심 키워드입니다.

| **현업 용어** | **영문명 (추천 물리명)**                            | **설명 및 모델링 팁**                                                              |
| --------- | ------------------------------------------- | --------------------------------------------------------------------------- |
| **자재명세서** | **BOM** _(Bill of Materials)_               | 제품 하나를 만들기 위한 원부자재 목록. 자식 품목이 또 부모 품목이 될 수 있는 **계층형(순환) 관계**로 모델링해야 합니다.    |
| **공정 경로** | **Routing**                                 | 제품이 생산되기 위해 거쳐야 하는 작업 순서 (예: 가공 ➡️ 세척 ➡️ 조립 ➡️ 포장).                         |
| **작업지시**  | **WO** _(Work Order)_                       | "몇 번 라인에서 어떤 품목을 몇 개 만들어라" 하는 구체적인 명령 단위. 가장 빈번히 조회되는 트랜잭션 테이블입니다.          |
| **생산 단위** | **LOT**                                     | 동일한 원료, 설비, 공정 하에서 한 번에 만들어진 제품 무리. **추적성(Traceability) 모델링의 기본 Key**가 됩니다. |
| **재공**    | **WIP** _(Work In Process)_                 | 공정 중간에 머물러 있는 반제품 상태. "원재료도 아니고 완제품도 아닌 상태"의 재고를 관리하기 위한 상태 값 설계가 중요합니다.    |
| **수율**    | **Yield**                                   | 원재료 대비 실제 생산된 양질의 완제품 비율. 수율 테이블은 경영진 보고서용 마트(Mart) 설계 시 필수적입니다.            |
| **설비효율**  | **OEE** _(Overall Equipment Effectiveness)_ | 설비가 얼마나 잘 돌아가고 있는지 평가하는 표준 지표 (가동률, 성능, 품질을 곱해서 산출).                        |
