아래 요구사항은 다음 전제를 반영합니다.

* MES 관리 대상 공정별 작업지시를 생성한다.
* MES 미관리 공정도 전체 라우팅에는 유지한다.
* 생산실적은 작업지시와 연결된다.
* 품질검사는 작업지시, 생산실적, 자재 LOT 또는 생산 LOT와 연결할 수 있다.
* 검사 결과에 따라 후속 공정 투입과 재고 사용 가능 여부를 통제한다.
* 한 단말기에서 여러 공정의 품질검사를 처리할 수 있다.

# MES 핵심 기능 요구사항 ④ 품질관리

## 1. 기능 목적

품질관리 기능은 자재 입고부터 공정 생산, 완제품 입고 및 출하까지 발생하는 검사와 품질판정을 관리하는 기능이다.

품질관리 기능은 다음 데이터와 연결되어야 한다.

```text
자재 LOT
→ 작업지시
→ 생산실적
→ 품질검사
→ 생산 LOT
→ 재고상태
→ 후속 공정 또는 출하
```

주요 목적은 다음과 같다.

* 검사 대상과 검사기준의 표준화
* 검사 누락 방지
* 공정별·LOT별 품질판정 관리
* 불량유형과 발생원인 기록
* 부적합품의 사용·이동·출하 통제
* 재검사·재작업·선별·특채 이력 관리
* 품질문제의 영향 LOT 추적
* 작업지시 완료 및 마감 조건 검증
* 품질 통계와 개선 데이터 제공

# 2. 용어 정의

## 2.1 검사계획

품목, 공정, 검사유형에 따라 어떤 항목을 어떤 방법과 기준으로 검사할지 정의한 기준정보이다.

## 2.2 검사항목

치수, 외관, 기능, 중량 등 실제로 확인하는 품질 특성이다.

## 2.3 검사규격

검사항목의 합격기준이다.

예:

```text
상한값
하한값
목표값
합격·불합격 기준
허용 불량수
```

## 2.4 검사대상

검사를 수행해야 하는 대상이다.

검사대상은 다음 중 하나가 될 수 있다.

* 자재 LOT
* 작업지시
* 생산실적
* 생산 LOT
* 반제품 LOT
* 완제품 LOT
* 출하 LOT

## 2.5 검사실적

검사항목별 측정값, 판정, 검사자 및 검사시각을 기록한 결과이다.

## 2.6 품질판정

검사결과를 기준으로 검사대상의 사용 가능 여부를 결정하는 결과이다.

기본 판정은 다음과 같다.

* 합격
* 불합격
* 보류
* 특채
* 재검사대기

## 2.7 불량

제품 또는 자재가 규격이나 작업기준을 충족하지 못한 상태이다.

## 2.8 부적합

검사 또는 생산과정에서 확인된 품질 요구사항 미충족 건이다.

하나의 부적합 건에는 여러 불량유형과 처리이력이 연결될 수 있다.

## 2.9 특채

규격을 완전히 충족하지 못했지만 승인된 조건에 따라 제한적으로 사용하거나 출하하도록 허용하는 판정이다.

## 2.10 재검사

보류 또는 불합격 대상에 대해 동일하거나 변경된 기준으로 다시 검사하는 처리이다.

## 2.11 선별

대상 수량 전체 또는 일부를 검사하여 양품과 불량품으로 분리하는 처리이다.

# 3. 품질관리 범위

품질검사는 다음 단계에서 수행할 수 있어야 한다.

| 검사유형 | 주요 대상               |
| ---- | ------------------- |
| 수입검사 | 구매 자재, 외주 입고품       |
| 초품검사 | 작업 시작 후 최초 생산품      |
| 공정검사 | 생산 중 중간 생산품         |
| 자주검사 | 작업자가 직접 수행하는 검사     |
| 순회검사 | 품질 담당자가 공정을 순회하며 수행 |
| 최종검사 | 생산 완료품              |
| 출하검사 | 출하 대상 LOT           |
| 재검사  | 보류·불합격·재작업 대상       |
| 특별검사 | 고객 요청, 변경점, 품질문제 대응 |

# 4. 기본 처리 구조

```text
검사대상 발생
   ↓
검사계획 및 검사항목 조회
   ↓
검사 요청 또는 자동 검사대상 생성
   ↓
샘플수량 확인
   ↓
측정값·외관·판정 입력
   ↓
검사항목별 판정
   ↓
검사 전체 판정
   ├─ 합격
   ├─ 불합격
   ├─ 보류
   ├─ 특채
   └─ 재검사대기
   ↓
LOT·재고·후속 공정 사용 가능 여부 반영
   ↓
필요 시 부적합·재작업·선별·폐기 처리
```

* 사용 여부

## FR-QM-002 검사계획 버전 관리

검사계획과 검사규격은 버전으로 관리해야 한다.

검사대상 생성 시 적용된 검사계획 버전을 저장해야 한다.

검사계획이 변경되어도 이미 생성되거나 수행된 검사의 적용기준은 변경되지 않아야 한다.

```text
검사계획 V1
→ 기존 검사실적에 유지

검사계획 V2
→ 신규 검사대상부터 적용
```

시스템은 설정된 검사주기와 생산 이벤트에 따라 검사대상을 자동 생성할 수 있어야 한다.

자동 생성 시점의 예시는 다음과 같다.

* 자재 입하 또는 입고

* 최초 생산실적 등록
* 일정 수량 생산
* 자재 LOT 변경
* 설비 또는 금형 변경
* 생산 LOT 생성
* 작업지시 완료
* 출하 요청

권한이 있는 사용자는 품질문제, 고객 요청, 변경점 확인 등의 사유로 검사대상을 수동 생성할 수 있어야 한다.

수동 생성 시 다음 정보를 기록해야 한다.

* 검사 생성사유
* 검사유형
* 검사대상
* 대상수량
* 검사계획
* 요청자

* 긴급 여부

작업지시 상세화면에서 다음 정보를 조회할 수 있어야 한다.

* 필수 검사 목록
* 검사 진행상태

## FR-QM-009 MES 미관리 공정 품질등록

MES 미관리 공정에서 품질검사가 발생하는 경우에도 검사결과를 등록할 수 있어야 한다.

이 경우 다음 정보를 구분하여 저장해야 한다.

* 실제 검사 또는 불량 발생 공정
* 등록을 담당한 MES 관리 대상 작업지시
* 검사대상 생산 LOT
* 검사자
* 입력 단말기

MES 미관리 공정에 별도의 작업지시를 생성하지 않아도 품질이력을 남길 수 있어야 한다.

## FR-QM-010 생산실적별 검사 연결

품질검사를 특정 생산실적과 연결할 수 있어야 한다.

이를 통해 다음 내용을 식별할 수 있어야 한다.

* 어느 생산구간을 검사했는지
* 검사대상 양품수량
* 검사결과로 보류된 수량
* 불합격으로 전환된 수량
* 합격 후 후속 공정에 사용 가능한 수량

---

## FR-QM-011 LOT별 검사 연결

품질검사는 다음 LOT 단위와 연결할 수 있어야 한다.

* 자재 LOT
* 반제품 LOT
* 생산 LOT
* 완제품 LOT
* 출하 LOT

하나의 LOT에 여러 검사이력이 존재할 수 있어야 한다.

하나의 검사에서 여러 LOT를 혼합하여 처리하는 경우 각 LOT별 대상수량을 구분해야 한다.

## FR-QM-012 공용 단말기 품질입력

단말기 한 대에서 여러 공정의 품질검사를 처리할 수 있어야 한다.

단말기별로 다음 권한을 설정할 수 있어야 한다.

* 처리 가능 공정
* 검사결과 입력
* 검사판정
* 부적합 등록
* 사진 첨부
* 재검사 처리
* 특채 승인 요청

허용되지 않은 공정의 검사를 입력하려는 경우 차단해야 한다.

공용 단말기에서 다음 바코드를 스캔하여 검사대상을 조회할 수 있어야 한다.

## FR-QM-014 검사자 인증

검사결과 입력 전 검사자를 식별할 수 있어야 한다.

검사자 인증 방식은 다음 중 하나 이상을 지원할 수 있어야 한다.

검사자 자격이 필요한 검사항목은 자격이 없는 사용자의 입력을 제한할 수 있어야 한다.

## FR-QM-015 샘플링 검사 지원

검사계획에 따라 모집단 수량과 샘플수량을 관리할 수 있어야 한다.

* 사용자 지정 샘플링

샘플수량과 허용 불량수 기준에 따라 전체 판정을 자동 계산할 수 있어야 한다.

## FR-QM-020 검사결과 임시저장

검사가 완료되지 않은 경우 검사결과를 임시저장할 수 있어야 한다.

임시저장 상태에서는 다음 처리에 반영하지 않는 것을 원칙으로 한다.

* LOT 품질상태 변경
* 후속 공정 가용수량
* 재고 가용상태
* 작업지시 마감
* ERP 품질결과 전송

---

## FR-QM-021 검사결과 확정

검사가 완료되면 검사결과를 확정할 수 있어야 한다.

공정별로 다음 확정방식을 설정할 수 있어야 한다.

* 검사자 입력 즉시 확정
* 품질 담당자 확인 후 확정
* 책임자 승인 후 확정
* 검사장비 결과 수신 후 자동 확정

확정된 검사실적만 공식 품질판정에 반영해야 한다.

---

## FR-QM-022 품질상태 관리

자재 LOT, 생산 LOT 및 재고에 다음 품질상태를 적용할 수 있어야 한다.

* 검사대기
* 합격
* 불합격
* 보류
* 특채
* 재검사대기
* 폐기

품질상태와 재고상태는 구분하여 관리해야 한다.

예:

```text
품질상태: 합격
재고상태: 가용
```

```text
품질상태: 보류
재고상태: 격리
```

## FR-QM-023 후속 공정 투입 통제

품질검사가 필수인 생산실적 또는 생산 LOT는 검사판정에 따라 후속 공정 투입을 통제해야 한다.

기본 정책은 다음과 같다.

| 품질판정 | 후속 공정 투입        |
| ---- | --------------- |
| 합격   | 허용              |
| 불합격  | 차단              |
| 보류   | 차단              |
| 특채   | 승인조건에 따라 허용     |
| 검사대기 | 품목·공정 정책에 따라 결정 |

검사 합격 전에도 생산을 진행할 수 있는 품목은 예외정책을 설정할 수 있어야 한다.

## FR-QM-024 재고 사용 통제

품질상태에 따라 자재와 생산품의 출고·이동·사용을 통제해야 한다.

불합격·보류·격리 상태의 LOT는 일반 생산투입이나 출하에 사용할 수 없어야 한다.

특채 LOT는 승인된 작업지시, 수량, 기간, 고객 등에 한정하여 사용할 수 있어야 한다.

## FR-QM-042 검사결과 취소

잘못 생성되거나 중복된 검사실적을 취소할 수 있어야 한다.

취소 전 다음 내용을 검증해야 한다.

* 품질판정이 LOT 상태에 반영되었는지
* 후속 공정에 이미 투입되었는지
* 재고가 출고되었는지
* 출하에 사용되었는지
* 부적합 또는 재작업이 연결되었는지
* 작업지시가 마감되었는지

후속처리가 존재하면 관련 데이터의 역처리 또는 별도 정정절차를 적용해야 한다.

# 7. 핵심 업무 규칙

## BR-QM-001

품질검사실적은 검사대상과 반드시 연결되어야 한다.

## BR-QM-002

검사대상 생성 시 적용된 검사계획과 버전을 보존해야 한다.

## BR-QM-003

MES 미관리 공정에서도 품질검사와 불량 발생공정을 기록할 수 있어야 한다.

## BR-QM-004

필수 검사항목이 완료되지 않으면 검사 전체를 확정할 수 없다.

## BR-QM-005

합격수량, 불합격수량 및 보류수량의 합계는 검사수량과 일치해야 한다.

## BR-QM-006

불합격·보류 LOT는 일반 생산투입과 출하에 사용할 수 없다.

## BR-QM-007

특채 LOT는 승인된 조건 범위에서만 사용할 수 있다.

## BR-QM-008

필수 검사 합격 전에는 후속 공정 투입이나 가용재고 전환을 제한할 수 있다.

## BR-QM-009

검사결과가 후속 공정, 재고 또는 출하에 사용된 이후에는 단순 삭제할 수 없다.

## BR-QM-010

검사결과 정정 또는 취소 시 LOT 품질상태와 관련 수량을 함께 검증해야 한다.

## BR-QM-011

재검사로 최종 합격되더라도 원래 불합격 또는 보류이력은 보존해야 한다.

## BR-QM-012

실제 불량 발생공정과 불량 발견공정을 구분하여 저장할 수 있어야 한다.

## BR-QM-013

마감된 작업지시의 품질결과는 승인된 마감 취소나 정정절차 없이 변경할 수 없다.

## BR-QM-014

검사결과 확정과 LOT 품질상태 반영은 동일한 트랜잭션으로 처리해야 한다.

## BR-QM-015

품질이력은 물리적으로 삭제하지 않고 취소·정정·판정변경 이력을 보존해야 한다.

# 8. 기본 품질관리 흐름

```text
검사대상 자동 또는 수동 생성
   ↓
작업지시·생산실적·LOT 연결
   ↓
검사계획 및 검사항목 조회
   ↓
샘플링 및 검사수량 확인
   ↓
측정값·외관·기능검사 입력
   ↓
검사항목별 자동·수동 판정
   ↓
검사 전체 판정
   ├─ 합격 → 후속 공정·재고 사용 허용
   ├─ 불합격 → 부적합 및 사용 차단
   ├─ 보류 → 격리 및 처리결정 대기
   ├─ 특채 → 승인조건에 따라 사용
   └─ 재검사대기 → 재검사 수행
   ↓
작업지시 완료·마감 검증
   ↓
품질이력 및 LOT 추적정보 보존
```

다음 핵심 검토 쟁점은 **검사대기 상태의 생산품을 후속 공정에 선투입할 수 있도록 허용할지**입니다. 이 정책은 품목·공정·검사유형별로 다르게 설정하는 것이 적절합니다.
