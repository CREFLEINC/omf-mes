MES 물류·재고 실행관리 사용자 이용 시나리오

1. 목적

본 문서는 MES 물류·재고 실행관리 기능을 실제 사용자 업무 흐름으로 정의한다.

적용 범위는 다음과 같다.

  • 구매자재 입하
  • 수입검사 및 입고
  • 창고 적치
  • 생산출고 및 피킹
  • 생산현장 인수와 작업지시 투입
  • 자재잔량 반납
  • 반제품·완제품 입고
  • 창고·로케이션 간 이동
  • 사업부 간 이동
  • 외주 출고·입고
  • 고객 출하
  • 입출고 취소·정정
  • 외부·위탁창고 이동 및 회수

각 시나리오는 다음 내용을 포함한다.

  • 사용자
  • 시작 조건
  • 정상 흐름
  • 시스템 검증
  • 완료 결과
  • 주요 예외 흐름

3. 공통 업무 전제

  • 구매자재 입하는 원칙적으로 ERP의 구매 P/O를 근거로 처리한다.
  • 입하는 물품의 물리적 도착이며, 입고는 MES 재고 증가를 의미한다.
  • 수입검사 대상 자재는 합격판정 전에 가용재고로 사용할 수 없다.
  • LOT 관리대상 품목은 LOT 없이 입고·출고·이동·투입·출하할 수 없다.
  • 생산출고와 작업지시 자재투입은 별도 이벤트로 관리한다.
  • 생산실적 등록과 반제품·완제품 창고 입고는 별도 이벤트로 관리한다.
  • 품질상태와 재고상태는 구분하여 관리한다.
  • 모든 재고수량 증감은 근거가 되는 재고 트랜잭션을 가져야 한다.
  • 실제 발생일시와 MES 입력일시를 구분하여 저장한다.
  • 입출고 및 이동이력이 존재하는 데이터는 물리적으로 삭제하지 않는다.

5. 사용자 이용 시나리오

SCN-01 생산계획 확정 및 작업지시 전체 생성

사용자

생산관리자

시작 조건

  • 생산오더가 존재한다.
  • 품목의 라우팅과 BOM이 등록되어 있다.
  • 라우팅 공정별 MES 관리 여부가 설정되어 있다.
  • 생산계획의 품목, 수량, 계획일자가 입력되어 있다.

정상 흐름

  1. 생산관리자가 생산계획 목록을 조회한다.
  2. 생산계획의 품목, 계획수량, 생산일자, 적용 라우팅을 확인한다.
  3. 생산관리자가 생산계획 확정을 실행한다.
  4. 시스템은 적용 라우팅의 버전을 확인한다.
  5. 시스템은 라우팅 공정 중 MES 관리 대상 공정을 식별한다.
  6. 시스템은 관리 대상 공정별 작업지시를 전체 일괄 생성한다.
  7. 시스템은 각 작업지시의 선행·후속 관리 공정 관계를 설정한다.
  8. 생산관리자는 생성된 작업지시 목록을 확인한다.
  9. 생산관리자는 작업지시를 일괄 발행하거나 선택하여 발행한다.
  10. 발행된 작업지시는 해당 공정의 현장 단말기에 표시된다.

예시

전체 라우팅

10 사출       MES 관리
20 사상       MES 미관리
30 조립       MES 관리
40 융착       MES 미관리
50 검사       MES 관리
60 포장       MES 관리

생성 결과:

사출 작업지시
조립 작업지시
검사 작업지시
포장 작업지시

시스템 검증

  • 생산계획이 이미 확정되었는지 확인
  • 작업지시 중복 생성 여부 확인
  • 라우팅 및 BOM 버전 유효성 확인
  • 필수 공정정보 누락 여부 확인
  • 작업지시 수량 합계 확인

완료 결과

  • MES 관리 대상 공정 작업지시가 전체 생성된다.
  • 모든 작업지시는 같은 생산계획과 연결된다.
  • MES 미관리 공정은 라우팅 화면에만 표시된다.

SCN-02 작업지시 배정 및 작업 준비

사용자

생산관리자, 현장 관리자

시작 조건

  • 작업지시가 생성되어 있다.
  • 작업지시 상태가 작성 또는 발행 상태이다.

정상 흐름

  1. 현장 관리자가 작업지시 목록을 조회한다.
  2. 설비, 금형, 작업구역, 계획 시작시간을 배정한다.
  3. 필요한 경우 예정 근무조를 지정한다.
  4. 작업지시 우선순위와 작업순서를 조정한다.
  5. 시스템은 동일 설비의 작업시간 중복 여부를 확인한다.
  6. 현장 관리자는 작업지시를 작업대기 상태로 전환한다.
  7. 작업자는 단말기에서 자신이 처리할 수 있는 작업지시를 확인한다.

시스템 검증

  • 해당 단말기에 허용된 공정인지 확인
  • 설비·금형이 사용 가능한 상태인지 확인
  • 작업지시가 취소·보류 상태가 아닌지 확인
  • 필수 자원이 지정되었는지 확인

완료 결과

  • 작업지시가 현장에서 실행 가능한 상태가 된다.
  • 예정 설비, 금형, 작업구역이 배정된다.

SCN-03 자재 예약 및 창고 불출

사용자

자재 담당자

시작 조건

  • 작업지시가 발행되어 있다.
  • 작업지시별 소요자재가 계산되어 있다.
  • 자재 LOT 재고가 존재한다.

정상 흐름

  1. 자재 담당자가 작업지시별 소요자재 목록을 조회한다.
  2. 시스템은 BOM과 공정별 자재정보를 기준으로 필요수량을 표시한다.
  3. 자재 담당자는 사용할 자재 LOT를 선택한다.
  4. 시스템은 FIFO 또는 권장 LOT를 안내한다.
  5. 자재 담당자는 자재를 작업지시에 예약한다.
  6. 자재창고에서 실제 자재를 피킹한다.
  7. 자재 LOT 바코드를 스캔한다.
  8. 시스템은 품목, LOT, 수량, 품질상태를 확인한다.
  9. 자재를 생산현장으로 불출한다.
  10. 시스템은 자재 위치를 자재창고에서 생산현장으로 변경한다.

시스템 검증

  • 작업지시 소요자재와 일치하는지 확인
  • 가용재고수량 확인
  • 품질상태 확인
  • 보류·불량·검사대기 자재 차단
  • 유효기간 확인
  • 동일 자재 중복 불출 여부 확인

완료 결과

  • 자재가 작업지시에 예약된다.
  • 창고재고가 생산현장 재고로 이동한다.
  • 실제 투입 전 상태로 관리된다.

SCN-04 작업 시작 및 자재 LOT 투입

사용자

작업자

시작 조건

  • 작업지시가 작업대기 상태이다.
  • 필요한 자재가 생산현장에 준비되어 있다.
  • 작업자가 사용할 단말기에 대상 공정이 허용되어 있다.

정상 흐름

  1. 작업자가 사번 또는 작업자 카드를 스캔한다.
  2. 작업자가 작업지시 바코드를 스캔한다.
  3. 시스템은 작업지시, 품목, 공정, 설비, 금형을 표시한다.
  4. 작업자는 실제 근무조, 설비, 금형을 확인한다.
  5. 작업자는 자재 LOT 바코드를 스캔한다.
  6. 시스템은 해당 자재가 작업지시에서 사용할 수 있는지 검증한다.
  7. 작업자는 실제 투입수량을 입력하거나 포장단위 전체 투입을 확인한다.
  8. 시스템은 자재 LOT를 작업지시와 연결한다.
  9. 작업자가 작업 시작을 실행한다.
  10. 작업지시는 작업중 상태로 변경된다.

시스템 검증

  • 단말기 허용 공정
  • 작업자 권한
  • 작업지시 상태
  • 자재 품목 일치
  • 자재 LOT 품질상태
  • 자재 가용수량
  • 선행 공정 가용수량
  • 필수 설비·금형 지정 여부

완료 결과

  • 실제 작업 세션이 생성된다.
  • 작업자, 근무조, 설비, 금형, 시작시각이 기록된다.
  • 자재 LOT가 작업지시와 연결된다.

SCN-05 초품검사

사용자

작업자, 품질 검사자

시작 조건

  • 작업지시가 작업중 상태이다.
  • 초품검사 대상 공정으로 설정되어 있다.
  • 최초 생산품이 만들어졌다.

정상 흐름

  1. 시스템은 작업 시작 이벤트를 기준으로 초품검사 대상을 생성한다.
  2. 작업자는 최초 생산품을 검사구역에 전달한다.
  3. 검사자는 작업지시 또는 생산 LOT 바코드를 스캔한다.
  4. 시스템은 적용 검사계획과 검사항목을 표시한다.
  5. 검사자는 측정값과 외관검사 결과를 입력한다.
  6. 시스템은 검사항목별 합격 여부를 자동 판정한다.
  7. 검사자는 전체 검사결과를 확정한다.
  8. 합격이면 시스템은 양산 진행을 허용한다.
  9. 불합격이면 작업지시를 일시중지하거나 보류한다.

시스템 검증

  • 적용 검사계획 버전
  • 검사자 권한 및 자격
  • 필수 검사항목 입력 여부
  • 측정값 규격 범위
  • 사용 검사장비의 교정 유효상태

완료 결과

  • 초품검사 합격: 양산 가능
  • 초품검사 불합격: 생산 중단 및 조건조정 필요

SCN-06 부분 생산실적 등록

사용자

작업자

시작 조건

  • 작업지시가 작업중 상태이다.
  • 실제 생산이 진행되고 있다.

정상 흐름

  1. 일정 수량 또는 박스 단위 생산이 완료된다.
  2. 작업자가 작업지시 바코드를 스캔한다.
  3. 시스템은 작업지시 누적실적과 잔여수량을 표시한다.
  4. 작업자가 양품수량과 불량수량을 입력한다.
  5. 필요한 경우 불량유형을 선택한다.
  6. 시스템은 실제 설비, 금형, 근무조, 작업자를 자동 적용한다.
  7. 작업자가 실적을 저장한다.
  8. 시스템은 작업지시 누적실적을 갱신한다.
  9. 양품수량은 생산 LOT에 반영된다.
  10. 품질검사가 필요하지 않거나 합격된 수량은 후속 공정 가용수량으로 반영된다.

시스템 검증

  • 지시수량 초과 여부
  • 공정투입 가능수량 초과 여부
  • 선행 공정 가용수량 초과 여부
  • 양품·불량수량 정합성
  • 필수 자재 LOT 등록 여부
  • 생산 LOT 생성 또는 연결 여부

완료 결과

  • 부분 생산실적이 저장된다.
  • 작업지시는 계속 작업중 상태를 유지한다.
  • 후속 공정은 완료수량 범위 내에서 작업할 수 있다.

SCN-07 생산 중 자재 LOT 변경

사용자

작업자, 현장 관리자

시작 조건

  • 작업지시가 작업중 상태이다.
  • 기존 자재 LOT가 소진되었거나 변경이 필요하다.

정상 흐름

  1. 작업자가 기존 자재 LOT 사용종료를 등록한다.
  2. 실제 사용수량과 잔량을 확인한다.
  3. 잔량이 있으면 반납 또는 계속 사용 여부를 선택한다.
  4. 작업자가 신규 자재 LOT를 스캔한다.
  5. 시스템은 신규 LOT의 적합성을 검증한다.
  6. 작업자가 LOT 변경시각 또는 적용 생산수량을 등록한다.
  7. 시스템은 변경 전후 LOT 사용구간을 구분한다.
  8. 이후 생산실적은 신규 자재 LOT와 연결된다.

시스템 검증

  • 대체자재 여부
  • LOT 품질상태
  • 가용수량
  • Running Change 승인 필요 여부
  • 기존 LOT 잔량 정합성

완료 결과

  • 생산 LOT별 사용 자재 LOT 관계가 구분된다.
  • 변경 전후 생산구간을 추적할 수 있다.

SCN-08 공정검사 및 품질판정

사용자

작업자, 품질 검사자

시작 조건

  • 검사주기 또는 검사수량 조건이 도래했다.
  • 검사대상 생산실적 또는 생산 LOT가 존재한다.

정상 흐름

  1. 시스템이 공정검사 대상을 자동 생성한다.
  2. 작업자 또는 검사자가 검사대상 바코드를 스캔한다.
  3. 시스템은 적용 검사항목과 규격을 표시한다.
  4. 검사자는 측정값과 판정을 입력한다.
  5. 시스템은 항목별 판정과 전체 판정을 계산한다.
  6. 검사결과가 합격이면 생산 LOT를 가용 상태로 유지한다.
  7. 검사결과가 불합격이면 해당 생산구간 또는 LOT를 보류한다.
  8. 품질관리자는 부적합 건을 확인한다.

시스템 검증

  • 검사주기 준수 여부
  • 검사대상 생산구간
  • 검사수량 정합성
  • 필수 검사항목
  • 판정과 LOT 상태 일치 여부

완료 결과

  • 합격수량은 후속 공정 사용 가능
  • 불합격·보류수량은 후속 공정과 출하 차단

SCN-09 후속 공정 부분 인계

사용자

선행 공정 작업자, 후속 공정 작업자

시작 조건

  • 선행 공정에서 일부 양품 생산실적이 등록되어 있다.
  • 후속 공정 작업지시가 이미 생성되어 있다.

정상 흐름

  1. 선행 공정에서 생산 LOT 또는 취급단위를 준비한다.
  2. 후속 공정 작업자가 LOT 바코드를 스캔한다.
  3. 시스템은 품목, LOT, 품질상태, 가용수량을 확인한다.
  4. 작업자는 후속 공정 투입수량을 입력한다.
  5. 시스템은 선행 LOT 가용수량을 차감한다.
  6. 후속 공정 작업지시의 공정투입수량을 증가시킨다.
  7. 후속 공정 작업자가 작업을 시작한다.
  8. 앞뒤 작업지시와 LOT 계보가 연결된다.

예시

사출 작업지시 수량: 10,000개
현재 사출 양품수량: 5,000개

조립 공정 투입
- 1차 투입: 3,000개
- 사출 LOT 잔여: 2,000개

완료 결과

  • 전체 선행 작업이 완료되지 않아도 후속 공정을 진행할 수 있다.
  • 공정 간 재공수량을 확인할 수 있다.

SCN-10 MES 미관리 공정을 거친 후속 공정 인계

사용자

후속 MES 관리 공정 작업자

시작 조건

  • 선행 MES 관리 공정에서 생산 LOT가 생성되어 있다.
  • 중간에 MES 미관리 공정이 존재한다.

정상 흐름

  1. 선행 관리 공정에서 생성된 생산 LOT가 미관리 공정을 거친다.
  2. 미관리 공정에서는 별도의 MES 작업지시나 생산실적을 입력하지 않는다.
  3. 후속 MES 관리 공정에서 작업자가 선행 생산 LOT를 스캔한다.
  4. 시스템은 전체 라우팅 순서가 올바른지 확인한다.
  5. 작업자는 실제 투입수량을 등록한다.
  6. 시스템은 선행 관리 공정 LOT와 후속 관리 공정 작업지시를 연결한다.
  7. 미관리 공정은 라우팅 경로에 존재하지만 별도 공식 실적은 생성하지 않는다.

완료 결과

  • MES 미관리 공정이 있어도 LOT 계보가 끊어지지 않는다.
  • 실제 미관리 공정 완료시각은 별도로 정확하게 추정하지 않는다.

SCN-11 작업 중단 및 재개

사용자

작업자, 현장 관리자

시작 조건

  • 작업지시가 작업중 상태이다.
  • 설비·자재·품질 등의 문제가 발생했다.

정상 흐름

  1. 작업자가 작업 일시중지를 선택한다.
  2. 중지사유를 입력한다.
  3. 시스템은 중지 시작시각을 기록한다.
  4. 문제 해결 후 작업자가 작업지시를 다시 조회한다.
  5. 작업자가 작업 재개를 선택한다.
  6. 시스템은 재개시각과 중지시간을 기록한다.
  7. 작업지시는 다시 작업중 상태가 된다.

주요 중지사유

  • 설비 고장
  • 금형 이상
  • 자재 부족
  • 품질 확인
  • 교대
  • 계획 변경
  • 작업자 부재

완료 결과

  • 작업지시 상태와 작업 세션 이력이 보존된다.
  • 순수 생산시간과 중지시간을 구분할 수 있다.

SCN-12 불량 및 부적합 처리

사용자

작업자, 품질 검사자, 품질 관리자

시작 조건

  • 생산 또는 검사 과정에서 불량이 발견되었다.

정상 흐름

  1. 작업자가 생산실적 입력 시 불량수량과 불량현상을 등록한다.
  2. 품질 검사자가 실제 불량 발생공정과 발견공정을 확인한다.
  3. 중대한 품질문제이면 부적합 건을 생성한다.
  4. 관련 생산 LOT 또는 수량을 보류한다.
  5. 품질 관리자가 처리방향을 결정한다.

처리방향:

  • 재작업
  • 선별
  • 재검사
  • 특채
  • 폐기
  • 반품
  • 공급사 귀책 처리
  • 시스템은 처리방향과 승인정보를 기록한다.
  • 처리 완료 전까지 해당 LOT의 후속 공정 투입과 출하를 차단한다.

완료 결과

  • 불량현상, 원인, 귀책, 처리결과가 연결된다.
  • 관련 LOT의 사용이 통제된다.

SCN-13 재작업 및 재검사

사용자

품질 관리자, 생산관리자, 작업자, 검사자

시작 조건

  • 부적합 처리결정이 재작업으로 확정되었다.

정상 흐름

  1. 품질 관리자가 재작업 대상수량을 확정한다.
  2. 시스템이 재작업 작업지시를 생성한다.
  3. 재작업 작업지시는 원본 작업지시와 생산 LOT에 연결된다.
  4. 작업자가 재작업 대상 LOT를 스캔한다.
  5. 작업자가 재작업 실적을 등록한다.
  6. 재작업 완료 후 재검사 대상을 생성한다.
  7. 검사자가 재검사 결과를 입력한다.
  8. 합격수량은 가용 상태로 전환한다.
  9. 재불량수량은 추가 재작업 또는 폐기 처리한다.

완료 결과

원본 생산 LOT
→ 불량
→ 재작업 작업지시
→ 재작업 생산실적
→ 재검사
→ 최종 품질판정

원래 불량이력은 삭제되지 않는다.

SCN-14 자재 및 생산 잔량 처리

사용자

작업자, 자재 담당자

시작 조건

  • 작업 종료 또는 자재 LOT 변경 시 잔량이 발생했다.

정상 흐름

  1. 작업자가 잔량 발생을 등록한다.
  2. 자재 품목, LOT, 잔량, 보관상태를 입력한다.
  3. 잔량 처리방식을 선택한다.

처리방식:

  • 동일 작업지시에서 계속 사용
  • 다음 작업지시에서 재사용
  • 생산현장 보관
  • 자재창고 반납
  • 품질확인 대기
  • 폐기
  • 창고 반납이면 자재 담당자가 잔량을 스캔한다.
  • 시스템은 자재 위치와 재고수량을 변경한다.
  • 필요한 경우 잔량 라벨을 출력한다.

완료 결과

  • 투입수량, 실제 사용수량, 잔량, 폐기수량이 일치한다.
  • 잔량은 원본 LOT와의 관계를 유지한다.

SCN-15 작업완료 및 마감

사용자

작업자, 현장 관리자, 생산관리자

시작 조건

  • 작업지시의 실제 생산이 종료되었다.

정상 흐름

  1. 작업자가 작업지시를 조회한다.
  2. 최종 양품·불량·보류수량을 확인한다.
  3. 자재 사용수량과 잔량을 확정한다.
  4. 작업자가 작업완료를 실행한다.
  5. 시스템은 필수 처리항목을 검증한다.
  6. 이상이 없으면 작업지시를 작업완료 상태로 변경한다.
  7. 생산관리자가 실적, 품질, 자재, LOT 현황을 확인한다.
  8. 생산관리자가 작업지시 마감을 실행한다.
  9. 시스템은 마감 후 일반 사용자의 수정을 차단한다.

마감 검증항목

  • 생산실적 확정
  • 양품·불량수량 확정
  • 필수 자재투입 등록
  • 자재잔량 처리
  • 필수 품질검사 완료
  • 생산 LOT 생성
  • 부적합 미처리 여부
  • 후속 공정 인계수량
  • ERP 전송대상 생성

완료 결과

  • 작업지시가 최종 확정된다.
  • 이후 정정은 마감 취소와 승인절차를 거쳐야 한다.

SCN-16 반제품·완제품 창고 입고

사용자

생산 작업자, 창고 담당자

시작 조건

  • 생산 LOT가 생성되어 있다.
  • 품질상태가 입고 가능한 상태이다.

정상 흐름

  1. 생산 작업자가 생산 LOT 또는 포장단위를 스캔한다.
  2. 생산현장에서 창고로 이동 요청을 등록한다.
  3. 창고 담당자가 입고 대상 LOT를 스캔한다.
  4. 시스템은 품목, 수량, 품질상태를 확인한다.
  5. 창고 담당자가 실제 보관위치를 지정한다.
  6. 시스템은 LOT 위치를 창고 로케이션으로 변경한다.
  7. 재고상태를 가용 또는 검사대기로 설정한다.

완료 결과

  • 생산 완료와 창고 입고를 구분하여 관리한다.
  • 생산실적 등록만으로 자동 창고입고 처리하지 않는다.

SCN-17 출하 및 출하 LOT 구성

사용자

출하 담당자, 품질 담당자

시작 조건

  • 출하요청이 존재한다.
  • 완제품 LOT가 창고에 존재한다.
  • 출하 가능 품질상태이다.

정상 흐름

  1. 출하 담당자가 출하요청을 조회한다.
  2. 시스템은 출하 가능한 생산 LOT를 표시한다.
  3. 출하 담당자는 생산 LOT 또는 포장 LOT를 스캔한다.
  4. 출하 LOT를 구성한다.
  5. 필수 출하검사가 있으면 검사대상을 생성한다.
  6. 품질 담당자가 출하검사를 수행한다.
  7. 검사 합격 후 출하 담당자가 출하를 확정한다.
  8. 시스템은 출하 LOT와 고객·출하문서를 연결한다.
  9. 출하수량을 재고에서 차감한다.

시스템 검증

  • 품목 일치
  • 가용수량
  • 품질상태
  • 보류·격리 여부
  • 고객별 특채조건
  • 유효기간
  • 출하검사 결과

완료 결과

  • 어느 생산 LOT가 어느 고객에게 출하되었는지 기록된다.
  • 출하 LOT에서 자재 LOT까지 역추적할 수 있다.

SCN-18 완제품 LOT 역추적

사용자

품질 관리자, 고객대응 담당자

시작 조건

  • 고객불만 또는 품질문제가 접수되었다.
  • 완제품 LOT, 고객 바코드 또는 출하 LOT를 알고 있다.

정상 흐름

  1. 사용자가 완제품 LOT 또는 고객 바코드를 검색한다.
  2. 시스템은 해당 출하정보를 조회한다.
  3. 사용자가 역방향 추적을 실행한다.
  4. 시스템은 다음 정보를 단계별로 조회한다.
출하 LOT
→ 완제품 생산 LOT
→ 생산실적
→ 공정별 작업지시
→ 설비·금형·작업자
→ 투입 반제품 LOT
→ 투입 자재 LOT
→ 공급사 LOT
  1. 시스템은 관련 품질검사와 재작업·특채 이력을 함께 표시한다.

완료 결과

  • 문제 제품에 사용된 모든 주요 자재 LOT와 생산조건을 확인할 수 있다.

SCN-19 자재 LOT 정방향 영향범위 조회

사용자

품질 관리자, 자재 담당자

시작 조건

  • 특정 자재 LOT에 품질문제가 확인되었다.

정상 흐름

  1. 사용자가 자재 LOT를 검색한다.
  2. 시스템은 해당 자재 LOT의 투입 작업지시를 조회한다.
  3. 해당 자재가 사용된 생산실적과 생산 LOT를 조회한다.
  4. 생산 LOT의 현재 위치를 조회한다.
  5. 포장·출하된 LOT와 고객을 조회한다.
  6. 시스템은 영향수량을 구분하여 표시한다.

영향수량:

  • 생산현장 재공
  • 반제품 재고
  • 완제품 재고
  • 출하대기
  • 출하완료
  • 고객별 출하수량
  • 품질 관리자는 영향 LOT를 일괄 보류한다.

완료 결과

  • 자재 LOT 문제의 전체 영향범위를 확인한다.
  • 미출하 재고 사용을 차단한다.
  • 출하분은 회수 검토 대상으로 등록한다.

SCN-20 구매자재 입하등록

사용자

입하 담당자, 자재 담당자

시작 조건

  • ERP 구매 P/O가 MES에 연계되어 있다.
  • 공급업체와 품목 기준정보가 등록되어 있다.
  • 차량 또는 납품물품이 공장 입하장에 도착했다.
  • 사용자가 입하등록 권한을 가지고 있다.

정상 흐름

  1. 입하 담당자가 ERP P/O 또는 입하예정 목록을 조회한다.
  2. 공급업체, P/O 번호, 예정 품목 및 미입하수량을 확인한다.
  3. 입하 담당자가 입하 Header를 생성한다.
  4. 공급업체, 거래명세서 번호, 차량정보, 입하일시를 입력한다.
  5. P/O Line을 선택하여 입하 품목을 추가한다.
  6. 품목별 실제 입하수량, 포장수량, 공급사 LOT를 입력한다.
  7. 제조일자와 유효기간이 필요한 품목은 해당 정보를 입력한다.
  8. 실제 포장상태와 수량을 검수한다.
  9. 입하 담당자가 입하등록을 확정한다.
  10. 시스템은 품목별 검사정책을 조회한다.
  11. 검사 대상 품목은 수입검사 대기상태로 전환한다.
  12. 무검사 품목은 입고대기상태로 전환한다.

예시

P/O 수량: 10,000개
기입하수량: 4,000개
금번 입하수량: 3,000개
미입하수량: 3,000개

시스템 검증

  • 유효한 P/O인지 확인
  • P/O 공급업체와 실제 공급업체 일치 여부
  • P/O 품목과 입하 품목 일치 여부
  • 미입하수량 초과 여부
  • 수량 단위 일치 여부
  • 공급사 LOT 필수 여부
  • 제조일자·유효기간 필수 여부
  • 동일 납품서 또는 입하 건 중복 여부
  • 사용자의 사업부·공장 권한

완료 결과

  • 입하 Header와 입하 Line이 생성된다.
  • P/O별 기입하수량과 미입하수량이 갱신된다.
  • 입하된 물품은 아직 일반 가용재고로 처리되지 않는다.
  • 품목별로 수입검사대기 또는 입고대기 상태가 생성된다.

주요 예외 흐름

P/O 수량 초과

  1. 입하수량이 P/O 잔량을 초과한다.
  2. 시스템은 초과수량을 표시한다.
  3. 설정된 허용범위 이내이면 경고 후 등록할 수 있다.
  4. 허용범위를 초과하면 관리자 승인을 요구하거나 입하를 차단한다.

P/O 없는 입하

  1. 사용자가 P/O 없이 입하등록을 시도한다.
  2. 고객사급, 무상샘플, 긴급입하 등 예외유형을 선택한다.
  3. 입하사유와 승인자를 등록한다.
  4. 승인된 경우에만 예외입하를 생성한다.

실물과 납품서 수량 불일치

  1. 입하 담당자가 실제수량 차이를 확인한다.
  2. 부족·초과·파손수량을 구분해 입력한다.
  3. 차이사유와 사진 등의 근거자료를 첨부한다.
  4. 실제 확인수량을 기준으로 입하등록한다.

SCN-21 수입검사 후 부분 입고

사용자

품질 검사자, 품질 관리자, 자재 담당자

시작 조건

  • 입하등록이 완료되어 있다.
  • 수입검사 대상이 생성되어 있다.
  • 자재가 검사대기구역에 물리적으로 보관되어 있다.
  • 검사계획과 검사항목이 등록되어 있다.

정상 흐름

  1. 품질 검사자가 수입검사 대기목록을 조회한다.
  2. 입하번호 또는 공급사 LOT 바코드를 스캔한다.
  3. 시스템은 검사대상 품목, 수량, 공급사 LOT와 검사계획을 표시한다.
  4. 검사자는 샘플수량과 검사항목을 확인한다.
  5. 측정값, 외관검사 및 포장상태 결과를 입력한다.
  6. 시스템은 검사항목별 판정을 계산한다.
  7. 검사자가 합격·보류·불합격수량을 확정한다.
  8. 시스템은 판정수량별 입고대상을 분리한다.
  9. 자재 담당자는 합격수량을 가용재고로 입고한다.
  10. 보류수량은 보류창고 또는 보류로케이션에 입고한다.
  11. 불합격수량은 격리 또는 반품대기 재고로 입고한다.
  12. 시스템은 내부 자재 LOT를 생성하거나 상태별 LOT를 분리한다.
  13. 필요한 자재 LOT 라벨을 출력한다.

예시

입하수량: 1,000kg

합격: 800kg
보류: 150kg
불합격: 50kg

처리 결과:

800kg → 가용재고
150kg → 보류재고
50kg → 격리·반품대기 재고

시스템 검증

  • 검사수량과 판정수량 합계 일치 여부
  • 검사계획 및 검사규격 버전
  • 필수 검사항목 입력 여부
  • 검사자 자격
  • 중복 검사결과 여부
  • 입하수량 초과 입고 여부
  • 내부 LOT 중복 생성 여부
  • 품질판정과 입고 재고상태 일치 여부

완료 결과

  • 합격·보류·불합격수량이 분리 입고된다.
  • 내부 자재 LOT와 공급사 LOT가 연결된다.
  • 가용재고와 보류·격리재고가 명확히 구분된다.
  • 불합격 자재는 생산출고와 자재투입이 차단된다.

주요 예외 흐름

검사결과 보류

  1. 검사자가 즉시 합격 여부를 결정하지 못한다.
  2. 검사 전체를 보류로 판정한다.
  3. 해당 자재는 보류로케이션에 입고하거나 검사대기상태로 유지한다.
  4. 재검사 또는 품질 관리자 판정을 기다린다.

특채 승인

  1. 검사결과가 규격에서 일부 벗어난다.
  2. 품질 관리자가 특채 승인요청을 생성한다.
  3. 사용 가능 품목·공정·수량·기간을 지정한다.
  4. 승인 후 조건부 가용재고로 입고한다.

입하수량과 판정수량 불일치

  1. 합격·보류·불합격수량 합계가 입하수량과 다르다.
  2. 시스템은 입고확정을 차단한다.
  3. 미검사·파손·부족수량을 추가로 구분해야 한다.

SCN-22 자재 창고 적치

사용자

창고 담당자

시작 조건

  • 자재 입고가 완료되어 있다.
  • 자재가 입고대기 또는 적치대기 구역에 있다.
  • 창고와 로케이션 기준정보가 등록되어 있다.
  • LOT 라벨과 로케이션 바코드를 사용할 수 있다.

정상 흐름

  1. 창고 담당자가 적치대기 목록을 조회한다.
  2. 자재 LOT 바코드를 스캔한다.
  3. 시스템은 품목, LOT, 수량, 품질상태를 표시한다.
  4. 시스템은 품목속성과 창고정책을 기준으로 권장 로케이션을 제시한다.
  5. 창고 담당자가 실제 적치할 로케이션으로 이동한다.
  6. 로케이션 바코드를 스캔한다.
  7. 적치수량을 입력하거나 포장단위 전체 적치를 확인한다.
  8. 시스템은 로케이션 적합성을 검증한다.
  9. 창고 담당자가 적치를 확정한다.
  10. 시스템은 LOT의 현재 위치와 로케이션별 수량을 갱신한다.

시스템 검증

  • 지정 창고의 유효한 로케이션인지 확인
  • 품목·LOT 혼재 허용 여부
  • 로케이션 수용량
  • 온도·습도·위험물 조건
  • 품질상태별 허용 로케이션
  • 동일 수량 중복 적치 여부
  • 적치수량이 입고대기수량을 초과하지 않는지 확인

완료 결과

  • 자재의 실제 창고·랙·셀 위치가 등록된다.
  • 로케이션별 재고수량이 갱신된다.
  • 해당 자재는 피킹 가능한 상태가 된다.

주요 예외 흐름

하나의 LOT 분산적치

  1. 한 로케이션에 전체수량을 적치할 수 없다.
  2. 일부 수량을 첫 번째 로케이션에 적치한다.
  3. 잔여수량을 다른 로케이션에 적치한다.
  4. 시스템은 동일 LOT의 위치별 수량을 관리한다.

잘못된 로케이션 스캔

  1. 품질 보류자재를 일반 가용재고 로케이션에 적치하려 한다.
  2. 시스템은 품질상태와 로케이션 정책 불일치를 확인한다.
  3. 적치를 차단하고 적합한 보류로케이션을 안내한다.

미적치 재고 장기체류

  1. 설정된 시간 이상 적치되지 않은 재고가 존재한다.
  2. 시스템은 미적치 예외목록에 등록한다.
  3. 창고 관리자에게 알림을 제공한다.

SCN-23 생산출고 요청 및 피킹

사용자

생산관리자, 자재 담당자, 창고 담당자

시작 조건

  • 작업지시가 발행되어 있다.
  • 작업지시의 BOM과 공정별 소요자재가 확정되어 있다.
  • 가용 자재재고가 존재한다.
  • 생산구역과 필요일시가 지정되어 있다.

정상 흐름

  1. 생산관리자가 작업지시별 소요자재를 조회한다.
  2. 시스템은 표준소요량, 기출고수량, 현장재고 및 부족수량을 계산한다.
  3. 생산관리자가 생산출고 요청을 생성한다.
  4. 시스템은 요청수량만큼 가용재고를 예약한다.
  5. FIFO·FEFO 등의 정책을 기준으로 권장 LOT와 로케이션을 할당한다.
  6. 창고 담당자가 피킹지시 목록을 조회한다.
  7. 피킹 대상 로케이션으로 이동한다.
  8. 로케이션 바코드를 스캔한다.
  9. 자재 LOT 바코드를 스캔한다.
  10. 시스템은 품목, LOT, 품질상태와 가용수량을 검증한다.
  11. 창고 담당자가 실제 피킹수량을 확인한다.
  12. 피킹을 확정한다.
  13. 모든 품목의 피킹이 완료되면 생산출고를 확정한다.
  14. 자재는 창고재고에서 이동중 또는 생산현장재고로 전환된다.

시스템 검증

  • 작업지시 소요자재인지 확인
  • 예약수량과 피킹수량 일치 여부
  • 가용재고 초과 여부
  • 품질상태 및 재고상태
  • 유효기간
  • FIFO·FEFO 위반 여부
  • 지정 로케이션 일치 여부
  • 동일 자재 중복 피킹 여부
  • 작업지시 취소·보류 여부

완료 결과

  • 자재가 생산현장으로 출고된다.
  • 출고 LOT와 작업지시가 연결된다.
  • 창고재고가 감소하고 이동중 또는 현장재고가 증가한다.
  • 출고된 자재는 아직 작업지시에 실제 투입된 것으로 처리되지 않는다.

주요 예외 흐름

권장 LOT 재고 부족

  1. 권장 LOT의 수량이 요청수량보다 부족하다.
  2. 시스템은 다음 가용 LOT를 제시한다.
  3. 여러 LOT로 분할 피킹한다.
  4. 작업지시에는 복수 자재 LOT 출고이력이 연결된다.

FIFO 위반

  1. 작업자가 권장 LOT보다 최근 LOT를 스캔한다.
  2. 시스템은 FIFO 위반을 경고한다.
  3. 정책에 따라 차단하거나 사유 입력 후 허용한다.

출고요청 수량 변경

  1. 생산계획 또는 작업지시 수량이 변경된다.
  2. 미피킹수량은 예약해제한다.
  3. 이미 피킹된 수량은 출고취소 또는 현장재고로 처리한다.

SCN-24 생산현장 인수 및 작업지시 투입

사용자

생산 작업자, 현장 관리자, 자재 담당자

시작 조건

  • 생산출고가 확정되어 있다.
  • 자재가 생산현장에 물리적으로 도착했다.
  • 작업지시가 작업대기 또는 작업중 상태이다.
  • 사용 단말기에서 해당 공정 처리가 허용되어 있다.

정상 흐름

  1. 생산 작업자가 출고문서 또는 운반단위 바코드를 스캔한다.
  2. 시스템은 출고 품목, LOT, 수량 및 도착 생산구역을 표시한다.
  3. 작업자가 자재 LOT별 실물수량과 포장상태를 확인한다.
  4. 이상이 없으면 현장 인수를 확정한다.
  5. 시스템은 이동중 재고를 생산현장 재고로 전환한다.
  6. 작업자는 실제 생산 시작 시 작업지시 바코드를 스캔한다.
  7. 투입할 자재 LOT 바코드를 스캔한다.
  8. 시스템은 해당 자재가 작업지시의 소요자재인지 검증한다.
  9. 작업자는 작업지시에 실제 투입할 수량을 입력한다.
  10. 시스템은 생산현장 재고를 차감한다.
  11. 자재 LOT와 작업지시의 자재투입 관계를 생성한다.
  12. 자재투입 완료 후 작업을 시작하거나 생산을 계속한다.

예시

창고 출고수량: 100kg
생산현장 인수수량: 100kg
작업지시 실제 투입수량: 80kg
현장 잔량: 20kg

시스템 검증

  • 유효한 생산출고 건인지 확인
  • 출고 도착 생산구역 일치 여부
  • 인수수량이 출고수량을 초과하지 않는지 확인
  • 작업지시 대상 자재와 실제 자재 일치 여부
  • LOT 품질상태
  • 생산현장 가용수량
  • 대체자재 승인 여부
  • 단말기 허용 공정
  • 작업지시 상태

완료 결과

  • 창고 출고와 생산현장 인수가 완료된다.
  • 실제 사용분만 작업지시에 투입된다.
  • 미투입수량은 생산현장 재고로 유지된다.
  • 투입 자재 LOT가 생산실적과 생산 LOT 추적의 근거가 된다.

주요 예외 흐름

출고수량과 인수수량 불일치

  1. 출고 100개 중 실제 도착수량이 98개다.
  2. 작업자가 차이수량과 사유를 입력한다.
  3. 해당 출고 건을 차이확인 상태로 전환한다.
  4. 창고 담당자와 현장 관리자가 차이를 확인한다.
  5. 분실·오출고·수량오류 등의 처리결과를 기록한다.

잘못된 자재 투입

  1. 작업자가 작업지시에 포함되지 않은 자재 LOT를 스캔한다.
  2. 시스템은 자재투입을 차단한다.
  3. 승인된 대체자재인지 확인하도록 안내한다.

출고됐으나 사용하지 않은 자재

  1. 자재가 현장에 인수됐지만 작업계획이 취소된다.
  2. 작업지시 투입은 수행하지 않는다.
  3. 해당 자재는 현장재고로 유지하거나 반납요청을 생성한다.

SCN-25 자재잔량 반납

사용자

생산 작업자, 현장 관리자, 창고 담당자, 품질 담당자

시작 조건

  • 작업 종료, 자재교체 또는 생산계획 변경으로 잔량이 발생했다.
  • 잔량의 원 자재 LOT를 식별할 수 있다.
  • 실제 사용수량과 잔량이 확인되어 있다.

정상 흐름

  1. 생산 작업자가 작업지시의 자재사용 현황을 조회한다.
  2. 투입수량, 실제 사용수량, 폐기수량과 잔량을 확인한다.
  3. 반납할 자재 LOT와 수량을 선택한다.
  4. 개봉 여부, 포장상태, 보관상태를 입력한다.
  5. 반납창고와 반납사유를 선택한다.
  6. 시스템은 자재 품목정책에 따라 품질 재확인 필요 여부를 판단한다.
  7. 작업자가 반납요청을 확정한다.
  8. 필요 시 잔량 라벨을 출력한다.
  9. 자재를 창고 반납구역으로 이동한다.
  10. 창고 담당자가 잔량 LOT와 수량을 검수한다.
  11. 품질확인이 필요 없으면 원 자재 LOT의 가용재고로 반납입고한다.
  12. 품질확인이 필요하면 보류재고로 입고하고 검사요청을 생성한다.
  13. 시스템은 생산현장 재고를 감소시키고 창고재고를 증가시킨다.

시스템 검증

  • 원본 자재 LOT 존재 여부
  • 현장 잔량수량
  • 다른 작업지시에 이미 투입되지 않았는지 확인
  • 유효기간
  • 개봉 후 사용 가능기간
  • 오염·혼합 가능성
  • 반납수량이 잔량을 초과하지 않는지 확인
  • 반납창고와 품질상태의 적합성

완료 결과

  • 현장 잔량이 창고재고로 복귀한다.
  • 원본 자재 LOT 계보가 유지된다.
  • 재사용 가능 여부와 품질상태가 확정된다.
  • 투입·사용·폐기·반납수량의 정합성이 유지된다.

주요 예외 흐름

오염 또는 혼합 의심

  1. 작업자가 자재 오염 가능성을 표시한다.
  2. 시스템은 일반 가용재고 반납을 차단한다.
  3. 보류·격리재고로 입고한다.
  4. 품질검사 후 재사용 또는 폐기 여부를 결정한다.

원본 LOT 식별 불가

  1. 잔량에 원 자재 LOT 라벨이 없다.
  2. 시스템은 일반 반납을 차단한다.
  3. 임시 식별번호를 부여하고 격리한다.
  4. 관리자 확인 후 원 LOT 연결 또는 폐기 처리한다.

반납 불가 자재

  1. 개봉 후 재사용이 허용되지 않는 자재다.
  2. 반납입고를 차단한다.
  3. 현장 계속사용, 폐기 또는 별도 품질처리를 선택한다.

SCN-26 반제품·완제품 부분 입고

사용자

생산 작업자, 창고 담당자, 품질 담당자

시작 조건

  • 생산실적이 등록되어 있다.
  • 반제품 또는 완제품 생산 LOT가 생성되어 있다.
  • 입고 가능한 양품 또는 승인된 수량이 존재한다.
  • 작업지시가 완료되지 않았더라도 부분 생산수량이 확정되어 있다.

정상 흐름

  1. 생산 작업자가 작업지시의 생산 LOT 목록을 조회한다.
  2. 창고로 이동할 생산 LOT와 수량을 선택한다.
  3. 생산 LOT 또는 포장단위 라벨을 출력한다.
  4. 생산현장에서 창고로 이동요청을 등록한다.
  5. 시스템은 생산 LOT의 입고 가능수량을 계산한다.
  6. 자재 또는 제품을 창고 입고대기구역으로 이동한다.
  7. 창고 담당자가 생산 LOT 바코드를 스캔한다.
  8. 품목, 수량, 품질상태와 생산 작업지시를 확인한다.
  9. 창고 담당자가 실제 입고수량을 입력한다.
  10. 입고 창고와 임시 또는 실제 로케이션을 지정한다.
  11. 생산품 입고를 확정한다.
  12. 시스템은 생산현장 재고를 감소시키고 창고재고를 증가시킨다.
  13. 이후 남은 수량에 대해서는 생산을 계속할 수 있다.

예시

작업지시 수량: 10,000개
현재 누적 양품수량: 5,000개
1차 창고 입고수량: 3,000개
생산현장 잔량: 2,000개
미생산수량: 5,000개

시스템 검증

  • 생산 LOT 존재 여부
  • 생산실적과 생산 LOT 수량 일치 여부
  • 기입고수량
  • 후속 공정에 이미 투입된 수량
  • 품질상태
  • 보류·격리 여부
  • 입고수량이 입고 가능수량을 초과하지 않는지 확인
  • 중복 입고 여부

완료 결과

  • 생산 완료된 일부 수량이 먼저 창고에 입고된다.
  • 작업지시는 계속 작업중 상태를 유지할 수 있다.
  • 생산현장 수량, 입고수량, 후속 공정 투입수량이 구분된다.
  • 창고 입고 LOT는 정방향·역방향 추적이 가능하다.

주요 예외 흐름

검사대기 생산품 입고

  1. 최종 품질판정이 완료되지 않았다.
  2. 창고에는 검사대기재고로 입고한다.
  3. 일반 출고와 출하를 차단한다.
  4. 검사 합격 후 가용재고로 전환한다.

입고수량과 실물수량 차이

  1. 생산 측 인계수량과 창고 실수량이 다르다.
  2. 창고 담당자가 차이수량을 등록한다.
  3. 이동 건을 차이확인 상태로 전환한다.
  4. 생산현장과 창고 담당자가 공동 확인한다.

동일 생산 LOT 일부만 입고

  1. 생산 LOT 1,000개 중 600개만 입고한다.
  2. 600개는 창고재고가 된다.
  3. 400개는 생산현장 또는 공정대기 재고로 유지한다.

SCN-27 창고·로케이션 간 이동

사용자

창고 담당자, 물류 관리자

시작 조건

  • 이동할 재고가 출발 창고·로케이션에 존재한다.
  • 이동 대상 LOT와 수량을 식별할 수 있다.
  • 도착 창고·로케이션이 등록되어 있다.

정상 흐름

  1. 창고 담당자가 이동요청을 생성하거나 즉시 이동을 선택한다.
  2. 출발 창고, 출발 로케이션, 도착 창고와 도착 로케이션을 지정한다.
  3. 이동할 LOT를 스캔한다.
  4. 이동수량을 입력한다.
  5. 시스템은 출발 로케이션의 가용수량을 검증한다.
  6. 이동출고를 확정한다.
  7. 창고 간 장거리 이동이면 재고상태를 이동중으로 변경한다.
  8. 재고가 도착하면 담당자가 이동문서 또는 운반단위를 스캔한다.
  9. 도착 LOT와 수량을 확인한다.
  10. 도착 로케이션을 스캔한다.
  11. 이동입고를 확정한다.
  12. 시스템은 출발 위치를 감소시키고 도착 위치를 증가시킨다.

시스템 검증

  • 출발 위치의 LOT별 수량
  • 예약·피킹·보류수량 여부
  • 이동 가능한 품질상태
  • 출발과 도착 위치 동일 여부
  • 도착 로케이션 혼재·수용량 정책
  • 이동수량 초과 여부
  • 동일 이동 건 중복처리 여부

완료 결과

  • 재고의 현재 위치가 도착 로케이션으로 변경된다.
  • 이동출고, 이동중, 이동입고 이력이 보존된다.
  • LOT별 위치와 수량 정합성이 유지된다.

주요 예외 흐름

동일 창고 내 즉시 이동

  1. 가까운 로케이션 간 이동을 수행한다.
  2. 출고·입고 단계를 분리하지 않고 한 번에 확정한다.
  3. 하나의 이동 이벤트로 출발·도착 위치를 갱신한다.

이동 중 수량차이

  1. 출발수량과 도착수량이 다르다.
  2. 도착 담당자가 차이수량과 사유를 입력한다.
  3. 이동완료를 차이확인 상태로 전환한다.
  4. 분실·파손·입력오류 여부를 조사한다.

보류재고 이동

  1. 보류 LOT를 일반 가용창고로 이동하려 한다.
  2. 시스템이 이동을 차단한다.
  3. 보류·격리 전용 위치만 선택할 수 있도록 한다.

SCN-28 사업부 간 출고·입고

사용자

송신 사업부 물류 담당자, 수신 사업부 자재 담당자, 생산관리자

시작 조건

  • 사업부 B의 생산품 또는 자재가 사업부 A에서 사용될 예정이다.
  • 사업부 간 이동요청 또는 내부 공급계획이 존재한다.
  • 송신 사업부에 가용재고가 존재한다.
  • 송신·수신 사업부 창고가 등록되어 있다.

정상 흐름

  1. 수신 사업부 담당자가 사업부 간 이동요청을 생성한다.
  2. 품목, 요청수량, 필요일자와 도착창고를 입력한다.
  3. 송신 사업부 담당자가 이동요청을 확인한다.
  4. 송신 사업부 재고에서 LOT를 할당한다.
  5. LOT와 로케이션을 기준으로 피킹한다.
  6. 사업부 간 출고를 확정한다.
  7. 시스템은 송신 사업부 재고를 감소시키고 이동중 재고를 생성한다.
  8. 이동문서와 LOT 정보를 수신 사업부에 전달한다.
  9. 수신 사업부 담당자가 도착한 LOT를 스캔한다.
  10. 수량, 품질상태와 포장상태를 확인한다.
  11. 수신 사업부 창고로 이동입고를 확정한다.
  12. 필요 시 수신 사업부의 내부 자재 LOT를 생성하고 송신 LOT와 연결한다.
  13. 수신 사업부 로케이션에 적치한다.

시스템 검증

  • 사업부 간 거래 가능한 품목인지 확인
  • 송신 사업부 가용재고
  • 송신·수신 품목코드 매핑
  • 수량과 단위 환산
  • 품질상태
  • 이동문서 중복 여부
  • 사업부별 재고 소유구분
  • 동일 법인 또는 법인 간 거래 여부

완료 결과

  • 송신 사업부 재고가 감소한다.
  • 수신 사업부 재고가 증가한다.
  • 송신 LOT와 수신 LOT의 계보관계가 유지된다.
  • 외부 고객 출하가 아니라 내부 재고이동으로 기록된다.

주요 예외 흐름

수신 사업부 품목코드 상이

  1. 같은 실물품목이 사업부마다 다른 품목코드를 사용한다.
  2. 시스템은 사업부 간 품목 매핑을 조회한다.
  3. 매핑정보가 없으면 입고를 차단한다.
  4. 관리자 승인 후 품목 매핑을 등록한다.

사업부 간 수량차이

  1. 출고수량과 수신수량이 다르다.
  2. 수신 담당자가 차이수량을 입력한다.
  3. 사업부 간 이동을 차이확인 상태로 전환한다.
  4. 양쪽 사업부가 확인 후 조정 또는 재출고 처리한다.

사업부 A에서 추가 수입검사 필요

  1. 사업부 B에서는 합격품이지만 A의 검사정책상 재검사가 필요하다.
  2. 검사대기재고로 입고한다.
  3. 수입 또는 인수검사 합격 후 가용재고로 전환한다.

SCN-29 외주 출고 및 외주 입고

사용자

외주 담당자, 자재 담당자, 품질 검사자, 생산관리자

시작 조건

  • 외주 작업지시 또는 외주가공계획이 존재한다.
  • 외주처와 외주공정 기준정보가 등록되어 있다.
  • 외주에 보낼 자재 또는 반제품 LOT가 존재한다.

정상 흐름: 외주 출고

  1. 외주 담당자가 외주 작업지시를 조회한다.
  2. 외주처, 외주공정, 출고 대상 품목과 수량을 확인한다.
  3. 외주출고 요청을 생성한다.
  4. 시스템은 출고 대상 LOT를 예약·할당한다.
  5. 창고 담당자가 LOT를 피킹한다.
  6. 피킹수량과 포장상태를 확인한다.
  7. 외주출고를 확정한다.
  8. 시스템은 자사 창고재고를 감소시키고 외주처 보유재고 또는 이동중 재고로 변경한다.
  9. 출고 LOT, 수량, 외주처와 외주 작업지시를 연결한다.

정상 흐름: 외주 입고

  1. 외주처 가공품이 공장에 도착한다.
  2. 외주 담당자가 원 외주출고 문서를 조회한다.
  3. 외주 입하수량, 외주처 LOT, 불량·잔량수량을 입력한다.
  4. 시스템은 원 출고수량과 금번 입하수량을 비교한다.
  5. 품질검사 대상이면 외주 수입검사를 생성한다.
  6. 검사자가 품질검사를 수행한다.
  7. 합격수량은 가용재고로 입고한다.
  8. 보류·불합격수량은 별도 상태로 입고한다.
  9. 외주처에 남은 수량과 향후 입고예정수량을 관리한다.
  10. 원 출고 LOT와 외주 입고 LOT의 계보를 연결한다.

수량 관계

외주출고수량
= 외주입고수량
+ 외주처 잔량
+ 불량수량
+ 폐기수량
+ 분실수량
+ 조정수량

시스템 검증

  • 유효한 외주 작업지시인지 확인
  • 외주처와 외주공정 일치 여부
  • 출고 LOT 품질상태
  • 출고 가용수량
  • 원 외주출고 문서 연결 여부
  • 외주입하수량 초과 여부
  • 외주처 잔량 정합성
  • 외주 입고 LOT 중복 여부

완료 결과

  • 외주처로 출고된 재고와 외주처 잔량을 조회할 수 있다.
  • 외주가공 전후 LOT 계보가 유지된다.
  • 외주 입고품의 품질상태와 재고가 생성된다.
  • 외주수량 차이를 추적할 수 있다.

주요 예외 흐름

외주 입고수량 부족

  1. 출고수량보다 입고·잔량·불량 합계가 적다.
  2. 부족수량을 분실 또는 미확인수량으로 등록한다.
  3. 외주수량 불일치 예외목록에 등록한다.
  4. 외주처 확인 후 정정한다.

외주처 LOT 변경

  1. 외주처가 자체 LOT를 부여한다.
  2. 외주처 LOT를 MES 내부 외주입고 LOT와 연결한다.
  3. 내부 원본 LOT와 외주처 LOT를 모두 추적할 수 있도록 한다.

외주품 불합격

  1. 외주 입고검사에서 불합격이 발생한다.
  2. 불합격 LOT를 격리한다.
  3. 외주 재작업, 반품, 특채 또는 폐기를 결정한다.

SCN-30 출하요청·피킹·출하검사·출하

사용자

출하 담당자, 창고 담당자, 품질 검사자, 영업 담당자

시작 조건

  • ERP 판매오더 또는 출하계획이 MES에 연계되어 있다.
  • 출하 가능한 완제품재고가 존재한다.
  • 고객·납품처·고객별 출하정책이 등록되어 있다.

정상 흐름

  1. 출하 담당자가 출하요청 목록을 조회한다.
  2. 고객, 납품처, 품목, 요청수량과 납기일을 확인한다.
  3. 시스템은 출하 가능한 LOT와 포장단위를 조회한다.
  4. FIFO·FEFO·고객 지정조건을 기준으로 출하 LOT를 할당한다.
  5. 창고 담당자에게 출하 피킹지시를 생성한다.
  6. 창고 담당자가 출발 로케이션을 스캔한다.
  7. 생산 LOT 또는 포장단위 바코드를 스캔한다.
  8. 피킹수량을 확인하고 피킹을 확정한다.
  9. 피킹제품을 출하검수구역으로 이동한다.
  10. 출하 담당자는 품목, LOT, 수량, 포장과 고객라벨을 검수한다.
  11. 출하검사가 필요한 경우 검사대상을 생성한다.
  12. 품질 검사자가 출하검사를 수행하고 결과를 확정한다.
  13. 합격된 생산 LOT·포장 LOT를 출하 LOT로 구성한다.
  14. 출하문서, 납품라벨과 고객 지정라벨을 발행한다.
  15. 제품을 차량에 상차한다.
  16. 차량번호, 운송업체, 운전자 및 상차일시를 입력한다.
  17. 출하 담당자가 출하를 확정한다.
  18. 시스템은 출하수량을 재고에서 차감한다.
  19. 출하 LOT와 고객·출하문서를 연결한다.
  20. ERP 출고실적 전송대상을 생성한다.

시스템 검증

  • 판매오더·출하요청 유효성
  • 고객·납품처 일치 여부
  • 품목과 LOT 일치 여부
  • 가용수량
  • 예약·피킹 중복 여부
  • 품질상태
  • 보류·격리 여부
  • 출하검사 합격 여부
  • 유효기간 및 고객별 잔여 유효기간
  • 특채 고객 제한조건
  • 초과·미달 출하 여부
  • 고객라벨 요구조건

완료 결과

  • 완제품 재고가 차감된다.
  • 생산 LOT가 출하 LOT와 고객에게 연결된다.
  • 출하 LOT에서 원자재 LOT까지 역추적할 수 있다.
  • 자재 LOT에서 출하 고객까지 정방향 추적할 수 있다.
  • ERP에 판매출고실적이 전송된다.

주요 예외 흐름

출하검사 불합격

  1. 출하검사에서 불합격이 발생한다.
  2. 해당 LOT를 출하대상에서 제거한다.
  3. 보류 또는 격리처리한다.
  4. 대체 출하 LOT를 재할당한다.
  5. 필요 시 출하일정을 변경한다.

출하수량 부족

  1. 가용재고가 출하요청수량보다 부족하다.
  2. 부분출하 여부를 확인한다.
  3. 부분출하를 허용하면 가능한 수량만 출하한다.
  4. 미출하수량은 차기 출하대상으로 유지한다.

고객 지정 LOT 불일치

  1. 고객이 지정한 LOT가 아닌 제품을 피킹한다.
  2. 시스템은 피킹을 차단한다.
  3. 지정 LOT 또는 승인된 대체 LOT를 선택해야 한다.

상차 후 출하취소

  1. 아직 공장 밖으로 반출되지 않았다면 상차취소 후 피킹재고로 복원한다.
  2. 공장 밖으로 반출되었다면 단순 출하취소를 제한한다.
  3. 실제 납품 이후에는 고객 반품절차를 사용한다.

SCN-31 입출고 취소·정정

사용자

창고 관리자, 생산관리자, 품질 관리자, 승인권자

시작 조건

  • 입하·입고·출고·이동·출하 데이터에 오류가 확인되었다.
  • 사용자가 정정 요청 권한을 가지고 있다.
  • 대상 이벤트와 후속처리 여부를 조회할 수 있다.

정상 흐름

  1. 사용자가 정정할 문서를 조회한다.
  2. 잘못된 품목, LOT, 수량, 로케이션 또는 일시를 확인한다.
  3. 정정 또는 취소 요청을 생성한다.
  4. 정정사유와 근거자료를 등록한다.
  5. 시스템은 해당 이벤트의 후속 업무를 조회한다.
  6. 후속처리가 없으면 승인 후 원 이벤트를 취소하거나 보정한다.
  7. 후속처리가 있는 경우 필요한 역처리 순서를 안내한다.
  8. 승인권자가 변경내용과 재고 영향을 검토한다.
  9. 승인되면 시스템이 반대 재고 트랜잭션 또는 보정 이벤트를 생성한다.
  10. 관련 LOT 수량과 위치를 재계산한다.
  11. ERP 전송이 완료된 건은 ERP 취소·정정 전송대상을 생성한다.
  12. 정정 전후 값과 승인정보를 이력으로 보존한다.

시스템 검증

  • 작업지시 마감 여부
  • LOT의 후속 사용 여부
  • 재고 현재수량
  • 품질검사 및 상태변경 여부
  • ERP 전송상태
  • 출하·고객납품 여부
  • 정정 후 음수재고 또는 수량 불일치 여부

완료 결과

  • 잘못된 입출고 데이터가 승인된 방식으로 정정된다.
  • 원본 이력은 삭제되지 않는다.
  • 재고, LOT, 품질, 작업지시와 ERP 상태가 함께 정합성을 유지한다.
  • 정정 전후 데이터와 처리사유를 감사할 수 있다.

주요 예외 흐름

이미 작업지시에 투입된 자재출고 취소

  1. 생산출고 자재가 작업지시에 이미 투입되었다.
  2. 단순 출고취소를 차단한다.
  3. 자재투입 취소 또는 사용량 정정이 선행되어야 한다.
  4. 이후 현장재고 반납과 출고취소를 처리한다.

출하완료 후 취소

  1. 제품이 고객에게 실제 반출되었다.
  2. 출하취소를 제한한다.
  3. 고객 반품 또는 출하정정 절차를 사용한다.
  4. 고객 반품입고 후 재고를 복원한다.

잘못된 LOT 정정

  1. 수량은 맞지만 다른 LOT로 등록되었다.
  2. 잘못된 LOT의 수량을 원복한다.
  3. 올바른 LOT에 동일 수량의 보정 이벤트를 생성한다.
  4. 생산·출하 추적관계를 함께 정정한다.

SCN-32 외부창고 재고 이동 및 회수

사용자

물류 담당자, 외부창고 담당자, 창고 관리자, 출하 담당자

시작 조건

  • 외부창고 또는 위탁창고가 기준정보에 등록되어 있다.
  • 외부창고 이동 대상 재고가 존재한다.
  • 외부창고의 MES 직접 사용 또는 대체 운영방식이 정해져 있다.

정상 흐름: 외부창고 이동

  1. 물류 담당자가 외부창고 이동요청을 생성한다.
  2. 외부창고, 품목, LOT, 수량과 이동목적을 지정한다.
  3. 자사 창고에서 이동 대상 재고를 예약한다.
  4. 창고 담당자가 LOT와 로케이션을 기준으로 피킹한다.
  5. 외부창고 이동출고를 확정한다.
  6. 시스템은 자사 창고재고를 감소시키고 이동중 재고를 생성한다.
  7. 운송정보와 이동문서를 등록한다.
  8. 외부창고 도착 후 다음 방식 중 하나로 입고확인한다.
    • 외부창고 담당자의 웹·모바일 입력
    • 파일 업로드
    • ERP 또는 API 연계
    • 본사 담당자의 문서 기준 사후등록
  9. 도착 LOT와 수량을 확인한다.
  10. 외부창고 입고를 확정한다.
  11. 시스템은 재고 위치를 외부창고로 변경한다.
  12. 외부창고별 LOT 재고와 마지막 확인일자를 갱신한다.

정상 흐름: 외부창고 회수

  1. 물류 담당자가 외부창고 회수요청을 생성한다.
  2. 회수할 LOT와 수량을 선택한다.
  3. 외부창고 출고정보를 등록한다.
  4. 시스템은 외부창고 재고를 이동중으로 변경한다.
  5. 자사 창고 도착 후 LOT와 수량을 검수한다.
  6. 자사 창고 이동입고를 확정한다.
  7. 품질 재확인이 필요한 경우 보류재고로 입고한다.
  8. 적치 로케이션을 지정한다.

시스템 검증

  • 외부창고에 해당 LOT 재고가 존재하는지 확인
  • 외부창고 재고수량 초과 여부
  • 품질상태와 사용 가능 여부
  • 소유구분
  • 이미 예약·출하된 수량 여부
  • 외부창고 마지막 확인일자
  • 이동출고와 입고수량 일치 여부
  • 중복 파일·API·수동등록 여부

완료 결과

  • 외부창고의 LOT별 수량과 위치를 조회할 수 있다.
  • 자사창고와 외부창고 간 이동이력과 이동중 재고가 관리된다.
  • 외부창고에 MES 단말기가 없어도 문서·파일·연계 방식으로 관리할 수 있다.
  • 외부창고에서 고객에게 직접 출하된 경우에도 출하 LOT와 고객정보를 연결할 수 있다.

주요 예외 흐름

외부창고 실재고 불일치

  1. 외부창고 확인수량이 MES 수량과 다르다.
  2. 차이수량과 사유를 등록한다.
  3. 외부창고 재고 불일치 예외를 생성한다.
  4. 증빙 확인과 승인을 거쳐 재고조정한다.

외부창고 데이터 지연수신

  1. 외부창고 입출고 데이터가 며칠 후 도착한다.
  2. 실제 발생일시와 MES 수신일시를 구분한다.
  3. 중간에 발생한 다른 예약·출하와의 충돌을 확인한다.
  4. 충돌이 있는 건은 자동반영하지 않고 예외목록으로 이동한다.

외부창고 직접 고객출하

  1. 외부창고가 고객에게 직접 제품을 출하한다.
  2. 외부창고 출하정보를 파일·API·수동 방식으로 수신한다.
  3. 외부창고 재고를 차감한다.
  4. 출하 LOT와 고객·출하문서를 연결한다.
  5. ERP 판매출고 전송대상을 생성한다.

10. 핵심 운영 원칙

  1. 입하는 재고를 증가시키지 않는다.
  2. 입고가 확정되어야 재고가 증가한다.
  3. 생산출고와 작업지시 자재투입을 구분한다.
  4. 생산실적과 생산품 창고 입고를 구분한다.
  5. 출고와 현장 인수를 구분할 수 있어야 한다.
  6. 창고 간 장거리 이동은 이동출고와 이동입고를 구분한다.
  7. 사업부 간 이동은 고객 출하로 처리하지 않는다.
  8. 외주 출고재고는 소진된 재고가 아니라 외주처 보유재고로 관리한다.
  9. 보류·격리·불합격 재고는 일반 생산과 출하에 사용할 수 없다.
  10. 모든 취소·정정은 원본 이력을 삭제하지 않고 보정 이벤트로 처리한다.
  11. 모든 재고변경은 품목, LOT, 수량, 출발위치, 도착위치와 근거문서를 가져야 한다.
  12. 외부창고에 MES 단말기가 없어도 최소한 출고·입고·회수시점에는 전산이력을 등록해야 한다.

11. 주요 예외 이용 시나리오

EX-01 잘못된 자재 LOT 스캔

  1. 작업자가 자재 LOT를 스캔한다.
  2. 시스템이 작업지시의 소요자재와 일치하지 않음을 확인한다.
  3. 투입을 차단한다.
  4. 화면에 예상 자재와 실제 스캔 자재를 표시한다.
  5. 승인된 대체자재인 경우 승인절차를 안내한다.

EX-02 자재 LOT 수량 부족

  1. 작업자가 100kg 투입을 요청한다.
  2. 시스템의 가용수량은 60kg이다.
  3. 투입을 차단한다.
  4. 가용수량과 부족수량을 표시한다.
  5. 다른 LOT 추가 투입 또는 수량 수정이 필요하다.

EX-03 보류 LOT 사용 시도

  1. 작업자가 보류 상태 자재 LOT를 스캔한다.
  2. 시스템은 품질상태를 확인한다.
  3. 일반 투입을 차단한다.
  4. 품질 담당자의 보류 해제 또는 특채 승인을 요구한다.

EX-04 지시수량 초과 실적입력

  1. 작업자가 생산실적을 입력한다.
  2. 누적실적이 지시수량을 초과한다.
  3. 시스템은 공정 정책을 확인한다.
  4. 초과 금지 정책이면 입력을 차단한다.
  5. 승인 허용 정책이면 관리자 승인 요청을 생성한다.

EX-05 선행 공정 가용수량 초과

  1. 후속 공정 작업자가 생산실적을 입력한다.
  2. 실적수량이 선행 공정의 가용수량보다 크다.
  3. 시스템은 입력을 차단한다.
  4. 선행 공정 미등록 실적 또는 공정 인계수량을 확인하도록 안내한다.

EX-06 품질검사 불합격

  1. 검사자가 불합격 결과를 확정한다.
  2. 시스템은 대상 생산 LOT를 보류 또는 격리한다.
  3. 후속 공정 투입 가능수량에서 제외한다.
  4. 창고 출고와 출하를 차단한다.
  5. 부적합 처리결정 대기상태로 전환한다.

EX-07 생산실적 오입력 정정

  1. 작업자가 잘못된 생산실적을 발견한다.
  2. 정정 요청을 등록한다.
  3. 시스템은 생산 LOT, 후속 공정, 재고, ERP 반영 여부를 확인한다.
  4. 후속처리가 없으면 승인 후 정정한다.
  5. 후속처리가 있으면 관련 업무의 역처리 또는 보정 이벤트를 생성한다.
  6. 기존 실적은 삭제하지 않고 정정이력을 보존한다.

EX-08 생산계획 변경

  1. 생산관리자가 확정된 생산계획을 변경한다.
  2. 시스템은 연결된 작업지시 상태를 확인한다.
  3. 미발행 작업지시는 취소 후 재생성한다.
  4. 작업중 작업지시는 기존 생산분을 유지한다.
  5. 잔여수량에 대해 신규 작업지시를 생성한다.
  6. 완료·마감 작업지시는 직접 변경하지 않는다.

EX-09 네트워크 장애 중 실적입력

  1. 작업자가 작업지시 또는 생산실적을 입력한다.
  2. 단말기가 서버 연결 실패를 감지한다.
  3. 허용된 업무이면 이벤트를 로컬에 임시 저장한다.
  4. 화면에 오프라인 저장 상태를 표시한다.
  5. 네트워크 복구 후 서버로 이벤트를 전송한다.
  6. 서버는 중복, 수량, 상태, 시간순서를 재검증한다.
  7. 충돌이 없으면 정상 반영한다.
  8. 충돌이 있으면 통합 예외업무 목록으로 이동한다.

EX-10 단말기 허용 공정 불일치

  1. 작업자가 작업지시 바코드를 스캔한다.
  2. 시스템은 현재 단말기에 허용되지 않은 공정임을 확인한다.
  3. 작업지시 화면 진입을 차단한다.
  4. 허용된 단말기의 위치 또는 담당자를 안내한다.
