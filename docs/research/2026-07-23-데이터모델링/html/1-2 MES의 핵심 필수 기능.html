MES의 핵심 필수 기능

도입 범위에 반드시 포함되어야 하는 기능군과 차기 확장 후보

MES의 핵심 필수 기능은 크게 5개로 보는 것이 가장 적절합니다.

1. 기준정보 관리

모든 MES 기능의 기준이 되는 마스터 데이터를 관리합니다.

  • 품목·자재·반제품·완제품
  • 공정과 라우팅
  • 설비·금형
  • 사업부·공장·창고·로케이션
  • 거래처·작업자
  • 불량 유형·검사항목
  • 단위, 포장수량, 표준 Cycle Time

기준정보가 불완전하면 작업지시, 생산실적, 재고, 추적성이 모두 흔들립니다.

2. 작업지시 및 생산 실행

무엇을, 언제, 어디에서, 얼마나 생산할지 지시하고 실제 작업을 실행하는 기능입니다.

주요 기능은 다음과 같습니다.

  • ERP 생산오더 또는 MES 작업지시 등록
  • 작업지시 배정
  • 작업 시작·중지·재개·종료
  • 설비·금형·작업자 지정
  • 계획수량, 생산수량, 잔량 관리
  • 공정별 작업상태 관리
  • 부분 생산실적 등록
  • 작업지시 초과생산·미달·취소 처리
  • 비가동 및 작업중단 사유 기록

대표적인 상태는 다음과 같습니다.

대기 → 준비 → 생산중 → 일시중지 → 생산완료 → 마감

단순히 생산수량을 입력하는 기능이 아니라, 현장의 작업 상태를 통제하는 기능이어야 합니다.

3. 자재 투입 및 재고·공정재 관리

생산에 어떤 자재가 투입되었는지 관리하고, 자재와 생산품의 수량 변화를 연결합니다.

  • 자재 입고 및 내부 LOT 생성
  • 창고·로케이션별 재고 관리
  • 생산라인 자재 출고
  • 자재 LOT 스캔 및 투입
  • 투입수량·사용수량·잔량 관리
  • 자재 교체와 Running Change
  • 잔량 반납·재사용
  • 공정재·반제품·완제품 이동
  • 부분 생산품 창고 입고
  • 재고 이동이력 관리
  • 가용·보류·격리·불량 재고 구분

예를 들어 10,000개 작업지시 중 5,000개가 먼저 완성되면 다음 처리가 가능해야 합니다.

5,000개 생산실적 등록
→ 생산 LOT 생성
→ 완제품 창고 이동
→ 나머지 5,000개 계속 생산

생산 완료와 작업지시 완료를 반드시 같은 시점으로 처리할 필요는 없습니다.

4. 생산실적 및 품질관리

실제로 생산된 결과와 검사 결과를 관리합니다.

생산실적

  • 양품수량
  • 불량수량
  • 생산 시작·종료시간
  • 작업자
  • 설비
  • 금형
  • 교대조
  • Cycle Time
  • 생산 LOT
  • 실적 수정·취소 이력

품질관리

  • 수입검사
  • 공정검사
  • 초품검사
  • 완제품검사
  • 샘플검사·전수검사
  • OK·NG·보류·특채 판정
  • 불량유형 및 원인
  • 재작업·폐기·선별
  • 부분 합격·부분 불합격

특히 생산실적은 단순 누적수량이 아니라 다음 관계를 보존해야 합니다.

어떤 작업지시에서
어떤 자재 LOT를 사용하여
어떤 설비와 금형으로
누가 생산했고
얼마가 양품·불량으로 발생했는가

5. LOT 추적성

MES의 가장 핵심적인 목적 중 하나입니다.

정방향 추적

원자재에서 어떤 제품이 만들어졌는지를 확인합니다.

공급사 LOT
→ 내부 자재 LOT
→ 자재 투입
→ 작업지시
→ 생산실적
→ 완제품 LOT
→ 출하

역방향 추적

출하된 제품에서 사용한 자재를 역으로 조회합니다.

출하 바코드
→ 완제품 LOT
→ 생산실적
→ 작업지시
→ 투입 자재 LOT
→ 공급사 LOT
→ 공급업체

다음 정보를 빠르게 조회할 수 있어야 합니다.

  • 특정 자재 LOT가 사용된 제품
  • 특정 완제품 LOT에 투입된 자재
  • 작업자·설비·금형·공정조건
  • 검사결과와 불량이력
  • 출하처와 출하일자
  • 문제가 발생한 LOT의 영향 범위

필수 공통 지원 기능

앞의 5개 핵심 업무기능을 운영하려면 다음 기능도 반드시 필요합니다.

사용자·권한 관리

  • 부서별 권한
  • 관리자·현장작업자·품질·자재·생산 권한
  • 조회·등록·수정·마감 권한 분리
  • 사업부·공장별 접근 제한

상태 및 마감 관리

  • 작업지시 상태
  • LOT 상태
  • 검사 상태
  • 재고 상태
  • 업무 마감
  • 마감 후 수정 승인

이력 및 감사 로그

  • 누가
  • 언제
  • 어떤 값을
  • 변경 전 값에서
  • 변경 후 값으로 바꾸었는지

MES에서는 데이터를 삭제하기보다 취소·무효화하고 이력을 남기는 방식이 적절합니다.

바코드·라벨 관리

  • 자재 LOT 라벨
  • 생산 LOT 라벨
  • 잔량 라벨
  • 완제품 라벨
  • 바코드 스캔
  • 재발행 이력
  • 중복 발행 방지

ERP 연동

  • 품목·거래처·구매발주 수신
  • 생산오더 수신
  • 입고·생산·불량·출고 실적 전송
  • 인터페이스 실패 재처리
  • ERP와 MES 데이터 책임 구분

현재 고객사 기준 최소 MES 구성

현재 진행 중인 사출·조립 MES라면 MVP는 다음 순서가 적절합니다.

우선순위필수 기능핵심 목적
1기준정보 관리전체 시스템 기준 확립
2작업지시·생산실행현장 작업 통제
3자재 LOT·투입·재고이동자재 사용 이력 확보
4생산실적·불량·검사생산 결과와 품질 기록
5LOT 추적성원자재부터 출하까지 추적

그다음 단계에서 확장할 기능은 다음과 같습니다.

  • 생산계획 및 CAPA
  • 설비 가동률·OEE
  • 금형 수명·누적 Shot
  • 예방보전
  • Andon
  • SPC
  • 공정조건 자동수집
  • 고급 대시보드
  • AI 생산계획 최적화

핵심 정리

MES의 필수 기능은 단순히 생산수량을 입력하는 것이 아닙니다.

작업지시
→ 자재 LOT 투입
→ 생산 실행
→ 양품·불량 실적
→ 생산 LOT 생성
→ 창고 이동
→ 출하
→ 전체 이력 추적

이 흐름이 하나의 데이터 체계로 연결되어야 합니다.

현재 프로젝트에서는 작업지시, 자재투입, 생산실적, 품질관리, LOT 추적성을 MES 1차 구축 범위의 핵심 5대 기능으로 정의하는 것이 가장 적절합니다.
