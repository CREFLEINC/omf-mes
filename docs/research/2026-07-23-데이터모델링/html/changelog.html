변경 이력

v3 — ERPNext 벤치마킹 반영

기준: ERPNext(frappe/erpnext) manufacturing·stock·subcontracting 모듈 doctype 스키마와 v2 설계를 대조 검토한 뒤, 사용자가 선택한 7개 항목을 반영했다. v2 원본은 v2/에 유지.

  • 물리 SQL: PostgreSQL 16에서 전체 DDL 실행 검증 (에러 0), 시드 14+4건 적재 확인, uq_bom_default 부분 유니크 동작 확인
  • 테이블 수: 126 → 127 (신규 1: putaway_rule)

v2 변경 이력 — DB 설계 검토 반영

기준: 요구사항 문서(1-1 ~ 2-7) 대비 설계 문서(3-1/3-2/3-3, 물리 SQL) 검토 결과를 위험도 높은 순서로 반영했다. 원본은 base-docs/에 유지하고 본 디렉터리는 사본이다.

  • 물리 SQL: PostgreSQL 16 컨테이너에서 전체 DDL 실행 검증 완료 (에러 0)
  • 신규 무결성 트리거 7종 스모크 테스트 통과 (음수재고 차단/허용, LOT 순환, 원장 불변, header 상태 전이, 분할 합계, 마감 차단)
  • 테이블 수: 101 → 126 (신규 25)
