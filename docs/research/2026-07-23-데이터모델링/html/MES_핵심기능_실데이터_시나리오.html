ERP → MES 이 단계에서 수신하는 것

  • 없음 — 현장 실행에 ERP는 관여하지 않습니다
  • 앞 단계에서 받은 품목 · 사원 기준정보만 참조

MES 이 단계에서 생성하는 것

  • 작업 세션 production.work_session — 공정별로 별도 세션
  • 세션 이벤트 work_session_event — 시작·중지·재개·종료, 비가동의 원천
  • 생산실적 production.production_result — 공정별 · 부분 실적 누적
  • 공정 간 인계 production.operation_handover — 공정재 이동

⚠️ 인터페이스 공백 — 실적을 ERP로 되돌릴 경로가 없음

고객 자료의 인터페이스는 ERP → MES 단방향 송신 8개 테이블(T_IF_SND_* · T_ERP_*_DOWN)이 전부입니다. 이 단계에서 만들어지는 생산실적·자재 실사용량을 ERP로 회신하는 인터페이스가 존재하지 않습니다. ERP가 원가와 재고를 마감하려면 MES → ERP 역방향 인터페이스를 신규 정의해야 하며, 최소 대상은 ① 공정별 생산실적(양품·불량) ② 자재 실사용량 ③ 완제품 입고 ④ 재고 조정입니다. 공정이 4개면 회신 단위를 공정별로 할지 오더 단위로 할지도 함께 정해야 합니다.

WITH bom AS (
  -- 1레벨: 조회 대상 품목의 직접 자재
  SELECT CAST(b.CHILD_ITEM_CD AS varchar(50)) ch, 1 lv,
         CAST(b.CHILD_ITEM_QTY/NULLIF(b.PRNT_ITEM_QTY,0) AS decimal(30,8)) qty,
         CAST('>'+b.CHILD_ITEM_CD+'>' AS varchar(900)) path
  FROM T_IF_SND_BOM_INFOR_KO324 b
  WHERE b.PRNT_ITEM_CD = 'AAR5WY1'          -- ← 조회할 품목
  UNION ALL
  -- 재귀: 자품목을 다시 모품목으로 삼아 한 단계씩 내려감
  SELECT CAST(c.CHILD_ITEM_CD AS varchar(50)), p.lv+1,
         CAST(p.qty*c.CHILD_ITEM_QTY/NULLIF(c.PRNT_ITEM_QTY,0) AS decimal(30,8)),
         CAST(p.path+c.CHILD_ITEM_CD+'>' AS varchar(900))
  FROM bom p
  JOIN T_IF_SND_BOM_INFOR_KO324 c ON c.PRNT_ITEM_CD = p.ch
                                -- ⚠️ PLANT_CD는 조인 조건에 넣지 말 것 (함정 ②)
  WHERE p.lv < 12
    AND p.path NOT LIKE '%>'+c.CHILD_ITEM_CD+'>%'   -- 순환 방지
)
SELECT b.ch AS 자재코드,
       MAX(i.ITEM_NM) AS 품명,
       MAX(i.ITEM_ACCT_CD) AS 계정,
       MIN(b.lv) AS 최소레벨,
       SUM(b.qty) AS 총소요량,        -- 단계마다 곱해 내려온 누적 소요
       MAX(i.BASIC_UNIT) AS 기본단위   -- BOM 라인 단위와 다를 수 있음 (함정 ④)
FROM bom b
LEFT JOIN T_IF_SND_ITEM_INFOR_KO324 i ON i.ITEM_CD = b.ch
-- leaf만: 더 이상 모품목이 아닌 것 = 실제 구매 자재
WHERE NOT EXISTS (SELECT 1 FROM T_IF_SND_BOM_INFOR_KO324 x
                   WHERE x.PRNT_ITEM_CD = b.ch)
GROUP BY b.ch
ORDER BY SUM(b.qty) DESC
OPTION (MAXRECURSION 0);

두 가지를 구분해야 합니다. ① 동일 품목의 LOT 교체는 재고가 소진되어 다음 LOT을 이어 쓰는 일상적 상황이고, ② Running Change는 생산 도중 자재 사양 자체가 바뀌는 변경입니다. 후자는 어느 시점부터 어느 자재가 들어갔는지를 남겨야 추적성이 성립합니다.
