2. 기능 요구사항 · 2-2 자재투입

자재투입

출고·현장 인수·투입·정정·Running Change·반납

MES 핵심 기능 요구사항 ② 자재 투입 관리

1. 적용 목적

자재 투입 관리 기능은 생산에 사용된 자재의 품목, LOT, 수량, 투입 공정, 작업지시, 작업자 및 투입 시점을 기록하여 다음 목적을 달성하기 위한 기능이다.

  • 올바른 자재의 투입 여부 확인
  • 자재 LOT와 생산 LOT 간 추적성 확보
  • 작업지시별 실제 자재 사용량 파악
  • 자재 교체 및 Running Change 이력 관리
  • 투입 후 잔량의 반납·보관·재사용 관리
  • 재고수량과 생산실적 간 정합성 확보

2. 용어 정의

2.1 소요자재

작업지시를 수행하기 위해 필요한 자재로서 BOM 또는 공정별 자재 구성에 정의된 자재이다.

2.2 투입자재

작업지시에 실제로 투입된 자재이다.

소요자재와 투입자재는 다음과 같이 다를 수 있다.

  • BOM의 표준 자재와 실제 투입자재가 동일한 경우
  • 승인된 대체자재가 투입된 경우
  • 여러 자재 LOT가 나누어 투입된 경우
  • 자재가 과다 또는 과소 투입된 경우

2.3 자재 LOT

동일한 제조·입고·품질 조건을 갖는 자재의 추적 단위이다.

2.4 투입수량

작업지시에 사용하기 위해 생산현장에 투입 등록한 수량이다.

2.5 실제 사용수량

투입수량 중 실제 생산에 소비된 수량이다.

2.6 자재잔량

투입수량 중 생산에 사용되지 않고 남은 수량이다.

자재잔량
= 투입수량
- 실제 사용수량
- 불량·폐기수량

2.7 Running Change

생산 진행 중 기존 자재에서 다른 자재 LOT 또는 변경 자재로 전환하는 것이다.

3. 기본 처리 구조

작업지시
   ↓
공정별 소요자재 조회
   ↓
자재 LOT 스캔 또는 자재 선택
   ↓
품목·LOT·상태·수량 검증
   ↓
자재투입 등록
   ↓
생산실적 등록
   ↓
실제 사용수량 및 잔량 확정
   ↓
생산 LOT와 투입 자재 LOT 연결

하나의 작업지시에는 여러 자재 LOT를 투입할 수 있어야 한다.

작업지시 1건
├─ Resin LOT A
├─ Resin LOT B
├─ Insert LOT C
└─ 부자재 LOT D

하나의 자재 LOT를 여러 작업지시에 나누어 투입할 수도 있어야 한다.

자재 LOT A
├─ 작업지시 WO-001에 100kg
├─ 작업지시 WO-002에 70kg
└─ 잔량 30kg

4. 자재 관리 수준

자재별로 MES 관리 수준을 설정할 수 있어야 한다.

관리 수준적용 대상처리 방식
LOT 추적원재료, 금속 Insert, 핵심부품자재 LOT 스캔 및 실제 수량 등록
수량 관리일반 부품, 포장재품목과 수량만 등록
자동 차감반복 투입되는 일반 부자재BOM과 생산실적 기준 자동 소비
관리 제외소모품, 공구성 자재MES 투입 관리 제외

자재의 중요도와 고객 추적성 요구에 따라 품목별 관리 수준을 변경할 수 있어야 한다.

5. 기능적 요구사항

FR-MI-001 작업지시별 소요자재 조회

시스템은 작업지시의 품목, 공정, 라우팅 버전 및 BOM을 기준으로 해당 작업지시에 필요한 소요자재 목록을 조회할 수 있어야 한다.

소요자재 목록에는 최소한 다음 정보가 포함되어야 한다.

  • 자재코드
  • 자재명
  • 자재 유형
  • 표준 소요량
  • 단위
  • LOT 추적 여부
  • 필수 투입 여부
  • 허용 대체자재
  • 투입 등록 대상 공정
  • 현재 투입수량
  • 부족수량

FR-MI-002 공정별 소요자재 관리

시스템은 동일 제품에 사용되는 자재라도 어느 공정에서 투입되는지를 구분할 수 있어야 한다.

예시:

사출 공정
- Resin
- Color Master Batch
- Metal Insert

조립 공정
- 사출 반제품
- 볼트
- Gasket
- Harness

자재는 BOM에만 연결하지 않고 필요에 따라 라우팅 공정과 연결할 수 있어야 한다.

FR-MI-003 MES 미관리 공정 투입자재 처리

MES 미관리 공정에서 실제 자재가 투입되는 경우에도 추적이 필요한 자재는 MES에 등록할 수 있어야 한다.

MES 미관리 공정의 자재에는 별도의 투입 등록 담당 공정을 지정해야 한다.

예시:

실제 투입 공정: 융착 공정
MES 관리 여부: 미관리
투입 등록 담당 공정: 조립 작업지시

시스템은 다음 정보를 구분하여 저장해야 한다.

  • 실제 자재가 사용되는 공정
  • MES에서 투입을 등록하는 관리 대상 공정
  • 해당 공정의 작업지시

이를 통해 단말기가 없는 공정의 자재도 인접한 관리 대상 공정에서 등록할 수 있어야 한다.

FR-MI-004 자재투입 등록 가능 상태 검증

자재투입은 다음 상태의 작업지시에 대해서만 허용해야 한다.

  • 발행
  • 작업대기
  • 작업중
  • 일시중지 상태 중 투입 허용 정책이 적용된 경우

다음 상태에서는 일반 사용자의 자재투입을 제한해야 한다.

  • 작성
  • 작업완료
  • 마감
  • 취소
  • 보류

관리자 권한으로 예외 투입하는 경우 사유를 기록해야 한다.

FR-MI-005 자재 LOT 바코드 스캔

LOT 추적 대상 자재는 자재 라벨의 바코드 또는 QR 코드를 스캔하여 투입할 수 있어야 한다.

스캔 시 시스템은 최소한 다음 정보를 조회해야 한다.

  • 자재 품목
  • 내부 자재 LOT
  • 공급사 LOT
  • 현재 재고수량
  • 현재 로케이션
  • 재고상태
  • 검사상태
  • 유효기간
  • 사용 가능 여부

FR-MI-006 작업지시 바코드와 자재 바코드 연속 처리

공용 단말기에서는 다음 순서로 작업지시와 자재를 연결할 수 있어야 한다.

작업자 인증
→ 작업지시 바코드 스캔
→ 대상 공정 확인
→ 자재 LOT 바코드 스캔
→ 자재 검증
→ 투입수량 입력
→ 저장

작업지시를 선택하지 않은 상태에서 자재 LOT를 스캔한 경우 시스템은 대상 작업지시 선택을 요구해야 한다.

FR-MI-007 자재 적합성 검증

자재 투입 시 시스템은 스캔된 자재가 작업지시에서 사용할 수 있는 자재인지 검증해야 한다.

검증 항목은 다음과 같다.

  • BOM 또는 공정별 소요자재에 포함되는지
  • 품목이 일치하는지
  • 승인된 대체자재인지
  • 해당 공정에서 사용할 수 있는지
  • 재고상태가 가용인지
  • 품질검사가 합격 또는 특채 상태인지
  • 유효기간이 지나지 않았는지
  • 보류·격리·불량 LOT가 아닌지
  • 해당 사업부 또는 공장에서 사용할 수 있는지

부적합한 자재는 기본적으로 투입을 차단해야 한다.

FR-MI-008 자재 LOT 상태별 투입 통제

시스템은 다음 재고상태의 자재 투입을 통제해야 한다.

재고상태기본 처리
가용투입 허용
검사대기투입 차단
보류투입 차단
격리투입 차단
불량투입 차단
특채승인조건 확인 후 허용
유효기간 경과투입 차단 또는 관리자 승인
소진투입 차단

FR-MI-009 투입수량 등록

자재 투입 시 실제 투입수량을 등록할 수 있어야 한다.

투입수량에는 다음 검증을 적용해야 한다.

  • 0보다 큰 수량인지
  • 현재 가용재고를 초과하지 않는지
  • 소수점 허용 기준에 맞는지
  • 품목의 기본단위와 일치하는지
  • 포장단위 또는 환산단위가 유효한지

FR-MI-010 단위 및 환산 관리

자재 입고단위, 재고단위, 생산 투입단위가 다른 경우 단위 환산을 지원해야 한다.

예시:

입고단위: BAG
1 BAG = 25kg

재고단위: kg
투입단위: kg

또는:

입고단위: BOX
1 BOX = 1,000개

투입단위: 개

환산기준은 품목 기준정보에서 관리하고, 투입 이력에는 입력단위와 환산된 재고단위를 모두 저장해야 한다.

FR-MI-011 포장단위 전체 투입 및 부분 투입

시스템은 다음 두 가지 방식을 지원해야 한다.

  • 포장단위 전체 투입
  • 포장 개봉 후 부분수량 투입

부분 투입 후 남은 수량은 동일 자재 LOT의 잔량으로 관리해야 한다.

예시:

원래 수량: 1,000개
투입수량: 600개
잔량: 400개

FR-MI-012 다중 자재 LOT 투입

하나의 작업지시에 동일 품목의 여러 자재 LOT를 투입할 수 있어야 한다.

예시:

작업지시 WO-001

Resin LOT R001: 80kg
Resin LOT R002: 30kg

시스템은 LOT별 투입 시작시점, 종료시점 및 투입수량을 구분하여 저장해야 한다.

FR-MI-013 자재 LOT 분할 사용

하나의 자재 LOT를 여러 작업지시 또는 여러 설비에 나누어 투입할 수 있어야 한다.

각 투입이 등록될 때마다 해당 자재 LOT의 가용수량을 차감해야 한다.

동일 자재 LOT의 투입수량 합계는 가용재고수량을 초과할 수 없어야 한다.

FR-MI-014 작업 시작 전 자재투입

공정별 운영정책에 따라 작업 시작 전에 자재투입을 등록할 수 있어야 한다.

예시:

전일 야간
→ 익일 생산에 사용할 자재 준비 및 투입예정 등록

익일 작업 시작
→ 실제 투입 확인

필요한 경우 다음 상태를 구분할 수 있어야 한다.

  • 투입예정
  • 현장출고
  • 실제투입
  • 사용완료
  • 잔량반납

FR-MI-015 생산 중 추가 자재투입

작업 진행 중 자재가 부족하거나 자재 LOT가 변경되는 경우 추가 투입할 수 있어야 한다.

추가 투입 시 기존 투입자재 이력을 삭제하거나 덮어쓰지 않아야 한다.

1차 투입: Resin LOT A 50kg
2차 투입: Resin LOT B 40kg
3차 투입: Resin LOT C 20kg

FR-MI-016 사후 투입 등록

공용 단말기 부족 또는 현장 상황으로 실제 투입 후 MES에 사후 등록하는 것을 허용할 수 있어야 한다.

사후 투입 시 다음 정보를 구분하여 저장해야 한다.

  • 실제 투입일시
  • MES 입력일시
  • 실제 투입 작업자
  • MES 입력자
  • 지연입력 사유

허용시간을 초과한 사후 등록은 관리자 승인 대상으로 설정할 수 있어야 한다.

FR-MI-017 공용 단말기 자재투입 지원

단말기 한 대에서 여러 공정의 자재투입을 처리할 수 있어야 한다.

단말기에서 작업지시를 선택하거나 스캔하면 해당 작업지시의 대상 공정과 소요자재 목록이 자동으로 결정되어야 한다.

단말기별로 다음 권한을 설정할 수 있어야 한다.

  • 처리 가능 공정
  • 자재투입 등록
  • 자재투입 취소
  • 잔량반납
  • 라벨 출력

FR-MI-018 단말기 허용 공정 검증

자재투입 시 시스템은 해당 단말기에서 대상 작업지시의 공정을 처리할 수 있는지 검증해야 한다.

허용되지 않은 공정의 자재투입을 시도하면 입력을 차단해야 한다.

FR-MI-019 FIFO 및 선입선출 안내

시스템은 동일 품목의 여러 자재 LOT가 존재하는 경우 입고일자, 제조일자 또는 유효기간을 기준으로 권장 투입 LOT를 안내할 수 있어야 한다.

FIFO 위반 시 다음 중 하나의 정책을 적용할 수 있어야 한다.

  • 경고만 표시
  • 사유 입력 후 허용
  • 관리자 승인 후 허용
  • 투입 차단

현재 고객사가 FIFO를 강제하지 않는 경우에도 향후 적용을 위해 정책 설정이 가능해야 한다.

FR-MI-020 대체자재 투입

BOM에 정의된 기본 자재 대신 승인된 대체자재를 투입할 수 있어야 한다.

대체자재 투입 시 다음 정보를 기록해야 한다.

  • 원래 자재
  • 대체자재
  • 대체사유
  • 승인자
  • 승인일시
  • 적용 작업지시
  • 적용수량

승인되지 않은 대체자재는 투입할 수 없어야 한다.

FR-MI-021 Running Change 관리

생산 중 자재 품목, 사양 또는 자재 LOT가 변경되는 경우 변경시점을 기록할 수 있어야 한다.

Running Change 이력에는 다음 정보가 포함되어야 한다.

  • 작업지시
  • 변경 전 자재 품목 및 LOT
  • 변경 후 자재 품목 및 LOT
  • 변경수량
  • 변경 적용시각
  • 적용 생산수량 또는 생산 LOT
  • 변경사유
  • 승인자
  • 처리자

FR-MI-022 LOT 전환시점 관리

동일 작업지시에서 자재 LOT가 변경된 경우 각 LOT가 어느 생산구간에 사용되었는지 구분할 수 있어야 한다.

구분방식은 다음 중 하나 이상을 지원할 수 있어야 한다.

  • 투입시각 기준
  • 생산실적 순번 기준
  • 생산 LOT 기준
  • 작업자가 지정한 전환수량 기준

예시:

제품 생산 LOT P001

1~2,000개: 자재 LOT R001
2,001~5,000개: 자재 LOT R002

FR-MI-023 자재투입량 초과 경고

실제 투입수량이 BOM 표준소요량 또는 허용범위를 초과하는 경우 경고해야 한다.

기본 비교식은 다음과 같다.

예상소요량
= 생산계획수량 × 단위당 표준소요량

초과 투입 정책은 다음과 같이 설정할 수 있어야 한다.

  • 경고
  • 사유 입력 후 허용
  • 관리자 승인 후 허용
  • 허용범위 초과 시 차단

FR-MI-024 자재투입 부족 확인

작업 시작 또는 작업완료 시 필수 자재 투입수량이 부족한 경우 시스템은 경고해야 한다.

필수 LOT 추적 자재가 등록되지 않은 경우 작업완료 또는 마감을 차단할 수 있어야 한다.

FR-MI-025 가용재고 및 음수재고 통제

자재 투입수량이 현재 가용재고를 초과하는 경우 기본적으로 투입을 차단해야 한다.

음수재고 허용 여부는 공장 또는 품목별 정책으로 관리할 수 있어야 한다.

음수재고를 허용하는 경우 다음 정보를 필수로 기록해야 한다.

  • 부족수량
  • 발생사유
  • 승인자
  • 사후 입고 또는 재고조정 대상 여부

FR-MI-026 자동 차감

LOT 추적이 필요하지 않은 일반 자재는 생산실적과 BOM을 기준으로 자동 차감할 수 있어야 한다.

자동 사용수량
= 생산실적수량 × 단위당 표준소요량

자동 차감 대상 자재는 품목별로 설정해야 한다.

자동 차감 결과는 사용자가 조회하고 권한에 따라 조정할 수 있어야 한다.

FR-MI-027 실제 사용수량 확정

투입수량과 실제 사용수량이 다른 경우 작업완료 시 실제 사용수량을 확정할 수 있어야 한다.

예시:

투입수량: 100kg
실제 사용수량: 92kg
잔량: 7kg
폐기: 1kg

다음 수량 관계가 성립해야 한다.

투입수량
= 실제 사용수량
+ 잔량
+ 폐기수량
+ 조정수량

FR-MI-028 자재잔량 등록

작업 종료 또는 자재 교체 시 남은 자재수량을 등록할 수 있어야 한다.

잔량 등록 시 다음 정보를 기록해야 한다.

  • 자재 품목
  • 자재 LOT
  • 잔량
  • 단위
  • 발생 작업지시
  • 발생 공정
  • 발생 설비
  • 잔량 상태
  • 보관 위치
  • 처리자
  • 발생일시

FR-MI-029 자재잔량 처리

자재잔량은 다음 방식으로 처리할 수 있어야 한다.

  • 동일 작업지시에서 계속 사용
  • 후속 작업지시에서 재사용
  • 생산현장 보관
  • 자재창고 반납
  • 다른 설비로 이동
  • 품질확인 대기
  • 폐기
  • 재고조정

처리방법에 따라 재고수량과 로케이션을 갱신해야 한다.

FR-MI-030 잔량 LOT 유지 및 잔량 라벨 발행

잔량이 발생한 경우 원래 자재 LOT를 유지하는 것을 원칙으로 한다.

필요한 경우 다음 정보가 포함된 잔량 라벨을 발행할 수 있어야 한다.

  • 자재코드
  • 자재명
  • 원 자재 LOT
  • 잔량
  • 단위
  • 개봉일시
  • 발생 작업지시
  • 보관위치
  • 재사용 가능 여부
  • 바코드

잔량을 별도 관리 단위로 분리하는 경우 원본 LOT와의 관계를 보존해야 한다.

FR-MI-031 잔량 재사용

이전 작업에서 발생한 자재잔량을 신규 작업지시에 재투입할 수 있어야 한다.

잔량 재사용 시 다음을 검증해야 한다.

  • 동일 자재인지
  • 자재 LOT가 유효한지
  • 잔량이 실제로 존재하는지
  • 보관상태가 적합한지
  • 재사용 가능기간 이내인지
  • 품질확인이 필요한지
  • 다른 작업지시에 이미 투입되지 않았는지

FR-MI-032 자재 폐기 및 손실 등록

투입된 자재 중 생산에 사용되지 못하고 폐기되거나 손실된 수량을 등록할 수 있어야 한다.

폐기 및 손실 사유 예시는 다음과 같다.

  • 퍼징
  • 자재 오염
  • 설비 청소
  • 자재 교체
  • 작업 중 유실
  • 품질불량
  • 유효기간 경과
  • 기타

폐기수량은 정상 사용수량과 구분하여 재고에서 차감해야 한다.

FR-MI-033 투입자재 취소

잘못 등록한 자재투입을 취소할 수 있어야 한다.

취소 시 다음을 검증해야 한다.

  • 해당 자재가 생산실적 또는 생산 LOT에 이미 연결되었는지
  • 자재잔량이나 폐기처리가 발생했는지
  • 작업지시가 마감되었는지
  • 취소 후 재고수량이 정상적으로 복원되는지

생산 LOT에 이미 연결된 투입은 단순 취소할 수 없고 승인된 정정 절차를 사용해야 한다.

FR-MI-034 투입자재 정정

투입수량, 실제 투입일시 또는 자재 LOT를 잘못 입력한 경우 정정할 수 있어야 한다.

정정 시 다음 정보를 보존해야 한다.

  • 정정 전 값
  • 정정 후 값
  • 정정사유
  • 요청자
  • 승인자
  • 정정일시

기존 이력을 삭제하거나 덮어쓰지 않아야 한다.

FR-MI-035 작업지시 마감 연계

작업지시 마감 시 다음 자재 관련 항목을 검증해야 한다.

  • 필수 자재투입 등록 여부
  • LOT 추적 대상 자재 등록 여부
  • 실제 사용수량 확정 여부
  • 잔량 처리 여부
  • 폐기수량 처리 여부
  • 미확정 자동 차감 여부
  • 음수재고 또는 부족재고 발생 여부

필수 항목이 처리되지 않은 경우 마감을 차단할 수 있어야 한다.

FR-MI-036 생산실적 연계

자재투입 정보는 해당 작업지시의 생산실적과 연결되어야 한다.

다음 정보를 조회할 수 있어야 한다.

작업지시
→ 투입 자재
→ 생산실적
→ 생산 LOT

한 작업지시에 생산실적이 여러 번 등록되는 경우에도 각 자재 LOT가 사용된 생산구간을 식별할 수 있어야 한다.

FR-MI-037 생산 LOT 연계

추적 대상 자재 LOT는 해당 자재가 사용된 반제품 또는 완제품 생산 LOT와 연결되어야 한다.

기본 추적 관계는 다음과 같다.

자재 LOT
→ 자재투입
→ 공정 작업지시
→ 생산실적
→ 생산 LOT

하나의 생산 LOT에 여러 자재 LOT가 연결될 수 있어야 한다.

하나의 자재 LOT가 여러 생산 LOT에 사용될 수도 있어야 한다.

FR-MI-038 자재투입 현황 조회

사용자는 다음 조건으로 자재투입 이력을 조회할 수 있어야 한다.

  • 작업지시번호
  • 생산오더번호
  • 생산계획번호
  • 품목
  • 공정
  • 자재 품목
  • 내부 자재 LOT
  • 공급사 LOT
  • 설비
  • 금형
  • 작업자
  • 투입일자
  • 사용 단말기
  • 투입상태
  • 잔량처리 상태

FR-MI-039 작업지시별 자재현황 조회

작업지시 상세화면에서는 다음 내용을 조회할 수 있어야 한다.

  • 표준 소요자재
  • 표준 소요량
  • 실제 투입자재
  • 투입 자재 LOT
  • 누적 투입수량
  • 실제 사용수량
  • 잔량
  • 폐기수량
  • 대체자재
  • LOT 변경이력
  • 미투입 필수자재
  • 예상 대비 투입차이

FR-MI-040 자재 LOT 사용처 조회

특정 자재 LOT가 어느 작업지시와 생산 LOT에 사용되었는지 조회할 수 있어야 한다.

자재 LOT R001
├─ 작업지시 WO-001: 50kg
│  ├─ 생산 LOT P001
│  └─ 생산 LOT P002
└─ 작업지시 WO-002: 30kg
   └─ 생산 LOT P003

FR-MI-041 자재투입 이력 관리

시스템은 다음 이벤트를 시간순으로 기록해야 한다.

  • 투입예정 등록
  • 자재 현장출고
  • 실제 투입
  • 추가 투입
  • 자재 LOT 전환
  • Running Change
  • 대체자재 투입
  • 투입수량 변경
  • 실제 사용수량 확정
  • 잔량 발생
  • 잔량 반납

  • 폐기
  • 투입 취소
  • 투입 정정
  • 관리자 승인

각 이력에는 최소한 다음 정보가 포함되어야 한다.

6. 비기능 요구사항

NFR-MI-001 응답성

자재 LOT 바코드 스캔 후 자재정보와 검증결과는 정상적인 사내 네트워크 환경에서 2초 이내에 표시되어야 한다.

자재투입 저장 요청은 일반적인 경우 2초 이내에 처리되어야 한다.

처리 중 사용자가 동일 요청을 반복하지 않도록 진행상태를 표시해야 한다.

NFR-MI-002 중복 등록 방지

동일한 자재투입 요청이 통신 지연, 버튼 중복 클릭 또는 재전송으로 여러 번 전달되더라도 한 번만 처리되어야 한다.

시스템은 다음 방법을 적용해야 한다.

  • 요청 식별키
  • 중복 스캔 방지
  • 데이터베이스 트랜잭션
  • 멱등성 처리
  • 처리완료 여부 확인

NFR-MI-003 동시성 통제

동일한 자재 LOT를 여러 단말기 또는 여러 작업지시에서 동시에 투입하는 경우 가용재고수량을 정확하게 통제해야 한다.

동시 투입으로 인해 다음 상황이 발생해서는 안 된다.

  • 동일 재고의 중복 차감
  • 가용수량 초과 투입
  • 잘못된 잔량 계산
  • 음수재고 발생
  • 동일 잔량의 중복 사용

NFR-MI-004 데이터 정합성

자재투입 등록, 재고차감, 작업지시 연결 및 자재이력 생성은 하나의 트랜잭션으로 처리해야 한다.

일부 처리만 성공하여 다음과 같은 상태가 발생해서는 안 된다.

  • 자재투입은 등록되었지만 재고가 차감되지 않음
  • 재고는 차감되었지만 투입이력은 없음
  • 잔량반납은 등록되었지만 재고가 복원되지 않음
  • 투입취소 후 생산 LOT 연결이 남아 있음

NFR-MI-005 추적성 보장

LOT 추적 대상 자재는 다음 정보가 끊김 없이 연결되어야 한다.

공급사 LOT
→ 내부 자재 LOT
→ 재고
→ 자재투입
→ 작업지시
→ 생산실적
→ 생산 LOT
→ 출하

중간 데이터가 수정되거나 취소되더라도 과거 연결관계와 변경이력을 조회할 수 있어야 한다.

NFR-MI-006 감사 가능성

자재투입, 취소, 정정, 대체, 잔량 및 폐기 처리는 감사 가능한 이력으로 보존해야 한다.

이력에는 최소한 다음 정보가 포함되어야 한다.

  • 처리자
  • 실제 작업자
  • 처리 단말기
  • 처리일시
  • 실제 발생일시
  • 변경 전 값
  • 변경 후 값
  • 처리사유
  • 승인자

감사 이력은 일반 사용자가 수정하거나 삭제할 수 없어야 한다.

NFR-MI-007 권한 관리

역할에 따라 자재투입 기능을 제한해야 한다.

역할주요 권한
작업자투입 등록, 잔량 등록
현장 관리자투입 정정 요청, 대체자재 요청
자재 담당자현장출고, 반납, 재고이동
품질 담당자보류·특채 LOT 사용 승인
생산관리자초과투입 승인, 사후입력 승인
시스템 관리자정책 및 기준정보 설정

모든 권한 검증은 화면뿐 아니라 서버에서도 수행해야 한다.

NFR-MI-008 사용성

공용 단말기에서 자재투입 처리는 최소한의 조작으로 완료할 수 있어야 한다.

권장 흐름은 다음과 같다.

작업지시 스캔
→ 자재 LOT 스캔
→ 수량 입력 또는 자동확인
→ 저장

화면에는 항상 다음 정보를 명확하게 표시해야 한다.

  • 현재 작업지시
  • 현재 공정
  • 생산품목
  • 스캔한 자재
  • 자재 LOT
  • 투입수량
  • 투입 가능 여부

품목 불일치, 보류 LOT, 수량 부족 등 오류는 명확한 원인과 조치방법을 표시해야 한다.

NFR-MI-009 장애 및 재처리

네트워크 또는 서버 장애가 발생한 경우 시스템은 저장 성공 여부를 명확하게 표시해야 한다.

처리 결과가 불확실한 경우 사용자가 다시 저장하기 전에 서버의 기존 처리 여부를 확인해야 한다.

장애 복구 후 실패한 ERP·재고 연계 건은 재처리할 수 있어야 한다.

NFR-MI-010 성능 및 처리용량

시스템은 다음 규모에서 자재투입 기능을 안정적으로 처리할 수 있어야 한다.

  • 현장 단말 1,000대 이하
  • 동시 사용자 300명 이상
  • 일 수만 건의 자재투입 이력
  • 다수 사업부·공장·창고 운영
  • 장기간 LOT 추적이력 보관

자재 LOT, 작업지시, 자재품목, 투입일자 등에 적절한 인덱스를 적용해야 한다.

NFR-MI-011 확장성

자재투입 모델은 다음 생산형태에서 공통으로 사용할 수 있어야 한다.

  • 사출
  • 자동조립
  • 수동조립
  • 검사
  • 포장
  • 외주공정
  • 재작업

품목별 차이는 프로그램 분기문이 아니라 기준정보와 정책 설정으로 처리해야 한다.

NFR-MI-012 유지보수성

다음 정책은 프로그램 소스 수정 없이 설정할 수 있어야 한다.

  • LOT 추적 대상 여부
  • 자동 차감 대상 여부
  • 필수 투입 여부
  • FIFO 통제 방식
  • 초과투입 허용범위
  • 사후입력 허용시간
  • 음수재고 허용 여부
  • 잔량 재사용 조건
  • 대체자재 승인정책
  • 작업완료 및 마감 검증조건

NFR-MI-013 시간 정확성

실제 투입일시와 MES 입력일시를 구분하여 저장해야 한다.

서버와 단말기의 시간 차이가 추적성에 영향을 미치지 않도록 서버 시간을 기준시간으로 사용해야 한다.

단말기 시간이 서버 시간과 크게 다른 경우 경고할 수 있어야 한다.

NFR-MI-014 데이터 보존

자재투입 및 LOT 추적이력은 고객사 품질보증기간, 제품수명 및 법적 보존기간을 고려하여 장기간 보존할 수 있어야 한다.

작업지시 또는 품목이 비활성화되어도 기존 자재투입 이력은 삭제되지 않아야 한다.

7. 핵심 업무 규칙

BR-MI-001

LOT 추적 대상 자재는 자재 LOT를 등록하지 않고 투입할 수 없다.

BR-MI-002

MES 미관리 공정에서 사용하는 추적 대상 자재는 지정된 MES 관리 대상 공정에서 투입 등록한다.

BR-MI-003

보류·격리·불량 상태의 자재 LOT는 일반 작업자가 투입할 수 없다.

BR-MI-004

자재투입수량은 해당 LOT의 가용재고수량을 초과할 수 없다.

BR-MI-005

하나의 작업지시에 동일 품목의 여러 자재 LOT를 투입할 수 있다.

BR-MI-006

하나의 자재 LOT를 여러 작업지시에 나누어 투입할 수 있다.

BR-MI-007

자재 LOT 전환과 Running Change 이력은 기존 투입이력을 덮어쓰지 않는다.

BR-MI-008

작업완료 시 투입수량, 사용수량, 잔량, 폐기수량 간 수량 정합성이 확인되어야 한다.

BR-MI-009

생산 LOT에 연결된 자재투입은 승인 없이 취소할 수 없다.

BR-MI-010

마감된 작업지시의 자재투입은 마감 취소 또는 별도 정정 승인 없이 변경할 수 없다.

BR-MI-011

자재 투입과 재고 차감은 동일한 트랜잭션으로 처리한다.

BR-MI-012

실제 투입일시와 MES 입력일시는 구분하여 보존한다.

8. 기본 자재 투입 흐름

작업지시 선택 또는 스캔
   ↓
공정별 소요자재 조회
   ↓
자재 LOT 스캔
   ↓
품목·LOT·상태·수량 검증
   ↓
투입수량 등록
   ↓
재고 차감
   ↓
생산 진행
   ↓
추가 투입 또는 LOT 변경
   ↓
실제 사용수량 확정
   ↓
잔량·폐기 처리
   ↓
생산 LOT 연결
   ↓
작업지시 마감
