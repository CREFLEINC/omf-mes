LOT 추적성

LOT 채번·계보·정역방향 추적·영향분석·증빙 발행

아래 요구사항은 앞서 정의한 작업지시·자재투입·생산실적·품질관리 구조를 전제로 합니다.

  • MES 관리 대상 공정별 작업지시를 생성한다.
  • MES 미관리 공정도 전체 라우팅에는 유지한다.
  • 자재 LOT는 작업지시의 자재투입과 연결한다.
  • 생산실적은 반제품·완제품 생산 LOT와 연결한다.
  • 품질판정에 따라 LOT의 사용 가능 여부를 통제한다.
  • 부분 생산, 복수 자재 LOT 투입, LOT 분할·병합을 지원한다.
  • 공급사 LOT부터 출하 LOT까지 정방향·역방향 추적이 가능해야 한다.

MES 핵심 기능 요구사항 ⑤ LOT 추적성

1. 기능 목적

LOT 추적성 기능은 자재의 입고부터 생산, 품질검사, 재고이동, 출하까지 발생하는 모든 LOT의 생성·변경·사용·이동 관계를 기록하고 조회하는 기능이다.

LOT 추적성은 다음 질문에 답할 수 있어야 한다.

  • 이 완제품을 생산할 때 어떤 자재 LOT를 사용했는가?
  • 특정 자재 LOT가 어떤 반제품·완제품에 사용되었는가?
  • 해당 제품은 어느 작업지시, 공정, 설비, 금형, 작업자가 생산했는가?
  • 품질문제가 발생한 LOT의 영향범위는 어디까지인가?
  • 해당 LOT가 어느 창고에 있으며 어느 고객에게 출하되었는가?
  • LOT가 분할·병합·재작업된 이후 현재 어떤 LOT로 존재하는가?

기본 추적 구조는 다음과 같다.

공급사 LOT
→ 내부 자재 LOT
→ 자재재고
→ 자재투입
→ 공정별 작업지시
→ 생산실적
→ 반제품·완제품 생산 LOT
→ 품질판정
→ 재고이동
→ 포장·출하 LOT
→ 고객 출하

2. 용어 정의

2.1 LOT

동일한 생산·입고·품질·추적 조건으로 관리되는 자재 또는 제품의 추적 단위이다.

LOT는 단순히 번호만 의미하지 않으며 다음 정보를 포함하는 관리단위이다.

  • 대상 품목
  • 수량
  • LOT 유형
  • 생성 근거
  • 생성일시
  • 품질상태
  • 재고상태
  • 보관위치
  • 상위·하위 LOT 관계
  • 작업지시 및 생산실적 관계

2.2 공급사 LOT

공급사가 부여한 자재의 원래 LOT 번호이다.

2.3 내부 자재 LOT

자재 입하·검사·입고 과정에서 MES가 생성하거나 관리하는 자재 LOT이다.

공급사 LOT가 없는 경우 내부 기준에 따라 대체 LOT를 생성할 수 있다.

2.4 생산 LOT

작업지시와 생산실적을 통해 생성된 반제품 또는 완제품의 LOT이다.

2.5 포장 LOT

박스, 팔레트, 컨테이너 등 포장단위로 묶인 추적단위이다.

2.6 출하 LOT

고객에게 출하하는 품목과 수량을 추적하기 위해 구성된 출하단위이다.

하나의 출하 LOT에 여러 생산 LOT가 포함될 수 있다.

2.7 LOT 계보

원자재 LOT가 생산과정을 거쳐 반제품·완제품·출하 LOT로 변환되는 부모·자식 관계이다.

2.8 정방향 추적

특정 자재 LOT가 어떤 생산품과 출하에 사용되었는지를 조회하는 것이다.

자재 LOT
→ 작업지시
→ 생산 LOT
→ 출하 LOT
→ 고객

2.9 역방향 추적

특정 완제품·출하 LOT를 생산할 때 어떤 자재 LOT와 생산조건을 사용했는지 조회하는 것이다.

출하 LOT
→ 생산 LOT
→ 생산실적
→ 작업지시
→ 자재 LOT
→ 공급사 LOT

2.10 LOT 분할

하나의 LOT 수량을 둘 이상의 독립적인 LOT 또는 재고단위로 나누는 것이다.

2.11 LOT 병합

둘 이상의 LOT 또는 재고단위를 하나의 관리단위로 합치는 것이다.

원본 LOT 식별정보는 병합 이후에도 유지해야 한다.

5. 기능적 요구사항

FR-LT-001 LOT 관리대상 설정

시스템은 품목별로 LOT 관리 여부와 관리방식을 설정할 수 있어야 한다.

설정항목은 다음을 포함한다.

  • LOT 관리 여부
  • 공급사 LOT 필수 여부
  • 내부 LOT 생성 여부
  • 생산 LOT 생성 여부
  • 개별 일련번호 관리 여부
  • LOT 분할 허용 여부
  • LOT 병합 허용 여부
  • 유효기간 관리 여부
  • 품질판정 필수 여부
  • 출하 LOT 관리 여부

FR-LT-002 내부 자재 LOT 생성

자재 입고 시 내부 자재 LOT를 생성할 수 있어야 한다.

내부 자재 LOT에는 최소한 다음 정보가 포함되어야 한다.

  • 내부 LOT 번호
  • 자재 품목
  • 공급사
  • 공급사 LOT
  • 입하번호
  • 입고번호
  • 입고일자
  • 제조일자
  • 유효기간
  • 입고수량
  • 단위
  • 품질상태
  • 재고상태
  • 최초 보관위치

FR-LT-003 공급사 LOT 연결

내부 자재 LOT는 공급사 LOT와 연결할 수 있어야 한다.

하나의 공급사 LOT를 여러 차례 나누어 입고한 경우 여러 내부 LOT와 연결할 수 있어야 한다.

공급사 LOT S001
├─ 내부 LOT M001: 100kg
├─ 내부 LOT M002: 150kg
└─ 내부 LOT M003: 50kg

FR-LT-004 공급사 LOT 미존재 처리

공급사가 LOT 정보를 제공하지 않는 경우 내부 대체 LOT를 생성할 수 있어야 한다.

대체 LOT 생성기준은 다음 정보를 조합하여 설정할 수 있어야 한다.

  • 공급사
  • 품목
  • 입고일자
  • 입하번호
  • 순번

대체 LOT에는 공급사 LOT 미제공 여부와 생성사유를 기록해야 한다.

FR-LT-005 LOT 번호 자동 생성

LOT 번호는 설정된 규칙에 따라 자동 생성할 수 있어야 한다.

예시:

품목코드-생산일자-순번
MAT001-20260715-001

또는:

공장-공정-생산일자-근무조-순번
VN-INJ-20260715-D-001

LOT 번호 생성규칙은 품목군, 공장, LOT 유형별로 설정할 수 있어야 한다.

FR-LT-006 LOT 번호 중복 방지

동일한 LOT 관리범위에서 LOT 번호가 중복 생성되지 않아야 한다.

바코드 재스캔, 네트워크 재전송 또는 버튼 중복 클릭이 발생해도 동일 LOT가 중복 생성되지 않아야 한다.

FR-LT-007 생산 LOT 생성

생산실적을 기준으로 반제품 또는 완제품 생산 LOT를 생성할 수 있어야 한다.

생산 LOT에는 다음 정보가 포함되어야 한다.

  • 생산 LOT 번호
  • 품목
  • 작업지시

FR-LT-010 여러 생산실적의 동일 LOT 연결

같은 조건에서 연속 생산된 여러 부분 생산실적을 하나의 생산 LOT에 연결할 수 있어야 한다.

생산 LOT의 수량은 연결된 유효 생산실적의 합계와 일치해야 한다.

FR-LT-011 자재 LOT와 생산 LOT 연결

LOT 추적 대상 자재는 자재투입·생산실적을 통해 생산 LOT와 연결되어야 한다.

기본 관계는 다음과 같다.

자재 LOT
→ 자재투입
→ 공정 작업지시
→ 생산실적
→ 생산 LOT

FR-LT-012 복수 자재 LOT 사용관계 관리

하나의 생산 LOT에 동일 품목 또는 서로 다른 품목의 여러 자재 LOT가 사용될 수 있어야 한다.

생산 LOT P001
├─ Resin LOT R001
├─ Insert LOT I005
├─ Gasket LOT G003
└─ Harness LOT H008

각 자재 LOT별 사용수량을 저장해야 한다.

FR-LT-013 하나의 자재 LOT의 복수 생산 LOT 사용

하나의 자재 LOT가 여러 생산 LOT에 나누어 사용될 수 있어야 한다.

Resin LOT R001
├─ 생산 LOT P001: 50kg
├─ 생산 LOT P002: 30kg
└─ 생산 LOT P003: 20kg

사용수량 합계는 해당 자재 LOT의 가용수량을 초과할 수 없어야 한다.

FR-LT-014 자재 LOT 전환구간 관리

작업지시 수행 중 자재 LOT가 변경되면 변경 전후 생산 LOT 또는 생산구간을 구분할 수 있어야 한다.

구분방법은 다음 중 하나 이상을 지원해야 한다.

  • 생산실적 순번
  • 전환시각
  • 생산수량 범위
  • 생산 LOT 분리
  • 작업자 지정 전환점

FR-LT-015 MES 미관리 공정의 LOT 관계 유지

MES 미관리 공정에 별도 작업지시와 생산실적이 없더라도 전체 라우팅 관계가 끊어지지 않아야 한다.

예시:

사출 생산 LOT
→ 사상 공정(MES 미관리)
→ 조립 작업지시

조립 공정 투입 시 사출 생산 LOT를 스캔하거나 선택하여 앞뒤 관리 공정 간 LOT 관계를 연결할 수 있어야 한다.

FR-LT-016 공정 간 LOT 인계

선행 MES 관리 대상 공정에서 생성된 생산 LOT를 후속 공정에 투입할 수 있어야 한다.

후속 공정 투입 시 다음을 검증해야 한다.

  • 품목 적합성
  • 라우팅 순서
  • 선행 공정 완료 여부
  • 품질상태
  • 가용수량
  • 보류·격리 여부
  • 동일 LOT 중복 투입 여부

FR-LT-017 부분수량 공정 인계

하나의 생산 LOT 전체가 아니라 일부 수량만 후속 공정에 인계할 수 있어야 한다.

사출 LOT P001: 5,000개

조립 공정 투입
- 1차: 2,000개
- 2차: 1,500개
- 잔여: 1,500개

LOT별 가용수량과 공정 투입수량을 관리해야 한다.

FR-LT-018 LOT 분할

하나의 LOT를 여러 LOT 또는 재고단위로 분할할 수 있어야 한다.

분할 시 다음 정보를 기록해야 한다.

FR-LT-019 동일 LOT 번호 유지 분할

LOT 번호는 유지하면서 재고단위나 포장단위만 분리할 수 있어야 한다.

예:

생산 LOT P001: 총 1,000개

박스 1: 300개
박스 2: 300개
박스 3: 400개

이 경우 동일 LOT 내의 포장단위 식별자를 별도로 관리해야 한다.

FR-LT-020 신규 LOT 번호를 이용한 분할

품질상태, 고객요구 또는 재작업 등의 사유로 원본 LOT에서 별도 신규 LOT를 생성할 수 있어야 한다.

원본 LOT P001: 1,000개

분할
- P001-A: 합격 800개
- P001-B: 보류 150개
- P001-C: 불합격 50개

각 신규 LOT는 원본 LOT와의 계보관계를 유지해야 한다.

FR-LT-021 LOT 병합

둘 이상의 LOT 또는 포장단위를 하나의 출하·포장단위로 병합할 수 있어야 한다.

병합 시 원본 LOT 번호를 제거하거나 대체해서는 안 되며 병합 구성정보를 보존해야 한다.

포장 LOT PK001
├─ 생산 LOT P001: 300개
├─ 생산 LOT P002: 400개
└─ 생산 LOT P003: 300개

FR-LT-022 품질상태가 다른 LOT 병합 통제

품질상태가 서로 다른 LOT는 기본적으로 병합할 수 없어야 한다.

다음 상태의 LOT를 병합하려는 경우 차단해야 한다.

  • 합격과 보류

  • 일반품과 특채품
  • 재검사대기와 합격품

관리자 승인으로 예외 병합하는 경우 사유와 승인정보를 기록해야 한다.

FR-LT-055 추적 정확도 수준 표시

시스템은 LOT 연결의 추적 정확도를 구분할 수 있어야 한다.

추적 정확도는 다음과 같이 관리할 수 있어야 한다.

  • 정확: 실제 스캔 또는 명확한 수량구간으로 연결
  • 추정: 시간, FIFO 또는 비례배분으로 연결
  • 미확정: 연결 대상은 알지만 수량배분이 확정되지 않음
  • 누락: 필수 연결정보가 존재하지 않음

정방향·역방향 추적 결과에서 추적 정확도를 사용자에게 표시해야 한다.

FR-LT-056 추적정보 완전성 검증

시스템은 LOT 추적관계의 누락과 단절을 자동으로 검증할 수 있어야 한다.

검증항목은 최소한 다음을 포함해야 한다.

  • 공급사 LOT가 필요한데 등록되지 않은 경우
  • LOT 추적 대상 자재가 작업지시에 투입되지 않은 경우
  • 생산실적은 있으나 생산 LOT가 없는 경우
  • 생산 LOT는 있으나 생산실적이 없는 경우
  • 생산 LOT에 필수 자재 LOT가 연결되지 않은 경우
  • 후속 공정 투입 LOT의 선행 생산이력이 없는 경우
  • 출하 LOT에 생산 LOT가 연결되지 않은 경우
  • LOT 분할 전후 수량이 일치하지 않는 경우
  • LOT 관계가 순환구조를 형성하는 경우
  • 현재수량과 이벤트 누적수량이 일치하지 않는 경우

재구축 전후 결과와 변경내역을 기록해야 하며, 원본 이벤트를 임의 수정해서는 안 된다.

6. 비기능 요구사항

NFR-LT-001 추적조회 응답성

일반적인 LOT 조회는 정상적인 사내 네트워크 환경에서 다음 응답시간을 목표로 해야 한다.

  • LOT 바코드 조회: 2초 이내
  • LOT 상세조회: 3초 이내
  • 일반 정방향·역방향 추적: 5초 이내
  • 대규모 영향범위 분석: 10초 이내

대규모 추적조회는 진행상태를 사용자에게 표시해야 한다.

NFR-LT-002 추적관계 완전성

LOT 추적 대상 자재는 다음 관계가 누락되지 않아야 한다.

공급사 LOT
→ 내부 LOT
→ 자재투입
→ 작업지시
→ 생산실적
→ 생산 LOT
→ 출하

필수 추적관계가 누락된 경우 작업완료·마감·출하를 제한할 수 있어야 한다.

NFR-LT-003 수량 정합성

LOT 생성, 분할, 병합, 투입, 이동, 출하 및 폐기 과정에서 수량 정합성이 유지되어야 한다.

동시 처리로 인해 다음 상황이 발생해서는 안 된다.

  • 가용수량 초과 사용
  • 동일 LOT 중복 출하
  • 동일 잔량 중복 투입
  • 분할 후 수량 증가
  • 병합 시 원본 LOT 누락
  • 음수재고 발생

NFR-LT-004 트랜잭션 정합성

LOT 관련 주요 처리는 하나의 논리적 트랜잭션으로 처리해야 한다.

예:

  • LOT 생성과 생산실적 연결
  • LOT 투입과 수량 차감
  • LOT 이동과 로케이션 변경
  • 품질판정과 LOT 상태 변경
  • 출하와 재고 차감
  • 분할과 신규 LOT 생성

일부 처리만 성공하는 상태가 발생해서는 안 된다.

NFR-LT-005 동시성 통제

여러 단말기와 사용자가 동일 LOT를 동시에 투입·이동·출하하려는 경우 수량과 상태를 정확하게 통제해야 한다.

시스템은 다음 중 하나 이상의 방식을 적용해야 한다.

  • 데이터베이스 행 잠금
  • 낙관적 잠금
  • LOT 버전값
  • 요청 식별키
  • 가용수량 재검증

NFR-LT-006 중복처리 방지

바코드 중복 스캔, 버튼 중복 클릭 또는 네트워크 재전송으로 동일 LOT 이벤트가 중복 처리되지 않아야 한다.

LOT 생성·분할·이동·출하 요청은 멱등성을 보장해야 한다.

NFR-LT-007 감사 가능성

LOT의 생성부터 출하까지 모든 주요 변경은 감사 가능한 이력으로 보존해야 한다.

감사이력에는 최소한 다음 정보가 포함되어야 한다.

  • 사용자
  • 실제 작업자
  • 입력 단말기
  • 발생일시
  • 입력일시
  • 변경 전 값
  • 변경 후 값
  • 처리수량
  • 처리사유
  • 승인자

일반 사용자가 감사이력을 수정하거나 삭제할 수 없어야 한다.

NFR-LT-008 데이터 불변성

이미 생산·품질·출하이력에 사용된 LOT 번호와 원본 관계는 임의로 변경하거나 삭제할 수 없어야 한다.

정정이 필요한 경우 기존 이력을 유지한 상태에서 정정이력을 추가해야 한다.

장애 복구 후 다음 미완료 처리를 재실행할 수 있어야 한다.

NFR-LT-018 데이터 보존

LOT 계보, 이동, 품질, 생산 및 출하이력은 고객사의 품질보증기간과 제품수명을 고려하여 장기간 보존해야 한다.

품목, 공정, 공급사, 설비, 금형, 작업자 등이 비활성화되어도 과거 LOT 이력은 유지해야 한다.

NFR-LT-019 보안 및 개인정보 최소화

LOT 추적조회에는 업무상 필요한 작업자 식별정보만 제공해야 한다.

고객·공급사·출하정보는 역할별 접근권한에 따라 제한해야 한다.

NFR-LT-020 유지보수성

화면, API, 배치, ERP 인터페이스에서 동일한 LOT 규칙을 중복 구현해서는 안 된다.

LOT 현재수량과 계보는 원본 이벤트를 기준으로 재계산하거나 정합성 검증할 수 있어야 한다.

  • 작업지시
  • LOT
  • 처리유형
  • 처리수량
  • 실제 발생일시
  • 저장일시

네트워크 복구 후 저장된 이벤트를 서버로 재전송할 수 있어야 한다.

재동기화 시 다음을 검증해야 한다.

  • 중복 이벤트
  • LOT 가용수량
  • LOT 상태변경
  • 다른 단말기의 선행처리
  • 작업지시 마감 여부
  • 라우팅 순서
  • 시간순서 충돌

충돌한 이벤트는 임의 자동반영하지 않고 예외처리 대상으로 분리해야 한다.

NFR-LT-022 이벤트 순서 보장

LOT 이벤트는 실제 발생순서와 MES 수신순서를 구분하여 관리해야 한다.

지연입력 또는 오프라인 입력으로 이벤트가 순서와 다르게 수신되더라도 LOT 계보와 수량을 올바르게 계산할 수 있어야 한다.

불가능한 이벤트 순서는 차단하거나 승인대상으로 처리해야 한다.

예:

출하 이후 생산실적 등록
소진 이후 추가 투입
후속 공정 투입 이후 선행 LOT 생성 취소

NFR-LT-023 계보 순환 방지

LOT 관계는 순환구조를 형성할 수 없어야 한다.

예를 들어 다음 관계가 저장되어서는 안 된다.

LOT A → LOT B → LOT C → LOT A

LOT 연결 생성 시 순환 여부를 검증해야 한다.

NFR-LT-024 추적성 데이터 품질 모니터링

시스템은 LOT 추적성 데이터의 품질을 지속적으로 점검하고 다음 지표를 제공할 수 있어야 한다.

  • 필수 관계 누락 건수
  • 추적 불가능 LOT 수
  • 미확정 배분 건수
  • 수량 불일치 건수
  • 지연입력 건수
  • 외부창고 미확인 건수
  • 미처리 예외 건수
  • 추적 정확도별 LOT 수

중대한 오류는 관리자에게 알림을 제공해야 한다.

NFR-LT-025 모니터링 및 운영 가시성

시스템은 LOT 이벤트 처리 상태를 모니터링할 수 있어야 한다.

모니터링 대상은 다음을 포함해야 한다.

  • LOT 이벤트 처리량
  • 처리실패 건수
  • 오프라인 대기 이벤트
  • ERP·외부창고 연계 실패
  • 추적조회 응답시간
  • 중복 이벤트 차단 건수
  • 정합성 검증 실패
  • 리콜 영향범위 조회시간

NFR-LT-026 백업 및 복구 검증

LOT 계보와 이벤트 데이터는 정기적으로 백업해야 한다.

백업 복구시험을 주기적으로 수행하여 다음 항목을 확인해야 한다.

  • LOT 수량 복원
  • LOT 상태 복원
  • 부모·자식 관계 복원
  • 분할·병합 관계 복원
  • 생산·품질·출하 연결 복원
  • 감사이력 복원

백업은 존재하지만 계보관계가 복구되지 않는 상태를 허용해서는 안 된다.

NFR-LT-027 복구목표 설정

LOT 추적성 데이터에 대해 복구목표를 정의해야 한다.

최소한 다음을 고객사 운영정책으로 확정해야 한다.

  • 복구목표시간 RTO
  • 복구시점목표 RPO
  • 백업주기
  • 백업 보관기간
  • 원격 또는 별도 장비 백업 여부
  • 재해복구 절차

NFR-LT-028 다중 사업부·공장 데이터 분리

LOT 번호와 LOT 데이터는 사업부·공장·법인 간 충돌이 발생하지 않도록 관리해야 한다.

사용자는 권한이 있는 사업부와 공장의 LOT만 조회하거나 처리할 수 있어야 한다.

사업부 간 내부 납품 시에는 송신 사업부 LOT와 수신 사업부 LOT의 연결관계를 유지해야 한다.

NFR-LT-029 시간대 및 현지시간 관리

한국 본사와 베트남 공장 등 서로 다른 시간대에서 LOT 데이터를 조회할 수 있으므로 모든 이벤트는 표준시간과 현지시간 정보를 함께 관리할 수 있어야 한다.

서버에는 표준화된 시각으로 저장하고 화면에는 공장 현지시간을 명확하게 표시해야 한다.

일광절약시간 또는 시간대 변경으로 이벤트 순서가 왜곡되어서는 안 된다.

NFR-LT-030 대량 리콜 조회 성능

대규모 자재 LOT 또는 장기간 생산분에 대한 영향범위 분석에서도 시스템이 중단되어서는 안 된다.

대량조회는 일반 생산 트랜잭션과 자원을 분리하거나 제한하여 생산실적·자재투입 업무의 성능에 영향을 최소화해야 한다.

NFR-LT-031 추적성 결과 재현성

동일한 기준시점과 동일한 조건으로 추적조회할 경우 동일한 결과가 반환되어야 한다.

정정 또는 추가입력으로 결과가 달라진 경우 변경원인을 확인할 수 있어야 한다.

NFR-LT-032 변경관리 및 테스트 가능성

LOT 생성·분할·병합·역처리·추적 알고리즘이 변경되는 경우 기존 주요 시나리오에 대한 회귀시험을 수행할 수 있어야 한다.

최소한 다음 시나리오를 자동 또는 반복 검증할 수 있어야 한다.

  • 한 자재 LOT가 여러 생산 LOT에 사용됨
  • 여러 자재 LOT가 하나의 생산 LOT에 사용됨
  • LOT 분할 후 공정 인계
  • LOT 병합 후 출하
  • 재작업 LOT 생성
  • 품질 보류와 부분 해제
  • 출하 후 리콜 영향범위 조회
  • 오프라인 이벤트 재동기화

NFR-LT-033 데이터 위변조 방지

LOT 생성, 품질판정, 출하 및 정정과 같은 중요 이벤트는 무단 변경을 방지해야 한다.

중요 이벤트의 변경은 승인권한과 감사이력을 요구해야 하며, 데이터베이스 직접 변경도 운영절차상 탐지할 수 있어야 한다.

필요한 경우 이벤트 순서번호, 해시 또는 변경감사 로그를 적용할 수 있어야 한다.

NFR-LT-034 장기보관 데이터 조회

운영 데이터가 장기보관 또는 아카이브 영역으로 이동된 이후에도 품질사고와 고객문의 발생 시 LOT 추적조회가 가능해야 한다.

아카이브 데이터의 조회방법과 최대 복원시간을 정의해야 한다.

7. 핵심 업무 규칙

BR-LT-001

LOT 추적 대상 품목은 LOT 없이 입고·투입·생산·출하할 수 없다.

BR-LT-002

모든 LOT는 반드시 하나의 품목과 LOT 유형을 가져야 한다.

BR-LT-003

생산 LOT는 작업지시 또는 승인된 수동 생성 근거와 연결되어야 한다.

BR-LT-004

자재 LOT와 생산 LOT의 연결은 자재투입과 생산실적을 근거로 생성해야 한다.

BR-LT-005

하나의 생산 LOT에 여러 자재 LOT를 연결할 수 있다.

BR-LT-006

하나의 자재 LOT를 여러 생산 LOT에 사용할 수 있다.

BR-LT-007

LOT 분할·병합 이후에도 원본 LOT 계보를 보존해야 한다.

BR-LT-008

분할된 LOT 수량의 합계는 원본 분할수량과 일치해야 한다.

BR-LT-009

품질상태가 서로 다른 LOT는 원칙적으로 병합할 수 없다.

BR-LT-010

보류·격리·불합격 LOT는 일반 생산투입이나 출하에 사용할 수 없다.

BR-LT-011

후속 공정에 투입된 LOT 수량은 선행 LOT 가용수량을 초과할 수 없다.

BR-LT-012

출하완료 또는 소진된 LOT는 다시 가용수량으로 사용할 수 없다.

BR-LT-013

재작업·재검사·특채 이후에도 원래 불량 및 품질이력을 보존해야 한다.

BR-LT-014

LOT 번호를 변경하더라도 기존 번호와 변경이력을 보존해야 한다.

BR-LT-015

생산·품질·출하이력이 존재하는 LOT는 물리적으로 삭제할 수 없다.

BR-LT-016

LOT 수량 변경은 반드시 입고·투입·생산·이동·출하·폐기·조정 등의 근거 이벤트를 가져야 한다.

BR-LT-017

LOT 생성과 생산실적 연결은 동일한 트랜잭션으로 처리해야 한다.

BR-LT-018

LOT 품질상태 변경과 사용 가능 여부 반영은 동일한 트랜잭션으로 처리해야 한다.

BR-LT-019

실제 LOT 발생일시와 MES 입력일시는 구분하여 보존해야 한다.

BR-LT-020

MES 미관리 공정이 존재하더라도 앞뒤 MES 관리 대상 공정 사이의 LOT 연결관계는 유지해야 한다.
