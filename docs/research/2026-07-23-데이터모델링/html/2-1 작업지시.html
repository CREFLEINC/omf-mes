2. 기능 요구사항 · 2-1 작업지시

작업지시

생산오더·생산계획·작업지시 3계층 구분과 공정별 지시 생성

MES 작업지시 관리 기능 요구사항

1. 적용 전제

본 요구사항은 다음 의사결정을 전제로 한다.

  1. 생산오더, 생산계획, 작업지시는 서로 구분하여 관리한다.
  2. 품목별 전체 실제 공정은 라우팅에 등록한다.
  3. 각 라우팅 공정에 MES 관리 여부를 설정한다.
  4. MES 관리 대상 공정에 대해서만 공정별 작업지시를 생성한다.
  5. 생산계획이 확정되면 해당 라우팅의 MES 관리 대상 공정 작업지시를 전체 일괄 생성한다.
  6. 작업지시 한 건은 하나의 MES 관리 대상 공정을 담당한다.
  7. 공정 수와 단말기 수는 별개로 관리한다.
  8. 단말기 한 대에서 여러 공정의 작업지시를 조회하고 처리할 수 있다.
  9. 기존의 ‘작업조’ 용어는 ‘근무조’로 통일한다.
  10. 작업지시 생성 시 예정 근무조는 미지정할 수 있으며, 작업 시작 시 실제 근무조와 실제 작업자를 등록할 수 있다.

2. 용어 정의

2.1 생산오더

특정 품목을 특정 수량만큼 생산하라는 상위 생산 명령이다.

2.2 생산계획

생산오더를 기준으로 생산일자, 공정, 설비, 수량 등을 배치한 계획이다.

2.3 라우팅

특정 품목을 생산하기 위해 수행해야 하는 전체 공정과 공정 순서를 정의한 기준정보이다.

2.4 라우팅 공정

특정 라우팅에 포함된 개별 공정이다.

라우팅 공정에는 다음 정보가 포함될 수 있다.

  • 공정
  • 공정순서
  • 표준 Cycle Time
  • MES 관리 여부
  • 필수 설비 여부
  • 필수 금형 여부
  • 자재투입 관리 여부
  • 생산실적 관리 여부
  • 품질검사 관리 여부
  • LOT 생성 여부

2.5 MES 관리 대상 공정

전체 라우팅 공정 중 작업지시, 자재투입, 생산실적 또는 품질정보를 MES에서 관리하기로 지정한 공정이다.

2.6 작업지시

확정된 생산계획을 기준으로 특정 품목의 특정 MES 관리 대상 공정을 수행하도록 현장에 발행하는 실행 명령이다.

2.7 근무조

주간조, 야간조 등 실제 작업이 수행되는 근무 시간대이다.

2.8 작업자

작업지시를 실제로 수행하거나 MES에 작업 내용을 입력한 사람이다.

3. 기본 데이터 구조

생산오더
   ↓
생산계획
   ↓
공정별 작업지시
   ↓
자재투입·생산실적·품질실적

예시:

전체 라우팅

10 사출       : MES 관리
20 사상       : MES 미관리
30 조립       : MES 관리
40 융착       : MES 미관리
50 기능검사   : MES 관리
60 포장       : MES 관리

생산계획 확정 시 다음 작업지시를 일괄 생성한다.

사출 작업지시
조립 작업지시
기능검사 작업지시
포장 작업지시

사상과 융착은 전체 라우팅에는 유지하지만 별도의 작업지시는 생성하지 않는다.

4. 기능적 요구사항

FR-WO-001 작업지시 일괄 생성

시스템은 생산계획이 확정되면 적용 라우팅의 모든 MES 관리 대상 공정에 대한 작업지시를 일괄 생성해야 한다.

작업지시는 실제 작업 시작 시점에 순차적으로 생성하지 않고, 생산계획 확정 시 전체 생성하는 것을 원칙으로 한다.

생산계획 확정 시 다음 절차를 수행해야 한다.

  1. 생산계획의 품목 확인
  2. 적용 라우팅 및 라우팅 버전 확인
  3. 전체 라우팅 공정 조회
  4. MES 관리 대상 공정 식별
  5. 관리 대상 공정별 작업지시 생성
  6. 작업지시 간 선후관계 설정
  7. 생성 결과 및 오류 기록

FR-WO-002 작업지시 생성 대상 공정 결정

시스템은 라우팅 공정의 MES 관리 여부에 따라 작업지시 생성 대상을 결정해야 한다.

  • MES 관리 공정: 작업지시 생성
  • MES 미관리 공정: 작업지시 미생성

MES 미관리 공정도 전체 라우팅 조회 화면에서는 공정순서에 따라 표시해야 한다.

FR-WO-003 작업지시 중복 생성 방지

동일한 생산계획과 동일한 라우팅 공정에 대해 작업지시가 중복 생성되지 않아야 한다.

사용자가 생산계획 확정 요청을 반복하거나 통신 지연으로 동일 요청이 재전송되더라도 작업지시는 한 번만 생성해야 한다.

FR-WO-004 작업지시 생성 결과 확인

생산계획 확정 후 사용자는 다음 내용을 확인할 수 있어야 한다.

  • 생성 대상 공정 수
  • 생성된 작업지시 수
  • 생성되지 않은 MES 미관리 공정
  • 생성 실패 작업지시
  • 실패 사유
  • 재처리 가능 여부

일부 작업지시 생성에 실패한 경우 전체 실패 또는 부분 성공 정책을 설정할 수 있어야 한다.

기본적으로는 데이터 정합성을 위해 전체 작업지시 생성이 하나의 트랜잭션으로 처리되는 것을 원칙으로 한다.

FR-WO-005 적용 라우팅 및 버전 저장

각 작업지시는 생성 시 적용된 다음 정보를 저장해야 한다.

  • 라우팅 ID
  • 라우팅 버전
  • 라우팅 공정 ID
  • 공정순서
  • MES 관리 설정
  • 생성 당시 공정별 주요 설정

작업지시 생성 후 라우팅 기준정보가 변경되더라도 기존 작업지시의 적용 라우팅과 공정정보는 자동 변경되지 않아야 한다.

FR-WO-006 작업지시 기본정보 생성

작업지시에는 최소한 다음 정보가 포함되어야 한다.

  • 작업지시번호
  • 생산오더번호
  • 생산계획번호
  • 사업부
  • 공장
  • 품목
  • 라우팅
  • 라우팅 버전
  • 라우팅 공정
  • 공정순서
  • 대상 공정
  • 지시수량
  • 계획 시작일시
  • 계획 종료일시
  • 생산라인
  • 작업구역
  • 예정 설비
  • 예정 금형
  • 예정 근무조
  • 우선순위
  • 이전 MES 관리 대상 공정
  • 다음 MES 관리 대상 공정
  • 작업지시 상태

FR-WO-007 작업지시번호 생성

시스템은 작업지시별로 중복되지 않는 작업지시번호를 자동 생성해야 한다.

작업지시번호를 통해 다음 정보를 조회할 수 있어야 한다.

  • 생산오더
  • 생산계획
  • 품목
  • 공정
  • 지시수량
  • 현재 상태

작업지시번호 자체에 모든 업무정보를 포함할 필요는 없다.

FR-WO-008 공정별 작업지시 관계 설정

시스템은 전체 라우팅 순서를 기준으로 MES 관리 대상 공정 작업지시 간의 선후관계를 자동 설정해야 한다.

예시:

전체 라우팅

사출 → 사상 → 조립 → 융착 → 검사 → 포장

MES 관리 대상이 사출, 조립, 검사, 포장인 경우 다음 관계를 설정한다.

사출 작업지시
→ 조립 작업지시
→ 검사 작업지시
→ 포장 작업지시

사상과 융착은 작업지시는 없지만 전체 라우팅에서는 그대로 유지한다.

FR-WO-009 첫 번째 관리 공정 식별

시스템은 라우팅의 MES 관리 대상 공정 중 첫 번째 공정을 식별해야 한다.

첫 번째 MES 관리 대상 공정은 이전 관리 공정의 실적 없이 작업할 수 있어야 한다.

다만 다음과 같은 시작 조건을 적용할 수 있어야 한다.

  • 필수 자재 준비
  • 작업지시 발행
  • 설비 준비
  • 금형 준비
  • 작업자 인증
  • 초품 승인
  • 생산관리자 승인

FR-WO-010 마지막 관리 공정 식별

시스템은 라우팅의 MES 관리 대상 공정 중 마지막 공정을 식별해야 한다.

마지막 관리 공정 완료 시 다음 후속 처리를 설정할 수 있어야 한다.

  • 완제품 LOT 생성
  • 완제품 라벨 출력
  • 완제품 재고 생성
  • 완제품 창고 입고
  • 생산계획 완료 여부 검토
  • 생산오더 완료 여부 검토

FR-WO-011 작업지시 발행

일괄 생성된 작업지시는 현장 작업자에게 제공하기 전에 발행 처리할 수 있어야 한다.

작업지시 발행 방식은 다음 중 하나를 설정할 수 있어야 한다.

  • 생산계획 확정과 동시에 자동 발행
  • 생산계획 확정 시 작성 상태로 생성 후 생산관리자가 일괄 발행
  • 공정별 또는 작업지시별 선택 발행

발행 전에는 다음 내용을 검증해야 한다.

  • 생산계획 확정 여부
  • 품목과 공정 유효성
  • 지시수량
  • 적용 라우팅
  • 필수 자원 지정 여부
  • 작업지시 중복 여부

FR-WO-012 공정별 지시수량 관리

각 공정 작업지시는 공정별 지시수량을 가져야 한다.

기본적으로 관리 공정별 지시수량은 생산계획 수량을 기준으로 생성한다.

공정별 투입·산출 수량이 다른 경우 라우팅의 수율 또는 단위 환산 기준을 적용할 수 있어야 한다.

예시:

사출 계획수량: 10,000개
조립 필요수량: 9,800개
검사 대상수량: 9,800개

FR-WO-013 동일 공정 작업지시 분할

동일한 공정 작업지시를 생산일자, 설비, 금형, 작업구역 또는 근무조에 따라 여러 작업지시로 분할할 수 있어야 한다.

예시:

사출 작업지시: 10,000개

분할 후
- 사출기 1호기: 4,000개
- 사출기 2호기: 3,000개
- 사출기 3호기: 3,000개

분할된 작업지시의 지시수량 합계는 원본 작업지시의 미작업 잔여수량을 초과할 수 없어야 한다.

FR-WO-014 작업지시 자원 배정

작업지시에 다음 자원을 배정할 수 있어야 한다.

  • 생산라인
  • 작업구역
  • 설비
  • 금형
  • 예정 근무조
  • 책임 작업자

공정별로 필수 배정 자원을 다르게 설정할 수 있어야 한다.

예:

공정필수 자원
사출설비, 금형
수동조립작업구역
기능검사검사설비
포장포장구역

FR-WO-015 예정 근무조 관리

작업지시에는 예정 근무조를 설정할 수 있어야 한다.

예정 근무조의 예시는 다음과 같다.

  • 주간조
  • 야간조
  • 1근
  • 2근
  • 3근

작업지시 일괄 생성 시 예정 근무조가 확정되지 않은 경우 미지정 상태를 허용해야 한다.

예정 근무조는 작업 시작 전까지 변경할 수 있어야 한다.

FR-WO-016 실제 근무조 및 작업자 등록

작업 시작 시 실제 근무조와 작업자를 등록할 수 있어야 한다.

시스템은 다음 정보를 구분하여 저장해야 한다.

  • 예정 근무조
  • 실제 근무조
  • 책임 작업자
  • 실제 작업자
  • MES 입력자

예정 근무조와 실제 근무조가 다른 경우 이를 이력으로 기록해야 한다.

FR-WO-017 작업지시 우선순위 관리

작업지시에 우선순위를 설정할 수 있어야 한다.

우선순위 예시는 다음과 같다.

  • 긴급
  • 높음
  • 보통
  • 낮음

우선순위 변경 시 다음 정보를 이력으로 저장해야 한다.

  • 변경 전 우선순위
  • 변경 후 우선순위
  • 변경자
  • 변경일시
  • 변경 사유

FR-WO-018 작업순서 관리

동일 설비, 생산라인 또는 작업구역에서 수행할 작업지시의 예정 순서를 지정할 수 있어야 한다.

생산관리자는 작업순서를 변경할 수 있어야 하며, 변경 전후 순서와 변경 사유를 기록해야 한다.

FR-WO-019 이전 관리 공정 가용수량 관리

후속 공정 작업지시는 이전 MES 관리 대상 공정에서 완료된 수량 범위 내에서 작업할 수 있어야 한다.

기본 계산식은 다음과 같다.

후속 공정 투입 가능수량
= 이전 관리 공정 완료수량
- 후속 공정 기투입수량

이전 관리 공정 작업지시가 전체 완료되지 않았더라도 부분 완료수량만큼 후속 공정을 시작할 수 있어야 한다.

FR-WO-020 부분 공정 진행 허용

선행 공정에서 일부 수량이 완료되면 후속 공정 작업지시를 부분적으로 시작할 수 있어야 한다.

예시:

사출 지시수량: 10,000개
사출 완료수량: 4,000개

조립 작업지시
→ 최대 4,000개 범위에서 작업 가능

후속 공정 작업지시 자체는 생산계획 확정 시 이미 생성되어 있지만, 실제 작업 가능수량은 선행 공정 완료수량에 따라 통제해야 한다.

FR-WO-021 작업지시 상태 관리

작업지시는 최소한 다음 상태를 지원해야 한다.

작성
→ 발행
→ 작업대기
→ 작업중
→ 작업완료
→ 마감

예외 상태는 다음과 같다.

  • 일시중지
  • 보류
  • 취소
  • 강제종료

상태는 정의된 상태전이 규칙에 따라서만 변경되어야 한다.

FR-WO-022 작업 시작

작업자는 발행된 작업지시를 선택하여 작업을 시작할 수 있어야 한다.

작업 시작 시 다음 조건을 검증해야 한다.

  • 작업지시가 작업 가능한 상태인지
  • 작업자가 해당 공정을 수행할 권한이 있는지
  • 사용 중인 단말기에서 해당 공정을 처리할 수 있는지
  • 필수 설비와 금형이 지정되었는지
  • 선행 공정 가용수량이 존재하는지
  • 필수 자재가 준비되었는지
  • 동일 설비에서 다른 작업이 충돌하지 않는지

작업 시작 시 다음 정보를 기록해야 한다.

  • 실제 시작일시
  • 실제 근무조
  • 실제 작업자
  • 실제 설비
  • 실제 금형
  • 사용 단말기

FR-WO-023 공용 단말기 지원

단말기 한 대에서 여러 공정의 작업지시를 조회하고 처리할 수 있어야 한다.

예시:

단말기 T-01
- 사출 공정
- 조립 공정

단말기 T-02
- 기능검사 공정
- 포장 공정

단말기와 공정은 다대다 관계로 관리해야 한다.

하나의 공정을 여러 단말기에서 처리하는 것도 허용할 수 있어야 한다.

FR-WO-024 단말기별 허용 공정 설정

각 단말기에는 처리 가능한 공정을 설정할 수 있어야 한다.

단말기별로 다음 권한을 설정할 수 있어야 한다.

  • 작업지시 조회
  • 작업 시작
  • 생산실적 입력
  • 자재투입 등록
  • 품질검사 입력
  • 작업완료
  • 라벨 출력

허용되지 않은 공정의 작업지시를 처리하려는 경우 입력을 차단해야 한다.

FR-WO-025 작업지시 바코드 조회

작업자는 공용 단말기에서 작업지시 바코드를 스캔하여 작업지시를 조회할 수 있어야 한다.

처리 흐름은 다음과 같다.

작업자 인증
→ 작업지시 바코드 스캔
→ 작업지시 및 공정 조회
→ 단말기 허용 공정 검증
→ 작업 화면 표시

작업지시 바코드를 통해 공정이 자동으로 결정되어야 하며, 작업자가 공정을 반복해서 직접 선택하지 않도록 해야 한다.

FR-WO-026 작업지시 수동 조회

바코드를 사용할 수 없는 경우 다음 조건으로 작업지시를 조회할 수 있어야 한다.

  • 작업지시번호
  • 생산오더번호
  • 생산계획번호
  • 품목
  • 공정
  • 설비
  • 금형
  • 계획일자
  • 실제 작업일자
  • 근무조
  • 작업상태

공용 단말기에서는 해당 단말기에 허용된 공정의 작업지시만 기본적으로 표시해야 한다.

FR-WO-027 작업 일시중지 및 재개

작업자는 진행 중인 작업지시를 일시중지하고 재개할 수 있어야 한다.

일시중지 시 중지 사유를 필수로 입력해야 한다.

중지 사유 예시는 다음과 같다.

  • 설비 고장
  • 금형 이상
  • 금형 교체
  • 자재 부족
  • 품질 확인
  • 작업자 부재
  • 계획 변경
  • 교대
  • 기타

시스템은 다음 정보를 기록해야 한다.

  • 중지 시작일시
  • 중지 사유
  • 중지 작업자
  • 재개일시
  • 재개 작업자
  • 총 중지시간

FR-WO-028 부분 생산실적 지원

작업지시가 완료되지 않은 상태에서도 생산실적을 여러 차례 등록할 수 있어야 한다.

예시:

작업지시 수량: 5,000개

1차 실적: 1,000개
2차 실적: 1,500개
3차 실적: 1,000개
4차 실적: 1,500개

부분 실적 등록 후에도 작업지시 상태를 작업중으로 유지할 수 있어야 한다.

FR-WO-029 실제 작업시각과 입력시각 관리

공용 단말기를 사용하여 실적이 지연 입력될 수 있으므로 다음 시간을 구분하여 저장해야 한다.

  • 실제 작업 발생일시
  • MES 입력일시

지연입력 허용시간을 초과한 경우 지연입력 사유 또는 관리자 승인을 요구할 수 있어야 한다.

FR-WO-030 작업지시 진행현황 조회

작업지시별로 다음 내용을 조회할 수 있어야 한다.

  • 지시수량
  • 누적 양품수량
  • 누적 불량수량
  • 잔여수량
  • 선행 공정 완료수량
  • 현재 공정 투입수량
  • 후속 공정 인계수량
  • 달성률
  • 실제 시작일시
  • 누적 중지시간
  • 작업상태

기본 달성률은 다음과 같이 계산한다.

달성률 = 누적 양품수량 ÷ 지시수량 × 100

FR-WO-031 작업완료 처리

작업자는 더 이상 해당 작업지시로 생산하지 않는 경우 작업완료 처리할 수 있어야 한다.

작업완료 시 다음 내용을 검증해야 한다.

  • 양품수량
  • 불량수량
  • 미처리 잔여수량
  • 필수 자재투입
  • 자재잔량 처리
  • 필수 품질검사
  • 필요한 생산 LOT
  • 설비 및 금형 사용종료
  • 미해제 일시중지 상태

미완료 항목이 존재하면 작업완료를 차단하거나 경고해야 한다.

FR-WO-032 미달 완료

지시수량을 모두 생산하지 못한 경우 미달 사유를 입력하여 작업완료할 수 있어야 한다.

미달 완료 시 다음 정보를 저장해야 한다.

  • 지시수량
  • 실제 완료수량
  • 미달수량
  • 미달 사유
  • 승인자
  • 승인일시
  • 잔여수량 처리방법

잔여수량은 다음 중 하나로 처리할 수 있어야 한다.

  • 신규 작업지시 생성
  • 기존 작업지시 분할
  • 생산계획 미지시수량으로 복원
  • 다음 근무조로 이관
  • 생산 취소

FR-WO-033 초과 생산 통제

지시수량을 초과하여 생산실적을 등록하려는 경우 시스템은 경고하거나 입력을 차단해야 한다.

품목 또는 공정별로 다음 정책을 설정할 수 있어야 한다.

  • 초과 생산 금지
  • 허용비율 이내 초과 허용
  • 관리자 승인 후 허용
  • 경고 후 허용

초과 생산 시 다음 정보를 기록해야 한다.

  • 초과수량
  • 승인자
  • 승인일시
  • 승인 사유

FR-WO-034 작업지시 변경

작업 시작 전에는 다음 정보를 변경할 수 있어야 한다.

  • 지시수량
  • 계획일시
  • 생산라인
  • 작업구역
  • 예정 설비
  • 예정 금형
  • 예정 근무조
  • 우선순위
  • 작업순서

작업 시작 이후에는 다음 핵심정보를 직접 변경할 수 없어야 한다.

  • 품목
  • 대상 공정
  • 라우팅
  • 라우팅 버전
  • 라우팅 공정

핵심정보 변경이 필요한 경우 기존 작업지시의 잔여수량을 취소하고 신규 작업지시를 생성해야 한다.

FR-WO-035 작업지시 보류

품질 문제, 자재 부족, 생산계획 변경 등의 사유로 작업지시를 보류할 수 있어야 한다.

보류 시 다음 정보를 기록해야 한다.

  • 보류 사유
  • 보류 시작일시
  • 보류 처리자
  • 생산 중단 여부
  • 재개 조건
  • 보류 해제자
  • 보류 해제일시

FR-WO-036 작업지시 취소

작업 시작 전 또는 미작업 잔여수량에 대해 작업지시를 취소할 수 있어야 한다.

생산실적이 존재하는 작업지시는 물리적으로 삭제할 수 없어야 한다.

실적이 존재하는 경우 다음 중 하나로 처리해야 한다.

  • 생산분 인정 후 잔여수량 취소
  • 생산실적 취소 후 전체 취소
  • 생산분 완료 처리 후 잔여수량 신규 지시
  • 생산분 마감 후 잔여수량 계획 반영

FR-WO-037 작업지시 마감

작업완료된 작업지시는 권한이 있는 사용자가 마감할 수 있어야 한다.

마감 조건은 다음과 같다.

  • 생산실적 확정
  • 양품·불량수량 확정
  • 필수 자재투입 등록
  • 자재잔량 처리
  • 필수 품질검사 완료
  • 필요한 LOT 생성
  • 미처리 보류 및 중지 없음

마감된 작업지시는 일반 사용자가 수정하거나 삭제할 수 없어야 한다.

FR-WO-038 작업지시 마감 취소

마감된 작업지시를 수정해야 하는 경우 권한이 있는 사용자만 마감을 취소할 수 있어야 한다.

마감 취소 시 다음 정보를 기록해야 한다.

  • 마감 취소 사유
  • 요청자
  • 승인자
  • 취소일시
  • 수정 대상
  • 수정 완료 후 재마감 여부

FR-WO-039 재작업 작업지시 생성

불량 또는 품질판정 결과에 따라 재작업 작업지시를 별도로 생성할 수 있어야 한다.

재작업 작업지시는 다음 정보와 연결되어야 한다.

  • 원본 생산오더
  • 원본 작업지시
  • 원본 생산 LOT
  • 불량 또는 부적합 정보
  • 재작업 대상공정
  • 재작업 대상수량
  • 재작업 사유

재작업 공정은 기존 라우팅의 관리 공정과 다를 수 있어야 한다.

FR-WO-040 작업지시 통합 진행현황 조회

생산오더 또는 생산계획을 기준으로 모든 MES 관리 대상 공정 작업지시의 진행현황을 조회할 수 있어야 한다.

예시:

공정지시수량양품수량상태
사출10,00010,000완료
조립10,0006,000작업중
기능검사10,0004,000작업중
포장10,0002,000작업중

전체 라우팅 화면에서는 MES 미관리 공정도 순서상 표시해야 한다.

FR-WO-041 작업지시 상세조회

작업지시 상세화면에서는 다음 정보를 조회할 수 있어야 한다.

  • 작업지시 기본정보
  • 생산오더
  • 생산계획
  • 적용 라우팅 및 버전
  • 대상 공정
  • 전체 라우팅
  • MES 관리 공정과 미관리 공정
  • 이전·다음 MES 관리 공정
  • 지시수량과 누적실적
  • 예정·실제 설비
  • 예정·실제 금형
  • 예정·실제 근무조
  • 작업자
  • 자재투입 현황
  • 품질검사 현황
  • 생산 LOT
  • 상태변경 이력
  • 사용 단말기
  • 수정·승인·취소 이력

FR-WO-042 작업지시 이력 관리

시스템은 작업지시와 관련된 다음 이벤트를 시간순으로 기록해야 한다.

  • 작업지시 일괄 생성
  • 개별 작업지시 생성
  • 발행
  • 수정
  • 분할
  • 작업 시작
  • 일시중지
  • 재개
  • 작업완료
  • 미달 완료
  • 초과생산 승인
  • 보류
  • 보류 해제
  • 취소
  • 강제종료
  • 마감
  • 마감 취소
  • 재작업 작업지시 생성

각 이력에는 다음 정보가 포함되어야 한다.

  • 작업지시번호
  • 이벤트 유형
  • 처리자
  • 처리 단말기
  • 실제 발생일시
  • 시스템 입력일시
  • 변경 전 값
  • 변경 후 값
  • 처리 사유

5. 핵심 업무 규칙

BR-WO-001

생산계획이 확정되면 모든 MES 관리 대상 공정 작업지시를 일괄 생성한다.

BR-WO-002

MES 미관리 공정은 작업지시를 생성하지 않지만 전체 라우팅에서는 유지한다.

BR-WO-003

작업지시 하나는 하나의 품목과 하나의 라우팅 공정을 대상으로 한다.

BR-WO-004

동일 생산계획에서 여러 공정 작업지시가 생성될 수 있다.

BR-WO-005

동일 공정의 작업지시를 설비, 생산일자, 근무조 등에 따라 분할할 수 있다.

BR-WO-006

작업지시 생성 이후 적용 라우팅 버전을 임의 변경할 수 없다.

BR-WO-007

후속 공정 작업지시는 사전에 생성하지만, 실제 작업 가능수량은 선행 공정 완료수량에 따라 통제한다.

BR-WO-008

선행 공정이 전체 완료되지 않아도 부분 완료수량만큼 후속 공정을 시작할 수 있다.

BR-WO-009

단말기와 공정은 1:1 관계가 아니다.

BR-WO-010

단말기 한 대에서 여러 공정의 작업지시를 처리할 수 있다.

BR-WO-011

작업지시 생성 시 예정 근무조는 미지정할 수 있다.

BR-WO-012

작업 시작 시 실제 근무조와 실제 작업자를 등록할 수 있다.

BR-WO-013

생산실적이 존재하는 작업지시는 물리적으로 삭제할 수 없다.

BR-WO-014

작업완료와 마감은 서로 다른 상태로 관리한다.

  • 작업완료: 현장 작업이 종료된 상태
  • 마감: 자재·실적·품질·LOT 처리가 모두 확정된 상태

BR-WO-015

실제 작업 발생일시와 MES 입력일시를 구분하여 보존한다.

6. 기본 상태 전이

작성
  ↓
발행
  ↓
작업대기
  ↓
작업중
  ├─ 일시중지 → 작업중
  ├─ 보류 → 작업대기 또는 작업중
  ↓

  ↓
마감

예외 흐름은 다음과 같다.

작성·발행·작업대기 → 취소
작업중 → 강제종료 → 작업완료 또는 취소
마감 → 마감취소 → 작업완료

7. 최종 구조

생산계획 확정
   ↓
전체 라우팅 조회
   ↓
MES 관리 대상 공정 식별
   ↓
대상 공정별 작업지시 전체 일괄 생성
   ↓
공정별 선후관계 설정
   ↓
현장 발행
   ↓
공용 단말기에서 작업지시 선택 또는 스캔
   ↓
작업 시작·실적입력·완료·마감

다음 검토 쟁점은 생산계획 확정과 동시에 작업지시를 자동 발행할지, 일괄 생성 후 생산관리자가 별도로 발행할지입니다.
