## §1. 배경 — 무엇이 충돌했나
**고객 요구(REQ-PR-0001, 명세서:43)**: "자재 LOT 번호 라벨"을 협력사가 미리 납품 자재에 부착해 납품받고 싶다(직접 부착 작업량 과다). **제약**: 모든 협력사가 협조하지 않으므로 **직접 부착 프로세스도 병존**해야 함.

**기존 확정(REQ-PR-0007, 명세서:49)**: "IQC 합격 시점에 LOT 생성"("합격 前 LOT 미생성", 자재LOT=MES 발번). → 협력사가 라벨을 IQC 前에 붙이면 LOT 번호가 이미 물리적으로 존재 → "합격 前 미생성"과 정면 충돌.

**해소**: LOT의 "번호 등록(존재)"과 "재고 가용(Release)"을 분리하고 Lot Status(Hold→Release) 프레임워크에 얹는다.

## §2. 확정 결정 (✓확정 2026-07-20 — 8건)
| # | 항목 | 결정 |
| --- | --- | --- |
| 1 | 개념 | 자재 LOT 번호는 **"발행"이 아니라 "등록"**(번호가 시스템에 기록되는 행위 — 발번 주체는 경로별 상이 #4). |
| 2 | 번호 구성 | **{제품코드}+{수량}+{날짜}+{번호}, 전부 숫자(구분문자 없음 — QR/바코드 겸용).** 단 **수량 = "최초 납품 수량 스냅샷"(라벨 표기용·불변)**, **실제 수량 = 별도 필드**(부분 입고·분할·정정 반영). 라벨 표기 수량 ≠ 시스템 수량 허용(결정 13 포장 라벨 규칙 동형). |
| 3 | 유일성 | 번호에 **공급사 성분 포함** + **등록 시 유일성 검증**(제품코드+날짜+번호만으론 협력사 간 충돌 가능). |
| 4 | 번호 출처(경로별) | **사전부착 = 공급사 번호를 MES가 수용·등록** / **직접부착 = MES 발번 + 등록.** |
| 5 | 등록 시점·상태 | **등록 = 입하 시점, Lot Status = Hold**(검사 대기). **재고 가용(Release) = IQC 합격 시점.** (REQ-PR-0007 개정 — #7) |
| 6 | 입하 P/O 확인 | 번호만으론 어떤 P/O 물품인지 확정 불가 → **입하 등록 시 담당자가 P/O 확인.** |
| 7 | 기존 요구 개정 | **REQ-PR-0007 개정**: "재고 LOT 생성=IQC 합격" → **"LOT 등록=입하(Hold)·Release=IQC 합격."** **REQ-PR-0001 재해석**: "LOT 번호 사전 발행" → **"공급사 번호 수용·등록"**(사전부착 경로). |
| 8 | IQC 생략 = 긴급 승인 | **정책적 생략 아님 — 긴급 처리 시 일시 조치.** 입하 등록 후 **작업자 IQC 생략 요청 → 권한자 승인 → Lot Status = 한도승인**("관리자 승인 한도 양품"). 승인 행위자·일시는 **LotStatus변경이력**에 기록(감사 — 결정 10 정합). |

**IQC "LOT 부착 여부" 분기 소멸**: #1~#5로 입하 시점엔 사전/직접 무관하게 모든 자재가 **LOT 등록(Hold)**이 되므로, IQC 시점에 "부착 여부"로 처리를 분기할 필요가 없다.

## §3. 자재LOT 엔티티 재정의 (개념모델 반영 지침)
- **자재LOT No**: {제품코드}+{수량 스냅샷}+{날짜}+{공급사 성분}+{번호} — 전부 숫자, 등록 시 유일성 검증.
- **생성(등록) 시점**: **입하 — Lot Status Hold** (기존 "IQC 합격 생성" 폐기).
- **발번 주체**: 사전부착=공급사(MES 수용·등록) / 직접부착=MES (기존 "자재LOT=MES 발번" → 경로 이원화).
- **수량**: 라벨 표기 수량(스냅샷·불변) + 실제 수량(가변·별도 필드).
- **P/O 참조**: 입하 등록 시 담당자 확정.
- **Lot Status 전이**: 입하 Hold → (IQC 합격) Release / (IQC 불량) Hold 유지→반품(01-S-I 공급사 반품·폐기) / (긴급 IQC 생략 승인) 한도승인.
- **재고 반영**(✓확정 2026-07-20 보강): 재고 편입 = **입하 등록 시(Lot Status Hold)** — 재고 행은 즉시 생기되 상태 Hold라 **가용 아님**. **가용 = Release(IQC 합격)**. 결정 08·10 정합(재고는 품질 상태 비보유·Lot Status 단일 참조·가용=Release분).
- **불합격 표기 통일**(✓확정 2026-07-20): 신모델에선 IQC 불합격분도 이미 등록된 LOT이므로 **"불합격=LOT 미생성"이 아니라 "불합격=Hold 유지·반품(재고 미가용)"**. 전 정본에서 "불합격=LOT 미생성" 표기를 일괄 대체한다.
